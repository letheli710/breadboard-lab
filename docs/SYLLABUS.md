# 理论练习区大纲 / Theory practice syllabus

每章列出必须覆盖的知识点。出题时每个知识点至少 1 题，整章难度从 1 到 5 递进。文件放在 `problems/<chapter>/NN-short-name.json`，`id` 用 `<chapter>-NN-short-name`。

Each chapter lists the knowledge points that must be covered — at least one problem per point, with difficulty rising from 1 to 5 across the chapter. Files go in `problems/<chapter>/NN-short-name.json`, id `<chapter>-NN-short-name`.

---

## 第 1 期 / Phase 1

### `basics` 电路模型与基本定律（目标 16 题）
1. 电压、电流的参考方向；关联/非关联参考方向（passive sign convention）
2. 功率的计算：吸收功率与发出功率的正负判断；功率守恒（Tellegen 的直观形式）
3. 电阻元件与欧姆定律（含负号情形）
4. 独立电压源、独立电流源的特性（电压源电流由外电路决定，电流源电压由外电路决定）
5. 受控源四种类型（VCVS、VCCS、CCVS、CCCS）及其识别
6. KCL：结点、广义结点（割集）
7. KVL：回路、开口回路求两点间电压
8. 综合：含受控源的简单电路求功率、验证功率平衡
9. 电位（以参考点为零）与电压的关系；改变参考点

### `equivalence` 电阻电路的等效变换（目标 16 题）
1. 串联、并联、分压公式、分流公式
2. 混联电路的等效电阻（含需要“重画”的电路）
3. 平衡电桥（中间电阻可去掉）
4. Y–Δ 变换（含对称情形 R_Y = R_Δ/3）
5. 电压源串联、电流源并联；与电流源串联的元件、与电压源并联的元件的处理
6. 实际电源两种模型的等效变换（电压源–电阻串联 ↔ 电流源–电阻并联）
7. 用电源等效变换逐步化简求电流
8. 输入电阻：含受控源的单口网络（加压求流法），可能为负电阻
9. 无限梯形网络或对称性化简（选做，难度 5）

## 第 2 期 / Phase 2

### `methods` 电阻电路的一般分析（目标 16 题）
1. 支路电流法（b 个方程的列写）
2. 网孔电流法；含电流源支路（超网孔或设电压变量）
3. 回路电流法（选独立回路）
4. 结点电压法；含电压源支路（超结点）；只有一个电压源接参考点的情形
5. 含受控源时的网孔法/结点法（补充控制量方程）
6. 弥尔曼定理（两结点电路）
7. 方法选择：同一电路用结点法和网孔法各做一遍，结果一致

### `theorems` 电路定理（目标 18 题）
1. 叠加定理（含受控源时受控源保留；功率不能叠加）
2. 齐性定理（线性比例）
3. 替代定理
4. 戴维宁定理：求开路电压、等效电阻（独立源置零；含受控源用外加电源法或开路电压/短路电流）
5. 诺顿定理；戴维宁与诺顿互换
6. 最大功率传输（R_L = R_eq，P_max = U_oc²/(4R_eq)）
7. 特勒根定理、互易定理（选做，难度 4–5）
8. 综合：用多个定理求同一个量

### `opamp` 含运算放大器的电阻电路（目标 14 题）
1. 理想运放：“虚短”“虚断”
2. 反相比例放大器、同相比例放大器、电压跟随器
3. 反相加法器、减法器（差分放大）
4. 多级运放电路
5. 运放电路求输入电阻、输出电压、负载电流（电压控制电流源）
6. 用结点电压法分析运放电路

## 第 3 期 / Phase 3

### `storage` 电容与电感（目标 12 题）
1. 电容 i = C du/dt、电感 u = L di/dt（给定波形求另一个量：用 tran 中的数值或选择题）
2. 储能 w = ½Cu²、½Li²（直流稳态下求储能）
3. 电容、电感的串并联等效
4. 直流稳态下电容开路、电感短路
5. 换路定则：u_C(0+) = u_C(0−)，i_L(0+) = i_L(0−)

### `first-order` 一阶电路（目标 18 题）
1. 初始值的计算（0+ 时刻其他支路电流、电压，可能跳变）
2. 零输入响应（RC 放电、RL 磁场释放）
3. 零状态响应（RC 充电、RL 电流建立）
4. 全响应 = 零输入 + 零状态 = 稳态 + 暂态
5. 三要素法：f(0+)、f(∞)、τ
6. 时间常数：含受控源时 R_eq 的求法
7. 开关动作（打开/闭合、换向），含电流源激励
8. 阶跃响应（step 源）
9. 正弦激励下的一阶电路（难度 5，选做）

### `second-order` 二阶电路（目标 12 题）
1. RLC 串联零输入响应：过阻尼、临界阻尼、欠阻尼的判定（R 与 2√(L/C) 比较）
2. 特征根、衰减系数 α、阻尼振荡角频率 ω_d
3. 求某一时刻的 u_C、i_L
4. 零状态响应（阶跃激励）
5. GCL 并联电路
6. 0+ 时刻 du_C/dt、di_L/dt 的求法（用选择或数值题）

## 第 4 期 / Phase 4

### `phasors` 相量法（目标 12 题）
1. 正弦量三要素：幅值、角频率、初相；有效值
2. 相位差（超前/滞后）
3. 正弦量 ↔ 相量（有效值相量为默认约定）
4. 相量形式的 KCL、KVL
5. R、L、C 元件的相量关系与相量图

### `ac-analysis` 正弦稳态电路分析（目标 18 题）
1. 阻抗、导纳；串并联
2. RLC 串联/并联电路的电压电流关系，感性/容性判定
3. 相量图辅助求解（例如三表法）
4. 用结点法、网孔法、叠加、戴维宁定理分析正弦稳态电路
5. 含受控源、含运放的正弦稳态电路

### `ac-power` 正弦稳态功率（目标 14 题）
1. 瞬时功率、平均功率（有功功率 P）、无功功率 Q、视在功率 S、功率因数
2. 复功率 S̄ = U İ*；复功率守恒
3. 功率因数提高（并联电容求 C）
4. 最大功率传输：共轭匹配（Z_L = Z_eq*），模匹配
5. 功率表读数（用 p 量计算）

### `coupled` 耦合电感与理想变压器（目标 12 题）
1. 互感 M、耦合系数 k；同名端
2. 互感电压的方向；顺接、反接串联的等效电感
3. 同侧、异侧并联；去耦等效（T 形去耦）
4. 含耦合电感的正弦稳态分析
5. 空心变压器：反映阻抗
6. 理想变压器：电压、电流、阻抗变换（n² 关系）；含理想变压器的最大功率

### `frequency` 频率响应与谐振（目标 14 题）
1. 网络函数 H(jω)；幅频、相频特性
2. RC/RL 低通、高通：截止频率、−3 dB
3. RLC 串联谐振：f0、品质因数 Q、谐振时电压
4. RLC 并联谐振
5. 带通滤波器：通频带
6. 用运放构成的有源滤波器（一阶）

### `three-phase` 三相电路（目标 12 题）
1. 对称三相电源：相电压、线电压（√3 关系、相位差 30°）
2. Y–Y 对称三相电路：归结为一相计算
3. Y–Δ、Δ–Δ 连接：相电流与线电流
4. 三相功率：P = √3 U_l I_l cos φ；二瓦计法
5. 不对称三相电路：中线的作用，中性点位移（难度 4–5）

### `non-sinusoidal` 非正弦周期电流电路（目标 15 题）
引擎：`"analysis": {"type": "periodic", "omega": …}`，电源写成直流 + 各次谐波（`harmonics`）或标准波形的傅里叶级数（`wave`），逐次谐波求解后叠加（PROBLEM_FORMAT §4.1、§5.1）。
1. 傅里叶级数与振幅频谱；标准波形（方波、三角波、锯齿波、整流波）的系数
2. 波形对称性：奇函数、偶函数、半波对称与谐波成分
3. 有效值、平均值、绝对平均值；不同类型仪表的读数
4. 平均功率 = 各次谐波功率之和；视在功率与功率因数 λ = P/(UI)；不同频率电源的功率叠加
5. 谐波分析法：RL、RC、RLC 电路的直流 + 各次谐波分别求解（每次谐波重算电抗）
6. 谐波谐振与滤波：串联谐振放大某次谐波，并联 LC 陷波，滤波器设计（难度 3–4），整流滤波的纹波
7. 三相电路中的高次谐波：零序 3 次谐波，中线电流 3I_3，无中线时的中性点电压，三角形绕组环流（难度 4–5）

### `two-port` 二端口网络（目标 12 题）
1. Z 参数、Y 参数
2. H 参数（混合参数）、T（ABCD）参数
3. 互易二端口、对称二端口的参数特点
4. 参数之间的换算
5. 二端口的等效电路（T 形、Π 形）
6. 二端口的级联（ABCD 相乘）与端接负载时的输入阻抗

About 241 problems in total. Each problem has 1–4 questions, easy to hard, with hints and a full worked solution.
