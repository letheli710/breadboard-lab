# 理论练习区大纲 / Theory practice syllabus

每章列出必须覆盖的知识点。出题时每个知识点至少 1 题，整章难度从 1 到 5 递进。文件放在 `problems/<chapter>/NN-short-name.json`，`id` 用 `<chapter>-NN-short-name`。

Each chapter lists the knowledge points that must be covered — at least one problem per point, with difficulty rising from 1 to 5 across the chapter. Files go in `problems/<chapter>/NN-short-name.json`, id `<chapter>-NN-short-name`.

---

## 第 1 期 / Phase 1

### `basics` 电路模型与基本定律（目标 16 题）
1. 电压、电流的参考方向；关联/非关联参考方向（passive sign convention）
2. 功率的计算：吸收功率与发出功率的正负判断；功率守恒（Tellegen 的直观形式）
3. 电阻元件与欧姆定律（含负号情形）
4. 独立电压源、独立电流源的特性（电压源电流由外电路决定，电流源电压由外电路决定）
5. 受控源四种类型（VCVS、VCCS、CCVS、CCCS）及其识别
6. KCL：结点、广义结点（割集）
7. KVL：回路、开口回路求两点间电压
8. 综合：含受控源的简单电路求功率、验证功率平衡
9. 电位（以参考点为零）与电压的关系；改变参考点

### `equivalence` 电阻电路的等效变换（目标 16 题）
1. 串联、并联、分压公式、分流公式
2. 混联电路的等效电阻（含需要“重画”的电路）
3. 平衡电桥（中间电阻可去掉）
4. Y–Δ 变换（含对称情形 R_Y = R_Δ/3）
5. 电压源串联、电流源并联；与电流源串联的元件、与电压源并联的元件的处理
6. 实际电源两种模型的等效变换（电压源–电阻串联 ↔ 电流源–电阻并联）
7. 用电源等效变换逐步化简求电流
8. 输入电阻：含受控源的单口网络（加压求流法），可能为负电阻
9. 无限梯形网络或对称性化简（选做，难度 5）

## 第 2 期 / Phase 2

### `methods` 电阻电路的一般分析（目标 16 题）
1. 支路电流法（b 个方程的列写）
2. 网孔电流法；含电流源支路（超网孔或设电压变量）
3. 回路电流法（选独立回路）
4. 结点电压法；含电压源支路（超结点）；只有一个电压源接参考点的情形
5. 含受控源时的网孔法/结点法（补充控制量方程）
6. 弥尔曼定理（两结点电路）
7. 方法选择：同一电路用结点法和网孔法各做一遍，结果一致

### `theorems` 电路定理（目标 18 题）
1. 叠加定理（含受控源时受控源保留；功率不能叠加）
2. 齐性定理（线性比例）
3. 替代定理
4. 戴维宁定理：求开路电压、等效电阻（独立源置零；含受控源用外加电源法或开路电压/短路电流）
5. 诺顿定理；戴维宁与诺顿互换
6. 最大功率传输（R_L = R_eq，P_max = V_oc²/(4R_eq)）
7. 特勒根定理、互易定理（选做，难度 4–5）
8. 综合：用多个定理求同一个量

### `opamp` 含运算放大器的电阻电路（目标 14 题）
1. 理想 op-amp：“虚短”“虚断”
2. 反相比例放大器、同相比例放大器、电压跟随器
3. 反相加法器、减法器（差分放大）
4. 多级 op-amp 电路
5. op-amp 电路求输入电阻、输出电压、负载电流（电压控制电流源）
6. 用结点电压法分析 op-amp 电路

## 第 3 期 / Phase 3

### `storage` 电容与电感（目标 12 题）
1. 电容 i = C dv/dt、电感 v = L di/dt（给定波形求另一个量：用 tran 中的数值或选择题）
2. 储能 w = ½Cv²、½Li²（直流稳态下求储能）
3. 电容、电感的串并联等效
4. 直流稳态下电容开路、电感短路
5. 换路定则：v_C(0+) = v_C(0−)，i_L(0+) = i_L(0−)

### `first-order` 一阶电路（目标 18 题）
1. 初始值的计算（0+ 时刻其他支路电流、电压，可能跳变）
2. 零输入响应（RC 放电、RL 磁场释放）
3. 零状态响应（RC 充电、RL 电流建立）
4. 全响应 = 零输入 + 零状态 = 稳态 + 暂态
5. 三要素法：f(0+)、f(∞)、τ
6. 时间常数：含受控源时 R_eq 的求法
7. 开关动作（打开/闭合、换向），含电流源激励
8. 阶跃响应（step 源）
9. 正弦激励下的一阶电路（难度 5，选做）

### `second-order` 二阶电路（目标 12 题）
1. RLC 串联零输入响应：过阻尼、临界阻尼、欠阻尼的判定（R 与 2√(L/C) 比较）
2. 特征根、衰减系数 α、阻尼振荡角频率 ω_d
3. 求某一时刻的 v_C、i_L
4. 零状态响应（阶跃激励）
5. GCL 并联电路
6. 0+ 时刻 dv_C/dt、di_L/dt 的求法（用选择或数值题）

## 第 4 期 / Phase 4

### `phasors` 相量法（目标 12 题）
1. 正弦量三要素：幅值、角频率、初相；有效值
2. 相位差（超前/滞后）
3. 正弦量 ↔ 相量（有效值相量为默认约定）
4. 相量形式的 KCL、KVL
5. R、L、C 元件的相量关系与相量图

### `ac-analysis` 正弦稳态电路分析（目标 18 题）
1. 阻抗、导纳；串并联
2. RLC 串联/并联电路的电压电流关系，感性/容性判定
3. 相量图辅助求解（例如三表法）
4. 用结点法、网孔法、叠加、戴维宁定理分析正弦稳态电路
5. 含受控源、含 op-amp 的正弦稳态电路

### `ac-power` 正弦稳态功率（目标 14 题）
1. 瞬时功率、平均功率（有功功率 P）、无功功率 Q、视在功率 S、功率因数
2. 复功率 S̄ = V İ*；复功率守恒
3. 功率因数提高（并联电容求 C）
4. 最大功率传输：共轭匹配（Z_L = Z_eq*），模匹配
5. 功率表读数（用 p 量计算）

### `coupled` 耦合电感与理想变压器（目标 12 题）
1. 互感 M、耦合系数 k；同名端
2. 互感电压的方向；顺接、反接串联的等效电感
3. 同侧、异侧并联；去耦等效（T 形去耦）
4. 含耦合电感的正弦稳态分析
5. 空心变压器：反映阻抗
6. 理想变压器：电压、电流、阻抗变换（n² 关系）；含理想变压器的最大功率

### `frequency` 频率响应与谐振（目标 14 题）
1. 网络函数 H(jω)；幅频、相频特性
2. RC/RL 低通、高通：截止频率、−3 dB
3. RLC 串联谐振：f0、品质因数 Q、谐振时电压
4. RLC 并联谐振
5. 带通滤波器：通频带
6. 用 op-amp 构成的有源滤波器（一阶）

### `three-phase` 三相电路（目标 12 题）
1. 对称三相电源：相电压、线电压（√3 关系、相位差 30°）
2. Y–Y 对称三相电路：归结为一相计算
3. Y–Δ、Δ–Δ 连接：相电流与线电流
4. 三相功率：P = √3 V_l I_l cos φ；二瓦计法
5. 不对称三相电路：中线的作用，中性点位移（难度 4–5）

### `non-sinusoidal` 非正弦周期电流电路（目标 15 题）
引擎：`"analysis": {"type": "periodic", "omega": …}`，电源写成直流 + 各次谐波（`harmonics`）或标准波形的傅里叶级数（`wave`），逐次谐波求解后叠加（PROBLEM_FORMAT §4.1、§5.1）。
1. 傅里叶级数与振幅频谱；标准波形（方波、三角波、锯齿波、整流波）的系数
2. 波形对称性：奇函数、偶函数、半波对称与谐波成分
3. 有效值、平均值、绝对平均值；不同类型仪表的读数
4. 平均功率 = 各次谐波功率之和；视在功率与功率因数 λ = P/(UI)；不同频率电源的功率叠加
5. 谐波分析法：RL、RC、RLC 电路的直流 + 各次谐波分别求解（每次谐波重算电抗）
6. 谐波谐振与滤波：串联谐振放大某次谐波，并联 LC 陷波，滤波器设计（难度 3–4），整流滤波的纹波
7. 三相电路中的高次谐波：零序 3 次谐波，中线电流 3I_3，无中线时的中性点电压，三角形绕组环流（难度 4–5）

### `s-domain` 线性动态电路的复频域分析（目标 17 题，教材第 14 章，含第 7 章的冲激响应与卷积）
引擎：暂态题（`tran`）照常求时域值；网络函数 `H`、极点 `pole`、零点 `zero`、系数 `hcoef`（分母首项系数为 1）、响应象函数的部分分式系数 `residue`；电源可以是冲激 `{"impulse": {"area": …}}` 和指数 `{"exp": {"amp", "alpha"}}`（PROBLEM_FORMAT §4、§6.1.8）。复数结果（极点、复极点处的系数）分成实部/虚部或模/角度两个小题问。
1. 拉普拉斯变换的定义（下限 0₋）与常用象函数：δ、ε、指数、t·e^{−at}、正弦、衰减正弦
2. 性质：线性、微分 sF(s) − f(0₋)、积分、时移、复频移；初值定理与终值定理（及其适用条件）
3. 部分分式展开：不同实数极点、重极点（K_11、K_12）、共轭复数极点（2|K|e^{−αt}cos(ωt + θ)）
4. 元件的运算模型：R、L、C 的串联电压源形式与并联电流源形式（附加电源的大小和方向）；耦合电感的互感附加电源
5. 运算法：一阶、二阶换路电路（零输入、零状态、全响应），用结点法/网孔法/叠加列运算方程
6. 网络函数 H(s)：驱动点函数与转移函数，零点与极点；含 op-amp、受控源的电路
7. 冲激响应 h(t) = ℒ⁻¹[H(s)]，阶跃响应，h = ds/dt；冲激引起的 i_L、v_C 跳变
8. 极点位置与时域响应（单调、衰减振荡、等幅、发散）、稳定性；H(jω) 与零极点（谐振峰、通带）
9. 卷积积分与时域卷积定理（简单情形）

### `matrix-form` 电路方程的矩阵形式（目标 15 题，教材第 15 章，含第 3 章“电路的图”）
引擎：`schematic.graph` 给出有向图（结点、带编号和方向的标准支路、参考结点、树、可画的割集），`schematic.state` 给出状态向量与输入向量；求关联矩阵 A、基本回路矩阵 B_f、基本割集矩阵 Q_f、支路矩阵 Y/Z、电源向量 V_s/I_s、结点/回路/割集方程的系数矩阵和右端、它们的解，以及状态方程 ẋ = Ax + Bu 的元素（PROBLEM_FORMAT §6.1.9）。矩阵用 `\mat{…}` 排版，学生逐个元素作答（每个元素一个小题），或在候选矩阵/支路集合中选择。
（章节顺序按网上可查到的第 5 版目录核对：15-1 割集；15-2 关联矩阵、回路矩阵、割集矩阵；15-3 矩阵 A、B_f、Q_f 之间的关系；回路电流方程、结点电压方程、割集电压方程的矩阵形式；列表法；状态方程。列表法不单独出题。）
1. 电路的图：标准支路（复合支路）、有向图、树与连支、独立 KCL/KVL 方程数
2. 割集：定义（恰好分成两部分且最少）、闭合面画法、割集 KCL、基本割集
3. 关联矩阵 A 的写法；KCL A·I = 0、KVL V = Aᵀ·V_n
4. 基本回路矩阵 B_f（方向同连支）、基本割集矩阵 Q_f（方向同树支）；B_f·V = 0、Q_f·I = 0
5. A、B_f、Q_f 的关系：A·B_fᵀ = 0、Q_f·B_fᵀ = 0、Q_l = −B_tᵀ（换一棵树再写一次）
6. 标准支路方程与支路导纳/阻抗矩阵、电源向量的符号约定
7. 结点电压方程 A·Y·Aᵀ·V_n = A·I_s − A·Y·V_s；回路电流方程 B·Z·Bᵀ·I_l = B·V_s − B·Z·I_s；割集电压方程 Q·Y·Qᵀ·V_t = Q·I_s − Q·Y·V_s
8. 含互感（Z 中的 ±jωM）、含受控源（Y 中的非对角元，VCCS、CCCS；相量形式）的结点方程（难度 4–5）
9. 状态方程：状态变量、常态树、用基本割集/基本回路列方程，A 的特征值 = 固有频率（难度 4–5）

### `two-port` 二端口网络（目标 12 题）
1. Z 参数、Y 参数
2. H 参数（混合参数）、T（ABCD）参数
3. 互易二端口、对称二端口的参数特点
4. 参数之间的换算
5. 二端口的等效电路（T 形、Π 形）
6. 二端口的级联（ABCD 相乘）与端接负载时的输入阻抗

### `nonlinear` 非线性电阻电路（目标 14 题，教材第 17 章前半）
引擎：元件 `NR`，特性 `law` 为多项式（压控 `i` / 流控 `v`）、分段线性 `pwl` 或理想二极管 `diode`；直流题求全部工作点，交流题是小信号分析（PROBLEM_FORMAT §6.1.7）；`schematic.plot` 画特性和负载线。
1. 非线性电阻的分类：压控型、流控型、单调型、双向/单向；静态电阻与动态电阻（含负动态电阻）
2. 非线性电阻的串联（电流相同、电压相加）与并联（电压相同、电流相加）：等效特性的图解与解析
3. 曲线相交法：线性部分化为戴维宁/诺顿电路（含受控源），负载线与特性相交；替代定理回到原电路
4. 解析法：平方律等特性得到的一元二次方程，按特性的适用范围舍去不合理的根
5. 分段线性化法：每段 = 电压源 + 电阻，假设所在段再检验；理想二极管与“开启电压 + 导通电阻”模型的假设状态法
6. 多个工作点：N 形（隧道二极管）、S 形特性；工作点个数随 V_s 变化；负阻区工作点的稳定性（难度 4）
7. 小信号分析法：直流工作点 → 动态电阻 → 小信号等效电路 → 总响应；电压源/电流源激励，稳压管纹波，两个非线性元件（难度 3–5）

### `transmission-line` 均匀传输线（目标 14 题，教材第 18 章）
引擎：二端口元件 `TL`（原参数 `R0`/`L0`/`G0`/`C0` + `length`，或无损耗线 `zc` + `vp` + `length`）；正弦稳态用精确的链参数模型，可与任何元件共存；暂态用无损耗线的波过程；量 `{"kind": "tl", "what": …}`（PROBLEM_FORMAT §6.1.10）。章节内容按教材核对：分布参数电路，均匀传输线及其方程，正弦稳态解，原参数与副参数，行波与反射（无限长线/匹配），无损耗线（含开路、短路、驻波），无损耗线的波过程。
1. 分布参数电路：l/λ 判据，波长、传播时间（50 Hz 长线、电缆、印制板走线）
2. 原参数 R_0、L_0、G_0、C_0 → 副参数 Z_c、γ = α + jβ，波长与相速（输电线的复数计算；无损耗电缆）
3. 正弦稳态解：从终端写起的双曲函数形式，已知终端电压电流求始端，功率与效率；传输线作为互易二端口（A = D = ch γl）
4. 行波：入射波与反射波，反射系数 Γ_2 与 Γ(x′) = Γ_2e^{−2γx′}，匹配（Z_2 = Z_c）
5. 无损耗线：输入阻抗公式，开路线与短路线（Z_oc、Z_sc，由测量求 Z_c），λ/4 与 λ/2 线，空载长线末端电压升高
6. 驻波：V_max、V_min、驻波比，波腹与波节的位置，电流驻波，负载功率
7. 无畸变线：R_0/L_0 = G_0/C_0，α、v 与频率无关（加感电话线）
8. 匹配：λ/4 阻抗变换器（及其频带）、单支节短路线匹配（难度 4）
9. 无损耗线的波过程：第一个波 V_sZ_c/(R_s + Z_c)，两端的反射系数，反射网格图，终值（难度 3–4）

合计目标约 301 题。题目风格：每题 1–4 小问，先易后难；每题都要有提示（hints）和完整解题步骤（solution）。

About 301 problems in total. Each problem has 1–4 questions, easy to hard, with hints and a full worked solution.
