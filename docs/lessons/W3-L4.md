## 第 1 幕：痛点引入与拓扑登场——当信号源怕“被抽血”时，反相放大器为什么会翻车？

同学们，欢迎回到 Breadboard Lab 的实验台。

上一讲（`W3-L3`）我们亲手搭出了运放家族的第一号明星——**反相放大器**，它的闭环增益 $A_v = -R_f / R_1$ 干净利落，既能放大又能衰减。但今天我要先给你泼一盆冷水：在真实的硬件系统里，如果你手里握着一只**高内阻传感器**（比如压电麦克风、pH 电极、高阻热敏电桥，戴维南内阻 $R_{Th}$ 动辄 $10\text{ k}\Omega$ 甚至几兆欧），直接往反相放大器里一插，信号往往瞬间“腰斩”！

为什么？回想一下 `W3-L3` 的“虚地”结论：反相放大器的反相端 $v_- = 0\text{ V}$，输入信号 $v_i$ 必须隔着电阻 $R_1$ 直接对地灌电流，所以反相放大器的输入电阻就是 $R_{in} = R_1$。只要你的传感器内阻 $R_{Th}$ 跟 $R_1$ 差不多大，传感器就会在自己的内阻上产生剧烈分压——用工程黑话讲，反相放大器太爱从前级“抽血”了。更麻烦的是，很多单电源传感器（例如 $0 \sim 3\text{ V}$ 的温度计）我们根本不想把它倒扣成负电压。

那怎么破局？把输入信号换个门进！

与其把 $v_i$ 塞进需要靠电阻拉扯的反相端，不如直接把 $v_i$ 送到运放的**同相输入端（$+$ 端）**！因为理想运放的同相端满足**虚断（$i_+ = 0$）**，信号源连着一堵近乎无穷大的绝缘墙，**一滴电流都不会被抽走**。与此同时，我们依然保留反相端的负反馈网络（$R_f$ 跨接输出与反相端，$R_1$ 将反相端接地），让运放乖乖工作在线性区。这就是今天的主角——**同相放大器（Noninverting Amplifier）**。

## 第 2 幕：三段式板书推导与分压反馈解剖——为什么增益永远 $\ge 1$？

同学们，推导出同相放大器的公式其实有两种绝妙的视角：一种是稳扎稳打的**反相端 KCL 节点法**，另一种是一眼看穿本质的**分压器视角（联动 `W1-L7 分压定律`）**。

请先盯着图 2-1 看三秒钟：因为 $i_- = 0$（虚断），反馈电阻 $R_f$ 和接地电阻 $R_1$ 根本没有被运放分流，它们俩就是一条**纯粹的串联电阻链**！顶端接在输出端 $v_o$，底端接在 $0\text{ V}$ 地线，中间抽头就是反相端 $v_-$。运放内部的高增益差分级像一个极其执着的“伺服管家”，拼命调节输出 $v_o$，直到这个分压器抽头上的电压 $v_-$ 恰好等于你喂给同相端的 $v_i$！

### 教授板书：同相放大器三段式严谨推导

下面我们严格按 Breadboard Lab 的**三段式板书规范**，先用公理和纯符号推到底，再代入一组将在面包板上实测的参数（$R_1 = 10\text{ k}\Omega$，$R_f = 20\text{ k}\Omega$，$v_i = 1.5\text{ V}$）验证结果。

#### ① 公理溯源
1. **理想运放虚断公理**（`W3-L2`）：流入两个输入端的电流恒为零，即
   $$i_+ = 0, \qquad i_- = 0$$
2. **理想运放虚短公理**（负反馈线性区成立）：两输入端电位相等，且输入电压直接加在同相端，即
   $$v_- = v_+ = v_i$$
3. **基尔霍夫电流定律（KCL）** 与 **欧姆定律**（节点 $v_-$ 处流出电流之和等于流入电流之和）。

#### ② 纯符号通式推导
对反相输入端节点 $v_-$ 列写 KCL 方程（取流出节点方向为正）：
$$\frac{v_- - 0}{R_1} + \frac{v_- - v_o}{R_f} + i_- = 0$$

代入虚断条件 $i_- = 0$ 与虚短条件 $v_- = v_i$：
$$\frac{v_i}{R_1} + \frac{v_i - v_o}{R_f} = 0$$

移项整理，将含 $v_o$ 的项留在右侧：
$$\frac{v_o}{R_f} = \frac{v_i}{R_1} + \frac{v_i}{R_f} = v_i \left(\frac{1}{R_1} + \frac{1}{R_f}\right)$$

两边同乘以 $R_f$，即得同相放大器的**纯符号闭环电压增益通式**：
$$v_o = \left(1 + \frac{R_f}{R_1}\right) v_i, \qquad A_v = \frac{v_o}{v_i} = 1 + \frac{R_f}{R_1}$$

*(交叉印证分压器视角：因 $i_- = 0$，由 `W1-L7` 分压定律直接写出 $v_- = \frac{R_1}{R_1 + R_f} v_o$，令 $v_- = v_i$ 反解 $v_o$，瞬间得到完全一致的 $v_o = \frac{R_1 + R_f}{R_1} v_i = \left(1 + \frac{R_f}{R_1}\right) v_i$。)*

#### ③ 代入数值逐步化简
给定实验室标准实测参数：$R_1 = 10\text{ k}\Omega$，$R_f = 20\text{ k}\Omega$，输入信号 $v_i = 1.5\text{ V}$（电源采用 $\pm 9\text{ V}$ 双电源，线性区 $[-7.5\text{ V}, +7.5\text{ V}]$）：

1. **计算闭环电压增益 $A_v$**：
   $$A_v = 1 + \frac{20\text{ k}\Omega}{10\text{ k}\Omega} = 1 + 2 = 3$$
2. **计算输出电压 $v_o$**：
   $$v_o = 3 \times 1.5\text{ V} = 4.5\text{ V}$$
3. **检验线性区与反馈支路电流 $i_f$**：
   $|4.5\text{ V}| < 7.5\text{ V}$，运放稳稳工作在线性区；反馈支路电流为
   $$i_f = \frac{v_o - v_-}{R_f} = \frac{4.5\text{ V} - 1.5\text{ V}}{20\text{ k}\Omega} = \frac{3.0\text{ V}}{20\text{ k}\Omega} = 0.15\text{ mA}$$
   与接地电阻电流 $i_1 = \frac{1.5\text{ V}}{10\text{ k}\Omega} = 0.15\text{ mA}$ 严格相等。

### 同相放大器的两大工程王牌（与反相放大器正面对比）

| 工程维度 | 反相放大器（`W3-L3`） | 同相放大器（`W3-L4`） | 工程选型启示 |
| :--- | :--- | :--- | :--- |
| **闭环增益 $A_v$** | $-\dfrac{R_f}{R_1}$ | $1 + \dfrac{R_f}{R_1}$ | 同相输出**不倒相**，但增益**永远 $\ge 1$**，无法直接做衰减器 |
| **输入电阻 $R_{in}$** | $R_{in} = R_1$（有限值） | $R_{in} \to \infty$（理想无穷大） | **高内阻传感器首选同相结构**，避免前级分压塌陷 |
| **反相端电位 $v_-$** | 虚地（$0\text{ V}$） | 跟随输入（$v_- = v_i$） | 同相放大器存在共模输入电压，需留意芯片共模输入范围 |
| **单电源适配性** | 正输入出负压，必须双电源 | 正输入出正压，可单 $+9\text{ V}$ 运行 | 单电源便携设备中同相结构极其常见（需防 $+7.5\text{ V}$ 削顶） |

## 第 3 幕：极限特例与阻抗隔离的威力——为什么我们需要增益为 1 的“电压跟随器”？

现在我们把同相放大器推向一个极端。

请盯着公式 $A_v = 1 + \dfrac{R_f}{R_1}$ 思考：如果我把反馈电阻 $R_f$ 换成一根**零欧姆短接线**（$R_f = 0$），同时把接地电阻 $R_1$ 直接**拔掉开路**（$R_1 \to \infty$），会发生什么？

$$\lim_{\substack{R_f \to 0 \\ R_1 \to \infty}} \left(1 + \frac{R_f}{R_1}\right) = 1 + 0 = 1 \implies v_o = v_i$$

这就是电路史上大名鼎鼎的**电压跟随器（Voltage Follower）**，也叫**单位增益缓冲器（Unity-Gain Buffer）**。

**绝不是！** 电压确实没放大，但它放大了**电流驱动能力**和**功率**，完成了电路设计中最关键的动作——**阻抗隔离（Buffer Isolation）**。

让我们用 `W2-L7 戴维南等效` 做一场触目惊心的数值对比实验：

假设你有一个精密传感器（例如电桥或微弱电池源），其戴维南等效参数为：
- 开路电压 $V_{Th} = 5.00\text{ V}$
- 内阻 $R_{Th} = 10\text{ k}\Omega$

现在你想用它直接驱动一个 $R_L = 1\text{ k}\Omega$ 的后级负载（比如一块低阻模拟表头或功放输入级）。

### 对比计算：直连塌陷 vs 电压跟随器隔离（三段式板书）

#### ① 公理溯源
- **情形 A（直接连接）**：$R_{Th}$ 与 $R_L$ 构成简单串联回路，遵循 `W1-L7` **分压定律** 与 **欧姆定律**。
- **情形 B（插入电压跟随器）**：传感器接运放同相端，遵循**虚断（$i_+ = 0$）** 与 **虚短（$v_o = v_- = v_+$）**；负载电流由运放的外部直流电源轨（$\pm 9\text{ V}$）提供。

#### ② 纯符号通式
- **直连负载电压与功率**：
  $$v_{L,\text{direct}} = \frac{R_L}{R_{Th} + R_L} V_{Th}, \qquad P_{L,\text{direct}} = \frac{v_{L,\text{direct}}^2}{R_L}$$
- **插入电压跟随器后的负载电压与功率**：
  因 $i_{\text{source}} = i_+ = 0$，内阻 $R_{Th}$ 上压降为零，故
  $$v_+ = V_{Th} - i_+ R_{Th} = V_{Th} \implies v_{L,\text{buf}} = v_o = V_{Th}, \qquad i_{L,\text{buf}} = \frac{V_{Th}}{R_L}, \qquad P_{L,\text{buf}} = \frac{V_{Th}^2}{R_L}$$

#### ③ 代入数值逐步化简（$V_{Th} = 5.00\text{ V}, R_{Th} = 10\text{ k}\Omega, R_L = 1\text{ k}\Omega$）

- **情形 A（直连惨案）**：
  $$v_{L,\text{direct}} = \frac{1\text{ k}\Omega}{10\text{ k}\Omega + 1\text{ k}\Omega} \times 5.00\text{ V} = \frac{1}{11} \times 5.00\text{ V} \approx 0.455\text{ V}$$
  $$i_{L,\text{direct}} = \frac{5.00\text{ V}}{11\text{ k}\Omega} \approx 0.455\text{ mA}, \qquad P_{L,\text{direct}} = \frac{(0.4545\text{ V})^2}{1\text{ k}\Omega} \approx 0.207\text{ mW}$$
  电压从 $5.00\text{ V}$ **暴跌至 $0.455\text{ V}$**，高达 **90.9%** 的信号电压白白浪费在传感器自身内阻上！

- **情形 B（插入电压跟随器后）**：
  $$v_+ = 5.00\text{ V} - 0 \times 10\text{ k}\Omega = 5.00\text{ V} \implies v_{L,\text{buf}} = 5.00\text{ V}$$
  $$i_{L,\text{buf}} = \frac{5.00\text{ V}}{1\text{ k}\Omega} = 5.00\text{ mA}, \qquad P_{L,\text{buf}} = \frac{(5.00\text{ V})^2}{1\text{ k}\Omega} = 25.00\text{ mW}$$
  负载稳稳拿到完整的 **$5.00\text{ V}$**，负载得到的功率暴涨至直连时的 **121 倍**！而这 $5.00\text{ mA}$ 的电流并非凭空变出来的——它是由插在 LM358 Pin 8 / Pin 4 上的 **$\pm 9\text{ V}$ 电池电源轨** 替传感器扛下来的。传感器只负责“报出 $5.00\text{ V}$ 的口令”，运放负责“出钱出力扛重活”！

### 教授板书：Sadiku Example 5.5 三段式推导（主法：KCL 节点分析法）

#### ① 公理溯源
1. **虚断公理**：$i_+ = 0$，$i_- = 0$。
2. **虚短公理**：同相端直连独立电压源 $V_{s2}$，故 $v_- = v_+ = V_{s2}$。
3. **KCL 与欧姆定律**：在反相输入节点 $v_-$ 处，流入电流 $i_1$ 必须全部经反馈电阻 $R_f$ 流出成为 $i_f$，即 $i_1 = i_f$。

#### ② 纯符号通式推导
分别写出输入支路电流 $i_1$ 与反馈支路电流 $i_f$ 的符号表达式：
$$i_1 = \frac{V_{s1} - v_-}{R_1} = \frac{V_{s1} - V_{s2}}{R_1}, \qquad i_f = \frac{v_- - v_o}{R_f} = \frac{V_{s2} - v_o}{R_f}$$

由节点 $v_-$ 的 KCL 方程 $i_1 = i_f + i_-$ 及 $i_- = 0$，得：
$$\frac{V_{s1} - V_{s2}}{R_1} = \frac{V_{s2} - v_o}{R_f}$$

解出 $v_o$ 的纯符号通式：
$$v_o = V_{s2} - \frac{R_f}{R_1}\left(V_{s1} - V_{s2}\right) = -\frac{R_f}{R_1} V_{s1} + \left(1 + \frac{R_f}{R_1}\right) V_{s2}$$

*(看看最后这个通式！它天然就是“反相放大器分量 + 同相放大器分量”的叠加！)*

#### ③ 代入数值逐步化简
代入题设：$V_{s1} = 6\text{ V}$，$V_{s2} = 4\text{ V}$，$R_1 = 4\text{ k}\Omega$，$R_f = 10\text{ k}\Omega$：

1. **先算输入支路电流 $i_1$ 与反馈支路电流 $i_f$**：
   $$i_1 = \frac{6\text{ V} - 4\text{ V}}{4\text{ k}\Omega} = \frac{2\text{ V}}{4\text{ k}\Omega} = 0.5\text{ mA}$$
   由虚断 $i_- = 0$，得：
   $$i_f = i_1 = 0.5\text{ mA}, \qquad i_- = 0\text{ mA}, \qquad i_+ = 0\text{ mA}$$
2. **再算输出电压 $v_o$**：
   $$v_o = 4\text{ V} - \frac{10\text{ k}\Omega}{4\text{ k}\Omega} \times (6\text{ V} - 4\text{ V}) = 4\text{ V} - 2.5 \times 2\text{ V} = 4\text{ V} - 5\text{ V} = -1\text{ V}$$

> **叠加定理交叉验证与教授安全提醒（Sadiku Method 1）**：  
> - 仅保留 $6\text{ V}$（$4\text{ V}$ 短路接地）→ 反相放大：$v_{o1} = -\frac{10}{4} \times 6 = -15\text{ V}$；  
> - 仅保留 $4\text{ V}$（$6\text{ V}$ 短路接地）→ 同相放大：$v_{o2} = \left(1 + \frac{10}{4}\right) \times 4 = +14\text{ V}$；  
> - 叠加总输出：$v_o = v_{o1} + v_{o2} = -15\text{ V} + 14\text{ V} = -1\text{ V}$！  
> **工程彩蛋**：在纸面上用理想运放做叠加完全正确，但在 $\pm 9\text{ V}$ 面包板实测时，你可千万别真把其中一个电源关掉去分别量 $-15\text{ V}$ 和 $+14\text{ V}$——单独通电时 LM358 早就撞上 $\pm 7.5\text{ V}$ 电源轨饱和了！只有两源同时接入时，最终输出 $-1\text{ V}$ 才稳稳落在 $[-7.5\text{ V}, +7.5\text{ V}]$ 的线性区内。

## 第 5 幕：3D LM358 面包板实测与单/双电源边界排错

理论讲透了，现在切换到左侧舞台第 3 层「`03 3D LM358 面包板实测`」，我们把 **LM358N（DIP-8）** 真正插到面包板中沟（Center Ravine）上！

LM358N 是一颗性价比极高的**双运放芯片**——一片 8 脚小黑块里住着两个完全独立的运放：

### 面包板实测三步检查法与单/双电源避坑指南

1. **为什么推荐 $\pm 9\text{ V}$ 双电源，也允许单 $+9\text{ V}$？**
   - 同相放大器对正输入输出正电压，所以当你的输入信号严格为正（例如 $v_i = 1.5\text{ V} \to v_o = 4.5\text{ V}$，或电压跟随器 $5\text{ V} \to 5\text{ V}$）时，**单 $+9\text{ V}$ 电池完全可以正常工作**；
   - 但请注意 LM358 不是轨到轨（Rail-to-Rail）运放：在单 $+9\text{ V}$ 供电下，它的输出上限大约比正电源低 $1.5\text{ V}$，即**最高只能顶到 $+7.5\text{ V}$**！如果你把 $v_i$ 调到 $3.0\text{ V}$（增益 $A_v = 3$，理论 $v_o = 9.0\text{ V}$），万用表会卡死在约 $+7.5\text{ V}$ 不动，同时你会发现 $v_- \approx 2.5\text{ V} \ne v_+ = 3.0\text{ V}$——**一旦进入饱和区，虚短立刻失效！**
   - 如果需要处理正负交变信号（或实测 Sadiku Example 5.5 的 $v_o = -1\text{ V}$），请务必切换为 **$\pm 9\text{ V}$ 双电源**（线性窗口 $[-7.5\text{ V}, +7.5\text{ V}]$）。
2. **三秒黄金排错法**：万用表黑表笔夹紧 GND，红表笔依次点触 `Pin 3`（$v_+$）与 `Pin 2`（$v_-$）。如果二者读数差超过几毫伏，只有两种可能：① 你的反馈电阻 $R_f$ 没插进同一排孔（断路开环了）；② 输出已经撞上 $\pm 7.5\text{ V}$ 饱和轨。
