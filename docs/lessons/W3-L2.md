# W3-L2：理想运放公式与节点分析（虚断与虚短黄金法则）

> **教授开场白**：欢迎回到 Breadboard Lab。上一讲（`W3-L1`）我们拆开了 741 运放的黑盒，看到了里面的输入电阻 $R_i$、输出电阻 $R_o$ 和高达二十万倍的受控电压源 $A v_d$。今天这节课是整章运放的**分水岭**——我们先咬牙用真实 741 模型硬解一道 Sadiku 经典闭环电路（Example 5.1），让你亲眼看看精确解到底长什么样；然后，你会瞬间明白为什么全世界的电路工程师都敢把那堆复杂参数扔进垃圾桶，只留两行“黄金法则”就能把误差控制在 **0.002% 以内**。系好安全带，我们直接上黑板。

## 第 1 幕：痛点与真相——用真实 741 模型硬解 Fig. 5.6（Example 5.1）

- **左侧舞台绑定**：`01 Fig. 5.6 真实 741 精确求解台`
- **教材锚点**：Sadiku *Fundamentals of Electric Circuits* — **Example 5.1 / Fig. 5.6(a)-(b) (p. 177)**

### 1.1 教授讲解：为什么要先“自讨苦吃”算一遍真实模型？

很多教材一上来就让你背“虚短、虚断”，结果同学们做题时心里总是发虚：“凭什么 $v_1 = v_2$？凭什么 $i_1 = i_2 = 0$？这不会把电路算崩吗？”

在 Breadboard Lab，我们不靠信仰学电路，我们靠**硬核证据**。来看 Sadiku **Example 5.1**：一颗经典的 **741 运放**，参数为开环增益 $A = 2 \times 10^5$、输入电阻 $R_i = 2\text{ M}\Omega$、输出电阻 $R_o = 50\ \Omega$，接入 **Fig. 5.6(a)** 所示的同相负反馈电路（输入源 $v_s$ 接同相端，反相端经 $R_1 = 10\text{ k}\Omega$ 接地，输出端经反馈电阻 $R_f = 20\text{ k}\Omega$ 连回反相端）。我们要做两件事：
1. 求出精确闭环电压增益 $\dfrac{v_o}{v_s}$；
2. 当 $v_s = 2\text{ V}$ 时，求出反馈回路电流 $i$，并顺手把芯片内部真实的差模电压 $v_d$ 和输入电流 $i_1$ 扒出来看个究竟。

### 1.3 三段式教授板书推导：Example 5.1 真实 741 精确求解

#### ① 公理溯源（KCL、欧姆定律与 VCVS 本构关系）
对 **Fig. 5.6(b)**，以公共参考地为 $0\text{ V}$，节点 2 直接由独立电压源钳位：
$$v_2 = v_s, \qquad v_d = v_2 - v_1 = v_s - v_1$$
根据基尔霍夫电流定律（KCL，流出节点电流代数和为零）与欧姆定律：
- **对反相输入节点 1 列 KCL**：
$$\frac{v_1 - 0}{R_1} + \frac{v_1 - v_o}{R_f} + \frac{v_1 - v_s}{R_i} = 0$$
- **对输出节点 $o$ 列 KCL**（注意：此处是真实模型，含非零输出电阻 $R_o$，故可对节点 $o$ 列 KCL）：
$$\frac{v_o - v_1}{R_f} + \frac{v_o - A v_d}{R_o} = 0 \implies \frac{v_o - v_1}{R_f} + \frac{v_o - A(v_s - v_1)}{R_o} = 0$$

#### ② 纯符号通式（联立消去 $v_1$）
将节点 1 与节点 $o$ 的方程整理为关于 $(v_1, v_o)$ 的标准线性方程组：
$$\begin{cases}
\left(\dfrac{1}{R_1} + \dfrac{1}{R_f} + \dfrac{1}{R_i}\right) v_1 - \dfrac{1}{R_f} v_o = \dfrac{1}{R_i} v_s \\[10pt]
\left(\dfrac{A}{R_o} - \dfrac{1}{R_f}\right) v_1 + \left(\dfrac{1}{R_f} + \dfrac{1}{R_o}\right) v_o = \dfrac{A}{R_o} v_s
\end{cases}$$
联立消去 $v_1$，得到真实运放闭环电压增益与节点 1 电压的**严格纯符号通式**（经 Python SymPy 符号化简验算）：
$$\frac{v_o}{v_s} = \frac{A R_1 R_i + A R_f R_i + R_1 R_o}{A R_1 R_i + R_1 R_f + R_1 R_i + R_1 R_o + R_f R_i + R_i R_o}$$
$$\frac{v_1}{v_s} = \frac{R_1 (A R_i + R_f + R_o)}{A R_1 R_i + R_1 R_f + R_1 R_i + R_1 R_o + R_f R_i + R_i R_o}$$

$$v_d = v_s - v_1, \qquad i_1 = \frac{v_1 - v_s}{R_i} = -\frac{v_d}{R_i}, \qquad i = \frac{v_1}{R_1}$$

### 2.1 教授讲解：从三个极限假设到两条黄金法则

既然真实 741 的 $A$ 巨大（$10^5 \sim 10^8$）、$R_i$ 巨大（$10^5 \sim 10^{13}\ \Omega$）、$R_o$ 极小（$10 \sim 100\ \Omega$），Sadiku 在 Section 5.3 正式定义了**理想运放（Ideal Op Amp）的三大理想化假设**：
1. **开环电压增益无穷大**：$A \to \infty$
2. **输入电阻无穷大**：$R_i \to \infty$
3. **输出电阻为零**：$R_o \to 0$

由这三条假设，配合**负反馈使运放工作在线性区（输出电压 $v_o$ 有限）**，立刻推出电路分析史上最锋利的两把手术刀——**理想运放黄金法则（Golden Rules）**：
- **黄金法则 ① 虚断（Virtual Open）**：$i_1 = i_2 = 0$（由 $R_i \to \infty$ 严格保证，无论有没有负反馈都近似成立）。
- **黄金法则 ② 虚短（Virtual Short）**：$v_1 = v_2$（由 **负反馈 + 有限 $v_o$ + $A \to \infty$** 共同保证）。

> **教授高压红线警告**：
> 1. **没有负反馈，就没有虚短！** 一旦断开负反馈（开环状态）或错接成正反馈，哪怕输入端只有 $1\text{ mV}$ 的微小压差，乘上 $A \to \infty$ 也会让输出瞬间撞上电源轨饱和（$v_o = \pm V_{CC}$），此时 $v_1 \neq v_2$，虚短彻底失效！
> 2. **虚短 ≠ 真短！** “虚短”的意思仅仅是“两输入端电位近似相等（$v_1 = v_2$）”，它们之间在物理上依然是 $R_i \to \infty$ 的**断路**，**绝对没有任何电流**能从 `+` 端穿过运放内部流到 `−` 端！

### 2.3 三段式教授板书推导：从三大理想假设到黄金法则与极限验证

#### ① 公理溯源（三大理想化假设与线性区约束）
在理想运放模型（Sadiku Section 5.3）中，对真实运放参数取极限：
$$A \to \infty, \qquad R_i \to \infty, \qquad R_o \to 0$$
同时要求外部存在**负反馈通路**，使运放稳定工作在**线性区**（输出电压 $v_o$ 为有限值，$-V_{CC} < v_o < +V_{CC}$）。

#### ② 纯符号通式（严格极限推导）
1. **导出黄金法则 ① —— 虚断（Virtual Open）**：
   由输入回路欧姆定律：
   $$i_1 = \frac{v_1 - v_2}{R_i} = -\frac{v_d}{R_i}, \qquad i_2 = \frac{v_2 - v_1}{R_i} = \frac{v_d}{R_i}$$
   当 $R_i \to \infty$ 时，无论 $v_d$ 为何有限值，均有：
   $$i_1 = i_2 = 0$$
2. **导出黄金法则 ② —— 虚短（Virtual Short）**：
   由受控电压源关系 $v_o = A v_d = A(v_2 - v_1)$（且 $R_o = 0$）：
   $$v_d = v_2 - v_1 = \frac{v_o}{A}$$
   因为负反馈保证 $v_o$ 为**有限值**，当 $A \to \infty$ 时，分母趋于无穷而分子有限：
   $$v_d = \lim_{A \to \infty} \frac{v_o}{A} = 0 \implies v_1 = v_2$$
3. **验证第 1 幕真实通式的理想极限**：
   对第 1 幕求得的精确闭环增益通式分子分母同除以 $A R_1 R_i$：
   $$\frac{v_o}{v_s} = \frac{1 + \dfrac{R_f}{R_1} + \dfrac{R_o}{A R_i}}{1 + \dfrac{R_f}{A R_i} + \dfrac{1}{A} + \dfrac{R_o}{A R_i} + \dfrac{R_f}{A R_1} + \dfrac{R_o}{A R_1}}$$
   令 $A \to \infty,\ R_i \to \infty,\ R_o \to 0$，分母所有误差项归零，瞬间坍缩为极其优雅的纯电阻比值公式：
   $$\lim_{\substack{A\to\infty,\ R_i\to\infty \\ R_o\to 0}} \frac{v_o}{v_s} = 1 + \frac{R_f}{R_1}$$

### 3.1 教授讲解：80% 初学者踩过的致命深坑

学完虚断和虚短后，很多同学做节点分析时会惯性地想：“既然输出端 $v_o$ 是我要求的未知节点，那我直接对输出节点 $o$ 列一个 KCL 不就行了吗？”

**绝对不行！立刻停笔！**

为什么？因为理想运放的输出端在内部连着一个**输出电阻 $R_o = 0$ 的理想受控电压源**（由隐藏的电源轨 $+V_{CC}, -V_{CC}$ 源源不断地提供能量）。这就意味着：
- 运放输出端是一个**硬电压源节点**，它往外“吐出”或往里“吸入”的电流 $i_o$ **不是零**，而且你**事先根本不知道 $i_o$ 是多少**！
- 如果你一上来就对输出节点 $o$ 列 KCL，方程里必然会冒出一个全新的未知数 $i_o$，你非但消不掉 $v_o$，反而凭空多了一个未知数；更可怕的是，很多同学会**漏写 $i_o$**（以为流出运放输出端的电流是 0），直接列出 $\frac{v_o - v_1}{R_f} + \frac{v_o}{R_L} = 0$ 这种荒谬方程，导致整道题全盘皆输！

### 3.3 三段式教授板书推导：输出端 KCL 方程的真实角色

#### ① 公理溯源（受控电压源节点的 KCL 约束）
根据 `W2-L1 节点分析法` 的规则，任何连接到理想电压源（含理想受控电压源）的节点，其支路电流都是独立未知量。对理想运放输出节点 $o$ 列 KCL（设流出节点为正）：
$$-i_o + i_f + i_L = 0$$

#### ② 纯符号通式（为何不能用来求 $v_o$，却能用来反算 $i_o$）
整理上式得：
$$i_o = \frac{v_o - v_1}{R_f} + \frac{v_o}{R_L}$$
- **求解 $v_o$ 阶段**：等式左侧的 $i_o$ 未知，因此该方程**不能**用于求解 $v_o$；必须先通过反相节点 1 的 KCL（利用 $i_1 = 0$ 与 $v_1 = v_2$）解出 $v_o$。
- **反算 $i_o$ 阶段**：一旦 $v_o$ 和 $v_1$ 均已求得，再把它们代回上式，**唯一且合法**地算出运放输出级必须提供的总电流 $i_o$（并检查 $|i_o| \le i_{o,\max}$ 是否超过芯片带载能力）。

#### ③ 代入数值逐步化简（直觉演示）
若 $v_1 = 2\text{ V},\ v_o = 6\text{ V},\ R_f = 20\text{ k}\Omega$：
- 无外部负载（$R_L \to \infty$，即 Example 5.2）：$i_o = \dfrac{6 - 2}{20\text{ k}\Omega} + 0 = 0.2\text{ mA}$。
- 若后续并联一个 $R_L = 2\text{ k}\Omega$ 负载：$v_o$ 仍死死保持 $6\text{ V}$ 不变，但输出电流自动跃升为：
  $$i_o = \frac{6 - 2}{20\text{ k}\Omega} + \frac{6}{2\text{ k}\Omega} = 0.2\text{ mA} + 3.0\text{ mA} = 3.2\text{ mA}$$
这恰好印证了为什么 $i_o$ 必须放到最后一步才算！

### 4.3 三段式教授板书推导：Sadiku Example 5.2 完整求解

#### ① 公理溯源（负反馈检验 + 黄金法则 + 节点 KCL）
1. **检查负反馈**：输出节点 $o$ 经 $R_f$ 接回反相输入端（`−`），确认存在负反馈，运放工作在线性区。
2. **应用黄金法则**：
   $$i_1 = i_2 = 0 \quad (\text{虚断}), \qquad v_1 = v_2 \quad (\text{虚短})$$
3. **锁定已知电位**：同相端直接接独立电压源 $v_s$，故：
   $$v_2 = v_s \implies v_1 = v_s$$
4. **选定 KCL 节点（遵守禁区）**：**严禁先对输出节点 $o$ 列 KCL**；只对反相节点 1 列 KCL（流入 = 流出）：
   $$\frac{v_o - v_1}{R_f} = \frac{v_1 - 0}{R_1} + i_1$$

#### ② 纯符号通式（分别求解闭环增益与输出电流）
将 $i_1 = 0$ 与 $v_1 = v_s$ 代入节点 1 的 KCL 方程：
$$\frac{v_o - v_s}{R_f} = \frac{v_s}{R_1}$$
两边同乘 $R_f$ 并移项：
$$v_o - v_s = \frac{R_f}{R_1} v_s \implies v_o = \left(1 + \frac{R_f}{R_1}\right) v_s$$
得到闭环电压增益的纯符号通式：
$$\frac{v_o}{v_s} = 1 + \frac{R_f}{R_1}$$
**最后一步（反算输出电流 $i_o$）**：现在 $v_o$ 和 $v_1$ 均已求得，对输出节点 $o$ 列 KCL（无外接负载 $R_L$，输出电流全部流经 $R_f$）：
$$i_o = i = \frac{v_o - v_1}{R_f} = \frac{\left(1 + \dfrac{R_f}{R_1}\right) v_s - v_s}{R_f} = \frac{v_s}{R_1}$$

#### ③ 代入数值逐步化简（SymPy 逐步核验）
代入 $R_1 = 10\text{ k}\Omega$、$R_f = 20\text{ k}\Omega$、$v_s = 2\text{ V}$：
1. **闭环电压增益**：
   $$\frac{v_o}{v_s} = 1 + \frac{20\text{ k}\Omega}{10\text{ k}\Omega} = 1 + 2 = \mathbf{3}$$
2. **输出电压**：
   $$v_o = 3 \times 2\text{ V} = \mathbf{6\text{ V}}$$
3. **输出电流（亦即反馈电流 $i$）**：
   $$i_o = \frac{v_o - v_1}{R_f} = \frac{6\text{ V} - 2\text{ V}}{20\text{ k}\Omega} = \frac{4\text{ V}}{20 \times 10^3\ \Omega} = 2 \times 10^{-4}\text{ A} = \mathbf{0.2\text{ mA}}$$
   交叉验算：$i_o = \dfrac{v_s}{R_1} = \dfrac{2\text{ V}}{10\text{ k}\Omega} = \mathbf{0.2\text{ mA}}$，完全一致！
