# W4-L8：RLC 阶跃响应与一般二阶电路通用求解流程

> **教授开场白**：欢迎回到 Breadboard Lab！在上一讲 W4-L7 里，我们把所有电源都拔掉，静静看着储能元件里的能量在 $R, L, C$ 之间自由耗散——那是电路的**自然响应**。但在真实世界里，电路从来不是孤零零地放电：你按下电源开关、单片机 GPIO 输出从 $0\text{ V}$ 翻到 $5\text{ V}$、电机驱动器接通母线，这些全都是**突然施加直流激励的阶跃响应**。今天这一讲，我们要打通二阶瞬态分析的“最后一公里”：不仅拿下串联与并联 RLC 的阶跃过冲与振铃，更要掌握面对任意混合拓扑都能一剑封喉的**通用四步法**，并在面包板示波器上亲眼驯服高速上升沿里的振荡“幽灵”。

---

## 第 1 幕：从自由衰减到强迫跃迁——二阶阶跃完全响应的统一结构与“头号致命陷阱”

### 1.1 为什么阶跃响应的暂态骨架与无源自然响应完全一致？

在 W4-L5 一阶阶跃响应中，你已经见过这个优美的拆分：$x(t) = x_{\text{ss}} + x_t(t)$。来到二阶电路（*Fundamentals of Electric Circuits*, Sections 8.5–8.6），由于线性定常二阶非齐次微分方程的通解严格等于**对应齐次方程的通解（暂态响应 $x_t(t)$）**加上**一个特解（直流稳态强迫响应 $x_{\text{ss}} = x(\infty)$）**，这个结构丝毫没有改变：

$$x(t) = \underbrace{x_{\text{ss}}}_{\text{直流稳态强迫响应 } x(\infty)} + \underbrace{x_t(t)}_{\text{与无源电路完全同型的暂态自然响应}}$$

请记住这条直觉：**直流电源 $V_s$ 或 $I_s$ 只负责把终点线从 $0$ 抬升到 $x_{\text{ss}}$，它完全不改变电路自身的特征方程、阻尼系数 $\alpha$ 和无阻尼谐振角频率 $\omega_0$！**

- **串联 RLC 阶跃激励（Section 8.5）**：我们优先选取**电容电压 $v_C(t)$** 作为主状态变量，因为 $t \to \infty$ 时电容开路、电流归零，电容稳态电压直接等于电源电压 $V_s$：
  $$v_C(t) = V_s + v_t(t)$$
- **并联 RLC 阶跃激励（Section 8.6）**：按照电路对偶原理，我们优先选取**电感电流 $i_L(t)$** 作为主状态变量，因为 $t \to \infty$ 时电感短路、两端电压归零，全部电流源电流都灌入电感，即 $i_L(\infty) = I_s$：
  $$i_L(t) = I_s + i_t(t)$$

| 对比维度 | 串联 RLC 阶跃响应 (Section 8.5) | 并联 RLC 阶跃响应 (Section 8.6) |
| :--- | :--- | :--- |
| 激励形式 | 电压阶跃 $V_s u(t)$ | 电流阶跃 $I_s u(t)$ |
| 首选主变量 | 电容电压 $v_C(t)$ | 电感电流 $i_L(t)$ |
| 稳态强迫项 $x_{\text{ss}}$ | $v_C(\infty) = V_s$ | $i_L(\infty) = I_s$ |
| 阻尼系数 $\alpha$ | $\alpha = \dfrac{R}{2L}$（$R$ 越大，阻尼越强） | $\alpha = \dfrac{1}{2RC}$（$R$ 越大，阻尼越弱） |
| 谐振角频率 $\omega_0$ | $\omega_0 = \dfrac{1}{\sqrt{LC}}$ | $\omega_0 = \dfrac{1}{\sqrt{LC}}$ |
| 辅助变量换算 | $i(t) = C\dfrac{dv_C}{dt}$ | $v(t) = L\dfrac{di_L}{dt}$ |

### 1.2 红牌警告：全章最高频的“致命错”！

> **教授拍黑板提醒**：每年期中考试，超过一半丢分的同学不是不会解特征方程，而是栽在下面这一步——
>
> **待定常数 $A_1, A_2$（或 $B_1, B_2$ / $D_1, D_2$）必须用包含稳态项 $x_{\text{ss}}$ 的完全响应 $x(t) = x_{\text{ss}} + x_t(t)$ 去代入 $t=0^+$ 初值与导数初值，绝对不能只拿暂态项 $x_t(t)$ 去代初值！**

我们来做一个最刺痛神经的反证。假设一块完全没充过电的串联 RLC 电路（$v_C(0^-) = 0\text{ V},\ i_L(0^-) = 0\text{ A}$）在 $t=0$ 时突然接入 $V_s = 5\text{ V}$ 电池。此时 $v_C(0^+) = 0$ 且 $v_C'(0^+) = i(0^+)/C = 0$。
- **错误做法**：只拿 $v_t(t) = e^{-\alpha t}(B_1\cos\omega_d t + B_2\sin\omega_d t)$ 去代 $v_t(0^+)=0, v_t'(0^+)=0$，立刻解出 $B_1 = 0, B_2 = 0$，于是写成 $v_C(t) = 5 + 0 = 5\text{ V}$——电容电压在 $t=0$ 瞬间从 $0\text{ V}$ 跳变到 $5\text{ V}$，彻底违背了电容电压不能突变的物理铁律！
- **正确做法**：把 $v_C(0^+) = V_s + B_1 = 0$ 写完整，立刻得到 $B_1 = -V_s = -5\text{ V}$，正是这个负的暂态分量在 $t=0^+$ 时刻精准抵消了 $+5\text{ V}$ 的稳态目标，才让电容从 $0\text{ V}$ 平滑起步！

## 第 2 幕：串联 RLC 阶跃响应三段式推导与三大阻尼波形全景（Section 8.5）

### 2.1 三段式教授板书推导（例题 1：Breadboard Lab 串联 RLC 欠阻尼阶跃）

> **题目设定（与面包板实操参数完全一致）**：串联 RLC 电路由 $0\text{ V}$ 阶跃至 $V_s = 5\text{ V}$ 的方波上升沿激励，元件参数为 $R = 56\ \Omega$、$L = 10\text{ mH}$、$C = 1\ \mu\text{F}$。设换路前电路处于零初始储能状态，即 $v_C(0^-) = 0\text{ V},\ i(0^-) = 0\text{ A}$。求 $t > 0$ 时的电容电压 $v_C(t)$、回路电流 $i(t)$，以及首次过冲峰值时间 $t_p$、峰值电压 $v_{\text{peak}}$ 与百分比超调量 $M_p$。

#### ① 公理溯源（物理定律列式）

对 $t > 0$ 的串联闭合回路应用基尔霍夫电压定律（KVL）：

$$v_R(t) + v_L(t) + v_C(t) = V_s$$

代入三个元件的电压-电流约束关系（VCR）：$v_R = Ri$，$v_L = L\dfrac{di}{dt}$，$i = C\dfrac{dv_C}{dt}$。

#### ② 纯符号通式（严禁提前代入数字）

将 $i = C\dfrac{dv_C}{dt}$ 与 $\dfrac{di}{dt} = C\dfrac{d^2 v_C}{dt^2}$ 代入 KVL，得关于 $v_C(t)$ 的二阶常系数非齐次微分方程：

$$LC\frac{d^2 v_C}{dt^2} + RC\frac{dv_C}{dt} + v_C = V_s$$

两边同除以 $LC$，化为标准型：

$$\frac{d^2 v_C}{dt^2} + \frac{R}{L}\frac{dv_C}{dt} + \frac{1}{LC}v_C = \frac{V_s}{LC}$$

定义串联阻尼系数 $\alpha$ 与无阻尼自然谐振角频率 $\omega_0$：

$$\alpha = \frac{R}{2L}, \qquad \omega_0 = \frac{1}{\sqrt{LC}}$$

当 $\alpha < \omega_0$（欠阻尼态）时，特征方程 $s^2 + 2\alpha s + \omega_0^2 = 0$ 具有一对共轭复根 $s_{1,2} = -\alpha \pm j\omega_d$，其中阻尼振荡角频率为 $\omega_d = \sqrt{\omega_0^2 - \alpha^2}$。

由线性微分方程叠加结构，电容电压完全响应的纯符号通式为：

$$v_C(t) = V_s + e^{-\alpha t}\left(B_1\cos\omega_d t + B_2\sin\omega_d t\right)$$

对其求导：

$$\frac{dv_C}{dt} = e^{-\alpha t}\left[\left(-\alpha B_1 + \omega_d B_2\right)\cos\omega_d t + \left(-\alpha B_2 - \omega_d B_1\right)\sin\omega_d t\right]$$

由储能连续性，零初始储能意味着 $v_C(0^+) = v_C(0^-) = 0$，且 $v_C'(0^+) = \dfrac{i(0^+)}{C} = \dfrac{i(0^-)}{C} = 0$。将两个初值**完整代入包含 $V_s$ 的方程**：

$$\begin{cases} v_C(0^+) = V_s + B_1 = 0 \implies B_1 = -V_s \\ v_C'(0^+) = -\alpha B_1 + \omega_d B_2 = 0 \implies B_2 = \dfrac{\alpha}{\omega_d}B_1 = -\dfrac{\alpha}{\omega_d}V_s \end{cases}$$

回代得到零状态串联欠阻尼阶跃响应纯符号解析解：

$$v_C(t) = V_s\left[1 - e^{-\alpha t}\left(\cos\omega_d t + \frac{\alpha}{\omega_d}\sin\omega_d t\right)\right]$$

进一步利用 $i(t) = C\dfrac{dv_C}{dt}$ 并结合 $\alpha^2 + \omega_d^2 = \omega_0^2 = \dfrac{1}{LC}$，化简得回路电流的极简纯符号通式：

$$i(t) = C\cdot e^{-\alpha t}\left(\frac{\alpha^2 + \omega_d^2}{\omega_d}V_s\right)\sin\omega_d t = \frac{V_s}{L\omega_d}e^{-\alpha t}\sin\omega_d t$$

令 $\dfrac{dv_C}{dt} = 0$（即 $\sin\omega_d t_p = 0$ 的首个正根），得到首次过冲峰值时间与百分比超调量通式：

$$t_p = \frac{\pi}{\omega_d}, \qquad M_p = \frac{v_C(t_p) - V_s}{V_s} = e^{-\pi\alpha/\omega_d}$$

#### ③ 代入数值逐步化简（经 Python 精确验证，ODE 残差 $< 10^{-12}$）

代入 $V_s = 5\text{ V}$、$R = 56\ \Omega$、$L = 10\times 10^{-3}\text{ H}$、$C = 1\times 10^{-6}\text{ F}$：

1. **特征参数计算**：
   $$\alpha = \frac{56}{2 \times 10^{-2}} = 2800\text{ Np/s}$$
   $$\omega_0 = \frac{1}{\sqrt{10^{-2} \times 10^{-6}}} = 10000\text{ rad/s}$$
   由于 $\alpha = 2800 < \omega_0 = 10000$，电路处于**欠阻尼态**，阻尼比 $\zeta = \dfrac{\alpha}{\omega_0} = 0.28$。注意到 $(7, 24, 25)$ 勾股数结构，阻尼振荡角频率为精确整数：
   $$\omega_d = \sqrt{10000^2 - 2800^2} = 9600\text{ rad/s}$$
2. **待定常数计算**：
   $$B_1 = -5\text{ V}, \qquad B_2 = -\frac{2800}{9600} \times 5 = -\frac{7}{24} \times 5 = -\frac{35}{24}\text{ V} \approx -1.458\text{ V}$$
3. **最终解析表达式（$t \ge 0$）**：
   $$v_C(t) = 5 - e^{-2800t}\left(5\cos 9600t + \frac{35}{24}\sin 9600t\right)\text{ V}$$
   $$i(t) = \frac{5}{0.01 \times 9600}e^{-2800t}\sin 9600t = \frac{5}{96}e^{-2800t}\sin 9600t\text{ A} \approx 52.08\,e^{-2800t}\sin(9600t)\text{ mA}$$
4. **过冲指标定量计算**：
   $$t_p = \frac{\pi}{9600} \approx 0.327\text{ ms}, \qquad M_p = e^{-\pi \times 2800 / 9600} = e^{-7\pi/24} \approx 0.4000 = 40.0\%$$
   $$v_{\text{peak}} = 5 \times (1 + 0.4000) = 7.00\text{ V}$$

> **教授点睛**：看这个惊人的物理事实！你只接了一颗 $5\text{ V}$ 电源，但在 $t = 0.327\text{ ms}$ 这一瞬间，电容两端居然冲到了 **$7.00\text{ V}$**（高出电源整整 $2\text{ V}$）！多出来的能量从哪来？正是上升阶段流过电感的电流在磁场中攒下的动能 $\frac{1}{2}Li^2$，在电容充到 $5\text{ V}$ 时电流还没归零，电感惯性硬把电荷继续往电容里“顶”，顶出了 $+40\%$ 的过冲！

### 2.2 同一组 $L, C$ 下三大阻尼态解析对照

保持 $V_s = 5\text{ V},\ L = 10\text{ mH},\ C = 1\ \mu\text{F}$（临界电阻 $R_{\text{crit}} = 2\sqrt{L/C} = 200\ \Omega$）不变，仅调节电阻 $R$：

- **欠阻尼（$R = 56\ \Omega < 200\ \Omega$）**：$\alpha = 2800,\ \omega_d = 9600$，$v_C(t) = 5 - e^{-2800t}(5\cos 9600t + \frac{35}{24}\sin 9600t)\text{ V}$。上升最猛，但过冲高达 $7.00\text{ V}$（$+40\%$）且剧烈振铃。

## 第 3 幕：并联 RLC 阶跃响应与苏格拉底式 5 步互动实战（Section 8.6）

### 3.1 并联电路的反直觉物理：为什么增大 $R$ 反而更爱振铃？

对并联 RLC 阶跃电路的上节点列写 KCL：

$$i_R + i_L + i_C = I_s \implies \frac{v}{R} + i_L + C\frac{dv}{dt} = I_s$$

利用电感 VCR 关系 $v = L\dfrac{di_L}{dt}$ 消去 $v$，立刻得到与串联完全对偶的标准二阶非齐次方程：

$$\frac{d^2 i_L}{dt^2} + \frac{1}{RC}\frac{di_L}{dt} + \frac{1}{LC}i_L = \frac{I_s}{LC}$$

这里的阻尼系数是 $\alpha = \dfrac{1}{2RC}$，临界阻尼电阻是 $R_{\text{crit}} = \dfrac{1}{2}\sqrt{\dfrac{L}{C}}$。请把物理图像刻进脑海里：
- 在**串联**回路里，电阻 $R$ 挡在电流必经之路上，$R$ 越大越“刹车”，所以阻尼越强；
- 在**并联**电路里，电阻 $R$ 是一条把 $L, C$ 振荡能量漏掉的“旁路排水沟”。如果把 $R$ 调大甚至开路（$R \to \infty$），排水沟堵死了，能量只能在 $L$ 和 $C$ 之间无休止地来回倒腾，所以 **$R$ 越大反而阻尼越弱（越容易欠阻尼振铃）**！

## 第 4 幕：走出温室——一般非标准二阶电路通用四步法（Section 8.7）

### 4.1 当电路既非纯串联也非纯并联时，怎么办？

打开任何一块真实电路板，你会发现元件几乎从不乖乖排成纯串联或纯并联——比如电源经串联限流电阻 $R_1$ 与电感 $L$ 后，再接入并联的负载电阻 $R_2$ 和滤波电容 $C$，或者电路里藏着受控源。此时，$\alpha = \dfrac{R}{2L}$ 和 $\alpha = \dfrac{1}{2RC}$ **全部失效**！

幸运的是，Alexander & Sadiku 在 **Section 8.7** 给了我们一把放之四海而皆准的万能钥匙——**一般二阶电路通用四步法**：

1. **第一步（初值锁定）**：沿用 W4-L6 的方法，由 $t=0^-$ 稳态得到 $v_C(0^-), i_L(0^-)$，画出 $t=0^+$ 等效电路，求出目标变量 $x(0^+)$ 与其一阶导数 $x'(0^+)$。
2. **第二步（求暂态形式 $x_t(t)$）**：将电路中所有**独立源置零**（独立电压源短路，独立电流源开路；受控源保留！），在无源网络中列出两个状态变量（$v_C, i_L$）的 KCL/KVL 方程，**消去另一个状态变量**，导出二阶齐次微分方程与特征方程，解出特征根 $s_1, s_2$，据此写出 $x_t(t)$ 的对应形式（过阻尼 / 临界阻尼 / 欠阻尼）。
3. **第三步（求直流稳态 $x_{\text{ss}}$）**：恢复独立直流源，令 $t \to \infty$（电感短路、电容开路），用纯电阻分压/分流求出稳态强迫响应 $x_{\text{ss}} = x(\infty)$。
4. **第四步（合并定常数）**：写出完全响应 $x(t) = x_{\text{ss}} + x_t(t)$，将第一步求得的 $x(0^+)$ 与 $x'(0^+)$ **代入完全响应**，解出两个待定常数；最后可按需由元件关系反推其余支路电压或电流并做双向自检。

### 4.3 三段式教授板书推导（例题 2：一般混合二阶电路完整求解）

> **题目设定**：上图所示混合二阶电路中，$V_s = 12\text{ V}$，$R_1 = 4\ \Omega$，$R_2 = 2\ \Omega$，$L = 1\text{ H}$，$C = 0.5\text{ F}$。开关在 $t=0$ 时刻闭合，换路前零初始储能（$v_C(0^-) = 0\text{ V},\ i_L(0^-) = 0\text{ A}$）。按通用四步法求 $t > 0$ 的电容电压 $v_C(t)$ 与电感电流 $i_L(t)$。

#### ① 公理溯源（物理定律列式）

对节点 A 列写 KCL，并对左侧回路列写 KVL：

$$\text{节点 A (KCL)：}\quad i_L(t) = \frac{v_C(t)}{R_2} + C\frac{dv_C(t)}{dt}$$

$$\text{左侧回路 (KVL)：}\quad R_1 i_L(t) + L\frac{di_L(t)}{dt} + v_C(t) = V_s$$

#### ② 纯符号通式（按通用四步法展开）

- **步骤 1（初值）**：由连续性 $v_C(0^+) = v_C(0^-)$，$i_L(0^+) = i_L(0^-)$。由节点 A 的 KCL 得导数初值：
  $$v_C'(0^+) = \frac{1}{C}\left(i_L(0^+) - \frac{v_C(0^+)}{R_2}\right)$$
- **步骤 2（独立源置零导出特征方程）**：令 $V_s = 0$，将 $i_L = \dfrac{v_C}{R_2} + C\dfrac{dv_C}{dt}$ 及其导数 $\dfrac{di_L}{dt} = \dfrac{1}{R_2}\dfrac{dv_C}{dt} + C\dfrac{d^2 v_C}{dt^2}$ 代入齐次 KVL 方程：
  $$LC\frac{d^2 v_C}{dt^2} + \left(R_1 C + \frac{L}{R_2}\right)\frac{dv_C}{dt} + \left(1 + \frac{R_1}{R_2}\right)v_C = 0$$
  两边同除以 $LC$，得到该混合拓扑的纯符号特征方程：
  $$s^2 + \left(\frac{R_1}{L} + \frac{1}{R_2 C}\right)s + \frac{R_1 + R_2}{R_2 LC} = 0$$
  *(教授点评：仔细看一次项系数 $\frac{R_1}{L} + \frac{1}{R_2 C}$——它恰好是串联阻尼通道与并联阻尼通道的叠加！这就是混合拓扑不能套单一公式的根本原因。)*
- **步骤 3（直流稳态）**：令 $t \to \infty$，电感短路、电容开路，$R_1$ 与 $R_2$ 构成纯电阻分压：
  $$v_C(\infty) = V_s\frac{R_2}{R_1 + R_2}, \qquad i_L(\infty) = \frac{V_s}{R_1 + R_2}$$
- **步骤 4（合并通式）**：若特征方程有两个不等负实根 $s_1, s_2$（过阻尼），则完全响应通式为：
  $$v_C(t) = v_C(\infty) + A_1 e^{s_1 t} + A_2 e^{s_2 t}$$
  其中 $A_1, A_2$ 由 $v_C(0^+) = v_C(\infty) + A_1 + A_2$ 与 $v_C'(0^+) = s_1 A_1 + s_2 A_2$ 联立求得。

#### ③ 代入数值逐步化简（经 Python 精确验证，ODE 残差 $< 10^{-12}$）

1. **代入求初值**：
   $$v_C(0^+) = 0\text{ V}, \quad i_L(0^+) = 0\text{ A} \implies v_C'(0^+) = \frac{1}{0.5}\left(0 - \frac{0}{2}\right) = 0\text{ V/s}$$
2. **代入求特征根**：
   $$\frac{R_1}{L} + \frac{1}{R_2 C} = \frac{4}{1} + \frac{1}{2 \times 0.5} = 4 + 1 = 5\text{ s}^{-1}$$
   $$\frac{R_1 + R_2}{R_2 LC} = \frac{4 + 2}{2 \times 1 \times 0.5} = 6\text{ s}^{-2}$$
   特征方程为 $s^2 + 5s + 6 = (s + 2)(s + 3) = 0$，得两个不等实根（过阻尼）：
   $$s_1 = -2\text{ s}^{-1}, \qquad s_2 = -3\text{ s}^{-1}$$
3. **代入求直流稳态**：
   $$v_C(\infty) = 12 \times \frac{2}{4 + 2} = 4\text{ V}, \qquad i_L(\infty) = \frac{12}{4 + 2} = 2\text{ A}$$
4. **合并代入初值定 $A_1, A_2$**：
   $$v_C(t) = 4 + A_1 e^{-2t} + A_2 e^{-3t}$$
   $$\begin{cases} v_C(0^+) = 4 + A_1 + A_2 = 0 \implies A_1 + A_2 = -4 \\ v_C'(0^+) = -2A_1 - 3A_2 = 0 \implies A_1 = -\dfrac{3}{2}A_2 \end{cases}$$
   解得 $A_1 = -12\text{ V},\ A_2 = +8\text{ V}$，于是完整电容电压为（$t \ge 0$）：
   $$v_C(t) = 4 - 12e^{-2t} + 8e^{-3t}\text{ V}$$
5. **反推电感电流并做物理双向自检**：
   $$i_L(t) = \frac{v_C(t)}{2} + 0.5\frac{dv_C(t)}{dt} = \left(2 - 6e^{-2t} + 4e^{-3t}\right) + 0.5\left(24e^{-2t} - 24e^{-3t}\right)$$
   $$i_L(t) = 2 + 6e^{-2t} - 8e^{-3t}\text{ A}$$
   **物理自检**：$i_L(0^+) = 2 + 6 - 8 = 0\text{ A}$（吻合）；$i_L'(0^+) = -12 + 24 = 12\text{ A/s}$，而 $t=0^+$ 时电感两端承受全部电源电压 $v_L(0^+) = 12\text{ V}$，故 $\frac{v_L(0^+)}{L} = \frac{12}{1} = 12\text{ A/s}$（完全吻合！）；$i_L(\infty) = 2\text{ A}$（吻合）。

## 第 5 幕：工程真相与 3D 面包板实操——PCB 走线振铃、串联端接与示波器安全

### 5.1 为什么高速 PCB 走线必须串一颗 $22\ \Omega\text{–}47\ \Omega$ 端接电阻？

在单片机 SPI、时钟总线或 DDR 接口设计中，你一定在芯片引脚旁见过一排不起眼的 $22\ \Omega$ 或 $33\ \Omega$ 贴片电阻，它们叫**源端串联端接电阻（Series Termination Resistor）**。为什么工程师要故意在信号线上加电阻？

因为当驱动器 GPIO 在 $1\text{–}2\text{ ns}$ 内完成 $0\text{ V} \to 3.3\text{ V}$ 阶跃翻转时，一根 $5\text{ cm}$ 长的 PCB 铜皮走线不再是理想导线，它带有寄生电感 $L_{\text{trace}} \approx 25\text{ nH}$，而接收端芯片引脚带有输入电容 $C_{\text{in}} \approx 10\text{ pF}$。驱动器内阻 $R_{\text{out}}$ 通常只有 $10\text{–}15\ \Omega$，而该寄生回路的临界阻尼电阻高达：

$$R_{\text{crit}} = 2\sqrt{\frac{L_{\text{trace}}}{C_{\text{in}}}} = 2\sqrt{\frac{25\times 10^{-9}}{10\times 10^{-12}}} = 2 \times 50 = 100\ \Omega$$

- **不加端接电阻（$R_{\text{total}} \approx 15\ \Omega \ll 100\ \Omega$）**：系统处于深度欠阻尼（$\zeta \approx 0.15$），上升沿会在接收端炸出超过 $+60\%$ 的高压过冲（击穿芯片 ESD 二极管）和剧烈下冲（导致时钟沿重复误触发、EMI 辐射超标）！
- **串联端接电阻 $R_{\text{term}} = 33\ \Omega\text{–}47\ \Omega$**：人为把总阻尼拉向临界阻尼（工程上通常取 $\zeta \approx 0.6\text{–}0.8$ 或匹配传输线特性阻抗 $Z_0 = 50\ \Omega$），瞬间把振铃抹平，同时保持足够陡峭的上升沿。

### 5.3 3D 面包板实操指南与示波器共地安全铁律

切换到左侧舞台 **第 3 层（3D 面包板方波激励实操）**，按以下 4 步亲手复现第 2 幕的理论波形：

1. **搭建串联回路**：在面包板上按 `信号源红夹 -> 可调电阻 R -> 10 mH 电感 L -> 1 uF 非极性电容 C -> 公共 GND 轨` 的顺序串联，确保 **电容 C 的负端直接插在 GND 轨上**。
2. **设定激励源**：将函数信号发生器设为 **0–5 V 单极性方波、频率 200 Hz**（每个上升沿后有 $2.5\text{ ms}$ 平台供瞬态充分收敛），输出阻抗 $50\ \Omega$（注意：实际回路总电阻为 $R_{\text{ext}} + 50\ \Omega + R_{\text{DCR}}$，仿真与实验校准时需计入信号源内阻）。
3. **双通道安全挂接（红线铁律！）**：
   - CH1 探头挂在信号源输出节点，**地夹接 GND 轨**；
   - CH2 探头挂在 $L$ 与 $C$ 的公共节点（即 $v_C(t)$），**地夹同样接在 GND 轨**。
   - **安全禁令**：严禁为了直接看 $v_L(t)$ 或 $v_R(t)$ 而把 CH2 黑色地夹夹到非地节点！示波器通道外壳与信号源外壳均直通市电地线，浮地夹接会瞬间短路元件并可能烧毁信号源输出级。
4. **旋钮扫阻观察**：缓慢旋转电位器，将回路总电阻从 $56\ \Omega$ 调升至 $200\ \Omega$ 再调至 $250\ \Omega$，观察示波器 CH2 上升沿如何从 $7.0\text{ V}$ 剧烈振铃精准收缩为无过冲的最快上升沿，再变为迟缓拖尾。
