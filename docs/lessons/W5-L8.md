# W5-L8：串联与并联谐振（品质因数 Q、带宽与 3D 面包板扫频实操）

> **教授开场白**：同学们好！前几讲我们一路打通了 `W4-L7 RLC 自然响应`、`W5-L2 复阻抗` 和 `W5-L7 传递函数与 -3dB 点`。今天我们要迎来交流稳态电路中最具戏剧性、也最贴近真实射频与音频工程的现象——**谐振（Resonance）**。
>
> 你小时候一定荡过秋千（Boylestad Ch. 20 的经典直觉）：如果你胡乱用力乱推，秋千只会原地晃动；可只要你**踩准秋千的固有节奏**轻轻一推，哪怕每次力气很小，秋千也能越荡越高！在 RLC 电路里，电感 $L$ 与电容 $C$ 组成的储能“秋千”也有一个独一无二的固有节奏 $\omega_0$。一旦外部正弦激励的频率踩中了这个点，奇迹就会发生——**5 V 的信号源，竟然能在电容两端憋出 50 V 的高压！** 今天我们就从物理直觉、严谨三段式推导，一路讲到 3D 面包板亲手扫频抓出这个谐振峰。

## 第 1 幕：秋千共振与串联 RLC 谐振条件（感抗与容抗的精确抵消）

### 1.1 物理直觉：为什么存在唯一“通畅频率”？

在串联 RLC 电路中，电流 $\mathbf{I}$ 必须依次穿过电阻 $R$、电感 $L$ 和电容 $C$。根据我们在 `W5-L2` 学过的复阻抗概念：
- 电感的阻抗 $\mathbf{Z}_L = j\omega L$，频率越**高**，阻碍越强（通低频、阻高频）；
- 电容的阻抗 $\mathbf{Z}_C = \frac{1}{j\omega C} = -j\frac{1}{\omega C}$，频率越**低**，阻碍越强（通高频、阻低频）。

把它们串联在一起，总复阻抗就是：
$$\mathbf{Z}(j\omega) = R + j\left(\omega L - \frac{1}{\omega C}\right) = R + j(X_L - X_C)$$

注意括号里那个迷人的**减号**！
- 当频率偏低（$\omega < \omega_0$）时，$X_C > X_L$，总阻抗虚部为负，电路呈**容性**（电流超前电压）；
- 当频率偏高（$\omega > \omega_0$）时，$X_L > X_C$，总阻抗虚部为正，电路呈**感性**（电流滞后电压）；
- 唯独在**某个精确的交叉点 $\omega = \omega_0$** 上，感抗 $X_L(\omega_0)$ 与容抗 $X_C(\omega_0)$ **大小相等、符号相反，彼此彻底归零**！

此时，电路对外仿佛电感和电容“双双隐身”，总阻抗跌到全频段的绝对谷底：
$$\mathbf{Z}(j\omega_0) = R \quad (\text{纯阻性，相角 } \theta = 0^\circ)$$
回路电流一举冲上最大值，且与电源电压完全同相：
$$I_{\max} = \frac{V_m}{R}, \qquad \omega_0 = \frac{1}{\sqrt{LC}}, \qquad f_0 = \frac{1}{2\pi\sqrt{LC}}$$

> **教授提醒**：请立刻对照 `W4-L7` 的无阻尼自然频率！你会惊喜地发现，强迫正弦稳态的串联谐振角频率 $\omega_0 = \frac{1}{\sqrt{LC}}$，与零输入自然响应的固有频率**完全是同一个数**——外部推力的频率精准命中了系统天生的固有频率，这就是共振的统一之美。

## 第 2 幕：高 Q 过压奇观与能量交换（5 V 信号源如何憋出 50 V 高压？）

### 2.1 表面波澜不惊，内部暗流汹涌

很多同学第一次看串联谐振，会犯一个致命直觉错误：“既然谐振时 $\mathbf{V}_L + \mathbf{V}_C = 0$，那电感和电容两端的电压是不是都很小？”

**大错特错！** 让我们算一笔账：
在谐振频率 $\omega_0$ 处，回路电流高达 $\mathbf{I}(\omega_0) = \frac{\mathbf{V}_s}{R}$（设 $\mathbf{V}_s = V_m \angle 0^\circ$）。此时三个元件各自的相量电压为：
$$\mathbf{V}_R = R \mathbf{I} = V_m \angle 0^\circ$$
$$\mathbf{V}_L = j\omega_0 L \cdot \frac{V_m}{R} = \left(\frac{\omega_0 L}{R}\right) V_m \angle +90^\circ = Q V_m \angle +90^\circ$$
$$\mathbf{V}_C = \frac{1}{j\omega_0 C} \cdot \frac{V_m}{R} = \left(\frac{1}{\omega_0 R C}\right) V_m \angle -90^\circ = Q V_m \angle -90^\circ$$

这里冒出了整个谐振理论的灵魂无量纲参数——**品质因数（Quality Factor）$Q$**：
$$Q_{\text{series}} = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 R C} = \frac{1}{R}\sqrt{\frac{L}{C}}$$

看到了吗？虽然 $\mathbf{V}_L$（朝上 $+90^\circ$）与 $\mathbf{V}_C$（朝下 $-90^\circ$）在串联回路总和里**精确相差 $180^\circ$ 互相抵消**（KVL 依然完美满足 $\mathbf{V}_R + \mathbf{V}_L + \mathbf{V}_C = \mathbf{V}_s$），但如果你拿示波器探头单独去量电容或电感两端，它们的幅值竟然被**放大了 $Q$ 倍**：
$$|\mathbf{V}_L(\omega_0)| = |\mathbf{V}_C(\omega_0)| = Q V_m$$

> **工程红灯警示（High-Q Overvoltage Hazard）**：
> 在一个 $Q = 10$ 的串联谐振回路里，哪怕你只输入 $V_m = 5\text{ V}$ 的安全低压正弦源，电感与电容各自两端也会憋出高达 **$50\text{ V}$ 峰值（$100\text{ V}_{\text{pp}}$）** 的高压！如果 $Q = 50$，更是直冲 $250\text{ V}$！
> - **能量守恒没破产**：这并不是凭空造出了能量，而是电感的磁场能 $\frac{1}{2}LI^2$ 与电容的电场能 $\frac{1}{2}CV^2$ 在内部以 $\omega_0$ 的节拍高速“左手倒右手”，电源只需补充电阻 $R$ 每周期消耗掉的那一小部分热量。
> - **物理本质定义**：事实上，品质因数 $Q$ 最根本的物理定义正是：
>   $$Q = 2\pi \cdot \frac{\text{谐振时的峰值储能}}{\text{每周期耗散的能量}}$$
>   损耗 $R$ 越小，系统越像一个几乎无摩擦的秋千，只需微弱推力就能把内部摆幅推到极高——这就是串联谐振的**电压放大效应**。

## 第 3 幕：品质因数 Q、半功率频率与带宽 B（选择性与通频带的黄金权衡）

### 3.1 核心权衡：$Q$ 越高，峰越尖，带宽 $B$ 越窄

在 `W5-L7` 中我们确立了**半功率频率（Half-Power Frequencies，即 $-3\text{ dB}$ 点）** $\omega_1, \omega_2$ 的定义：电路吸收的有功功率跌落到谐振峰值功率一半时的两个边界频率。由于电阻功率 $P(\omega) = \frac{1}{2}|I(\omega)|^2 R$，功率减半等价于电流幅值跌落至最大值的 $\frac{1}{\sqrt{2}} \approx 0.7071$：
$$|I(\omega_{1,2})| = \frac{I_{\max}}{\sqrt{2}} = \frac{V_m}{\sqrt{2}R} \iff |\mathbf{Z}(\omega_{1,2})| = \sqrt{2}R$$

让我们用**三段式教授板书推导**（严格区分公理溯源、纯符号通式与数值代入，绝不混写）彻底打通 Sadiku Section 14.5 的经典例题！

### 3.2 三段式教授板书推导（串联 RLC：Sadiku 14.5 经典高 $Q$ 例题与低 $Q$ 误差对比）

> **例题背景（Sadiku 14.5 经典参数）**：一串联 RLC 电路由 $R = 2\ \Omega$、$L = 1\text{ mH}$、$C = 0.4\ \mu\text{F}$ 组成，外接正弦电压源 $v_s(t) = 5\cos(\omega t)\text{ V}$。求：（1）谐振频率 $\omega_0, f_0$；（2）品质因数 $Q$ 与带宽 $B$；（3）精确半功率频率 $\omega_1, \omega_2$ 与高 $Q$ 对称近似值及其误差；（4）谐振时电流峰值 $I_{\max}$ 与电容峰值电压 $|V_C(\omega_0)|$。

#### ① 公理溯源
1. **串联复阻抗定义**（由 KVL 与元件相量 VCR 导出）：
   $$\mathbf{Z}(j\omega) = R + j\left(\omega L - \frac{1}{\omega C}\right), \qquad |\mathbf{Z}(j\omega)| = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}$$
2. **串联谐振公理**：令总阻抗虚部 $\operatorname{Im}\{\mathbf{Z}(j\omega_0)\} = 0$。
3. **半功率（$-3\text{ dB}$）定义**：$P(\omega_{1,2}) = \frac{1}{2}P_{\max} \iff |\mathbf{Z}(j\omega_{1,2})| = \sqrt{2}R$。

#### ② 纯符号通式
1. **谐振频率通式**：
   $$\omega_0 L - \frac{1}{\omega_0 C} = 0 \implies \omega_0 = \frac{1}{\sqrt{LC}}, \qquad f_0 = \frac{1}{2\pi\sqrt{LC}}$$
2. **品质因数通式**：
   $$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 R C}$$
3. **精确半功率频率通式**：由 $|\mathbf{Z}| = \sqrt{2}R$ 得 $\omega L - \frac{1}{\omega C} = \pm R$，整理为两道一元二次方程 $\omega^2 \mp \frac{R}{L}\omega - \frac{1}{LC} = 0$，舍去负根得：
   $$\omega_1 = -\frac{R}{2L} + \sqrt{\left(\frac{R}{2L}\right)^2 + \frac{1}{LC}}, \qquad \omega_2 = +\frac{R}{2L} + \sqrt{\left(\frac{R}{2L}\right)^2 + \frac{1}{LC}}$$
4. **几何平均与带宽精确恒等式**（对**任意 $Q$ 值**均严格成立！）：
   $$\omega_1 \omega_2 = \left(\frac{R}{2L}\right)^2 + \frac{1}{LC} - \left(\frac{R}{2L}\right)^2 = \frac{1}{LC} = \omega_0^2 \implies \omega_0 = \sqrt{\omega_1 \omega_2}$$
   $$B = \omega_2 - \omega_1 = \frac{R}{L} = \frac{\omega_0}{Q}, \qquad B_f = \frac{B}{2\pi} = \frac{f_0}{Q}$$
5. **高 $Q$ 对称近似公式**（当 $Q \ge 10$ 时，$\left(\frac{R}{2L}\right)^2 = \left(\frac{\omega_0}{2Q}\right)^2 \ll \omega_0^2$）：
   $$\omega_{1,\text{approx}} \approx \omega_0 - \frac{B}{2}, \qquad \omega_{2,\text{approx}} \approx \omega_0 + \frac{B}{2}$$
6. **谐振电流与电容电压峰值通式**：
   $$I_{\max} = \frac{V_m}{R}, \qquad |V_C(\omega_0)| = |V_L(\omega_0)| = Q V_m$$

#### ③ 代入数值逐步化简（Python 精确验算）
已知 $R = 2\ \Omega$，$L = 1 \times 10^{-3}\text{ H}$，$C = 0.4 \times 10^{-6}\text{ F}$，$V_m = 5\text{ V}$：

1. **谐振频率**：
   $$\omega_0 = \frac{1}{\sqrt{(1 \times 10^{-3})(0.4 \times 10^{-6})}} = \frac{1}{\sqrt{4 \times 10^{-10}}} = 50{,}000\text{ rad/s} = 50\text{ krad/s}$$
   $$f_0 = \frac{50{,}000}{2\pi} \approx 7{,}957.75\text{ Hz} \approx 7.96\text{ kHz}$$
2. **品质因数与带宽**：
   $$Q = \frac{\omega_0 L}{R} = \frac{50{,}000 \times 10^{-3}}{2} = 25$$
   $$B = \frac{\omega_0}{Q} = \frac{50{,}000}{25} = 2{,}000\text{ rad/s} \quad \left(B_f = \frac{2{,}000}{2\pi} \approx 318.31\text{ Hz}\right)$$
3. **精确半功率频率 vs 高 $Q$ 近似对比**：
   令 $\alpha = \frac{R}{2L} = \frac{2}{2 \times 10^{-3}} = 1{,}000\text{ rad/s}$：
   $$\sqrt{\alpha^2 + \omega_0^2} = \sqrt{1{,}000^2 + 50{,}000^2} = \sqrt{2.501 \times 10^9} \approx 50{,}009.999\text{ rad/s}$$
   $$\omega_1 = -1{,}000 + 50{,}009.999 = 49{,}009.999\text{ rad/s}, \qquad \omega_2 = +1{,}000 + 50{,}009.999 = 51{,}009.999\text{ rad/s}$$
   - **验算几何平均**：$\sqrt{49{,}009.999 \times 51{,}009.999} = 50{,}000.000\text{ rad/s} = \omega_0$（严格吻合！）。
   - **高 $Q$ 对称近似**（因 $Q = 25 \ge 10$）：
     $$\omega_{1,\text{approx}} = 50{,}000 - 1{,}000 = 49{,}000\text{ rad/s}, \qquad \omega_{2,\text{approx}} = 50{,}000 + 1{,}000 = 51{,}000\text{ rad/s}$$
   - **相对误差**：仅 **$0.020\%$**！完全满足工程精度要求。
4. **谐振电流与惊人的电容过压**：
   $$I_{\max} = \frac{5}{2} = 2.5\text{ A}, \qquad |V_C(\omega_0)| = |V_L(\omega_0)| = 25 \times 5 = 125\text{ V}$$

> **教授加餐：什么时候不能偷懒用高 $Q$ 对称近似？**
> 下表由 Python 精确计算了不同 $Q$ 值下的误差。一旦 $Q < 10$（例如 $Q=2$ 或面包板实操的 $Q=3.16$），谐振曲线向左显著偏斜，对称近似的误差会立刻飙升到 $1\%\sim 4\%$，此时**必须使用精确二次方程根公式**！

| 场景对比 | $Q$ 值 | 精确 $\omega_1 / \omega_0$ | 近似 $\omega_1 / \omega_0$ | $\omega_1$ 相对误差 | 结论 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| Sadiku 14.5 高 $Q$ 例题 | $25.0$ | $0.9802$ | $0.9800$ | $0.020\%$ | 高 $Q$ 对称近似极准 |
| 临界判据（本课例题） | $10.0$ | $0.9512$ | $0.9500$ | $0.131\%$ | $Q \ge 10$ 可放心近似 |
| 3D 面包板实操参数 | $3.16$ | $0.8543$ | $0.8419$ | $1.454\%$ | 明显非对称，须用精确式 |
| 低 $Q$ 宽带回路 | $2.0$ | $0.7808$ | $0.7500$ | $3.942\%$ | 严禁对称近似！ |

## 第 4 幕：并联 RLC 谐振与串并联对偶宇宙（收音机调谐选台原理）

### 4.1 对偶思维：把串联里的“阻抗、电压、电流”全盘镜像！

现在把 $R$、$L$、$C$ 改接为**并联**，由电流源 $\mathbf{I}_s$ 激励（比如收音机天线感应出的微弱高频电流）。此时用**复导纳（Admittance）** $\mathbf{Y}(j\omega) = \frac{1}{\mathbf{Z}(j\omega)}$ 来分析简直如丝般顺滑：
$$\mathbf{Y}(j\omega) = \frac{1}{R} + j\left(\omega C - \frac{1}{\omega L}\right)$$

当导纳虚部（总电纳）精确抵消时，即 $\omega_0 C = \frac{1}{\omega_0 L}$：
- **谐振频率完全相同**：$\omega_0 = \frac{1}{\sqrt{LC}}$；
- **总导纳最小、总阻抗最大**：$\mathbf{Y}(\omega_0) = \frac{1}{R} \implies \mathbf{Z}(\omega_0) = R$（串联是阻抗谷底，并联是阻抗尖峰！）；
- **端电压冲上峰值**：$V_{\max} = I_m R$（这就是老式 AM/FM 收音机选台的秘诀——旋转可变电容 $C$ 改变 $\omega_0$，只有目标电台频率能激发最大谐振电压，其余干扰电台全被低阻抗“旁路短接”掉了！）；
- **内部 $Q$ 倍环流奇观**：虽然外部电流源只送进来 $I_m$，但在电感与电容支路之间却奔腾着 $Q$ 倍大小、反相 $180^\circ$ 互相抵消的循环大电流：
  $$|\mathbf{I}_L(\omega_0)| = |\mathbf{I}_C(\omega_0)| = Q I_m, \qquad \mathbf{I}_L + \mathbf{I}_C = 0$$

### 4.2 串联 vs 并联 RLC 谐振对偶速查表

| 核心物理量 | 串联 RLC 谐振（Sadiku 14.5） | 并联 RLC 谐振（Sadiku 14.6） | 对偶记忆口诀 |
| :--- | :--- | :--- | :--- |
| 谐振角频率 $\omega_0$ | $\dfrac{1}{\sqrt{LC}}$ | $\dfrac{1}{\sqrt{LC}}$ | 频率公式完全一致 |
| 谐振时阻抗 $\mathbf{Z}(\omega_0)$ | **最小值** $R$（纯阻性） | **最大值** $R$（纯阻性） | 串最小（通流）、并最大（保压） |
| 品质因数 $Q$ | $\dfrac{\omega_0 L}{R} = \dfrac{1}{\omega_0 R C}$ | $\dfrac{R}{\omega_0 L} = \omega_0 R C$ | 串联 $R$ 越小 $Q$ 越高；并联 $R$ 越大 $Q$ 越高 |
| 带宽 $B = \omega_2 - \omega_1$ | $\dfrac{\omega_0}{Q} = \dfrac{R}{L}$ | $\dfrac{\omega_0}{Q} = \dfrac{1}{RC}$ | 永远满足 $B = \omega_0 / Q$ |
| 半功率几何平均 | $\omega_0 = \sqrt{\omega_1 \omega_2}$ | $\omega_0 = \sqrt{\omega_1 \omega_2}$ | 严格成立（无论 $Q$ 大小） |
| 谐振内部放大效应 | **电压放大**：$\|V_L\|=\|V_C\| = Q V_m$ | **电流放大**：$\|I_L\|=\|I_C\| = Q I_m$ | 串联防电容过压，并联防电感过流 |

### 4.3 三段式教授板书推导（并联 RLC：Sadiku 14.6 经典调谐回路例题）

> **例题背景**：一台选频接收机前端采用并联 RLC 谐振回路，已知 $R = 1\text{ k}\Omega$、$L = 4\text{ mH}$、$C = 0.1\ \mu\text{F}$，等效天线输入电流源 $i_s(t) = 10\cos(\omega t)\text{ mA}$。求：（1）$\omega_0$ 与 $f_0$；（2）品质因数 $Q$ 与带宽 $B$；（3）精确半功率频率 $\omega_1, \omega_2$ 与对称近似误差；（4）谐振时端口峰值电压 $V_{\max}$ 与电感/电容支路环流幅值 $|I_L|, |I_C|$。

#### ① 公理溯源
1. **并联复导纳定义**（由 KCL 与元件相量 VCR 导出）：
   $$\mathbf{Y}(j\omega) = \frac{1}{R} + j\left(\omega C - \frac{1}{\omega L}\right), \qquad |\mathbf{Y}(j\omega)| = \sqrt{\frac{1}{R^2} + \left(\omega C - \frac{1}{\omega L}\right)^2}$$
2. **并联谐振公理**：令总电纳 $\operatorname{Im}\{\mathbf{Y}(j\omega_0)\} = 0$。
3. **半功率（$-3\text{ dB}$）定义**：$|V(\omega_{1,2})| = \frac{V_{\max}}{\sqrt{2}} \iff |\mathbf{Y}(j\omega_{1,2})| = \frac{\sqrt{2}}{R}$。

#### ② 纯符号通式
1. **谐振频率与品质因数**：
   $$\omega_0 = \frac{1}{\sqrt{LC}}, \qquad Q = \frac{R}{\omega_0 L} = \omega_0 R C$$
2. **精确半功率频率与带宽**：由 $\omega C - \frac{1}{\omega L} = \pm \frac{1}{R}$ 得：
   $$\omega_1 = -\frac{1}{2RC} + \sqrt{\left(\frac{1}{2RC}\right)^2 + \frac{1}{LC}}, \qquad \omega_2 = +\frac{1}{2RC} + \sqrt{\left(\frac{1}{2RC}\right)^2 + \frac{1}{LC}}$$
   $$B = \omega_2 - \omega_1 = \frac{1}{RC} = \frac{\omega_0}{Q}$$
3. **谐振端电压与支路环流**：
   $$V_{\max} = I_m R, \qquad |I_L(\omega_0)| = |I_C(\omega_0)| = Q I_m$$

#### ③ 代入数值逐步化简（Python 精确验算）
已知 $R = 1{,}000\ \Omega$，$L = 4 \times 10^{-3}\text{ H}$，$C = 0.1 \times 10^{-6}\text{ F}$，$I_m = 10\text{ mA}$：

1. **谐振频率**：
   $$\omega_0 = \frac{1}{\sqrt{(4 \times 10^{-3})(0.1 \times 10^{-6})}} = \frac{1}{\sqrt{4 \times 10^{-10}}} = 50{,}000\text{ rad/s}, \qquad f_0 = \frac{50{,}000}{2\pi} \approx 7{,}957.75\text{ Hz}$$
2. **品质因数与带宽**：
   $$Q = \omega_0 R C = (50{,}000)(1{,}000)(0.1 \times 10^{-6}) = 5$$
   $$B = \frac{\omega_0}{Q} = \frac{50{,}000}{5} = 10{,}000\text{ rad/s} \quad \left(B_f = \frac{10{,}000}{2\pi} \approx 1{,}591.55\text{ Hz}\right)$$
3. **精确半功率频率 vs 对称近似对比**：
   令 $\alpha = \frac{1}{2RC} = \frac{1}{2 \times 1{,}000 \times 10^{-7}} = 5{,}000\text{ rad/s}$：
   $$\sqrt{\alpha^2 + \omega_0^2} = \sqrt{5{,}000^2 + 50{,}000^2} \approx 50{,}249.378\text{ rad/s}$$
   $$\omega_1 = 45{,}249.378\text{ rad/s} \ (f_1 \approx 7.20\text{ kHz}), \qquad \omega_2 = 55{,}249.378\text{ rad/s} \ (f_2 \approx 8.79\text{ kHz})$$
   - **对称近似**（因为 $Q = 5 < 10$，已产生可见偏差）：$\omega_{1,\text{approx}} = 45{,}000\text{ rad/s}$（误差 $0.551\%$），$\omega_{2,\text{approx}} = 55{,}000\text{ rad/s}$（误差 $0.451\%$）。
4. **端口电压峰值与内部环流**：
   $$V_{\max} = (10 \times 10^{-3})(1{,}000) = 10\text{ V}, \qquad |I_L(\omega_0)| = |I_C(\omega_0)| = 5 \times 10\text{ mA} = 50\text{ mA}$$

> **收音机超高 $Q$ 选台延伸（Sadiku Example 14.9）**：若把并联电阻提高到 $R = 8\text{ k}\Omega$ 并配 $L = 0.2\text{ mH}, C = 8\ \mu\text{F}$，则 $\omega_0 = 25{,}000\text{ rad/s}$，$Q = \omega_0 R C = 1{,}600$，带宽 $B_f$ 骤缩至区区 **$2.49\text{ Hz}$**！这正是窄带选频电路从万千杂波中精准锁定单一载波电台的威力。

## 第 5 幕：3D 面包板串联 RLC 扫频找谐振峰实操（工程安全缩放与实测误差溯源）

### 5.1 为什么选 $L = 10\text{ mH}, C = 100\text{ nF}, R = 100\ \Omega$？

书本上的例题常常出现 $R = 2\ \Omega$、电流高达 $2.5\text{ A}$、电容憋出 $125\text{ V}$ 的参数——这在真实面包板上会瞬间烧焦电阻并触发信号发生器过载保护！在 Breadboard Lab 的 3D 实操舞台中，我们采用了严格缩放的**黄金安全实验室参数**：

- **元件清单**：$L = 10\text{ mH}$、$C = 100\text{ nF}$（50 V 无极性薄膜电容）、$R = 100\ \Omega$（1/4 W）；
- **理论工作点**（Python 精确验算）：
  - 谐振频率：$f_0 = \frac{1}{2\pi\sqrt{10 \times 10^{-3} \times 100 \times 10^{-9}}} \approx \mathbf{5.03\text{ kHz}}$（$\omega_0 \approx 31{,}622.78\text{ rad/s}$，恰好落在普通函数发生器与音频示波器最舒适的频段！）；
  - 谐振电抗：$\omega_0 L = \frac{1}{\omega_0 C} \approx \mathbf{316.23\ \Omega}$；
  - 理论品质因数：$Q = \frac{316.23}{100} \approx \mathbf{3.16}$；
  - 理论带宽：$B_f = \frac{5.03\text{ kHz}}{3.16} \approx \mathbf{1.59\text{ kHz}}$（精确 $f_1 \approx 4.30\text{ kHz}$，$f_2 \approx 5.89\text{ kHz}$）；
- **安全扫频激励**：函数信号发生器输出 **$1.0\text{ V}_{\text{pp}}$** 正弦波，从 $1\text{ kHz}$ 缓慢扫频至 $15\text{ kHz}$。此时最大回路电流仅 $5\text{ mA}$ 峰值，电阻耗散功率仅 $1.25\text{ mW}$，而在 $f_0 \approx 5.03\text{ kHz}$ 处，你可以在电容两端安全观测到高达 **$3.16\text{ V}_{\text{pp}}$** 的清脆过压峰——既震撼，又绝不击穿任何元件！

### 5.2 面包板扫频实操三步法（务必防共地短路！）

1. **接法排布（把被测元件放到最下端接地）**：
   - 若要测**回路电流幅值与相位**（通过 $v_R = i R$ 间接观测），按 `信号源(+) → L → C → R → GND` 串联，CH1 探头接信号源正端，CH2 探头接 $R$ 上端，两只黑色地夹**同接 GND 轨道**。缓慢旋动频率旋钮，当 CH2 波形幅值达到最大且与 CH1 **完全同相（相位差 $\Delta\phi = 0^\circ$）** 时，频率读数即为实测 $f_0$！
   - 若要亲眼见证**高 $Q$ 电容过压峰**，将 $C$ 换到最下端接地（`信号源(+) → R → L → C → GND`），CH2 探头接 $C$ 上端。扫频至 $f_0 \approx 5.03\text{ kHz}$ 附近，CH2 幅值将冲破输入 $1\text{ V}_{\text{pp}}$ 直达 $3.16\text{ V}_{\text{pp}}$，且相位滞后 CH1 恰好 **$90^\circ$**！
2. **寻找 $-3\text{ dB}$ 带宽 $B_f$**：在测 $v_R$ 模式下，记下谐振峰值 $V_{R,\max}$，向低频与高频微调旋钮，分别找到幅值跌落至 $0.707\,V_{R,\max}$ 时的 $f_1$ 与 $f_2$，计算实测带宽 $B_{\text{meas}} = f_2 - f_1$ 与实测品质因数 $Q_{\text{meas}} = f_0 / B_{\text{meas}}$。
3. **真实工程排障（为什么实测 $Q$ 比 $3.16$ 小？）**：
   打开 3D 舞台的“启用真实寄生参数”开关后你会发现：真实 $10\text{ mH}$ 电感铜线自带约 $R_L \approx 20\ \Omega$ 直流内阻，标准函数发生器自带 $R_{\text{gen}} = 50\ \Omega$ 输出阻抗。它们与外接 $R = 100\ \Omega$ 串联，使回路有效总阻变为 $R_{\text{eff}} = 100 + 20 + 50 = 170\ \Omega$！于是：
   $$Q_{\text{real}} = \frac{316.23}{170} \approx 1.86 < 3.16$$
   电容峰值电压随之回落至约 $1.86\text{ V}_{\text{pp}}$，带宽变宽至约 $2.71\text{ kHz}$。**能看懂理想模型与真实寄生参数的这一差距，你就真正踏入了硬件工程师的大门！**
