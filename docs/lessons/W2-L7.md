# W2-L7：戴维南与诺顿定理（含受控源测试源法与面包板实测）

> **教授开场白**：欢迎回到 Breadboard Lab！前两节课我们刚刚练熟了叠加定理的“独立源置零”以及电压源与电流源的“电源变换”。今天我们要迎来线性电路分析中**工程价值最高、考试区分度最大**的王牌工具——**戴维南定理（Thevenin's Theorem）与诺顿定理（Norton's Theorem）**。学完今天这一课，你不仅能把几十个元件的复杂网络打包成一个“黑盒”，更能彻底攻克电路学里最容易踩坑的硬骨头——**含受控源电路的测试源法**，并亲手在 3D 面包板上完成安全实测。

## 第 1 幕：黑盒等效直觉与戴维南定理公理

### 1.1 为什么工程上离不开戴维南黑盒？（Boylestad Ch.9 坡度直觉）

设想你正在实验室里调试一台音频功放的输出级，或者给一块传感器主板匹配不同规格的负载电阻 $R_L$。前面的供电与偏置网络包含 10 个电阻、3 个电源甚至晶体管受控源——这部分电路**已经焊死在 PCB 上、99% 固定不变**；唯一变化的是接在输出端口 $a\text{–}b$ 上的负载 $R_L$（你需要依次测试 $R_L = 6\ \Omega$、$16\ \Omega$、$36\ \Omega$ 甚至 50 个不同阻值）。

如果每次换一个 $R_L$，你都要重新列一遍节点方程或网孔方程，工作量会爆炸。法国电报工程师 **Léon Charles Thévenin** 在 1883 年提出了一个极其优雅的洞察：

> **戴维南定理（Sadiku Section 4.5）**：任何由独立源、线性受控源和线性电阻构成的**线性双端网络**，从外部负载端口 $a\text{–}b$ 看进去，对外电路的伏安特性都可以**完全等效**为一个独立电压源 $V_{Th}$ 与一个电阻 $R_{Th}$ 的串联组合：
> - **戴维南等效电压 $V_{Th}$**：等于将负载拆掉后，端口 $a\text{–}b$ 之间的**开路电压** $v_{oc}$（open-circuit voltage）。
> - **戴维南等效电阻 $R_{Th}$**：等于将网络内部所有**独立源置零**后，从端口 $a\text{–}b$ 看进去的**等效输入电阻** $R_{in}$。

一旦把前面 99% 固定不变的电路“打包”成 1 个 $V_{Th}$ 和 1 个 $R_{Th}$，无论后面怎么更换负载 $R_L$，负载电流和电压都只需一行串联分压/欧姆定律就能秒算：

$$I_L = \frac{V_{Th}}{R_{Th} + R_L}, \qquad V_L = V_{Th} \cdot \frac{R_L}{R_{Th} + R_L}$$

> **教授敲黑板（边界提醒）**：等效仅对**端口 $a\text{–}b$ 外部**（即负载 $R_L$ 的电压、电流、功率）完全成立；黑盒**内部**的功率损耗并不等于原电路内部的实际功率损耗！

## 第 2 幕：Case 1 纯独立源电路 — 独立源置零串并联法

当黑盒内部**只有独立电源和线性电阻（不含任何受控源）**时，我们称其为 **Case 1**。此时回想我们在 `W2-L5 叠加置零` 中学过的铁律：
- 独立电压源置零 $\implies$ 电压为 $0\text{ V}$ $\implies$ **短路（Short Circuit）**；
- 独立电流源置零 $\implies$ 电流为 $0\text{ A}$ $\implies$ **开路（Open Circuit）**。

置零后，整个黑盒退化成一个纯电阻网络，直接从端口 $a\text{–}b$ 往里看做串并联化简，即可得到 $R_{Th}$。

### 2.2 三段式教授板书推导（Case 1）

#### ① 公理溯源（Origin）
- **求 $R_{Th}$**：依据戴维南定理 Case 1，网络中无受控源，将独立电压源置零（短路）、独立电流源置零（开路）后，由电阻串并联等效公理求端口看入电阻。
- **求 $V_{Th}$**：端口 $a\text{–}b$ 开路时，端口电流 $i_a = 0$，由欧姆定律可知串联电阻 $R_3$ 上无压降，故 $V_{Th} = v_a = v_1$。对节点 $1$ 应用基尔霍夫电流定律（KCL，流出电流之和等于流入电流之和）。

#### ② 纯符号通式（General Formula）
1. **等效电阻通式**：$R_1$ 与 $R_2$ 并联后再与 $R_3$ 串联：
$$R_{Th} = R_3 + \left(R_1 \parallel R_2\right) = R_3 + \frac{R_1 R_2}{R_1 + R_2}$$
2. **开路电压通式**：节点 $1$ 的 KCL 方程为：
$$\frac{v_1 - V_s}{R_1} + \frac{v_1}{R_2} = I_s$$
移项合并 $v_1$ 项：
$$v_1 \left(\frac{1}{R_1} + \frac{1}{R_2}\right) = \frac{V_s}{R_1} + I_s \implies V_{Th} = v_1 = \frac{V_s R_2 + I_s R_1 R_2}{R_1 + R_2}$$
3. **接回任意负载 $R_L$ 后的负载电流通式**：
$$I_L = \frac{V_{Th}}{R_{Th} + R_L}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
已知 $V_s = 32\text{ V}$，$I_s = 2\text{ A}$，$R_1 = 4\ \Omega$，$R_2 = 12\ \Omega$，$R_3 = 1\ \Omega$：

1. **计算 $R_{Th}$**：
$$R_{Th} = 1 + \frac{4 \times 12}{4 + 12} = 1 + \frac{48}{16} = 1 + 3 = 4\ \Omega$$

2. **计算 $V_{Th}$**：
$$\frac{v_1 - 32}{4} + \frac{v_1}{12} = 2$$
两边同乘最小公倍数 $12$：
$$3(v_1 - 32) + v_1 = 24$$
$$3v_1 - 96 + v_1 = 24 \implies 4v_1 = 120 \implies v_1 = 30\text{ V}$$
由于开路时流过 $R_3 = 1\ \Omega$ 的电流为 $0$，因此：
$$V_{Th} = v_{oc} = v_1 = 30\text{ V}$$

3. **体会黑盒威力：秒算三组不同负载 $R_L$**：
- 当 $R_L = 6\ \Omega$ 时：$I_L = \dfrac{30}{4 + 6} = 3\text{ A}$，$V_L = 3 \times 6 = 18\text{ V}$；
- 当 $R_L = 16\ \Omega$ 时：$I_L = \dfrac{30}{4 + 16} = 1.5\text{ A}$，$V_L = 1.5 \times 16 = 24\text{ V}$；
- 当 $R_L = 36\ \Omega$ 时：$I_L = \dfrac{30}{4 + 36} = 0.75\text{ A}$，$V_L = 0.75 \times 36 = 27\text{ V}$。

## 第 3 幕：Case 2 含受控源电路 — 外加测试源法与负等效电阻剖析（核心必讲！）

> **教授红色警戒**：这是整门电路学考试中**失分率最高**的知识点！很多同学做完 Case 1 就形成肌肉记忆：“求 $R_{Th}$ 不就是把所有电源置零，然后直接串并联吗？”
> **错！大错特错！**

### 3.1 为什么受控源绝对不能置零？

独立电源是外部施加的“固定激励”，置零意味着撤掉外部激励；而**受控源（Dependent Source）**本质上是放大器、晶体管、运放等内部物理器件的**耦合关系**，它受电路内部的电压或电流控制，**是电路结构的一部分**，绝不是外部激励！
- **铁律**：求 $R_{Th}$ 时，**只将所有独立源置零，必须完整保留所有受控源及其控制量**。
- 一旦保留了受控源，你就再也无法用简单的“串联/并联”公式直接看出端口电阻。怎么办？回到电阻最原始的定义——**欧姆定律**！

### 3.2 外加测试源法（Test Source Method）

在将内部所有独立源置零、保留全部受控源后，我们像手持一台理想欧姆表一样，在端口 $a\text{–}b$ 人为接上一个已知的外部测试源：
- **做法 A（外加测试电压源）**：在端口 $a\text{–}b$ 施加 $v_o = 1\text{ V}$（$a$ 正 $b$ 负），用节点分析或网孔分析求出**流入端口 $a$** 的测试电流 $i_o$，则：
$$R_{Th} = \frac{v_o}{i_o} = \frac{1\text{ V}}{i_o}$$
- **做法 B（外加测试电流源）**：在端口 $a\text{–}b$ 注入 $i_o = 1\text{ A}$（流入端口 $a$），求出端口电压 $v_o = v_{ab}$，则：
$$R_{Th} = \frac{v_o}{i_o} = \frac{v_o}{1\text{ A}}$$

> **为什么可以随便选 $1\text{ V}$ 或 $1\text{ A}$？** 因为网络完全由线性元件构成（齐次性）：如果你把测试电压翻倍为 $v_o = 2\text{ V}$，电流 $i_o$ 也会严格翻倍，比值 $R_{Th} = v_o / i_o$ **绝对不变**！选 $1\text{ V}$ 或 $1\text{ A}$ 纯粹是为了让算术最简单。

### 3.4 三段式教授板书推导（Case 2 测试源法）

#### ① 公理溯源（Origin）
- **求 $V_{Th}$**：端口 $a\text{–}b$ 开路时流过 $R_3$ 的电流为 $0$，故 $V_{Th} = v_a = v_1$。对节点 $1$ 列写 KCL，并代入受控源约束方程 $v_x = v_1$。
- **求 $R_{Th}$**：因网络含受控电压源 $\mu v_x$（$\mu = 2$），遵循 Case 2 原则：将独立电流源 $I_s$ 置零（开路），**保留受控电压源 $\mu v_x$**；在端口 $a\text{–}b$ 施加测试电压源 $v_o$（令 $v_a = v_o$），联立节点 $1$ 的 KCL 与端口支路欧姆定律求出流入端口电流 $i_o$，由 $R_{Th} = v_o / i_o$ 定出等效电阻。

#### ② 纯符号通式（General Formula）
1. **开路电压 $V_{Th}$ 通式**（$v_x = v_1$）：
$$\frac{v_1 - \mu v_1}{R_1} + \frac{v_1}{R_2} = I_s \implies v_1 \left(\frac{1 - \mu}{R_1} + \frac{1}{R_2}\right) = I_s \implies V_{Th} = \frac{I_s R_1 R_2}{(1 - \mu)R_2 + R_1}$$
2. **外加测试电压源 $v_o$ 时的节点 $1$ KCL 通式**（$I_s = 0$，$v_a = v_o$，$v_x = v_1$）：
$$\frac{v_1 - \mu v_1}{R_1} + \frac{v_1}{R_2} + \frac{v_1 - v_o}{R_3} = 0$$
解出 $v_1$：
$$v_1 \left(\frac{1 - \mu}{R_1} + \frac{1}{R_2} + \frac{1}{R_3}\right) = \frac{v_o}{R_3}$$
流入端口 $a$ 的测试电流 $i_o$ 与戴维南电阻通式：
$$i_o = \frac{v_o - v_1}{R_3}, \qquad R_{Th} = \frac{v_o}{i_o} = R_3 + \frac{R_1 R_2}{(1 - \mu)R_2 + R_1}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
已知 $\mu = 2$，$I_s = 5\text{ A}$，$R_1 = 4\ \Omega$，$R_2 = 2\ \Omega$，$R_3 = 6\ \Omega$：

1. **计算开路电压 $V_{Th}$**：
$$\frac{v_1 - 2v_1}{4} + \frac{v_1}{2} = 5$$
$$-\frac{v_1}{4} + \frac{2v_1}{4} = 5 \implies \frac{v_1}{4} = 5 \implies v_1 = 20\text{ V}$$
故：
$$V_{Th} = v_{oc} = 20\text{ V}$$

2. **外加测试源 $v_o = 1\text{ V}$ 计算 $R_{Th}$**（$I_s = 5\text{ A}$ 开路，保留 $2v_x$）：
$$\frac{v_1 - 2v_1}{4} + \frac{v_1}{2} + \frac{v_1 - 1}{6} = 0$$
先化简前两项：$-\dfrac{v_1}{4} + \dfrac{v_1}{2} = \dfrac{v_1}{4}$，方程变为：
$$\frac{v_1}{4} + \frac{v_1 - 1}{6} = 0$$
两边同乘 $12$：
$$3v_1 + 2(v_1 - 1) = 0 \implies 5v_1 = 2 \implies v_1 = 0.4\text{ V}$$
求流入端口 $a$ 的测试电流 $i_o$：
$$i_o = \frac{v_o - v_1}{R_3} = \frac{1 - 0.4}{6} = \frac{0.6}{6} = 0.1\text{ A}$$
因此，戴维南等效电阻为：
$$R_{Th} = \frac{v_o}{i_o} = \frac{1\text{ V}}{0.1\text{ A}} = 10\ \Omega$$

> **错误反例警示**：如果你把受控源 $2v_x$ 误当成独立电压源短路掉，算出的结果是 $R_{\text{错}} = 6 + (4 \parallel 2) = 6 + \frac{4}{3} = 7.33\ \Omega \neq 10\ \Omega$！受控源的反馈效应将端口电阻从 $7.33\ \Omega$ 抬升到了 $10\ \Omega$。

3. **通用法 $R_{Th} = v_{oc} / i_{sc}$ 交叉验算**：
保留全部独立源与受控源，将端口 $a\text{–}b$ 短路（$v_a = 0$），列节点 $1$ 的 KCL：
$$\frac{v_{1,\text{sc}} - 2v_{1,\text{sc}}}{4} + \frac{v_{1,\text{sc}}}{2} + \frac{v_{1,\text{sc}} - 0}{6} = 5 \implies \left(\frac{1}{4} + \frac{1}{6}\right)v_{1,\text{sc}} = 5 \implies \frac{5}{12}v_{1,\text{sc}} = 5 \implies v_{1,\text{sc}} = 12\text{ V}$$
端口短路电流 $i_{sc} = \dfrac{v_{1,\text{sc}}}{6} = \dfrac{12}{6} = 2\text{ A}$，于是：
$$R_{Th} = \frac{v_{oc}}{i_{sc}} = \frac{20\text{ V}}{2\text{ A}} = 10\ \Omega \quad \checkmark\text{（与测试源法完全一致！）}$$

### 3.5 深度拓展：当 $R_{Th} < 0$（负等效电阻）出现时意味着什么？

考虑一个**不含任何独立源、仅含受控源**的极简网络：端口 $a\text{–}b$ 之间并联一个 $R_1 = 4\ \Omega$ 电阻（向下流过电流 $i_x$）和一个受控电流源 $2i_x$（箭头向上指向端口 $a$）。
1. **为什么通用法 $v_{oc}/i_{sc}$ 彻底失效？** 因为内部没有任何独立源，端口开路时 $v_{oc} = 0\text{ V}$，短路时 $i_{sc} = 0\text{ A}$，$R_{Th} = 0/0$ 无定义！**此时只能用测试源法！**
2. **施加测试源 $v_o = 1\text{ V}$**：
   - 流下 $R_1$ 的控制电流：$i_x = \dfrac{v_o}{R_1} = \dfrac{1}{4} = 0.25\text{ A}$；
   - 受控电流源向上注入端口 $a$ 的电流：$2i_x = 0.5\text{ A}$；
   - 端口 $a$ 的 KCL：$i_o + 2i_x = i_x \implies i_o = -i_x = -0.25\text{ A}$；
   - 等效电阻：
   $$R_{Th} = \frac{v_o}{i_o} = \frac{1\text{ V}}{-0.25\text{ A}} = -4\ \Omega < 0$$
3. **物理意义解读**：
   - 算出了负数，千万别以为自己算错了！$i_o = -0.25\text{ A}$ 意味着你在端口施加 $+1\text{ V}$ 正电压时，电流没有“被网络吸收”，反而从网络内部**向外倒灌流出**；
   - 按无源符号约定，网络吸收功率 $p = v_o i_o = (1\text{ V})(-0.25\text{ A}) = -0.25\text{ W} < 0$，即**内部有源受控源正在向外电路提供 $0.25\text{ W}$ 净功率**。
   - 在真实模拟电子工程中，这种特性被称为**有源负阻（Active Negative Resistance）**，广泛用于运放负阻抗变换器（NIC）与正反馈振荡器中。

## 第 4 幕：诺顿定理与戴维南↔诺顿端口特性线

### 4.1 诺顿定理（Sadiku Section 4.6）与对偶互换

1926 年，贝尔实验室工程师 **Edward Lawry Norton** 提出了戴维南定理的电流源对偶版本：

> **诺顿定理**：任何线性双端网络从端口 $a\text{–}b$ 看进去，都可以等效为一个独立电流源 $I_N$ 与一个电阻 $R_N$ 的**并联**组合：
> - **诺顿电流 $I_N$**：等于将端口 $a\text{–}b$ **短路**时的短路电流 $i_{sc}$；
> - **诺顿电阻 $R_N$**：与戴维南电阻**完全相同**，即 $R_N = R_{Th}$。

结合我们在 `W2-L6 电源变换` 中学过的互换公式，戴维南与诺顿等效电路完全是同一枚硬币的两面：

$$V_{Th} = I_N R_{Th}, \qquad I_N = \frac{V_{Th}}{R_{Th}}, \qquad R_N = R_{Th}$$

以第 2 幕 Case 1 例题（$V_{Th} = 30\text{ V}$，$R_{Th} = 4\ \Omega$）为例，它的诺顿等效模型立即可得：$I_N = \frac{30}{4} = 7.5\text{ A}$，$R_N = 4\ \Omega$。

### 4.2 端口 $v\text{–}i$ 特性直线（左舞台 `02` 联动）

对戴维南等效电路的外部端口 $a\text{–}b$（设端口电压为 $v$，**流出**端口 $a$ 进入负载的电流为 $i$）列写 KVL：

$$v = V_{Th} - R_{Th} \cdot i$$

这条方程在 $(i, v)$ 平面上是一条清晰的向下倾斜直线：
- **纵轴截距（$i = 0$，开路）**：$v = V_{Th} = 30\text{ V}$；
- **横轴截距（$v = 0$，短路）**：$i = \dfrac{V_{Th}}{R_{Th}} = I_N = 7.5\text{ A}$；
- **直线斜率**：$\dfrac{\mathrm{d}v}{\mathrm{d}i} = -R_{Th} = -4\ \Omega$；
- **实际工作点**：在图上画出负载线 $v = R_L i$，两条直线的唯一交点 $(I_L, V_L)$ 就是接入该负载后的真实电流与电压！

## 第 5 幕：3D 面包板安全缩放与真实实验室 $R_{Th}$ 实测法（Type C 实操核心）

> **教授实验室安全训话**：在纸上算题用 $4\ \Omega$、$12\ \Omega$、$1\ \Omega$ 非常痛快，但如果你直接拿这三颗电阻插上实验室的面包板，再把直流电源拧到 $32\text{ V}$——**恭喜你，三秒内实验室就会飘起烤焦电阻的蓝烟！**

### 5.1 面包板安全与 $1000\times$ 阻抗缩放铁律

我们来算一笔真实的功耗账（以第 2 幕 Sadiku Example 4.8 原题数值为例）：
- **原题直接搭建的毁灭性后果**：
  - 哪怕端口 $a\text{–}b$ 开路，节点电压 $v_1 = 30\text{ V}$，电阻 $R_2 = 12\ \Omega$ 的功耗就高达 $P_{R_2} = \dfrac{30^2}{12} = 75\text{ W}$！
  - 若端口 $a\text{–}b$ 短路测 $I_N = 7.5\text{ A}$，节点电压 $v_{1,\text{sc}} = 7.5\text{ V}$，电阻 $R_1 = 4\ \Omega$ 功耗飙升至 $P_{R_1} = \dfrac{(32-7.5)^2}{4} = 150.06\text{ W}$，$R_3 = 1\ \Omega$ 功耗高达 $56.25\text{ W}$！而实验室常见的色环碳膜电阻额定功率只有 $0.25\text{ W}$（$250\text{ mW}$），超载高达 **600 倍**！
- **Type C 黄金缩放法则（等比例放大 $1000\times$ 至 $\text{k}\Omega$ 级）**：
  因为原题阻值 $< 100\ \Omega$，在 3D 面包板实测层必须将**所有电阻等比例放大 $1000\times$**（$4\ \Omega \to 4\text{ k}\Omega$、$12\ \Omega \to 12\text{ k}\Omega$、$1\ \Omega \to 1\text{ k}\Omega$），同时保持电压源 $V_s = 32\text{ V}$ 不变、将独立电流源同比例缩小 $1000\times$（$2\text{ A} \to 2\text{ mA}$）。

### 5.2 真实实验室如何安全测量 $R_{Th}$？

在真实的黑盒电路（例如带有内部稳压器或受控源、且无法拆开置零电源的模块）上，**绝对不能把数字万用表拨到欧姆档直接插到带电端口 $a\text{–}b$ 上**（会烧表或读数错乱），也**不要在真实电源上直接用万用表电流档短路强测 $I_N$**（极易烧断万用表保险丝甚至击穿电源输出级；仅在像本课 $\text{k}\Omega$ 级限流保护、$I_N = 7.5\text{ mA}$ 时才安全）。工程上最标准、最安全的两大实测方法是：

1. **半压法（Half-Voltage Method）**：
   - **Step 1**：端口 $a\text{–}b$ 开路，用万用表直流电压档测得 $V_{Th} = 30.00\text{ V}$；
   - **Step 2**：在端口 $a\text{–}b$ 接一只 $10\text{ k}\Omega$ 精密电位器作为可变负载 $R_L$，缓慢旋转旋钮，盯住万用表，直到端口电压恰好下降为开路电压的一半：
   $$V_L = \frac{V_{Th}}{2} = 15.00\text{ V}$$
   - **Step 3**：由串联分压原理 $V_L = V_{Th}\dfrac{R_L}{R_{Th} + R_L} = \dfrac{V_{Th}}{2}$，此时必然有 $R_L = R_{Th}$！将电位器从电路拆下（**断电测量！**），用欧姆档测得其阻值 $4.00\text{ k}\Omega$，即为 $R_{Th}$。

2. **带载双点法（Two-Point Loaded Method）**：
   - 若手头没有电位器，只需找一颗已知阻值的安全负载电阻（例如 $R_L = 6\text{ k}\Omega$），接在端口 $a\text{–}b$ 上测得带载电压 $V_L = 18.00\text{ V}$；
   - 代入分压反推公式，全程零短路风险：
   $$R_{Th} = R_L \left(\frac{V_{Th}}{V_L} - 1\right) = 6\text{ k}\Omega \times \left(\frac{30}{18} - 1\right) = 6\text{ k}\Omega \times \frac{2}{3} = 4\text{ k}\Omega$$
