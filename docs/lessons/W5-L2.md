## 第 1 幕：从微积分到复代数——三大元件的相量关系与 ELI the ICE man

### 1.1 为什么交流电路里不能再只用“电阻”说话？

在第四周（W4-L1/L2）我们吃过苦头：一旦电路里出现电感 $L$ 和电容 $C$，电压和电流的关系就不再是简单的比例常数，而是带有时间导数的微分方程：
- 电阻：$v(t) = R\,i(t)$
- 电感：$v(t) = L\frac{di(t)}{dt}$
- 电容：$i(t) = C\frac{dv(t)}{dt}$

只要处于**正弦稳态**，根据 W5-L1 建立的相量微分法则 $\frac{d}{dt} \longleftrightarrow j\omega$，时域里所有的导数瞬间坍缩为复平面上的**代数乘法**。请看黑板上的三段式严格推导！

### 1.2 三段式教授板书推导：三大元件频域欧姆定律与单元件激励求解

> **例题 1.1**：已知正弦电压源 $v(t) = 12\cos(4000t + 30^\circ)\text{ V}$，分别单独施加在 $L = 5\text{ mH}$ 的纯电感与 $C = 10\ \mu\text{F}$ 的纯电容两端。试从元件时域伏安关系出发，推导频域相量关系，并求出稳态电流 $i_L(t)$ 与 $i_C(t)$。

#### ① 公理溯源（Axiomatic Origin）
依据三大理想无源元件的时域本构方程及正弦稳态相量映射 $\mathcal{P}\{x(t)\} = \mathbf{X}$、$\mathcal{P}\{\frac{dx}{dt}\} = j\omega\mathbf{X}$：
- 电阻本构方程：$v_R(t) = R\,i_R(t)$
- 电感本构方程：$v_L(t) = L\frac{di_L(t)}{dt}$
- 电容本构方程：$i_C(t) = C\frac{dv_C(t)}{dt}$

#### ② 纯符号通式（Pure Symbolic Derivation）
对上述三式两端分别取相量变换，整理出电压相量 $\mathbf{V}$ 与电流相量 $\mathbf{I}$ 的比值（定义该比值为复阻抗 $\mathbf{Z} \triangleq \frac{\mathbf{V}}{\mathbf{I}}$）：

1. **电阻元件**：
   $$\mathbf{V}_R = R\,\mathbf{I}_R \implies \mathbf{Z}_R = \frac{\mathbf{V}_R}{\mathbf{I}_R} = R = R\angle 0^\circ$$
   电压与电流**同相**（相位差 $0^\circ$），与角频率 $\omega$ 无关。

2. **电感元件**：
   $$\mathbf{V}_L = j\omega L\,\mathbf{I}_L \implies \mathbf{Z}_L = \frac{\mathbf{V}_L}{\mathbf{I}_L} = j\omega L = \omega L\angle 90^\circ, \qquad X_L \triangleq \omega L$$
   其中 $X_L = \omega L$ 称为**感抗（Inductive Reactance）**。因为乘以 $j = 1\angle 90^\circ$，所以**电感电压超前电流 $90^\circ$**。由此得纯电感电流相量通式：
   $$\mathbf{I}_L = \frac{\mathbf{V}}{\mathbf{Z}_L} = \frac{V_m\angle\phi_v}{\omega L\angle 90^\circ} = \frac{V_m}{\omega L}\angle(\phi_v - 90^\circ)$$

3. **电容元件**：
   $$\mathbf{I}_C = j\omega C\,\mathbf{V}_C \implies \mathbf{Z}_C = \frac{\mathbf{V}_C}{\mathbf{I}_C} = \frac{1}{j\omega C} = -\frac{j}{\omega C} = \frac{1}{\omega C}\angle -90^\circ, \qquad X_C \triangleq \frac{1}{\omega C}$$
   其中 $X_C = \frac{1}{\omega C}$ 称为**容抗（Capacitive Reactance）**。因为乘以 $-j = 1\angle -90^\circ$，所以**电容电流超前电压 $90^\circ$**（即电压滞后电流 $90^\circ$）。由此得纯电容电流相量通式：
   $$\mathbf{I}_C = \frac{\mathbf{V}}{\mathbf{Z}_C} = j\omega C\,\mathbf{V} = \omega C V_m\angle(\phi_v + 90^\circ)$$

#### ③ 代入数值逐步化简（Numerical Substitution & Simplification）
从 $v(t) = 12\cos(4000t + 30^\circ)\text{ V}$ 提取频域参数：$V_m = 12\text{ V}$，$\phi_v = 30^\circ$，$\omega = 4000\text{ rad/s}$，电压相量 $\mathbf{V} = 12\angle 30^\circ\text{ V}$。

- **电感支路**（$L = 5\times 10^{-3}\text{ H}$）：
  $$X_L = (4000)(5\times 10^{-3}) = 20\ \Omega \implies \mathbf{Z}_L = j20 = 20\angle 90^\circ\ \Omega$$
  $$\mathbf{I}_L = \frac{12\angle 30^\circ}{20\angle 90^\circ} = 0.60\angle(30^\circ - 90^\circ) = 0.60\angle -60^\circ\text{ A}$$
  还原至时域：
  $$i_L(t) = 0.60\cos(4000t - 60^\circ)\text{ A}$$

- **电容支路**（$C = 10\times 10^{-6}\text{ F}$）：
  $$X_C = \frac{1}{(4000)(10\times 10^{-6})} = \frac{1}{0.04} = 25\ \Omega \implies \mathbf{Z}_C = -j25 = 25\angle -90^\circ\ \Omega$$
  $$\mathbf{I}_C = \frac{12\angle 30^\circ}{25\angle -90^\circ} = 0.48\angle(30^\circ - (-90^\circ)) = 0.48\angle 120^\circ\text{ A}$$
  还原至时域：
  $$i_C(t) = 0.48\cos(4000t + 120^\circ)\text{ A}$$

### 1.3 Boylestad 频率直觉与“ELI the ICE man”记忆锚点

同学们千万别死背正负号！Boylestad 第 15 章给出了电路工程师一生受用的两个超级直觉：

1. **口诀锚点——“ELI the ICE man”**（$E$ 代表电动势/电压，$I$ 代表电流）：
   - **E-L-I**：在电感（**L**）中，**E（电压）在 I（电流）前面** $\implies$ 电压超前电流 $90^\circ$（因为电感阻碍电流突变，电流总是慢半拍！）。
   - **I-C-E**：在电容（**C**）中，**I（电流）在 E（电压）前面** $\implies$ 电流超前电压 $90^\circ$（因为电容必须先充进电流，极板电压才能慢慢抬升！）。
2. **极端频率的物理直觉**：
   - **直流极限（$\omega \to 0$）**：$X_L = \omega L \to 0$（电感变**短路**导线）；$X_C = \frac{1}{\omega C} \to \infty$（电容变**开路**断线）。
   - **高频极限（$\omega \to \infty$）**：$X_L = \omega L \to \infty$（电感变**开路**阻断高频）；$X_C = \frac{1}{\omega C} \to 0$（电容变**短路**旁路高频）。

## 第 2 幕：复阻抗 $\mathbf{Z}$ 与复导纳 $\mathbf{Y}$——非相量的复数算子

### 2.1 核心概念警示：复阻抗 $\mathbf{Z}$ 绝对不是相量！

在 Sadiku Section 9.5 中，有一句每个电路学教授都会拍着黑板强调三遍的铁律：

> **概念红线警示**：尽管复阻抗 $\mathbf{Z} = R + jX = |\mathbf{Z}|\angle\theta_Z$ 和相量一样写成复数与极坐标形式，但 **$\mathbf{Z}$ 本身不是相量（NOT a phasor）**！
> - **为什么？** 相量 $\mathbf{V}$ 与 $\mathbf{I}$ 背后隐含了旋转因子 $e^{j\omega t}$，它们对应着真实的时域正弦波 $v(t)$ 和 $i(t)$。当你把两个旋转速度相同的相量相除时：
>   $$\mathbf{Z} = \frac{\mathbf{V}\,e^{j\omega t}}{\mathbf{I}\,e^{j\omega t}} = \frac{\mathbf{V}}{\mathbf{I}}$$
>   时间因子 $e^{j\omega t}$ 被**彻底约掉了**！
> - **本质是什么？** $\mathbf{Z}$ 是一个**静态的频域复数算子（Complex Operator）**。它不随时间旋转，也没有所谓的“时域阻抗正弦波 $z(t)$”；它的物理职责是把电流相量缩放 $|\mathbf{Z}|$ 倍、并旋转 $\theta_Z$ 角度，从而映射出电压相量。

| 复阻抗 $\mathbf{Z} = R + jX$ | 虚部符号 | 负载性质 | 电压与电流相位关系 | 复导纳 $\mathbf{Y} = G + jB$ 虚部符号 |
| :--- | :--- | :--- | :--- | :--- |
| $X > 0$（感抗占优） | $+j$ | **感性负载（Inductive）** | 电流滞后电压（Lagging） | $B < 0$（感纳为负） |
| $X < 0$（容抗占优） | $-j$ | **容性负载（Capacitive）** | 电流超前电压（Leading） | $B > 0$（容纳为正） |
| $X = 0$（感容抵消） | $0$ | **纯阻性 / 谐振（Resistive）** | 电流与电压同相 | $B = 0$ |

### 2.2 复导纳 $\mathbf{Y}$ 与“$G \neq 1/R$”的高频陷阱

在并联电路中，用复阻抗的倒数——**复导纳（Admittance）** $\mathbf{Y} = \frac{1}{\mathbf{Z}} = G + jB$（单位：西门子 $\text{S}$）往往更顺手。但请务必盯紧分母有理化：
$$\mathbf{Y} = \frac{1}{R + jX} = \frac{R - jX}{R^2 + X^2} = \underbrace{\frac{R}{R^2 + X^2}}_{G\text{ (电导)}} + j\underbrace{\left(\frac{-X}{R^2 + X^2}\right)}_{B\text{ (电纳)}}$$

> **高频易错预警**：只要电抗 $X \neq 0$，就有 **$G \neq \frac{1}{R}$** 且 **$B \neq \frac{1}{X}$**！千万不要分别对实部和虚部直接取倒数！

### 2.3 三段式教授板书推导：串联 RLC 复阻抗与复导纳互化

> **例题 2.1**：一个串联 RLC 支路包含 $R = 30\ \Omega$、$L = 80\text{ mH}$、$C = 25\ \mu\text{F}$，工作在角频率 $\omega = 1000\text{ rad/s}$ 下。求该支路的等效复阻抗 $\mathbf{Z}$（直角与极坐标形式）及等效复导纳 $\mathbf{Y} = G + jB$，并判断电路的感/容性质。

#### ① 公理溯源
依据串联复阻抗叠加律与复导纳定义：
$$\mathbf{Z} = \mathbf{Z}_R + \mathbf{Z}_L + \mathbf{Z}_C, \qquad \mathbf{Y} = \frac{1}{\mathbf{Z}} = G + jB$$

#### ② 纯符号通式
代入三元件频域阻抗表达式，分离实部与虚部：
$$\mathbf{Z} = R + j\omega L + \frac{1}{j\omega C} = R + j\left(\omega L - \frac{1}{\omega C}\right) = R + j(X_L - X_C) \triangleq R + jX$$
其极坐标模与阻抗角为：
$$|\mathbf{Z}| = \sqrt{R^2 + X^2}, \qquad \theta_Z = \arctan\left(\frac{X}{R}\right)$$
复导纳的直角与极坐标通式为：
$$\mathbf{Y} = \frac{R}{R^2 + X^2} - j\frac{X}{R^2 + X^2} = \frac{1}{|\mathbf{Z}|}\angle(-\theta_Z)$$

#### ③ 代入数值逐步化简
1. 计算感抗与容抗（$\omega = 1000\text{ rad/s}$）：
   $$X_L = (1000)(80\times 10^{-3}) = 80\ \Omega, \qquad X_C = \frac{1}{(1000)(25\times 10^{-6})} = 40\ \Omega$$
   净电抗 $X = X_L - X_C = 80 - 40 = +40\ \Omega > 0$（呈**感性**）。
2. 合成复阻抗：
   $$\mathbf{Z} = 30 + j40\ \Omega$$
   $$|\mathbf{Z}| = \sqrt{30^2 + 40^2} = 50\ \Omega, \qquad \theta_Z = \arctan\left(\frac{40}{30}\right) = 53.13^\circ$$
   $$\mathbf{Z} = 50\angle 53.13^\circ\ \Omega$$
3. 求解复导纳：
   $$G = \frac{30}{30^2 + 40^2} = \frac{30}{2500} = 0.012\text{ S} = 12\text{ mS}$$
   $$B = \frac{-40}{30^2 + 40^2} = \frac{-40}{2500} = -0.016\text{ S} = -16\text{ mS}$$
   $$\mathbf{Y} = 0.012 - j0.016 = 0.020\angle -53.13^\circ\text{ S}$$
   （顺手核对陷阱：$1/R = 1/30 \approx 0.0333\text{ S} \neq 0.012\text{ S}$，验证了绝不可分项取倒数！）

### 3.3 三段式教授板书推导：混联复阻抗、总电流与复数分流

> **例题 3.1**：针对上图所示混联电路，激励源 $v_s(t) = 30\cos(50t + 10^\circ)\text{ V}$。求总输入复阻抗 $\mathbf{Z}_{\text{eq}}$、干路稳态电流 $i(t)$ 以及两并联支路电流相量 $\mathbf{I}_A$、$\mathbf{I}_B$。

#### ① 公理溯源
依据元件频域阻抗定义、串并联复阻抗等效法则、频域欧姆定律及复数分流法则：
$$\mathbf{Z}_p = \mathbf{Z}_A \parallel \mathbf{Z}_B = \frac{\mathbf{Z}_A \mathbf{Z}_B}{\mathbf{Z}_A + \mathbf{Z}_B}, \qquad \mathbf{Z}_{\text{eq}} = \mathbf{Z}_1 + \mathbf{Z}_p, \qquad \mathbf{I} = \frac{\mathbf{V}_s}{\mathbf{Z}_{\text{eq}}}$$

#### ② 纯符号通式
写出各子块复阻抗的符号表达式：
$$\mathbf{Z}_1 = R_1 - \frac{j}{\omega C_1}, \qquad \mathbf{Z}_A = R_2 + j\omega L, \qquad \mathbf{Z}_B = -\frac{j}{\omega C_2}$$
并联阻抗与支路分流公式为：
$$\mathbf{Z}_p = \frac{\mathbf{Z}_A \mathbf{Z}_B}{\mathbf{Z}_A + \mathbf{Z}_B}, \qquad \mathbf{I}_A = \frac{\mathbf{Z}_B}{\mathbf{Z}_A + \mathbf{Z}_B}\,\mathbf{I}, \qquad \mathbf{I}_B = \frac{\mathbf{Z}_A}{\mathbf{Z}_A + \mathbf{Z}_B}\,\mathbf{I}$$

#### ③ 代入数值逐步化简
已知 $\omega = 50\text{ rad/s}$，$\mathbf{V}_s = 30\angle 10^\circ\text{ V}$：

1. **逐一转换元件复阻抗**：
   - $\mathbf{Z}_{C1} = \frac{-j}{(50)(5\times 10^{-3})} = -j4\ \Omega \implies \mathbf{Z}_1 = 2 - j4\ \Omega$
   - $\mathbf{Z}_L = j(50)(120\times 10^{-3}) = j6\ \Omega \implies \mathbf{Z}_A = 8 + j6\ \Omega$
   - $\mathbf{Z}_B = \frac{-j}{(50)(2\times 10^{-3})} = -j10\ \Omega$

2. **计算并联等效阻抗 $\mathbf{Z}_p$**：
   $$\mathbf{Z}_p = \frac{(8 + j6)(-j10)}{(8 + j6) + (-j10)} = \frac{60 - j80}{8 - j4}$$
   分子分母同乘共轭复数 $(8 + j4)$：
   $$\mathbf{Z}_p = \frac{(60 - j80)(8 + j4)}{8^2 + 4^2} = \frac{480 + j240 - j640 + 320}{80} = \frac{800 - j400}{80} = 10 - j5\ \Omega$$

3. **串联叠加求总阻抗 $\mathbf{Z}_{\text{eq}}$**：
   $$\mathbf{Z}_{\text{eq}} = \mathbf{Z}_1 + \mathbf{Z}_p = (2 - j4) + (10 - j5) = 12 - j9\ \Omega$$
   转为极坐标：
   $$|\mathbf{Z}_{\text{eq}}| = \sqrt{12^2 + (-9)^2} = 15\ \Omega, \qquad \theta_Z = \arctan\left(\frac{-9}{12}\right) = -36.87^\circ$$
   $$\mathbf{Z}_{\text{eq}} = 15\angle -36.87^\circ\ \Omega$$

4. **求干路电流相量并还原时域**：
   $$\mathbf{I} = \frac{30\angle 10^\circ}{15\angle -36.87^\circ} = 2.00\angle 46.87^\circ\text{ A} \implies i(t) = 2.00\cos(50t + 46.87^\circ)\text{ A}$$

5. **复数分流求支路电流**（已知 $\mathbf{Z}_A + \mathbf{Z}_B = 8 - j4 = 4\sqrt{5}\angle -26.57^\circ\ \Omega$）：
   $$\mathbf{I}_A = \frac{10\angle -90^\circ}{4\sqrt{5}\angle -26.57^\circ}(2.00\angle 46.87^\circ) = \sqrt{5}\angle -16.57^\circ \approx 2.24\angle -16.57^\circ\text{ A}$$
   $$\mathbf{I}_B = \frac{10\angle 36.87^\circ}{4\sqrt{5}\angle -26.57^\circ}(2.00\angle 46.87^\circ) = \sqrt{5}\angle 110.30^\circ \approx 2.24\angle 110.30^\circ\text{ A}$$

> **教授点睛**：你发现神奇的地方了吗？干路总电流幅值只有 $2.00\text{ A}$，可两个并联支路的电流幅值居然都是 $2.24\text{ A}$——**每个支路的电流都比总电流还大**！这在直流电路里绝不可能发生，但在交流电路里，感性支路 $\mathbf{I}_A$ 和容性支路 $\mathbf{I}_B$ 相位差高达 $126.87^\circ$，二者矢量合成时彼此抵消了一部分，精准满足频域 KCL：$\mathbf{I}_A + \mathbf{I}_B = 2.00\angle 46.87^\circ\text{ A}$！

## 第 4 幕：双通道示波器读相法——实时观测 RC 相移与幅值衰减

现在，请把目光切到左侧舞台的 **Layer 2：`02 实时双通道示波器`**。我们把纸面上的复数分压搬到真实实验室里最经典的 **RC 相移网络** 上：用函数信号发生器输出 $f = 1\text{ kHz}$、峰值 $V_{\text{in,pk}} = 5.0\text{ V}$（$10\text{ V}_{\text{pp}}$）的正弦波，串联一颗 $R = 1.6\text{ k}\Omega$（或 $1.5\text{ k}\Omega$）电阻与一颗 $C = 100\text{ nF}$ 电容。

### 4.1 三段式教授板书推导：RC 相移与示波器时间差 $\Delta t$ 换算

#### ① 公理溯源
依据频域复数分压法则及正弦波周期与相位线性对应关系：
$$\mathbf{V}_C = \frac{\mathbf{Z}_C}{\mathbf{Z}_R + \mathbf{Z}_C}\mathbf{V}_{\text{in}}, \qquad \Delta\phi = -\frac{\Delta t}{T} \times 360^\circ$$
其中 $\Delta t = t_{\text{CH2,peak}} - t_{\text{CH1,peak}}$ 为输出波形相对输入波形在示波器水平轴上的延迟时间（右移为滞后，取负号）。

#### ② 纯符号通式
将 $\mathbf{Z}_R = R$、$\mathbf{Z}_C = \frac{1}{j\omega C}$ 代入复数分压式，分子分母同乘 $j\omega C$：
$$\mathbf{H}_C(j\omega) \triangleq \frac{\mathbf{V}_C}{\mathbf{V}_{\text{in}}} = \frac{1/(j\omega C)}{R + 1/(j\omega C)} = \frac{1}{1 + j\omega RC} = \frac{1}{1 + j(R/X_C)}$$
提取幅值衰减比与相移角通式：
$$|\mathbf{H}_C(j\omega)| = \frac{1}{\sqrt{1 + (\omega RC)^2}}, \qquad \Delta\phi_C = -\arctan(\omega RC) = -\arctan\left(\frac{R}{X_C}\right)$$
同步给出电阻两端电压传递比（供超前相移对比）：
$$\mathbf{H}_R(j\omega) = \frac{\mathbf{V}_R}{\mathbf{V}_{\text{in}}} = \frac{j\omega RC}{1 + j\omega RC} \implies \Delta\phi_R = 90^\circ - \arctan(\omega RC) > 0$$
由 $\Delta\phi_C = -\frac{\Delta t}{T}\times 360^\circ$ 反解示波器上的水平延迟时间：
$$\Delta t = \frac{|\Delta\phi_C|}{360^\circ}\,T = \frac{|\Delta\phi_C|}{360^\circ f}$$

#### ③ 代入数值逐步化简
给定标准实验参数：$f = 1000\text{ Hz}$（周期 $T = 1.00\text{ ms} = 1000\ \mu\text{s}$，$\omega = 2\pi f \approx 6283.19\text{ rad/s}$），$C = 100\text{ nF} = 10^{-7}\text{ F}$，$V_{\text{in,pk}} = 5.0\text{ V}$。

1. **计算容抗 $X_C$**：
   $$X_C = \frac{1}{2\pi (1000)(100\times 10^{-9})} = \frac{10^4}{2\pi} \approx 1591.55\ \Omega \approx 1.59\text{ k}\Omega$$
2. **主推荐方案（$R = 1.6\text{ k}\Omega$ E24 金属膜电阻）**：
   $$\frac{R}{X_C} = \frac{1600}{1591.55} = 1.0053$$
   $$|\mathbf{H}_C| = \frac{1}{\sqrt{1 + 1.0053^2}} = 0.7052 \approx 0.707 \implies V_{C,\text{pk}} = 5.0 \times 0.7052 = 3.53\text{ V}$$
   $$\Delta\phi_C = -\arctan(1.0053) = -45.15^\circ \approx -45^\circ$$
   $$\Delta t = \frac{45.15^\circ}{360^\circ} \times 1000\ \mu\text{s} = 125.42\ \mu\text{s} \approx \frac{1}{8}T$$
   （若改测电阻两端，则 $\Delta\phi_R = +44.85^\circ \approx +45^\circ$，波形相对 CH1 **向左超前** $1/8$ 个周期！）
3. **备选常见方案（$R = 1.5\text{ k}\Omega$ E12 碳膜电阻）**：
   $$|\mathbf{H}_C| = 0.7277 \ (V_{C,\text{pk}} = 3.64\text{ V}), \quad \Delta\phi_C = -43.30^\circ, \quad \Delta t = 120.29\ \mu\text{s}$$

## 第 5 幕：3D 面包板 RC 相移实操与双通道探头共地安全规范

请切换到左侧舞台的 **Layer 3：`03 3D 面包板 RC 相移电路 + 信号发生器与双通道示波器实操`**。现在我们要像真正的电子工程师一样，把电阻、电容、信号发生器和示波器接在 830 孔面包板上。

### 5.1 为什么实验室选 $R = 1.6\text{ k}\Omega$、$C = 100\text{ nF}$、$f = 1\text{ kHz}$？

初学面包板实操的同学常问：“老师，教材例题里经常写 $R = 2\ \Omega$、$C = 5\text{ mF}$，我为什么不能直接把那些元件插到面包板上？”
这里藏着至关重要的**工程缩放与安全规范**：
1. **防过载与保功率**：若在 $5\text{ V}_{\text{pk}}$ 下接 $2\ \Omega$ 电阻，电流会飙升至 $2.5\text{ A}$，远超函数信号发生器 $50\ \Omega$ 内阻的驱动极限，也会瞬间烧毁面包板簧片与 $1/4\text{ W}$ 电阻！而选用 $R = 1.6\text{ k}\Omega$（或常见 $1.5\text{ k}\Omega$）配 $C = 100\text{ nF}$，总阻抗 $|\mathbf{Z}| \approx 2.26\text{ k}\Omega$，峰值电流仅 $2.22\text{ mA}$（$I_{\text{rms}} = 1.57\text{ mA}$），电阻发热功率仅 $3.93\text{ mW}$，安全裕度超过 $60$ 倍！
2. **肉眼黄金辨识点**：在 $f = 1\text{ kHz}$ 下，$X_C \approx 1.59\text{ k}\Omega \approx R$，此时电容相移刚好落在 $-45^\circ$（$1/8$ 个周期），幅值衰减到 $0.707$ 倍（$-3\text{ dB}$ 截止点），示波器上既不会因为相移太小看不清，也不会因为衰减太狠淹没在噪声里。
3. **3D 扫频交互任务**：请在 3D 实操面板中拖动信号发生器频率旋钮，记录以下三个典型频点的物理演化：
   - **$f = 100\text{ Hz}$**（低频区）：$X_C = 15.92\text{ k}\Omega \gg R \implies |\mathbf{H}_C| = 0.995$，$\Delta\phi_C = -5.74^\circ$（电容近似开路，输出几乎紧贴输入）。
   - **$f = 1\text{ kHz}$**（转折点）：$X_C = 1.59\text{ k}\Omega \approx R \implies |\mathbf{H}_C| = 0.705$，$\Delta\phi_C = -45.15^\circ$（黄金 $-45^\circ$ 相移）。
   - **$f = 10\text{ kHz}$**（高频区）：$X_C = 159.2\ \Omega \ll R \implies |\mathbf{H}_C| = 0.099$，$\Delta\phi_C = -84.32^\circ$（电容近似短路，幅值剧烈衰减，相位逼近 $-90^\circ$）。

### 5.2 实验室头号安全红线：双通道示波器探头共地规范

> **绝对禁令（Common Ground Rule）**：台式双通道示波器的 **CH1 黑色地夹** 与 **CH2 黑色地夹**，在示波器机箱内部通过 BNC 外壳**直接短接在一起并连向市电保护地（PE）**！
> - **正确做法**：信号发生器黑夹、CH1 黑夹、CH2 黑夹**三根地线全部统一夹在面包板蓝色负极轨（GND，即电容下端）**；CH1 红探针钩住输入节点 `IN`，CH2 红探针钩住 R-C 中间节点 `OUT`。
> - **致命错误**：如果你为了同时看 $v_{\text{in}}$ 和 $v_R$，把 CH2 的黑色地夹直接夹在了 R-C 中间节点 `OUT` 上，示波器内部地线会立刻把节点 `OUT` 拉死到 `GND`——**你亲手用示波器把电容给短路了！** 此时不仅测不出 $v_R$，在带电源大电流电路中甚至会瞬间烧毁探头地线或炸保险丝。
> - **安全测 $v_R(t)$ 的两种正确方法**：① 在电路板上物理对调 $R$ 与 $C$ 的上下位置，让电阻下端接地；② 保持共地接法不变，在示波器上开启 `MATH = CH1 - CH2` 差分波形。
