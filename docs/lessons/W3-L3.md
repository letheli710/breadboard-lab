## 第 1 幕：虚地（Virtual Ground）的诞生——电位为 0 V，却绝没有接地！

### 1.1 物理直觉：为什么运放能把一个悬空的节点“钉”在 0 V？

观察反相放大器的输入级连接方式：我们把运放的**同相输入端（$+$）直接连到参考地（GND）**，因此同相端电位被硬性锁定为：

$$v_+ = 0\text{ V}$$

同时，我们在输出端 $v_o$ 与反相输入端（$-$）之间跨接了一颗反馈电阻 $R_f$，构成了深度**负反馈（Negative Feedback）**。只要运放工作在线性区（未饱和），根据 `W3-L2` 建立的**虚短（Virtual Short）**公理，反相输入端（图中记为节点 1）的电位必须紧紧跟随同相端：

$$v_- = v_+ = 0\text{ V}$$

这个现象在电路学中被称为**虚地（Virtual Ground）**。但同学们千万不要被“地”字骗了——请牢记教授的**虚地双铁律**：

1. **电位像地，物理不是地**：节点 1 的对地电压确实是 $0\text{ V}$，但**它绝对没有用导线连到地线上**！它是靠运放输出端 $v_o$ 通过 $R_f$ 不断“向回拉扯”才维持在 $0\text{ V}$ 平衡态的。
2. **电流全部被迫拐弯**：既然节点 1 没有接地，且根据**虚断（Virtual Open）**公理，流入运放反相端的电流 $i_- = 0$，那么从输入源 $v_i$ 经过 $R_1$ 流过来的电流 $i_1$ 到达节点 1 后，面前是两条死路（既无地线可下泄，也钻不进运放内部），它唯一的出路就是**100% 向上拐弯，全部流过反馈电阻 $R_f$**：

$$i_f = i_1$$

> **教授防坑提醒**：如果你在面包板上误以为“既然 $v_- = 0\text{ V}$，那我直接拿根跳线把 Pin 2 接到 GND 轨岂不是更稳？”——**绝对不行！** 一旦物理短接到地，输入电流 $i_1$ 会直接泄入大地，反馈回路彻底断链，输出电压 $v_o$ 会瞬间失去控制（归零或撞轨）。

## 第 2 幕：闭环增益的黄金公式——三段式教授板书推导（Eq. 5.8 & Eq. 5.9）

### 2.1 三段式教授板书推导

下面我们严格按照 Sadiku **Fig. 5.10**，用**① 公理溯源 → ② 纯符号通式 → ③ 代入数值逐步化简**三段式板书推导反相放大器的闭环传输方程（**Eq. 5.8** 与 **Eq. 5.9**）。

#### ① 公理溯源（物理定律与理想运放公理）
1. **节点 1 基尔霍夫电流定律（KCL，`W1-L5`）**：流入节点 1 的电流之和等于流出节点 1 的电流之和：
   $$i_1 = i_- + i_f$$
2. **欧姆定律（`W1-L3`）**：用节点电位差表示两条支路电流：
   $$i_1 = \frac{v_i - v_-}{R_1}, \qquad i_f = \frac{v_- - v_o}{R_f}$$
3. **理想运放公理（`W3-L2`）**：
   - **虚断**：$i_- = 0$
   - **虚短**（结合同相端接地 $v_+ = 0$）：$v_- = v_+ = 0$

#### ② 纯符号通式（严禁混入任何数字）
将虚断 $i_- = 0$ 代入 KCL：
$$i_1 = i_f$$

代入欧姆定律表达式：
$$\frac{v_i - v_-}{R_1} = \frac{v_- - v_o}{R_f}$$

代入虚地条件 $v_- = 0$：
$$\frac{v_i - 0}{R_1} = \frac{0 - v_o}{R_f} \implies \frac{v_i}{R_1} = -\frac{v_o}{R_f}$$

整理得到 Sadiku **Eq. 5.8**（输出电压通式）与 **Eq. 5.9**（闭环电压增益通式）：

$$v_o = -\frac{R_f}{R_1} v_i \qquad \text{(Eq. 5.8)}$$

$$A_v = \frac{v_o}{v_i} = -\frac{R_f}{R_1} \qquad \text{(Eq. 5.9)}$$

#### ③ 代入数值逐步化简（以本课 3D 面包板实测参数为例）
取标准 E12 电阻 $R_1 = 10\text{ k}\Omega$、$R_f = 22\text{ k}\Omega$，输入直流电压 $v_i = +1.00\text{ V}$（采用 $\pm 9\text{ V}$ 双电源供电）：

1. 计算闭环电压增益 $A_v$：
   $$A_v = -\frac{22\text{ k}\Omega}{10\text{ k}\Omega} = -2.20$$
2. 计算输出电压 $v_o$：
   $$v_o = A_v \cdot v_i = (-2.20) \times (+1.00\text{ V}) = -2.20\text{ V}$$
3. 核验支路电流：
   $$i_1 = \frac{+1.00\text{ V} - 0\text{ V}}{10\text{ k}\Omega} = 0.10\text{ mA} = 100\ \mu\text{A}, \qquad i_f = \frac{0\text{ V} - (-2.20\text{ V})}{22\text{ k}\Omega} = 100\ \mu\text{A}$$
   两者严丝合缝相等，且 $-2.20\text{ V}$ 稳稳落在 LM358 $\pm 9\text{ V}$ 供电的线性输出区间 $[-9.0\text{ V}, +7.5\text{ V}]$ 内。

### 2.2 深度解读：负号的意义与“与芯片内部 $A$ 无关”的奇迹

1. **负号的物理意义（反相 $180^\circ$）**：
   - 对直流信号：正输入产生负输出，负输入产生正输出。
   - 对交流正弦信号：输出波形与输入波形**相位完全相反（反相 $180^\circ$）**——输入到达波峰时，输出正好到达波谷。
2. **闭环增益为何与芯片内部开环增益 $A$ 无关？**
   - 真实的 LM358 开环增益 $A$ 既庞大又不稳定（受温度、批次影响，可能在 $5 \times 10^4$ 到 $2 \times 10^5$ 之间剧烈漂移）。
   - 若计入有限开环增益 $A$，严格推导出的闭环增益为：
     $$A_{v,\text{real}} = \frac{-R_f / R_1}{1 + \dfrac{1 + R_f / R_1}{A}}$$
   - 当 $R_f / R_1 = 2.2$、$A = 10^5$ 时，经 Python 精确验算：
     $$A_{v,\text{real}} = \frac{-2.2}{1 + 3.2 / 10^5} = -2.1999296$$
     与理想值 $-2.20$ 的相对误差仅为 **$-0.0032\%$**！这就是负反馈最伟大的工程魔法：**用两颗廉价但精密的外接电阻比值，换取了不受半导体离散性影响的超高精度增益。**

## 第 3 幕：输入电阻 $R_{\text{in}} = R_1$ 与工程选阻权衡（Fig. 5.11 等效模型）

### 3.1 为什么说“反相放大器的输入电阻就是 $R_1$”？

虽然运放芯片本身的差分输入电阻趋近于无穷大（$R_i \to \infty$），但从**整个反相放大器的输入端口**往里看，信号源 $v_i$ 感受到的等效输入电阻 $R_{\text{in}}$ 却完全不是无穷大！我们用三段式板书把它彻底看穿：

#### ① 公理溯源
输入电阻的定义为输入端口电压与输入端口电流之比：
$$R_{\text{in}} \triangleq \frac{v_i}{i_1}$$
同时节点 1 为虚地（$v_- = 0$），流过 $R_1$ 的电流由欧姆定律给出：$i_1 = \frac{v_i - v_-}{R_1}$。

#### ② 纯符号通式
$$R_{\text{in}} = \frac{v_i}{i_1} = \frac{v_i}{(v_i - 0)/R_1} = R_1$$

这就是 Sadiku **Fig. 5.11** 所揭示的二端口等效模型：
- **输入侧**：等效为一颗直接接地的电阻 $R_1$（因为右端被虚地钉在 $0\text{ V}$）；
- **输出侧**：等效为一个受控电压源（VCVS），其电压为 $-\frac{R_f}{R_1} v_i$（理想输出电阻 $R_{\text{out}} = 0$）。

#### ③ 数值对比：前级信号源加载效应（设前级内阻 $R_s = 1\text{ k}\Omega$，开路电动势 $V_s = 1.00\text{ V}$）
实际传感器或信号发生器都有内阻 $R_s$，它会与 $R_{\text{in}} = R_1$ 构成分压器：$v_i = V_s \cdot \frac{R_1}{R_s + R_1}$。

| 选取的 $R_1$ | 实际到达放大器输入端的 $v_i$ | 加载衰减误差 | 工程评价 |
| :--- | :--- | :--- | :--- |
| $1\text{ k}\Omega$ | $0.5000\text{ V}$ | **$-50.00\%$** | 严重加载前级，增益缩水一半！ |
| **$10\text{ k}\Omega$** | **$0.9091\text{ V}$** | **$-9.09\%$** | 面包板实测甜点区（配合低阻源） |
| $100\text{ k}\Omega$ | $0.9901\text{ V}$ | $-0.99\%$ | 加载极轻，但需留意噪声与偏置电流 |

### 3.2 工程选阻的“黄金折中区间”

既然 $R_1$ 越大加载越轻，那是不是把 $R_1$ 选成 $10\text{ M}\Omega$ 就万事大吉了？**绝对不行！** 在真实模拟电路中，选阻永远是两头夹击的权衡：

- **$R_1$ 不能太小（通常 $\ge 1\text{ k}\Omega$）**：不仅会严重加载前级信号源，而且为了维持相同增益，若 $R_f$ 也偏小，会迫使运放输出级提供过大的反馈电流，触发 LM358 的输出电流限流（约 $20\text{ mA}$ 灌电流 / $40\text{ mA}$ 拉电流）并增加发热。
- **$R_1$ 与 $R_f$ 不能太大（通常 $\le 1\text{ M}\Omega$）**：
  1. **约翰逊热噪声（Thermal Noise）**与电阻平方根成正比（$v_{n,\text{rms}} = \sqrt{4k_B T R \Delta f}$），兆欧级电阻会引入明显底噪；
  2. **输入偏置电流误差**：真实 LM358 反相端存在约 $45\text{ nA}$（典型值）的输入偏置电流 $I_B$，流过 $10\text{ M}\Omega$ 的 $R_f$ 就会凭空产生 $45\text{ nA} \times 10\text{ M}\Omega = 0.45\text{ V}$ 的输出直流失调！
  3. **寄生电容限带宽**：面包板插孔间存在约 $2\sim 5\text{ pF}$ 的寄生电容，与兆欧电阻形成极低截止频率的低通滤波器，还会诱发高频拾噪。

> **教授口诀**：面包板运放实验认准 **$\text{k}\Omega$ 级黄金区（$10\text{ k}\Omega \sim 100\text{ k}\Omega$）**——既不拖垮前级，又不招惹噪声与偏置误差。如果前级传感器内阻极高（例如压电陶瓷或 pH 电极），下一讲（`W3-L4`）的**同相放大器 / 电压跟随器**才是正解！

## 第 4 幕：经典例题精讲——Example 5.3 与 Example 5.4（跨阻放大器视角）

### 4.1 经典例题 Example 5.3（对齐 Sadiku Fig. 5.12）

**题目**：如图所示反相放大器电路中，已知 $R_1 = 10\text{ k}\Omega$，$R_f = 25\text{ k}\Omega$，输入电压 $v_i = 0.5\text{ V}$（运放理想且供电充足）。试求：
1. 闭环电压增益 $A_v$ 与输出电压 $v_o$；
2. 流过 $10\text{ k}\Omega$ 输入电阻的电流 $i_1$ 与反馈电阻电流 $i_f$；
3. 空载时运放输出端流出的电流 $i_o$（并拓展计算：若在输出端接入 $R_L = 5\text{ k}\Omega$ 负载电阻，$i_o$ 变为多少？）。

#### ① 公理溯源
- 节点 1（反相端）：虚短得 $v_- = v_+ = 0$，虚断得 $i_- = 0$，KCL 得 $i_1 = i_f$。
- 输出节点（$v_o$ 处）：设运放输出电流 $i_o$ 的参考方向为**从运放输出端向右流出**，则 KCL 满足 $i_o + i_f = i_L$（空载时 $i_L = 0$）。

#### ② 纯符号通式
$$A_v = -\frac{R_f}{R_1}, \qquad v_o = A_v v_i = -\frac{R_f}{R_1} v_i$$

$$i_1 = \frac{v_i - 0}{R_1} = \frac{v_i}{R_1}, \qquad i_f = i_1$$

$$i_o\big|_{\text{空载}} = -i_f = -\frac{v_i}{R_1}, \qquad i_o\big|_{\text{带载 } R_L} = i_L - i_f = \frac{v_o}{R_L} - \frac{v_i}{R_1}$$

#### ③ 代入数值逐步化简（Python 精确验算）
1. **闭环增益与输出电压**：
   $$A_v = -\frac{25\text{ k}\Omega}{10\text{ k}\Omega} = -2.5$$
   $$v_o = (-2.5) \times 0.5\text{ V} = -1.25\text{ V}$$
2. **输入支路电流与反馈支路电流**：
   $$i_1 = \frac{0.5\text{ V}}{10\text{ k}\Omega} = 0.05\text{ mA} = 50\ \mu\text{A}, \qquad i_f = i_1 = 50\ \mu\text{A}$$
   （交叉验算：$i_f = \frac{0 - (-1.25\text{ V})}{25\text{ k}\Omega} = 0.05\text{ mA} = 50\ \mu\text{A}$，完全吻合！）
3. **运放输出电流 $i_o$**：
   - **空载情况**：$i_o = -i_f = -50\ \mu\text{A}$。负号说明电流实际上是**灌入（Sink）运放输出引脚**，最终经芯片内部负电源轨 $V^-$ 回到地线！
   - **拓展带载情况（若接 $R_L = 5\text{ k}\Omega$ 到地）**：
     $$i_L = \frac{v_o}{R_L} = \frac{-1.25\text{ V}}{5\text{ k}\Omega} = -0.25\text{ mA} = -250\ \mu\text{A}$$
     $$i_o = i_L - i_f = (-250\ \mu\text{A}) - 50\ \mu\text{A} = -300\ \mu\text{A}$$
     此时运放同时“吸走”来自 $R_f$ 的 $50\ \mu\text{A}$ 和来自地线经 $R_L$ 倒流的 $250\ \mu\text{A}$，总计灌电流 $300\ \mu\text{A}$。

### 4.2 经典例题 Example 5.4：电流-电压转换器（跨阻放大器 TIA）视角

Sadiku 在 Section 5.4 紧接着给出了一个极其漂亮的工程变形（**Example 5.4** 视角）：如果我们把反相放大器左侧的“电压源 $v_i$ + 输入电阻 $R_1$”拆掉，直接把一个**电流源 $i_s$**（现实中最典型的就是光纤通信或心率血氧仪里的**光电二极管 Photodiode**）接入反相端，会发生什么？

- **① 公理溯源**：同相端接地 $v_+ = 0 \implies v_- = 0$（虚地）；虚断 $i_- = 0$；节点 1 KCL：$i_s = i_f$。
- **② 纯符号通式**：
  $$i_s = \frac{0 - v_o}{R_f} \implies v_o = -R_f i_s$$
  定义**跨阻增益（Transresistance Gain）** $R_m \triangleq \frac{v_o}{i_s} = -R_f$（量纲为 $\Omega$ 或 $\text{V/mA}$）。
- **③ 代入数值化简**：设光电二极管光电流 $i_s = 200\ \mu\text{A} = 0.20\text{ mA}$，反馈电阻 $R_f = 20\text{ k}\Omega$，则：
  $$v_o = -(20\text{ k}\Omega) \times (0.20\text{ mA}) = -4.00\text{ V}$$
  不仅线性地把微弱电流转换成了易于 ADC 采样的伏特级电压，而且由于反相端是 $0\text{ V}$ 虚地，光电二极管两端压降恒定为 $0\text{ V}$，消除了结电容充放电带来的非线性！

## 第 5 幕：电源轨与防削波铁律——为什么必须用 $\pm 9\text{ V}$ 双电源？

### 5.1 核心必讲：反相放大器的负电压宿命与 LM358 真实输出摆幅

同学们，这是从“纸上谈兵”跨越到“面包板真枪实弹”最致命的一道关卡！

观察公式 $v_o = -\frac{R_f}{R_1} v_i$：**只要你输入一个正电压（$+v_i > 0$），运放就必须输出一个负电压（$-v_o < 0$）**。然而，运放不是永动机，它输出端的电位永远无法突破自身供电轨 $[V^-, V^+]$ 的天花板与地板。

以本课 3D 面包板使用的经典芯片 **LM358** 为例，当我们采用 **$\pm 9\text{ V}$ 双电源**供电（$V^+ = +9.0\text{ V}$，$V^- = -9.0\text{ V}$）时，其真实输出摆幅并不是对称的 $\pm 9.0\text{ V}$，而是：

- **负向极限**：$V_{o,\min} \approx V^- = -9.0\text{ V}$（LM358 输出级具备贴近负轨的下摆能力）
- **正向极限**：$V_{o,\max} \approx V^+ - 1.5\text{ V} = +7.5\text{ V}$（受内部达林顿上拉管约 $1.5\text{ V}$ 饱和压降限制）

### 5.2 三段式推导：线性输入窗口与饱和临界点

对面包板实测电路（$R_1 = 10\text{ k}\Omega, R_f = 22\text{ k}\Omega, A_v = -2.20$）：

1. **① 公理溯源**：线性工作前提为 $V_{o,\min} \le v_o \le V_{o,\max}$，即 $V_{o,\min} \le -\frac{R_f}{R_1} v_i \le V_{o,\max}$。
2. **② 纯符号通式**：注意两边同除以负数 $-\frac{R_f}{R_1}$ 时不等号方向翻转：
   $$-\frac{R_1}{R_f} V_{o,\max} \le v_i \le -\frac{R_1}{R_f} V_{o,\min}$$
3. **③ 代入数值逐步化简**：
   - 正输入饱和临界点（输出撞上负轨 $-9.0\text{ V}$）：
     $$v_{i,\max+} = -\frac{10\text{ k}\Omega}{22\text{ k}\Omega} \times (-9.0\text{ V}) = +4.0909\text{ V} \approx +4.09\text{ V}$$
   - 负输入饱和临界点（输出撞上正轨 $+7.5\text{ V}$）：
     $$v_{i,\min-} = -\frac{10\text{ k}\Omega}{22\text{ k}\Omega} \times (+7.5\text{ V}) = -3.4091\text{ V} \approx -3.41\text{ V}$$
   - **结论**：本电路在 $\pm 9\text{ V}$ LM358 下的不失真线性输入窗口为 **$-3.41\text{ V} \le v_i \le +4.09\text{ V}$**。

### 5.3 红牌警示：若误用单 $+9\text{ V}$ 供电会发生什么？

> **严重警告（面包板第一号惨案）**：如果你图省事只接一节 9 V 电池（$V^+ = +9\text{ V}$，$V^- = 0\text{ V}$），然后照着课本给反相放大器输入 $v_i = +1.0\text{ V}$——理论要求输出 $-2.2\text{ V}$，但芯片最低只能吐出 $0\text{ V}$！结果：
> 1. **输出彻底死锁在 $0\text{ V}$ 削波**（实测约 $+5\sim 20\text{ mV}$）；
> 2. **负反馈失效、虚地当场崩溃**：既然 $v_o$ 降不下去，反相端电位 $v_-$ 会被 $v_i$ 通过 $R_1$ 与 $R_f$ 的电阻分压硬生生拉高到 $v_- = v_i \cdot \frac{R_f}{R_1 + R_f} = 1.0 \times \frac{22}{32} \approx +0.69\text{ V} \neq 0\text{ V}$！

**工程拓展：单电源系统怎么搭反相放大器？**
在只有单节电池（如 $+9\text{ V}$ 或 $+5\text{ V}$）的便携设备中，工程师会把同相端（$+$）接到一个由电阻分压生成的 **$V_{CC}/2$ 虚地偏置点**（例如 $+4.5\text{ V}$），并在输入输出端加隔直电容（交流耦合），让输出信号以 $+4.5\text{ V}$ 为中心上下摆动，从而在单电源下实现无削波交流放大。但在本课直流+交流通用的 3D 面包板实测中，我们**严格采用 $\pm 9\text{ V}$ 双电源供电**，让“真地”与“虚地”都落在直观的 $0\text{ V}$！

## Claude 工程落地清单（前端 / 3D 舞台可执行规范）

以下清单供 Claude 或前端工程师将本课件直接装配进 Breadboard Lab 应用：

1. **状态机与核心计算引擎 (`invertingAmpEngine.ts`)**：
   - 输入状态：`vi`（$-5.0\text{ V} \sim +5.0\text{ V}$，步进 $0.05\text{ V}$）、`R1`（默认 $10\text{ k}\Omega$）、`Rf`（默认 $22\text{ k}\Omega$）、`supplyMode`（`"dual_±9V"` | `"single_+9V"`）。
   - 核心输出计算：
     - `vSatPos = 7.5`（LM358 正摆幅上限）；
     - `vSatNeg = supplyMode === "dual_±9V" ? -9.0 : 0.0`；
     - `voIdeal = -(Rf / R1) * vi`；
     - `voActual = clamp(voIdeal, vSatNeg, vSatPos)`；
     - `isSaturated = (voIdeal !== voActual)`；
     - `vMinus = isSaturated ? (vi * Rf + voActual * R1) / (R1 + Rf) : 0.0`（精确模拟饱和时虚地崩溃的电阻分压值！）；
     - `i1_uA = ((vi - vMinus) / R1) * 1e6`。
2. **左侧舞台 3 层联动规格**：
   - **Layer 01（2D 动态原理图）**：渲染本课件第 1/2 幕 SVG 拓扑；`isSaturated === false` 时节点 1 虚地气泡呈金色脉冲并显示 `v₋ = 0.00 V`，电流颗粒速率正比于 `|i1_uA|`；一旦 `isSaturated === true`，虚地气泡切为红色告警并实时显示失锁后的 `vMinus`。
