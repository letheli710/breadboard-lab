# W2-L8：最大功率传输定理（Maximum Power Transfer）

> **教授开场白**：
> 同学们好，欢迎回到 Breadboard Lab。上一讲（`W2-L7`）我们学会了一项极其优雅的“降维打击”本领——**戴维南定理**：无论负载左侧的线性电路多么盘根错节，站在负载端口 $a\text{–}b$ 往左看，它统统等价于一个独立电压源 $V_{Th}$ 串联一个等效内阻 $R_{Th}$。
>
> 今天，我们紧接着追问电路设计中最核心的工程问题之一：**既然左侧电源网络的 $V_{Th}$ 和 $R_{Th}$ 已经给定，我手里有一堆不同阻值的负载电阻 $R_L$（比如不同阻抗的扬声器、射频天线或传感器后级），究竟该选多大的 $R_L$，才能从这个电路里“榨”出最大的功率？**
>
> 先别急着背结论。这节课我们将按工程师的真实思维走完五幕：**边界直觉 → 微积分严格证明 → 戴维南综合实战 → 50% 效率的残酷工程真相 → 3D 面包板亲手拧电位器抓峰值**。请把目光投向左侧舞台，我们开始第一幕。

## 第一幕：物理直觉与边界夹逼——为什么峰值一定藏在中间？

### 1.1 把复杂网络装进戴维南黑盒
假设你正在设计一个音频功放或无线电接收机前端。根据 `W2-L7 戴维南定理`，任何只含独立源、受控源与线性电阻的复杂供电网络，只要把负载电阻 $R_L$ 摘下来，端口 $a\text{–}b$ 左侧就能等效为 $V_{Th}$ 与 $R_{Th}$ 的串联。

把可调负载 $R_L$ 重新接回 $a\text{–}b$ 端口后，整个世界瞬间简化为一个单回路分压电路（回顾 `W1-L7 分压定律` 与 `W1-L2 功率公式`）：

- 回路电流：$I_L = \dfrac{V_{Th}}{R_{Th} + R_L}$
- 负载电压：$V_L = V_{Th} \cdot \dfrac{R_L}{R_{Th} + R_L}$
- 负载吸收功率：$P_L = V_L \cdot I_L$

### 1.3 Boylestad 坡度直觉：先看两个极端，再看中间的拔河
在动笔求导之前，我们先用 Boylestad 教材最经典的“边界夹逼法”建立物理直觉。负载功率是**电压与电流的乘积**（$P_L = V_L I_L$），而 $V_L$ 和 $I_L$ 在 $R_L$ 变化时正好是一场此消彼长的拔河：

1. **极端一：$R_L \to 0$（负载短路）**
   - 此时回路电流冲到最大值 $I_{sc} = V_{Th}/R_{Th}$，看起来声势浩大；
   - 但短路电阻两端的电压 $V_L = I_L R_L = 0$！所有电压全被内阻 $R_{Th}$ 吞掉了；
   - 结果：$P_L = 0 \times I_{sc} = 0\text{ W}$。
2. **极端二：$R_L \to \infty$（负载开路）**
   - 此时负载两端拿到了全部的开路电压 $V_L = V_{Th}$，电压登顶；
   - 但断路里根本没有电流流过，$I_L = 0$！
   - 结果：$P_L = V_{Th} \times 0 = 0\text{ W}$。
3. **中间必然存在唯一峰值，且曲线“左陡右缓”**
   - 既然 $R_L = 0$ 时功率为 $0$，$R_L \to \infty$ 时功率也趋于 $0$，而只要 $0 < R_L < \infty$ 就有正功率 $P_L > 0$，根据连续函数性质，中间必然存在一个**最大功率峰值**！
   - 更微妙的是曲线形状：从 $0$ 增加到峰值只跨越了有限区间 $[0, R_{Th}]$，因此**左侧爬坡非常陡峭**；而越过峰值后，横轴一直延伸到 $+\infty$ 才慢慢回落到 $0$，因此**右侧衰减比左侧平缓得多**。记住这个“偏态山峰”特征，它在第四幕的工程选型里会派上大用场。

## 第二幕：微积分严格推导——锁定 $R_L = R_{Th}$ 与峰值双曲线

现在我们把直觉变成铁打的数学定理。以下板书严格遵守 **① 公理溯源 → ② 纯符号通式 → ③ 数值验算** 三段式，绝不把符号和具体数字混在一起写。

### 2.1 三段式教授板书推导

#### ① 公理溯源（Origin）
- 由 `W2-L7 戴维南定理`，端口 $a\text{–}b$ 左侧线性有源网络等效为电压源 $V_{Th}$ 串联电阻 $R_{Th}$，且两者仅由左侧网络决定，**相对于可调负载 $R_L$ 均为常数**。
- 由 `W1-L2 功率公式` 与欧姆定律，串联回路电流为 $i_L = \dfrac{V_{Th}}{R_{Th} + R_L}$，负载吸收功率为 $p(R_L) = i_L^2 R_L$。
- 为寻找 $p(R_L)$ 在 $R_L \in (0, +\infty)$ 上的极大值点，对自变量 $R_L$ 求一阶导数并令 $\dfrac{dp}{dR_L} = 0$（运用微积分商的求导法则 $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$）。

#### ② 纯符号通式（General Formula）
先写出负载功率关于 $R_L$ 的纯符号目标函数：

$$p(R_L) = i_L^2 R_L = \left(\frac{V_{Th}}{R_{Th} + R_L}\right)^2 R_L = V_{Th}^2 \frac{R_L}{(R_{Th} + R_L)^2}$$

对 $R_L$ 求一阶导数（$V_{Th}$、$R_{Th}$ 视为常数）：

$$\frac{dp}{dR_L} = V_{Th}^2 \cdot \frac{1 \cdot (R_{Th} + R_L)^2 - R_L \cdot 2(R_{Th} + R_L)}{(R_{Th} + R_L)^4}$$

分子提取公因式 $(R_{Th} + R_L)$ 并与分母约去一次方：

$$\frac{dp}{dR_L} = V_{Th}^2 \cdot \frac{(R_{Th} + R_L) - 2R_L}{(R_{Th} + R_L)^3} = V_{Th}^2 \cdot \frac{R_{Th} - R_L}{(R_{Th} + R_L)^3}$$

令一阶导数为零 $\dfrac{dp}{dR_L} = 0$（因 $V_{Th} \neq 0$ 且分母 $(R_{Th}+R_L)^3 > 0$）：

$$R_{Th} - R_L = 0 \implies R_L = R_{Th}$$

> **极值性质检验**：当 $R_L < R_{Th}$ 时，$\dfrac{dp}{dR_L} > 0$（功率严格递增）；当 $R_L > R_{Th}$ 时，$\dfrac{dp}{dR_L} < 0$（功率严格递减）。因此 $R_L = R_{Th}$ 是全局唯一极大值点！

将 $R_L = R_{Th}$ 回代至 $p(R_L)$，得到**最大传输功率公式**：

$$p_{\max} = \left(\frac{V_{Th}}{R_{Th} + R_{Th}}\right)^2 R_{Th} = \frac{V_{Th}^2}{4 R_{Th}^2} \cdot R_{Th} = \frac{V_{Th}^2}{4 R_{Th}}$$

同时，写出此时**戴维南等效电路的功率传输效率**（负载功率占电源总发出功率之比）：

$$\eta(R_L) = \frac{P_L}{P_{\text{total}}} = \frac{i_L^2 R_L}{i_L^2 (R_{Th} + R_L)} = \frac{R_L}{R_{Th} + R_L}$$

当满足最大功率匹配条件 $R_L = R_{Th}$ 时：

$$\eta_{\text{match}} = \frac{R_{Th}}{R_{Th} + R_{Th}} = \frac{1}{2} = 50\%$$

同时，此时负载端电压恰好分得一半的开路电压（实验室抓峰值的黄金判据）：

$$V_{L,\text{match}} = V_{Th} \cdot \frac{R_{Th}}{R_{Th} + R_{Th}} = \frac{V_{Th}}{2}$$

#### ③ 归一化数值验算（验证曲线偏态与对称律）
为了看清曲线为何“左陡右缓”，我们定义无量纲负载比 $x = \dfrac{R_L}{R_{Th}}$，则功率归一化公式为 $\dfrac{p(x)}{p_{\max}} = \dfrac{4x}{(1+x)^2}$，效率为 $\eta(x) = \dfrac{x}{1+x}$：

- 当 $x = 0.5$（即 $R_L = 0.5 R_{Th}$）：
  $$\frac{p}{p_{\max}} = \frac{4 \times 0.5}{(1 + 0.5)^2} = \frac{2}{2.25} = \frac{8}{9} \approx 88.89\%, \qquad \eta = \frac{0.5}{1.5} = 33.33\%$$
- 当 $x = 1.0$（即 $R_L = R_{Th}$，**峰值匹配点**）：
  $$\frac{p}{p_{\max}} = \frac{4 \times 1}{(1 + 1)^2} = 100.00\%, \qquad \eta = \frac{1}{2} = 50.00\%$$
- 当 $x = 2.0$（即 $R_L = 2 R_{Th}$）：
  $$\frac{p}{p_{\max}} = \frac{4 \times 2}{(1 + 2)^2} = \frac{8}{9} \approx 88.89\%, \qquad \eta = \frac{2}{3} = 66.67\%$$

> **教授点睛**：你发现了吗？$R_L = 0.5 R_{Th}$ 和 $R_L = 2 R_{Th}$ 的传输功率**一模一样**（都是峰值的 $88.89\%$）！但前者只往左偏了 $0.5 R_{Th}$，后者却往右偏了整整 $1.0 R_{Th}$——这就是右侧更平缓的数学根源；更妙的是，右侧 $2 R_{Th}$ 的效率（$66.67\%$）正好是左侧 $0.5 R_{Th}$（$33.33\%$）的**两倍**！

### 3.3 三段式标准求解板书

#### ① 公理溯源（Origin）
- 先断开负载 $R_L$，使端口 $a\text{–}b$ 处于开路状态。
- 独立源置零法则：将电压源 $V_s$ 短路、电流源 $I_s$ 开路，从端口 $a\text{–}b$ 向左看入求等效内阻 $R_{Th}$。
- 叠加定理（或节点电压法）：分别计算 $V_s$ 单独作用与 $I_s$ 单独作用在开路端口 $a\text{–}b$ 产生的电压，代数相加得 $V_{Th}$。
- 应用最大功率传输定理：令 $R_L = R_{Th}$ 求 $p_{\max}$，并对比偏离匹配点后的功率与效率。

#### ② 纯符号通式（General Formula）

$$R_{Th} = (R_1 \parallel R_2) + R_3 = \frac{R_1 R_2}{R_1 + R_2} + R_3$$

$$V_{Th} = V_{Th1} + V_{Th2} = V_s \frac{R_2}{R_1 + R_2} + I_s \left(R_3 + \frac{R_1 R_2}{R_1 + R_2}\right)$$

$$R_{L,\text{opt}} = R_{Th}, \qquad p_{\max} = \frac{V_{Th}^2}{4 R_{Th}}, \qquad p(R_L) = \left(\frac{V_{Th}}{R_{Th} + R_L}\right)^2 R_L, \qquad \eta(R_L) = \frac{R_L}{R_{Th} + R_L}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）

1. **求戴维南等效内阻 $R_{Th}$**（将 $12\text{ V}$ 电压源短路、$1\text{ A}$ 电流源开路）：
   $$R_1 \parallel R_2 = \frac{6 \times 12}{6 + 12} = \frac{72}{18} = 4\ \Omega$$
   $$R_{Th} = 4 + 4 = 8\ \Omega$$

2. **求戴维南开路电压 $V_{Th}$**（采用叠加定理，端口 $a\text{–}b$ 开路）：
   - **仅 $V_s = 12\text{ V}$ 作用（$I_s$ 开路）**：因端口 $a\text{–}b$ 开路，流过 $R_3 = 4\ \Omega$ 的电流为 $0$，其压降为 $0$，故 $V_{Th1}$ 等于节点 $A$ 的分压：
     $$V_{Th1} = 12 \times \frac{12}{6 + 12} = 12 \times \frac{2}{3} = 8\text{ V}$$
   - **仅 $I_s = 1\text{ A}$ 作用（$V_s$ 短路）**：$1\text{ A}$ 电流全部向左流经 $R_3 = 4\ \Omega$，再流入 $(R_1 \parallel R_2) = 4\ \Omega$ 到地，总输入电阻为 $4 + 4 = 8\ \Omega$：
     $$V_{Th2} = 1 \times (4 + 4) = 8\text{ V}$$
   - **叠加求和**：
     $$V_{Th} = V_{Th1} + V_{Th2} = 8 + 8 = 16\text{ V}$$

3. **求最大功率负载 $R_{L,\text{opt}}$ 与最大功率 $p_{\max}$**：
   $$R_{L,\text{opt}} = R_{Th} = 8\ \Omega$$
   $$p_{\max} = \frac{V_{Th}^2}{4 R_{Th}} = \frac{16^2}{4 \times 8} = \frac{256}{32} = 8\text{ W}$$
   （此时回路电流 $I_L = \dfrac{16}{8 + 8} = 1\text{ A}$，负载电压 $V_L = 8\text{ V}$，效率 $\eta = 50.00\%$。）

4. **对比 $R_L = 0.5 R_{Th} = 4\ \Omega$ 与 $R_L = 2 R_{Th} = 16\ \Omega$**：
   - 当 $R_L = 4\ \Omega$（$0.5 R_{Th}$）：
     $$I_L = \frac{16}{8 + 4} = \frac{4}{3}\text{ A} \approx 1.333\text{ A}, \quad V_L = \frac{16}{3}\text{ V} \approx 5.333\text{ V}$$
     $$p(4\ \Omega) = \left(\frac{4}{3}\right)^2 \times 4 = \frac{64}{9}\text{ W} \approx 7.111\text{ W} \ (88.89\%\ p_{\max}), \quad \eta = \frac{4}{8 + 4} = 33.33\%$$
   - 当 $R_L = 16\ \Omega$（$2 R_{Th}$）：
     $$I_L = \frac{16}{8 + 16} = \frac{2}{3}\text{ A} \approx 0.667\text{ A}, \quad V_L = \frac{32}{3}\text{ V} \approx 10.667\text{ V}$$
     $$p(16\ \Omega) = \left(\frac{2}{3}\right)^2 \times 16 = \frac{64}{9}\text{ W} \approx 7.111\text{ W} \ (88.89\%\ p_{\max}), \quad \eta = \frac{16}{8 + 16} = 66.67\%$$

## 第四幕：50% 效率的工程权衡——为什么电力电网绝不用最大功率传输？

同学们，刚才我们在第三幕里算出了一个令人警醒的数字：当 $R_L = R_{Th}$ 时，效率 $\eta$ **恰好只有 $50\%$**！这意味着每往负载送出 $1\text{ W}$ 的有用功率，电源内阻 $R_{Th}$ 自己就要白白烧掉 $1\text{ W}$ 的废热！

这就引出了整个电路学中最重要的工程分水岭：**什么时候该追求“最大功率（$R_L = R_{Th}$）”，什么时候必须追求“最高效率（$R_L \gg R_{Th}$）”？**

### 4.1 两大工程阵营的鲜明对比

| 维度 | 阵营 A：小信号与通信系统（阻抗匹配） | 阵营 B：电力系统与大功率供电（高效率输电） |
| :--- | :--- | :--- |
| **典型场景** | 射频天线（$50\ \Omega$）、有线电视同轴电缆（$75\ \Omega$）、微弱传感器前端、音频功放与扬声器匹配 | 发电厂 → 变电站 → 城市电网、电动车电池包驱动电机、主板 DC-DC 稳压电源 |
| **核心矛盾** | 信号源功率极其微弱（微瓦 $\mu\text{W}$ 到毫瓦 $\text{mW}$ 级），怕信号被噪声淹没，必须“寸土必争”榨取最大功率（同时在高频下消除信号反射） | 传输功率高达兆瓦（$\text{MW}$）至吉瓦（$\text{GW}$）级，如果效率只有 $50\%$，意味着一半的发电量全变成热能，会瞬间烧毁发电机与输电线，且经济成本不可承受 |
| **设计准则** | **$R_L = R_{Th}$（最大功率匹配）** | **$R_L \gg R_{Th}$（极低内阻供电）** |
| **传输效率 $\eta$** | **$50\%$**（可接受，因为绝对发热量极小） | **$> 90\% \sim 98\%$**（强制要求） |
| **关键误区警报** | 只有在 $R_{Th}$ **无法改变**时才令 $R_L = R_{Th}$；如果能降低 $R_{Th}$，功率还能进一步飙升！ | 绝不能为了“匹配”而人为增大发电机或输电线电阻！ |

### 4.3 教授必敲黑板：最容易掉进去的“反直觉”大坑
很多同学背完 $R_L = R_{Th}$ 后，看到一道题问：“**如果负载 $R_L$ 固定为 $8\ \Omega$ 不变，现在允许你修改电源内阻 $R_{Th}$，请问 $R_{Th}$ 设为多大时负载功率最大？**”——竟脱口而出“$R_{Th} = R_L = 8\ \Omega$”！

**大错特错！** 看公式 $p = \left(\dfrac{V_{Th}}{R_{Th} + R_L}\right)^2 R_L$：
- 当 **$R_{Th}$ 固定、调节 $R_L$** 时，$R_L$ 同时出现在分子和分母，存在折中峰值 $R_L = R_{Th}$；
- 当 **$R_L$ 固定、调节 $R_{Th}$** 时，$R_{Th}$ **只出现在分母**！$R_{Th}$ 越小，分母越小，电流越大，负载功率严格单调递增——理想极限是 $R_{Th} \to 0$，此时负载拿满全部电压 $V_{Th}$，功率高达 $V_{Th}^2 / R_L$（是 $R_{Th}=R_L$ 时的 **4 倍**），效率直逼 **$100\%$**！

### 5.1 安全缩放说明（`breadboard_safety_and_scaling` 落地）
第三幕的理论例题中，$R_{Th} = 8\ \Omega < 100\ \Omega$、$V_{Th} = 16\text{ V}$，峰值功率高达 $8\text{ W}$、电流 $1\text{ A}$。实验室桌面常见的碳膜/金属膜电阻与旋转电位器额定功率仅为 $1/4\text{ W} = 250\text{ mW}$，直接按原值搭建会在 $2$ 秒内冒烟烧毁！

因此，我们在 3D 面包板层执行标准 **$\text{k}\Omega$ 级等比例安全缩放**：
- **电源电压**：$V_{Th} = 5.0\text{ V}$（面包板红蓝电源轨标准 USB 稳压供电）
- **固定内阻**：$R_{Th} = 1\text{ k}\Omega$（色环：**棕-黑-红-金**，额定 $250\text{ mW}$，即便负载完全短路，最大热功耗仅 $5^2 / 1000 = 25\text{ mW}$，留有 $10$ 倍安全裕量！）
- **可调负载**：$0\text{–}10\text{ k}\Omega$ 线性旋转电位器（B10K），将滑动端（Pin 2）与一侧固定端（Pin 3）短接，接成安全的两脚可变电阻，防止旋转接触瞬间悬空。
- **理论预测峰值**：
  - 匹配阻值：$R_{L,\text{opt}} = R_{Th} = 1.00\text{ k}\Omega$
  - 峰值负载电压：$V_{L,\text{opt}} = \dfrac{V_{Th}}{2} = 2.50\text{ V}$（**无需拆电路测电流，盯紧万用表电压读数是否到达电源一半即可！**）
  - 峰值电流：$I_{L,\text{opt}} = \dfrac{5.0}{1000 + 1000} = 2.50\text{ mA}$
  - 最大功率：$P_{\max} = \dfrac{V_{L,\text{opt}}^2}{R_{L,\text{opt}}} = \dfrac{2.50^2}{1000} = 6.25\text{ mW}$

## Claude 工程落地清单（2D / 3D 三层联动实现规范）

供 Breadboard Lab 前端工程 Agent（Claude）直接照单落地的开发规格：

1. **统一响应式状态源（Single Source of Truth）**
   - 维护全局状态对象 `{ mode: "THEORY_EXAMPLE" | "BREADBOARD_LAB", V_Th, R_Th, R_L }`。
   - 切换至 `THEORY_EXAMPLE` 时自动加载 `V_Th = 16 V, R_Th = 8 Ω, R_L ∈ [0.1 Ω, 40 Ω]`；切换至 `BREADBOARD_LAB`（或点击 Layer 03 标签）时自动执行安全缩放 `V_Th = 5 V, R_Th = 1000 Ω, R_L ∈ [50 Ω, 10000 Ω]`，并在顶部弹出非阻塞提示条说明“已按安全规范等比例缩放至 kΩ 级”。
   - 派生只读计算量：
     - `I_L = V_Th / (R_Th + R_L)`
     - `V_L = I_L * R_L`
     - `P_L = (V_L * V_L) / R_L`
     - `P_Th = I_L * I_L * R_Th`
     - `P_max = (V_Th * V_Th) / (4 * R_Th)`
     - `eta = R_L / (R_Th + R_L)`
2. **Layer 01（2D 原理图）交互规格**
   - 渲染第一幕戴维南等效 SVG，右侧 $R_L$ 绑定拖动滑块与数值输入框；
   - 支路电流动画粒子速度与 `I_L` 成正比；
   - 当 `Math.abs(R_L - R_Th) / R_Th < 0.02` 时，$R_L$ 边框高亮为翠绿色并显示 `MATCHED: P_max` 徽章。
3. **Layer 02（实时双曲线图）联动规格**
   - 同屏绘制精确的 $P_L(R_L)$ 偏态峰曲线（蓝）与 $\eta(R_L)$ 单调递增曲线（绿），横轴支持切换“真实阻值”与“归一化比值 $R_L/R_{Th}$”；
   - 固定红色垂直虚线标注 $R_L = R_{Th}$，同时高亮 `(1.0, 100% P_max)` 与 `(1.0, 50% η)` 两个锚点；
   - 两个实时游标圆点分别附着在功率曲线与效率曲线上，随 Layer 01 滑块或 Layer 03 电位器旋钮 60 FPS 同步滑动。
4. **Layer 03（Three.js 3D 面包板实操）联动规格**
   - 场景组件：标准 830 孔面包板、+5V/GND 跳线、`1 kΩ` 棕-黑-红-金四环电阻、B10K 三脚旋转电位器（Pin 2 与 Pin 3 经绿色短接线相连）、虚拟数字万用表（DMM）红黑表笔。
   - 交互控制：支持鼠标指针在电位器旋钮上水平/环形拖拽，将旋转角度 $\theta \in [0^\circ, 270^\circ]$ 线性映射至 $R_L \in [50\ \Omega, 10\text{ k}\Omega]$（并在 $1.00\text{ k}\Omega$ 附近提供柔和的视觉阻尼反馈）；
