### 3. 右侧讲课正文

#### 第 1 幕：节点不是“电荷仓库”——电荷守恒与水流直觉
欢迎来到 **W1-L5**。上节课我们用欧姆定律搞定了单个电阻的“脾气”（$v = iR$），但现实电路动辄几十上百个元件连在一起，光靠欧姆定律远远不够。从今天起，我们要请出电路分析的两大“宪法级”定律——基尔霍夫定律。今天先拿下第一条：**基尔霍夫电流定律（Kirchhoff's Current Law，简称 KCL）**。

别被名字吓住，它的物理直觉你其实早就懂了。把目光移到左侧的 **01 多支路节点动态合流台**，切换一下「水流管道类比模式」（Boylestad Ch. 6 的经典直觉）：想象四根装满水的水管焊在同一个金属接头上。水是不可压缩的，如果左边三根管子每秒一共灌进来 6 升水，右边第四根管子每秒必须正好流出去 6 升水——既不能多，也不能少。如果只流出 5 升，那多出来的 1 升水往哪儿藏？接头要么瞬间憋爆，要么你得变出一个隐藏水箱。

把水管换成铜导线，把水流换成自由电子的定向移动，就得到了电路里最硬核的物理根源：**电荷守恒定律（Law of Conservation of Charge）**。一个理想节点（Node）只是一个没有体积、也没有电容存储能力的几何连接点，它**绝对不能囤积电荷，也不能凭空消灭电荷**。只要多滞留哪怕一微库仑的多余电子，同性相斥的静电力就会瞬间把后续电子顶回去。你可以拖动左侧的三条输入支路滑块试试看：无论你怎么折腾 $i_1, i_2, i_3$，第四条输出支路 $i_4$都会像被一只无形的手死死拽住一样，实时自动守恒。

现在，我们用最严谨的三段式数学语言，把这句物理直觉铸成公式：

**① 公理溯源（电荷守恒与电流定义）** 在任意时间段内，节点 $A$ 处净累积的电荷量变化率为零： $$\frac{dq_{\text{node}}}{dt} = 0$$ 由电流定义 $i_n = \frac{dq_n}{dt}$，若约定流入节点的电荷变化率为正、流出为负，则进入节点的总电荷变化率必须恒等于零： $$\sum_{n=1}^{N} \frac{dq_n}{dt} = 0$$

**② 纯符号通式（KCL 两种等价表达）** 将 $\frac{dq_n}{dt} = i_n$ 代入，得到 **KCL 的标准代数和形式**（Alexander & Sadiku Eq. 2.19）： $$\sum_{n=1}^{N} i_n = 0$$ 将所有流入节点的电流归到等号左边、流出节点的电流移到等号右边，得到工程中最顺手的**流入等于流出等价形式**： $$\sum i_{\text{in}} = \sum i_{\text{out}}$$

**③ 代入数值逐步化简（四支路节点默认工况）** 在左侧默认状态中，节点 $A$ 有三条流入支路 $i_1 = 4\text{ A}$、$i_2 = 3\text{ A}$、$i_3 = -1\text{ A}$（参考方向指向节点 $A$），以及一条流出支路 $i_4$（参考方向背离节点 $A$）。按“流入为正、流出为负”列式： $$i_1 + i_2 + i_3 - i_4 = 0$$ 移项并代入数值： $$i_4 = i_1 + i_2 + i_3 = 4\text{ A} + 3\text{ A} + (-1\text{ A}) = 6\text{ A}$$ 验证流入与流出平衡：实际流入电流为 $4 + 3 = 7\text{ A}$，实际流出电流为 $1 + 6 = 7\text{ A}$，电荷收支绝对平衡。

#### 第 2 幕：正负号的铁律——参考方向、代数和与“负电流”真相
很多同学刚学 KCL 时，最容易在正负号上栽跟头：“老师，我怎么知道哪条支路是真正流入的？万一我把符号写反了怎么办？”

答案特别干脆：**你根本不需要提前猜对真实方向！** KCL 认的是你图上标好的**参考方向（Reference Direction）**。只要你在同一个节点上坚持同一套正负约定，列出来的方程就是百分百正确的。如果最后解出来某个电流是负值（比如$i_3 = -1\text{ A}$），它**绝对不代表你算错了**，它只是电路在诚实地告诉你：“你画的参考箭头指反了，真实电流大小是 $1\text{ A}$，方向与你的箭头正好相反。”

我们拿 Alexander & Sadiku Ch. 2.4 经典的五支路节点来验证一下：无论你用“流入为正、流出为负”，还是反过来用“流出为正、流入为负”，得到的物理结论完全一模一样。你可以在左侧 Layer 01 点击「符号约定切换按钮」亲眼验证。

**① 公理溯源（节点电流代数和守恒）** 对包含 $N=5$ 条支路的节点 $B$，应用 KCL 电荷守恒通式： $$\sum_{n=1}^{5} i_n = 0$$ 图中参考方向设定为：$i_1, i_3, i_4$ 指向节点 $B$（流入）；$i_2, i_5$ 背离节点 $B$（流出）。

**② 纯符号通式（两种约定等价证明）**

- **约定 A（流入为正，流出为负）**： $$(+i_1) + (-i_2) + (+i_3) + (+i_4) + (-i_5) = 0 \implies i_1 + i_3 + i_4 = i_2 + i_5$$
- **约定 B（流出为正，流入为负）**： $$(-i_1) + (+i_2) + (-i_3) + (-i_4) + (+i_5) = 0$$ 将约定 B 两边同乘 $-1$，立刻还原为 $i_1 + i_3 + i_4 = i_2 + i_5$，两种约定**完全等价**。

**③ 代入数值逐步化简（求解未知支路电流 $i_5$）** 已知 $i_1 = 5\text{ A}$，$i_2 = 8\text{ A}$，$i_3 = -2\text{ A}$，$i_4 = 1\text{ A}$，求 $i_5$： $$i_5 = i_1 + i_3 + i_4 - i_2$$ 代入数值： $$i_5 = 5\text{ A} + (-2\text{ A}) + 1\text{ A} - 8\text{ A} = -4\text{ A}$$ **物理翻译**：$i_5 = -4\text{ A}$ 意味着，尽管参考箭头画成“流出节点 $B$”，但实际上有 $4\text{ A}$ 的电流正在**流入**节点 $B$。

#### 第 3 幕：跳出单个“点”——封闭曲面（广义节点）与 World 3 运放伏笔
到这里，我要带你完成一次思维升维。请把左侧切换到 **02 封闭曲面/超级节点 KCL 演示台**，点击**「一键切出封闭虚线边界」**。

很多初学者以为 KCL 只能对着一根导线交叉出来的“几何点”来写。错！**KCL 对空间中任意一个封闭曲面（Closed Surface，又称广义节点或超级节点边界）都严格成立！**

为什么？理由美妙得像魔术一样：假设你用一把虚线剪刀，把一大块包含几十个电阻、甚至一整块黑盒芯片的子电路圈进一个封闭边界 $\mathcal{S}$ 里。只要你把边界里面每一个独立节点的 KCL 方程全部加在一起，任何一条**两端都在边界内部**的支路（比如连接内部节点 $a$ 和 $b$ 的支路 $i_{\text{int}}$），对节点 $a$ 来说是“流出（$-i_{\text{int}}$）”，对节点 $b$ 来说就必然是“流入（$+i_{\text{int}}$）”。两式相加，所有内部支路电流都会两两精确抵消，最后剩下的**全都是穿越封闭边界的外部电流**！

**【重磅伏笔：World 3 运算放大器 Eq. 5.1】** 赶紧点击左侧的「LM741 运放封装预设」，提前看一眼我们将在 **World 3** 遇到的核心元件——运算放大器（Op-Amp）。一块运放芯片内部密密麻麻藏着二三十个晶体管，但如果你把它整片芯片当成一个封闭曲面来列 KCL（正是 Alexander & Sadiku **Eq. 5.1**），你会立刻看穿一个让无数工程师踩坑的真相： $$i_o = i_1 + i_2 + i_+ + i_-$$ 理想运放的两个输入脚几乎不吸电流（$i_1 \approx 0, i_2 \approx 0$），那输出脚哗哗往外送的 $i_o$ 是从哪儿来的？**全是从正负电源脚 $i_+, i_-$ 抽进来的！** 封闭曲面 KCL 让你一眼看穿黑盒芯片的能量与电流去向。

我们用最简洁的双内部节点子电路，完成封闭曲面 KCL 的三段式证明：

**① 公理溯源（对边界内每个节点分别应用 KCL）** 设封闭曲面 $\mathcal{S}$ 内包含节点 $a$ 与节点 $b$，二者之间连有一条内部支路电流 $i_{\text{int}}$（由 $a$ 流向 $b$）。外部有 $i_A, i_B$ 流入 $\mathcal{S}$（分别接至 $a, b$），$i_C, i_D$ 流出 $\mathcal{S}$（分别接自 $a, b$）。按“流入为正、流出为负”： $$\text{节点 } a:\quad i_A - i_C - i_{\text{int}} = 0$$ $$\text{节点 } b:\quad i_B + i_{\text{int}} - i_D = 0$$

**② 纯符号通式（两式相加消去内部支路）** 将节点 $a$ 与节点 $b$ 的 KCL 方程相加： $$(i_A - i_C - i_{\text{int}}) + (i_B + i_{\text{int}} - i_D) = 0$$ 内部支路 $-i_{\text{int}}$ 与 $+i_{\text{int}}$ 精确抵消，得到封闭曲面 $\mathcal{S}$ 的宏观 KCL： $$i_A + i_B - i_C - i_D = 0 \implies \sum i_{\text{in},,\mathcal{S}} = \sum i_{\text{out},,\mathcal{S}}$$

**③ 代入数值逐步化简（求解外部未知引脚电流 $i_D$）** 设外部流入电流 $i_A = 5\text{ A}$、$i_B = 3\text{ A}$，外部流出电流 $i_C = 2\text{ A}$，无论内部电阻如何变动（哪怕内部环流 $i_{\text{int}}$ 从 $1\text{ A}$ 变成 $100\text{ A}$），外部流出电流 $i_D$ 恒为： $$i_D = i_A + i_B - i_C = 5\text{ A} + 3\text{ A} - 2\text{ A} = 6\text{ A}$$

#### 第 4 幕：并联电流源的等效合并与“串联禁区”
掌握了 KCL，我们立刻就能解锁一个极实用的化简技巧——**并联电流源的等效合并**，顺便彻底搞懂电路里的一条“高压红线”——**两个不同电流源绝不能串联**。

先看**并联**：如果有三个独立电流源并联在相同的两个节点 $a$ 和 $b$ 之间，它们共同向外部电路送出总电流 $I_T$。你只需对顶部的公共节点 $a$ 列一次 KCL，就能把这三个源合并成一个等效电流源 $I_T$，大小等于各支路电流源的**代数和**（箭头同向相加，反向相减）。可以在左侧 Layer 02 切换到「电流源实验」点击「一键合并」看动画。

再看**串联禁区**：假如你手滑把一个 $2\text{ A}$ 的理想电流源和一个 $5\text{ A}$ 的理想电流源首尾直接串联起来，会发生什么？对它们俩中间的那个连接节点列 KCL：左边强行每秒塞进来 2 库仑电荷，右边强行每秒抽走 5 库仑电荷——KCL 瞬间变成 $2\text{ A} = 5\text{ A}$！这不仅在数学上是赤裸裸的荒谬，在物理上更是直接违背了电荷守恒（理想电流源内阻无穷大，为对抗这 $3\text{ A}$ 的差值，中间节点电压会瞬间飙升至无穷大并击穿器件）。**记住铁律：不同电流值的理想电流源绝对禁止串联（只有电流值与方向完全一致时才在数学上不矛盾，但工程上也绝不这样画）。**

**① 公理溯源（公共节点 KCL 与反证法）**

- **并联情形**：对并联电流源顶部节点 $a$ 列 KCL（流入为正、流出为负），$I_1, I_3$ 向上流入节点 $a$，$I_2$ 向下流出节点 $a$，等效总电流 $I_T$ 向右流出节点 $a$： $$\sum_{n=1}^{4} i_n = 0 \implies I_1 - I_2 + I_3 - I_T = 0$$
- **串联禁区（反证）**：设 $I_A$ 与 $I_B$（$I_A \neq I_B$）串联于同一无分支路径，对中间节点 $m$ 列 KCL： $$I_A - I_B = 0 \implies I_A = I_B$$ 与前提 $I_A \neq I_B$ 直接矛盾。

**② 纯符号通式（并联电流源等效合并公式）** 由节点 $a$ 的 KCL 移项即得等效合并通式（Alexander & Sadiku Ch. 2.4）： $$I_T = I_1 - I_2 + I_3$$

**③ 代入数值逐步化简** 设 $I_1 = 5\text{ A}$（向上）、$I_2 = 2\text{ A}$（向下）、$I_3 = 4\text{ A}$（向上），则等效单一电流源为： $$I_T = 5\text{ A} - 2\text{ A} + 4\text{ A} = 7\text{ A}\quad(\text{方向向上流出节点 } a)$$ 而在串联禁区中，若 $I_A = 2\text{ A}$ 与 $I_B = 5\text{ A}$ 串联，中间节点得出 $2\text{ A} - 5\text{ A} = -3\text{ A} \neq 0$，**电路非法**。

#### 第 5 幕：综合实战——含受控电流源的 KCL + 欧姆定律联立
理论讲完，我们来啃一块考试和工程里最常碰见的硬骨头：当电路里出现一个**菱形符号的受控电流源（Dependent Current Source）**时，KCL 怎么列？

记住教授的一句口诀：**“把受控源当普通电流支路先写进 KCL，再用欧姆定律把所有未知量拧成一根绳。”** 菱形框并不神秘，它只是电流大小听命于电路里另一条支路的电流（或电压）罢了。

来看下面这道并联电路：一个 $I_s = 15\text{ A}$ 的独立电流源、两个电阻 $R_1 = 6,\Omega$ 和 $R_2 = 3,\Omega$、以及一个受控电流源 $\alpha i_1$（其中 $\alpha = 2$，方向向下流出顶部节点 $a$）全部并联在节点 $a$ 与参考地之间。我们需要求出节点电压 $v_o$ 和各支路电流 $i_1, i_2$。

**① 公理溯源（节点 KCL + 电阻欧姆定律）** 对顶部节点 $a$ 应用 KCL（$\sum i_{\text{in}} = \sum i_{\text{out}}$），同时对并联在节点 $a$ 与参考地之间的两条电阻支路应用欧姆定律： $$I_s = i_1 + i_2 + \alpha i_1$$ $$i_1 = \frac{v_o}{R_1}, \qquad i_2 = \frac{v_o}{R_2}$$

**② 纯符号通式（消元并解出 $v_o$）** 合并 KCL 中的 $i_1$ 项，并将欧姆定律代入，全部统一为未知数 $v_o$： $$I_s = (1 + \alpha) i_1 + i_2 = (1 + \alpha)\frac{v_o}{R_1} + \frac{v_o}{R_2} = v_o \left(\frac{1 + \alpha}{R_1} + \frac{1}{R_2}\right)$$ 解出纯符号通式： $$v_o = \frac{I_s}{\dfrac{1 + \alpha}{R_1} + \dfrac{1}{R_2}}$$

**③ 代入数值逐步化简** 代入 $I_s = 15\text{ A}$、$R_1 = 6,\Omega$、$R_2 = 3,\Omega$、$\alpha = 2$： $$v_o = \frac{15}{\dfrac{1 + 2}{6} + \dfrac{1}{3}} = \frac{15}{\dfrac{3}{6} + \dfrac{2}{6}} = \frac{15}{\dfrac{5}{6}} = 15 \times \frac{6}{5} = 18\text{ V}$$ 反代求各支路电流并做 KCL 复核： $$i_1 = \frac{18\text{ V}}{6,\Omega} = 3\text{ A}, \qquad i_2 = \frac{18\text{ V}}{3,\Omega} = 6\text{ A}, \qquad 2i_1 = 6\text{ A}$$ 复核：总流出 $= 3 + 6 + 6 = 15\text{ A} = I_s$，完美闭合！
