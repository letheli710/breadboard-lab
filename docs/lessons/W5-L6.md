# W5-L6：视在功率、复功率、功率三角形与功率因数校正

> **教授开场白**：欢迎回到 Breadboard Lab。上一讲（`W5-L5`）我们搞懂了交流电路里的**平均功率（有功功率）$P$** 与**有效值（RMS）**，知道了真正让电烙铁发热、让电机干活的功率是 $P = V_{\text{rms}} I_{\text{rms}} \cos(\theta_v - \theta_i)$。但今天我要问你一个让无数工厂电工和电网总工头疼的现实问题：
>
> **既然电机只“吃”了 $4\text{ kW}$ 的有功功率，为什么供电局却要按 $5\text{ kVA}$ 的变压器容量给你配电、按 $41.67\text{ A}$ 的大电流给你拉粗电缆，甚至在你的功率因数低于 $0.90$ 时直接给你开“力调电费”罚单？**
>
> 今天这一课，我们就用五幕完整拆解交流功率体系的终极拼图——从一杯啤酒的工程直觉出发，立起**复功率 $\mathbf{S} = \mathbf{V}_{\text{rms}}\mathbf{I}_{\text{rms}}^*$** 的数学铁律，打通**多负载复功率守恒**，最后亲手设计一套**并联电容功率因数校正（PFC）**方案，把工厂输电线损一口气砍掉近三成！

## 第 1 幕：啤酒杯直觉——视在功率 $S$、无功功率 $Q$ 与滞后/超前功率因数

### 1.1 为什么交流电路不能只看有功功率 $P$？

在直流电路里，功率只有一种：$P = VI$。但在正弦稳态交流电路中，由于电感（电机绕组、变压器）和电容的存在，电压与电流之间出现了相位差 $\theta = \theta_v - \theta_i$。

这就导致了一件很微妙的事：电网送过来的电流里，只有**一部分**在真正对外做功（转化为机械能、热能、光能），另一部分电流则在电源与电感磁场（或电容电场）之间**来回吞吐、原地折返**——它一个周期平均下来不做净功，但它**实实在在地占用了导线的载流截面积、变压器的铁芯容量，并且在输电线电阻上白白产生 $I^2 R_{\text{line}}$ 铜损！**

电力工程师发明了一个流传百年的绝妙比喻——**啤酒杯模型**：

- **酒液 = 有功功率 $P$（单位：瓦特 $\text{W}$）**：你真正喝进肚子解渴的部分，对应负载实际消耗的能量速率：$P = V_{\text{rms}} I_{\text{rms}} \cos(\theta_v - \theta_i)$。
- **泡沫 = 无功功率 $Q$（单位：乏 $\text{VAR}$，Volt-Ampere Reactive）**：虽然不能解渴，但没有泡沫就没有电机的旋转磁场（无法建立励磁），它负责在电源和储能元件之间交换能量：$Q = V_{\text{rms}} I_{\text{rms}} \sin(\theta_v - \theta_i)$。
- **整杯容量 = 视在功率 $S$（单位：伏安 $\text{VA}$）**：酒液和泡沫合起来占用的杯子总容积（注意在数学上是**勾股合成**而非简单相加！），它直接决定了供电局必须为你配备多大的变压器与多粗的电缆：
  $$S = V_{\text{rms}} I_{\text{rms}} = \sqrt{P^2 + Q^2}$$
- **功率因数 $\text{pf}$**：衡量这杯“电啤酒”的**含酒量（有效利用率）**：
  $$\text{pf} = \frac{P}{S} = \cos(\theta_v - \theta_i) = \cos\theta$$

> **教授敲黑板（单位铁律）**：在国际单位制里，$\text{W}$、$\text{VAR}$、$\text{VA}$ 的量纲全都是 $\text{V}\cdot\text{A}$，但工程上**严禁混用**！看到 $\text{W}$ 就知道是 $P$，看到 $\text{VAR}$ 就知道是 $Q$，看到 $\text{VA}$ 或 $\text{kVA}$ 就知道是视在功率 $S$（这也是为什么变压器铭牌永远标 $\text{kVA}$ 而不是 $\text{kW}$——变压器不在乎你接的是电阻还是电感，它只怕电流超过额定值烧毁绕组！）。

### 1.2 滞后（Lagging）与超前（Leading）：决定符号的生死线

因为 $\cos(-\theta) = \cos(\theta)$，如果我只告诉你“某负载功率因数是 $0.8$”，你根本不知道它是电感性负载还是电容性负载！因此，在工程表达中，**功率因数必须附带“滞后（Lagging）”或“超前（Leading）”标签**，这一称呼永远以**电流相量 $\mathbf{I}$ 相对于电压相量 $\mathbf{V}$ 的相位关系**为准：

| 负载性质 | 电流与电压相位关系 | 功率因数角 $\theta = \theta_v - \theta_i$ | 无功功率 $Q$ 符号 | 功率因数标注 | 典型工程设备 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **感性负载 (Inductive)** | 电流**滞后**于电压 | $\theta > 0$（$0^\circ < \theta \le 90^\circ$） | $Q > 0$（**吸收**无功） | **滞后 (Lagging)** | 异步电机、变压器、日光灯镇流器 |
| **纯阻负载 (Resistive)** | 电流与电压**同相** | $\theta = 0^\circ$ | $Q = 0$ | **单位功率因数 ($\text{pf}=1$)** | 电阻炉、白炽灯、电热水器 |
| **容性负载 (Capacitive)** | 电流**超前**于电压 | $\theta < 0$（$-90^\circ \le \theta < 0^\circ$） | $Q < 0$（**发出/提供**无功） | **超前 (Leading)** | 并联电力电容器组、过励磁同步调相机 |

## 第 2 幕：复功率 $\mathbf{S} = \mathbf{V}_{\text{rms}}\mathbf{I}_{\text{rms}}^*$、共轭铁律与功率三角形

### 2.1 为什么必须对电流相量取共轭 $\mathbf{I}_{\text{rms}}^*$？

很多同学刚学复功率时，会下意识地写 $\mathbf{S} = \mathbf{V}_{\text{rms}} \mathbf{I}_{\text{rms}}$。**停！这是交流电路分析里最致命的符号错误！**

让我们亲自试一下如果不取共轭会发生什么惨案：
设 $\mathbf{V}_{\text{rms}} = V_{\text{rms}} \angle \theta_v$，$\mathbf{I}_{\text{rms}} = I_{\text{rms}} \angle \theta_i$。
- **错误写法（不取共轭）**：
  $$\mathbf{V}_{\text{rms}} \mathbf{I}_{\text{rms}} = V_{\text{rms}} I_{\text{rms}} \angle(\theta_v + \theta_i)$$
  这里相位角变成了**相加** $\theta_v + \theta_i$！哪怕把时间零点平移一下，$\theta_v + \theta_i$ 就会跟着乱变；更糟糕的是，当 $\theta_v = 0^\circ$ 时，感性负载的电流滞后（$\theta_i < 0$），相乘后虚部变成负的——**感性负载的 $Q$ 竟然算成了负值，符号全反！**
- **正确定义（对电流取共轭 $\mathbf{I}_{\text{rms}}^*$）**：
  $$\mathbf{S} = \mathbf{V}_{\text{rms}} \mathbf{I}_{\text{rms}}^* = \left(V_{\text{rms}} \angle \theta_v\right)\left(I_{\text{rms}} \angle -\theta_i\right) = V_{\text{rms}} I_{\text{rms}} \angle(\theta_v - \theta_i)$$
  展开为直角坐标形式：
  $$\mathbf{S} = V_{\text{rms}} I_{\text{rms}} \cos(\theta_v - \theta_i) + j\, V_{\text{rms}} I_{\text{rms}} \sin(\theta_v - \theta_i) = P + jQ$$

你看，加上这个小小的共轭星号 `*`，奇迹立刻发生：
1. **实部** $\text{Re}(\mathbf{S}) = P$，精确等于有功功率；
2. **虚部** $\text{Im}(\mathbf{S}) = Q$，精确等于无功功率，且**感性负载 $Q > 0$（第一象限），容性负载 $Q < 0$（第四象限）**；
3. **模长** $|\mathbf{S}| = S = \sqrt{P^2 + Q^2}$，精确等于视在功率；
4. **辐角** $\angle \mathbf{S} = \theta_v - \theta_i$，精确等于负载阻抗角 $\theta_Z$（与电源参考初相完全无关！）。

结合欧姆定律 $\mathbf{V}_{\text{rms}} = \mathbf{Z}\mathbf{I}_{\text{rms}}$，我们还能立刻得到复功率的另外两个黄金等价形式：
$$\mathbf{S} = \mathbf{V}_{\text{rms}}\mathbf{I}_{\text{rms}}^* = I_{\text{rms}}^2 \mathbf{Z} = \frac{V_{\text{rms}}^2}{\mathbf{Z}^*}$$
*(注意最后一个式子：分母上的阻抗 $\mathbf{Z}$ 也必须取共轭 $\mathbf{Z}^*$！)*

### 2.3 三段式教授板书推导：单感性负载复功率全量求解

**题目条件**：一台单相感性负载阻抗 $\mathbf{Z} = (12 + j16)\,\Omega$，接在有效值 $\mathbf{V}_{\text{rms}} = 120\angle 0^\circ\text{ V}$ 的交流电源上。求电流相量 $\mathbf{I}_{\text{rms}}$、复功率 $\mathbf{S}$、有功功率 $P$、无功功率 $Q$、视在功率 $S$ 及功率因数 $\text{pf}$。

#### ① 公理溯源
根据交流欧姆定律与复功率基本定义（**严格对电流相量取共轭**）：
$$\mathbf{I}_{\text{rms}} = \frac{\mathbf{V}_{\text{rms}}}{\mathbf{Z}}, \qquad \mathbf{S} = \mathbf{V}_{\text{rms}}\mathbf{I}_{\text{rms}}^* = P + jQ$$

#### ② 纯符号通式
设 $\mathbf{Z} = R + jX = |\mathbf{Z}|\angle \theta_Z$，其中 $|\mathbf{Z}| = \sqrt{R^2 + X^2}$，$\theta_Z = \arctan(X/R)$。代入复功率定义：
$$\mathbf{I}_{\text{rms}} = \frac{V_{\text{rms}}}{|\mathbf{Z}|}\angle(\theta_v - \theta_Z)$$
$$\mathbf{S} = \mathbf{V}_{\text{rms}}\mathbf{I}_{\text{rms}}^* = \left(\frac{V_{\text{rms}}}{|\mathbf{Z}|}\right)^2 (R + jX) = I_{\text{rms}}^2 R + j\,I_{\text{rms}}^2 X$$
由此得到各分量的纯符号解析式：
$$P = I_{\text{rms}}^2 R, \qquad Q = I_{\text{rms}}^2 X, \qquad S = \sqrt{P^2 + Q^2} = V_{\text{rms}} I_{\text{rms}}, \qquad \text{pf} = \frac{P}{S} = \cos\theta_Z$$

#### ③ 代入数值逐步化简
1. **阻抗模与阻抗角**：
   $$|\mathbf{Z}| = \sqrt{12^2 + 16^2} = \sqrt{144 + 256} = 20\,\Omega, \qquad \theta_Z = \arctan\left(\frac{16}{12}\right) = 53.13^\circ$$
2. **电流有效值相量**：
   $$\mathbf{I}_{\text{rms}} = \frac{120\angle 0^\circ}{20\angle 53.13^\circ} = 6.00\angle -53.13^\circ\text{ A}$$
3. **复功率（严格取共轭 $\mathbf{I}_{\text{rms}}^* = 6.00\angle +53.13^\circ\text{ A}$）**：
   $$\mathbf{S} = (120\angle 0^\circ)(6.00\angle +53.13^\circ) = 720\angle 53.13^\circ\text{ VA}$$
   用 $I_{\text{rms}}^2 \mathbf{Z}$ 交叉验算直角坐标：
   $$P = 6.00^2 \times 12 = 432\text{ W}, \qquad Q = 6.00^2 \times 16 = +576\text{ VAR}$$
   $$\mathbf{S} = 432 + j576\text{ VA}$$
4. **视在功率与功率因数**：
   $$S = \sqrt{432^2 + 576^2} = 720\text{ VA}, \qquad \text{pf} = \frac{432}{720} = 0.60\text{ 滞后 (Lagging)}$$

## 第 3 幕：交流复功率守恒定律与多负载复功率叠加

### 3.1 为什么 $P$ 和 $Q$ 可以直接相加，但 $S$ 绝不能标量相加？

在实际工厂车间里，一条 $220\text{ V}$ 或 $380\text{ V}$ 母线上往往并联着几十台设备：冲床电机（感性）、烘干炉（纯阻）、照明与电容补偿柜（容性）。我们需要算出整条母线的总功率和总电流。

**交流复功率守恒定律（Sadiku §11.7）**：无论负载是串联、并联还是混联，整个网络消耗的总复功率等于各支路元件复功率的**复数代数和**：
$$\mathbf{S}_{\text{total}} = \sum_{k=1}^{n} \mathbf{S}_k = \left(\sum_{k=1}^{n} P_k\right) + j\left(\sum_{k=1}^{n} Q_k\right) = P_{\text{total}} + jQ_{\text{total}}$$

请把下面这条**工程铁律**刻进脑子里：
- **有功功率 $P$ 标量相加**：$P_{\text{total}} = P_1 + P_2 + \cdots + P_n$（无源负载 $P_k \ge 0$）。
- **无功功率 $Q$ 带符号代数相加**：$Q_{\text{total}} = Q_1 + Q_2 + \cdots + Q_n$（感性为正 $+$，容性为负 $-$，**彼此可以直接抵消！**）。
- **视在功率 $S$ 严禁直接标量相加！**
  $$S_{\text{total}} = \sqrt{P_{\text{total}}^2 + Q_{\text{total}}^2} \le \sum_{k=1}^{n} S_k$$
  只有当所有负载具有完全相同的功率因数角 $\theta_k$ 时等号才成立。如果一个 $10\text{ kVA}$ 感性负载与一个 $5\text{ kVA}$ 容性负载并联，总视在功率**远小于** $15\text{ kVA}$，因为它们的无功分量一上一下互相抵消了！Boylestad 第 19 章用**功率三角形首尾相接矢量合成**最直观地揭示了这一几何本质。

### 3.3 三段式教授板书推导：三路并联工厂母线总复功率与总电流

**题目条件**：一条 $V_{\text{rms}} = 220\text{ V}$、$f = 50\text{ Hz}$ 的工厂配电母线上并联了三个负载：
- 负载 1（感应电机群）：$S_1 = 10\text{ kVA}$，$\text{pf}_1 = 0.8$ 滞后；
- 负载 2（电阻加热炉）：$P_2 = 6\text{ kW}$，$\text{pf}_2 = 1.0$；
- 负载 3（过励磁同步机）：$S_3 = 5\text{ kVA}$，$\text{pf}_3 = 0.6$ 超前。

求母线总复功率 $\mathbf{S}_{\text{total}}$、总视在功率 $S_{\text{total}}$、总功率因数 $\text{pf}_{\text{total}}$ 以及母线总电流有效值 $I_{\text{total}}$。

#### ① 公理溯源
依据交流复功率守恒定律，各并联支路复功率的实部与虚部分别代数叠加：
$$\mathbf{S}_{\text{total}} = \sum_{k=1}^{3} \mathbf{S}_k = \left(\sum_{k=1}^{3} P_k\right) + j\left(\sum_{k=1}^{3} Q_k\right)$$
其中对每个负载，滞后取正号（$+Q$）、超前取负号（$-Q$）。

#### ② 纯符号通式
$$P_k = S_k \cdot \text{pf}_k, \qquad Q_k = \pm S_k \sqrt{1 - \text{pf}_k^2}$$
$$P_{\text{total}} = P_1 + P_2 + P_3, \qquad Q_{\text{total}} = Q_1 + Q_2 + Q_3$$
$$S_{\text{total}} = \sqrt{P_{\text{total}}^2 + Q_{\text{total}}^2}, \qquad \text{pf}_{\text{total}} = \frac{P_{\text{total}}}{S_{\text{total}}}, \qquad I_{\text{total}} = \frac{S_{\text{total}}}{V_{\text{rms}}}$$

#### ③ 代入数值逐步化简
1. **逐一拆解各负载的 $P_k$ 与 $Q_k$**：
   - 负载 1（滞后，$Q_1 > 0$）：
     $$P_1 = 10 \times 0.8 = 8.00\text{ kW}, \qquad Q_1 = +10 \times \sqrt{1 - 0.8^2} = +6.00\text{ kVAR}$$
   - 负载 2（纯阻，$Q_2 = 0$）：
     $$P_2 = 6.00\text{ kW}, \qquad Q_2 = 0\text{ kVAR}$$
   - 负载 3（超前，$Q_3 < 0$）：
     $$P_3 = 5 \times 0.6 = 3.00\text{ kW}, \qquad Q_3 = -5 \times \sqrt{1 - 0.6^2} = -4.00\text{ kVAR}$$
2. **总有功与总无功代数叠加**：
   $$P_{\text{total}} = 8.00 + 6.00 + 3.00 = 17.00\text{ kW}$$
   $$Q_{\text{total}} = +6.00 + 0 - 4.00 = +2.00\text{ kVAR}$$
   $$\mathbf{S}_{\text{total}} = 17.00 + j2.00\text{ kVA}$$
3. **总视在功率、总功率因数与母线总电流**：
   $$S_{\text{total}} = \sqrt{17.00^2 + 2.00^2} = \sqrt{293} = 17.12\text{ kVA} \quad (\text{远小于错误标量之和 } 21\text{ kVA!})$$
   $$\text{pf}_{\text{total}} = \frac{17.00}{17.12} = 0.9932\text{ 滞后 (因 } Q_{\text{total}} = +2.00\text{ kVAR} > 0\text{)}$$
   $$I_{\text{total}} = \frac{17117.24\text{ VA}}{220\text{ V}} = 77.81\text{ A}$$

## 第 4 幕：并联电容功率因数校正（Power Factor Correction）

### 4.1 为什么要给感性负载“并联”电容器？三个核心物理真相

绝大多数工业负载（异步电动机、电焊机、荧光灯镇流器）都是**感性负载**，自然功率因数往往只有 $0.65 \sim 0.80$ 滞后。为了把功率因数提升到供电局要求的 $0.95$ 滞后，工程师在负载两端**并联**一组电力电容器。

请牢记以下**三条铁律**：

1. **绝不改变负载本身的有功功率 $P$！**
   因为电容是**并联**在恒压母线 $V_{\text{rms}}$ 两端的，负载两端的电压 $V_{\text{rms}}$ 纹丝不动，负载内部电流 $\mathbf{I}_L$ 也不变，所以电机照常出力，**有功功率 $P$ 保持绝对不变**。理想电容本身消耗的有功功率 $P_C = 0$。
2. **就地提供无功，砍断输电线上的“折返泡沫电流”！**
   并联电容发出负无功功率 $Q_C = -\omega C V_{\text{rms}}^2$（就地向电机磁场供给无功交换），使得供电线路只需送出极少量的净无功 $Q_2 = Q_1 - |Q_C|$。视在功率 $S = P / \text{pf}$ 显著缩小，线路电流 $I_{\text{line}} = \frac{P}{V_{\text{rms}} \cdot \text{pf}}$ 与 $\text{pf}$ 成反比下降！
3. **输电线损按平方比例暴跌！**
   由于输电线铜损 $P_{\text{loss}} = I_{\text{line}}^2 R_{\text{line}} \propto \frac{1}{\text{pf}^2}$：
   - 把 $\text{pf}$ 从 $0.70$ 校正到 $0.95$：电流下降 $26.3\%$，**输电线损暴跌 $45.7\%$**！
   - 把 $\text{pf}$ 从 $0.80$ 校正到 $0.95$：电流下降 $15.8\%$，**输电线损暴跌 $29.1\%$**！

> **教授进阶追问**：既然提高 $\text{pf}$ 这么好，为什么工厂通常校正到 $0.95$ 滞后，而不是死磕到 $1.00$ 甚至超前？
> 因为 $\tan\theta$ 在 $\theta \to 0^\circ$ 时边际收益急剧下降（从 $0.95$ 到 $1.00$ 需要额外增加近 $45\%$ 的电容投资，却只换来 $5\%$ 的电流降幅），而且工厂夜间轻载时，过大电容会导致电网变成**超前容性**，引发**母线过电压**甚至谐振烧毁设备！

### 4.3 三段式教授板书推导：经典 Sadiku §11.7 并联电容功率因数校正

**题目条件**（对标 Sadiku 2026 Release §11.7 经典例题）：一台接在 $V_{\text{rms}} = 120\text{ V}$、$f = 60\text{ Hz}$ 交流电源上的感性负载消耗有功功率 $P = 4\text{ kW}$，初始功率因数为 $\text{pf}_1 = 0.8$ 滞后。现欲在负载两端并联一只电容器，将总功率因数校正到 $\text{pf}_2 = 0.95$ 滞后。求：
1. 所需并联电容的无功容量 $Q_C$ 与电容值 $C$；
2. 校正前后输电线路电流 $I_1, I_2$ 及线损下降百分比。

#### ① 公理溯源
并联电容接在理想电压源母线两端，负载有功功率 $P$ 保持恒定。依据功率三角形几何关系与交流复功率守恒：
$$Q_1 = P\tan\theta_1, \qquad Q_2 = P\tan\theta_2, \qquad Q_C = Q_1 - Q_2$$
理想电容器在有效值电压 $V_{\text{rms}}$、角频率 $\omega = 2\pi f$ 下发出的无功功率幅值为：
$$Q_C = \frac{V_{\text{rms}}^2}{|X_C|} = \omega C V_{\text{rms}}^2$$

#### ② 纯符号通式
联立上述两式，消去 $Q_C$，得到电力工程中最核心的**功率因数校正电容通式**：
$$Q_C = P(\tan\theta_1 - \tan\theta_2), \qquad C = \frac{Q_C}{\omega V_{\text{rms}}^2} = \frac{P(\tan\theta_1 - \tan\theta_2)}{2\pi f V_{\text{rms}}^2}$$
其中 $\theta_1 = \arccos(\text{pf}_1)$、$\theta_2 = \arccos(\text{pf}_2)$（均取正值，对应滞后状态）。
校正前后线路电流与线损降幅通式：
$$I_1 = \frac{P}{V_{\text{rms}} \cdot \text{pf}_1}, \qquad I_2 = \frac{P}{V_{\text{rms}} \cdot \text{pf}_2}, \qquad \Delta P_{\text{loss}}\% = \left[1 - \left(\frac{\text{pf}_1}{\text{pf}_2}\right)^2\right] \times 100\%$$

#### ③ 代入数值逐步化简
1. **计算校正前后功率因数角与无功功率**：
   $$\theta_1 = \arccos(0.80) = 36.87^\circ \implies \tan\theta_1 = 0.7500$$
   $$\theta_2 = \arccos(0.95) = 18.19^\circ \implies \tan\theta_2 = 0.3287$$
   $$Q_1 = 4000 \times 0.7500 = 3000.00\text{ VAR}$$
   $$Q_2 = 4000 \times 0.328684 = 1314.74\text{ VAR}$$
2. **求所需补偿无功 $Q_C$ 与电容值 $C$**：
   $$Q_C = Q_1 - Q_2 = 3000.00 - 1314.74 = 1685.26\text{ VAR}$$
   $$\omega = 2\pi \times 60 = 376.99\text{ rad/s}$$
   $$C = \frac{1685.26}{376.99 \times 120^2} = \frac{1685.26}{5.4287 \times 10^6} = 3.1044 \times 10^{-4}\text{ F} = 310.44\,\mu\text{F}$$
3. **校正前后线路电流与输电线损对比**：
   $$I_1 = \frac{4000}{120 \times 0.80} = 41.67\text{ A}, \qquad I_2 = \frac{4000}{120 \times 0.95} = 35.09\text{ A}$$
   $$\text{电流降幅} = \frac{41.67 - 35.09}{41.67} \times 100\% = 15.79\%$$
   $$\text{线损降幅} = \left[1 - \left(\frac{0.80}{0.95}\right)^2\right] \times 100\% = 29.09\%$$
