### 第三章：右侧讲课正文（共 8 幕）

#### 第 1 幕：开篇悬念 — 手头只有一颗 9 V 电池，怎么“切”出精准的 6 V 和 3 V？
同学们好！上一讲我们刚把基尔霍夫电压定律（KVL）、电流定律（KCL）和欧姆定律这“电路三板斧”练熟。今天这节课，我们要把这三把斧头锻造成电路设计中最常用、也最容易踩坑的两个工程利器：**串联分压器（Voltage Divider）与并联分流器（Current Divider）**。

先看一个你在实验室第一周就会撞上的真实场景：你的实验箱里只有一颗 **9 V 直流电池**，但你手上的传感器参考电压需要 **6.0 V**，或者你需要把一路总电流按 **2 : 1** 的精确比例分配给两条不同阻值的支路。你手边没有昂贵的稳压芯片，只有一把碳膜电阻。怎么办？

答案非常优雅：

- **想“切”电压** $\rightarrow$ 把两个电阻 **串联** 起来，让它们按阻值比例分担 9 V；
- **想“切”电流** $\rightarrow$ 把两个电阻 **并联** 起来，让总电流按“阻力越小分得越多”的规律自动分流。

**先看一眼左侧的三层舞台**：你可以在 01 2D 动态原理图 里拖动滑块改变 $R_1$ 和 $R_2$，观察 02 比例权重曲线 的实时移动，同时 03 3D 面包板 上的真实色环电阻和万用表读数会同步跳动。不过在正式通电之前，后面第 5 幕我还要告诉你一个**保命秘诀**：为什么教材例题里写的 $2\ \Omega$ 和 $4\ \Omega$，到了 9 V 面包板上必须乘以 $1000$ 变成 $2\text{ k}\Omega$ 和 $4\text{ k}\Omega$？卖个关子，咱们先从最严谨的公理推导开始！

#### 第 2 幕：串联等效电阻与分压公式 — 为什么“分压看自己”？
在 Alexander & Sadiku 第 2.5 节中，串联（Series）有一个极其严格的拓扑定义：**两个元件首尾相连，且公共节点上没有任何第三条支路分流**。因此，流过 $R_1$ 和 $R_2$ 的电流必然完全相等，记为同一个电流 $i$。

下面我们用最严谨的三段式推导，把串联等效电阻和分压公式从基尔霍夫公理里“推”出来（以单 9 V 电源、安全缩放后的 $R_1 = 2\text{ k}\Omega$、$R_2 = 4\text{ k}\Omega$ 为例）：
##### 推导 2.1：串联等效电阻与分压公式
**① 公理溯源（KVL + 欧姆定律）**

沿单一闭合回路顺时针列写 KVL 方程，并结合各电阻的欧姆定律本构关系：

$$-v + v_1 + v_2 = 0 \implies v = v_1 + v_2$$

$$v_1 = i R_1, \qquad v_2 = i R_2$$

**② 纯符号通式（消去电流 $i$，导出 $R_{\text{eq}}$ 与分压公式）**

将欧姆定律代入 KVL 方程，提取公共电流 $i$：

$$v = i R_1 + i R_2 = i(R_1 + R_2) \implies R_{\text{eq}} = \frac{v}{i} = R_1 + R_2$$

由此解得回路电流 $i = \dfrac{v}{R_1 + R_2}$。再代回各电阻的欧姆定律，即得**两电阻分压公式**：

$$v_1 = i R_1 = \frac{R_1}{R_1 + R_2} v, \qquad v_2 = i R_2 = \frac{R_2}{R_1 + R_2} v$$

推广至 $N$ 个电阻串联，任意第 $n$ 个电阻上的电压为：

$$v_n = \frac{R_n}{R_1 + R_2 + \cdots + R_N} v = \frac{R_n}{R_{\text{eq}}} v$$

**③ 代入数值逐步化简（$v = V_s = 9\text{ V},\ R_1 = 2\text{ k}\Omega,\ R_2 = 4\text{ k}\Omega$）**

$$R_{\text{eq}} = 2\text{ k}\Omega + 4\text{ k}\Omega = 6\text{ k}\Omega$$

$$i = \frac{9\text{ V}}{6\text{ k}\Omega} = 1.5\text{ mA}$$

$$v_1 = \frac{2\text{ k}\Omega}{2\text{ k}\Omega + 4\text{ k}\Omega} \times 9\text{ V} = \frac{2}{6} \times 9\text{ V} = 3.00\text{ V}$$

$$v_2 = \frac{4\text{ k}\Omega}{2\text{ k}\Omega + 4\text{ k}\Omega} \times 9\text{ V} = \frac{4}{6} \times 9\text{ V} = 6.00\text{ V}$$

检验 KVL：$v_1 + v_2 = 3.00\text{ V} + 6.00\text{ V} = 9.00\text{ V} = V_s$，严丝合缝！

**教授划重点（物理直觉）—— “分压看自己”** 为什么求 $v_2$ 时分子放的是**它自己的阻值 $R_2$**？想象水流过两段串联的狭窄管道，流量（电流 $i$）被迫完全相同。谁的管子越细、阻力（$R_n$）越大，推动水流通过它所消耗的水压（电压 $v_n = i R_n$）就越高！所以：**串联电路中，电阻越大，分得的电压越大；公式分子写自己的阻值。**

#### 第 3 幕：并联等效电阻与分流公式 — 为什么“分流看对方”？
现在我们把左侧舞台切换到 并联分流 (R1 || R2) 模式。按照 Alexander & Sadiku 第 2.6 节的定义，**两个电阻并联，意味着它们的两端分别连接在同一对节点上**，因此两个电阻两端的电压必然完全相同，记为同一个电压 $v$。

这一次，主导规律不再是 KVL，而是上节点处的 **KCL（基尔霍夫电流定律）**。让我们依然严格走完三段式推导：
##### 推导 3.1：并联等效电阻与分流公式
**① 公理溯源（KCL + 欧姆定律）**

在并联上节点列写 KCL 方程，并用欧姆定律将各支路电流写成电压与电阻之比：

$$i = i_1 + i_2$$

$$i_1 = \frac{v}{R_1}, \qquad i_2 = \frac{v}{R_2}$$

**② 纯符号通式（导出 $R_{\text{eq}}$ 与两支路分流公式）**

将支路电流代入 KCL，提取公共电压 $v$：

$$i = v\left(\frac{1}{R_1} + \frac{1}{R_2}\right) = \frac{v}{R_{\text{eq}}} \implies \frac{1}{R_{\text{eq}}} = \frac{1}{R_1} + \frac{1}{R_2}$$

通分取倒数，得到两电阻并联的经典**“积除以和”**公式：

$$R_{\text{eq}} = R_1 \parallel R_2 = \frac{R_1 R_2}{R_1 + R_2}$$

由此反解公共节点电压 $v = i R_{\text{eq}} = i \dfrac{R_1 R_2}{R_1 + R_2}$。代回支路欧姆定律 $i_1 = \dfrac{v}{R_1}$ 与 $i_2 = \dfrac{v}{R_2}$，约去 $R_1$ 或 $R_2$，立刻得出**两支路分流公式（Current Divider Rule）**：

$$i_1 = \frac{v}{R_1} = \frac{1}{R_1} \cdot \left(i \frac{R_1 R_2}{R_1 + R_2}\right) = \frac{R_2}{R_1 + R_2} i$$

$$i_2 = \frac{v}{R_2} = \frac{1}{R_2} \cdot \left(i \frac{R_1 R_2}{R_1 + R_2}\right) = \frac{R_1}{R_1 + R_2} i$$

(若用**电导** $G_k = 1/R_k$ 表达，则 $N$ 条并联支路具有与分压完全对偶的优美通式：$i_n = \dfrac{G_n}{G_1 + G_2 + \cdots + G_N} i$。)

**③ 代入数值逐步化简（$V_s = 9\text{ V}$ 供电，$R_1 = 2\text{ k}\Omega,\ R_2 = 4\text{ k}\Omega$）**

$$R_{\text{eq}} = \frac{2\text{ k}\Omega \times 4\text{ k}\Omega}{2\text{ k}\Omega + 4\text{ k}\Omega} = \frac{8}{6}\text{ k}\Omega = \frac{4}{3}\text{ k}\Omega \approx 1.333\text{ k}\Omega$$

总干路电流为：

$$i = \frac{9\text{ V}}{(4/3)\text{ k}\Omega} = 6.75\text{ mA}$$

用分流公式求 支路 1 电流 $i_1$ 与支路 2 电流 $i_2$：

$$i_1 = \frac{R_2}{R_1 + R_2} i = \frac{4\text{ k}\Omega}{2\text{ k}\Omega + 4\text{ k}\Omega} \times 6.75\text{ mA} = \frac{4}{6} \times 6.75\text{ mA} = 4.50\text{ mA}$$

$$i_2 = \frac{R_1}{R_1 + R_2} i = \frac{2\text{ k}\Omega}{2\text{ k}\Omega + 4\text{ k}\Omega} \times 6.75\text{ mA} = \frac{2}{6} \times 6.75\text{ mA} = 2.25\text{ mA}$$

检验 KCL：$i_1 + i_2 = 4.50\text{ mA} + 2.25\text{ mA} = 6.75\text{ mA} = i$，且独立验算 $9\text{ V}/2\text{ k}\Omega = 4.50\text{ mA}$，完全吻合！

**全课最重要口诀 —— “分压看自己，分流看对方”** 很多同学一到考试就把分流公式的分子写反。请你用物理直觉把它锁死在脑子里： 电流是极其“懒惰”的，它永远偏爱阻力小的路径。在两条并联支路中，如果你想知道流进 $R_1$ 的电流 $i_1$ 有多大，关键看**对面那条路 $R_2$ 有多堵**！对面 $R_2$ 越堵（阻值越大），电流就被逼着往你这边 $R_1$ 钻得越多。

- 极限检验 1：如果对面 $R_2 \to \infty$（开路，彻底堵死），则 $i_1 = \frac{\infty}{R_1+\infty} i = i$，电流全走你这边；
- 极限检验 2：如果对面 $R_2 \to 0$（短路，畅通无阻），则 $i_1 = \frac{0}{R_1+0} i = 0$，电流全被对面抢走！

#### 第 4 幕：负载效应（Loading Effect）与比例权重曲线 — 为什么接上负载后电压“掉链子”？
很多新手第一次在面包板上搭出 6.00 V 分压器后，得意洋洋地把一个 负载电阻 $R_L = 4\text{ k}\Omega$（比如一个待测模块）并联接到 $R_2$ 两端，拿万用表一测——傻眼了：电压怎么从 **6.00 V 暴跌到了 4.50 V**？

这就是工程上赫赫有名的**负载效应（Loading Effect）**。一旦你在分压节点接出负载 $R_L$，公共节点就多了一条分流支路，$R_1$ 和 $R_2$ **不再是单纯串联**，而是变成 **$R_1$ 与 $(R_2 \parallel R_L)$ 串联**！

请结合左侧 02 比例权重与负载效应曲线，看我们的三段式推导：
##### 推导 4.1：带载分压器的输出电压塌陷公式
**① 公理溯源（并联等效 + 串联分压）**

负载 $R_L$ 与下臂电阻 $R_2$ 共享分压节点与地节点，构成并联支路 $R_{2L} = R_2 \parallel R_L$；该等效块再与 $R_1$ 串联分压：

$$R_{2L} = \frac{R_2 R_L}{R_2 + R_L}, \qquad v_{\text{out}} = \frac{R_{2L}}{R_1 + R_{2L}} V_s$$

**② 纯符号通式（引入负载比 $\alpha = R_L / R_2$）**

将 $R_{2L} = \dfrac{\alpha}{1 + \alpha} R_2$ 代入分压公式，化简得：

$$v_{\text{out}} = \frac{R_2 \parallel R_L}{R_1 + (R_2 \parallel R_L)} V_s = \frac{R_2}{R_1 \left(1 + \dfrac{R_2}{R_L}\right) + R_2} V_s$$

显然，由于 $R_2 \parallel R_L < R_2$，带载输出电压 $v_{\text{out}}$ 必然**严格低于**空载电压 $v_{2,\text{空载}}$。

**③ 代入数值逐步化简（$V_s = 9\text{ V},\ R_1 = 2\text{ k}\Omega,\ R_2 = 4\text{ k}\Omega$）**

- **情形 A：重负载 $R_L = 4\text{ k}\Omega$（$\alpha = 1$）** $$R_{2L} = \frac{4\text{ k}\Omega \times 4\text{ k}\Omega}{4\text{ k}\Omega + 4\text{ k}\Omega} = 2\text{ k}\Omega$$ $$v_{\text{out}} = \frac{2\text{ k}\Omega}{2\text{ k}\Omega + 2\text{ k}\Omega} \times 9\text{ V} = 4.50\text{ V} \quad (\text{压降损失高达 } 25%!)$$

- **情形 B：轻负载 $R_L = 40\text{ k}\Omega$（满足工程“十倍硬分压准则” $R_L \ge 10 R_2$）** $$R_{2L} = \frac{4\text{ k}\Omega \times 40\text{ k}\Omega}{4\text{ k}\Omega + 40\text{ k}\Omega} = \frac{160}{44}\text{ k}\Omega \approx 3.636\text{ k}\Omega$$ $$v_{\text{out}} = \frac{3.636\text{ k}\Omega}{2\text{ k}\Omega + 3.636\text{ k}\Omega} \times 9\text{ V} \approx 5.81\text{ V} \quad (\text{误差仅 } 3.2%)$$

**工程黄金法则**：如果你希望用纯电阻分压器给下一级提供较稳定的参考电压，务必满足 **$R_L \ge 10 R_2$**（更严格时取 $100 R_2$）。在左侧 02 负载效应曲线 上，你会直观看到曲线在 $R_L / R_2 = 10$ 之后才逐渐趋平并逼近 6.00 V 虚线！

#### 第 5 幕：3D 面包板 9V 实测与“1000× 阻值安全缩放法则” — 保护你的实验箱不冒烟！
现在揭晓第 1 幕留下的悬念！翻开 Alexander & Sadiku 或 Boylestad 的纸面习题，你会频繁看到 $R_1 = 2\ \Omega$、$R_2 = 4\ \Omega$ 这样的小整数。**千万别照着纸面阻值直接往 9 V 面包板上插！**

让我们用功率公式做一次严格的 三段式安全校验：
##### 推导 5.1：教材原值 vs. $1000\times$ 缩放后的功耗与比例不变性证明
**① 公理溯源（分压/分流齐次性 + 焦耳功耗定律）**

若将电路中所有电阻同时乘以正比例因子 $k > 0$（即 $R_n' = k R_n$），则电阻功耗遵循：

$$P_n = i^2 R_n = \frac{v_n^2}{R_n}$$

实验室常用四环碳膜电阻额定功率为 $P_{\max} = \dfrac{1}{4}\text{ W} = 250\text{ mW}$。

**② 纯符号通式（证明缩放因子 $k$ 在比例中完全约去，功耗缩小 $k$ 倍）**

$$v_n' = \frac{k R_n}{k R_1 + k R_2} V_s = \frac{R_n}{R_1 + R_2} V_s = v_n \quad (\text{分压比完全不变})$$

$$i_1' = \frac{k R_2}{k R_1 + k R_2} i' = \frac{R_2}{R_1 + R_2} i' \quad (\text{分流比完全不变})$$

$$i' = \frac{V_s}{k R_{\text{eq}}} = \frac{i}{k}, \qquad P_n' = \frac{v_n^2}{k R_n} = \frac{P_n}{k} \quad (\text{电流与功耗同缩 } k \text{ 倍！})$$

**③ 代入数值逐步化简（$V_s = 9\text{ V},\ k = 1000$）**

- **未缩放（教材原值 $R_1 = 2\ \Omega,\ R_2 = 4\ \Omega$）**： $$i = \frac{9\text{ V}}{2\ \Omega + 4\ \Omega} = 1.5\text{ A}, \qquad P_{R_2} = \frac{(6\text{ V})^2}{4\ \Omega} = 9.0\text{ W} = 36 \times P_{\max} \implies \text{瞬间冒烟烧毁！}$$

- **等比例放大 $1000\times$（面包板安全值 $R_1' = 2\text{ k}\Omega,\ R_2' = 4\text{ k}\Omega$）**： $$i' = \frac{9\text{ V}}{2\text{ k}\Omega + 4\text{ k}\Omega} = 1.5\text{ mA}, \qquad P_{R_2}' = \frac{(6\text{ V})^2}{4\text{ k}\Omega} = 9.0\text{ mW} = 3.6% \times P_{\max} \implies \text{冰凉安全！}$$

**3D 面包板实操守则（对照左侧 ****03 3D 面包板 9V 实测接线台****）**：

- **认准色环**：$2\text{ k}\Omega$ 为 **红-黑-红-金**，$4\text{ k}\Omega$ 为 **黄-黑-红-金**；

#### 第 7 幕：工程防坑清单 — 三支路并联绝不能套“对方之和”！
恭喜你闯过了混联例题！但作为你的课程教授，我必须在下课前帮你排掉全班 60% 学生在作业里都会踩中的**头号大坑**：**三支路及以上并联时的分流公式误用**。

不少同学把两支路口诀“分流看对方”生搬硬套到三条并联支路（$R_1 \parallel R_2 \parallel R_3$）上，随手写出错误式子 $i_1 \stackrel{\text{错!}}{=} \dfrac{R_2 + R_3}{R_1 + R_2 + R_3} i$。**为什么错了？** 因为另外两条支路 $R_2$ 和 $R_3$ 是**并联**在一起充当“对方”的，而不是串联！
##### 推导 7.1：三支路并联分流的正确通式
**① 公理溯源（公共电压相等 + 并联总等效电阻）**

三支路共享同一端电压 $v = i R_{\text{eq}}$，其中 $\dfrac{1}{R_{\text{eq}}} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \dfrac{1}{R_3}$。

**② 纯符号通式（等效电阻法 / 电导法）**

$$i_1 = \frac{v}{R_1} = \frac{R_{\text{eq}}}{R_1} i = \frac{G_1}{G_1 + G_2 + G_3} i = \frac{R_2 \parallel R_3}{R_1 + (R_2 \parallel R_3)} i$$

**③ 代入数值逐步化简（$i = 11\text{ mA},\ R_1 = 2\text{ k}\Omega,\ R_2 = 3\text{ k}\Omega,\ R_3 = 6\text{ k}\Omega$）**

$$\frac{1}{R_{\text{eq}}} = \frac{1}{2} + \frac{1}{3} + \frac{1}{6} = \frac{3 + 2 + 1}{6} = 1\text{ mS} \implies R_{\text{eq}} = 1\text{ k}\Omega$$

$$i_1 = \frac{R_{\text{eq}}}{R_1} i = \frac{1\text{ k}\Omega}{2\text{ k}\Omega} \times 11\text{ mA} = 5.50\text{ mA}$$

(检验另两支路：$i_2 = \frac{1}{3}\times 11 = 3.67\text{ mA}$，$i_3 = \frac{1}{6}\times 11 = 1.83\text{ mA}$，三者之和 $= 11.00\text{ mA}$！若按错误公式算 $(3+6)/(2+3+6)\times 11 = 9\text{ mA}$，谬以千里！)
