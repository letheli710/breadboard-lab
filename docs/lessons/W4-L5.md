## 第一幕：单位阶跃函数 $u(t)$ 与开关闭合的数学建模

同学们好。在实验室里，合上一个拨动开关只需要指尖一按；但在微分方程的世界里，我们怎么精确描述“在 $t = 0$ 之前电路里没有电压，在 $t = 0$ 这一瞬间突然接入一个恒定直流电压 $V_s$”这件事呢？

工程数学为我们准备了一把最锋利的开关刻刀——**单位阶跃函数（Unit Step Function）$u(t)$**。

### 1.1 教授板书：单位阶跃函数与阶跃激励建模

#### ① 公理溯源
根据奇异函数（Singularity Functions）定义，单位阶跃函数 $u(t)$ 是一个在 $t = 0$ 处发生幅度为 $1$ 的瞬时跳变的无量纲分段函数：

$$u(t) = \begin{cases} 0, & t < 0 \\ 1, & t > 0 \end{cases}$$

注意在 $t = 0$ 这一点函数不连续，因此电路分析中严格区分换路前瞬间 $t = 0^-$ 与换路后瞬间 $t = 0^+$。若开关动作发生在任意时刻 $t = t_0$，则由时间平移性质得到延时阶跃函数：

$$u(t - t_0) = \begin{cases} 0, & t < t_0 \\ 1, & t > t_0 \end{cases}$$

#### ② 纯符号通式
一个在 $t = 0$ 闭合、将直流电源 $V_s$ 接入线性网络的理想开关，其等效电源激励可写成：

$$v_s(t) = V_s\,u(t)$$

若电源在 $t = t_1$ 接通、在 $t = t_2$（$t_2 > t_1$）断开，形成矩形脉冲激励，则由两个阶跃函数相减构造门函数：

$$v_{\text{pulse}}(t) = V_s\,[u(t - t_1) - u(t - t_2)]$$

#### ③ 代入数值逐步化简
以我们稍后在面包板上实测的 $5\ \text{V}$ 直流充电实验为例：设 $V_s = 5\ \text{V}$，在 $t = 0\ \text{s}$ 合上充电开关：

1. $t < 0\ \text{s}$ 时，$u(t) = 0 \implies v_s(t) = 5 \times 0 = 0\ \text{V}$；
2. $t > 0\ \text{s}$ 时，$u(t) = 1 \implies v_s(t) = 5 \times 1 = 5\ \text{V}$；
3. 若我们在 $t = 5\ \text{s}$ 时把开关切回地端放电，整个充放电激励可统一写作 $v_s(t) = 5[u(t) - u(t - 5)]\ \text{V}$。

## 第二幕：一阶 RC 阶跃响应推导与“完全响应 = 暂态 + 稳态”分解

现在开关在 $t = 0$ 闭合了。设电容在换路前已存有初始电压 $v_C(0^-) = V_0$，由于电容储能 $W_C = \frac{1}{2}Cv_C^2$ 不能在零时间内突变，电容电压必然连续：

$$v_C(0^+) = v_C(0^-) = V_0$$

我们来严格从基尔霍夫定律出发，推导出整个 $t \ge 0$ 时段的精确波形，并看清它背后的物理结构。

### 2.1 教授板书：RC 阶跃响应微分方程求解

#### ① 公理溯源
在 $t > 0$ 的闭合回路中，对电容上节点应用 **KCL**，并代入电阻欧姆定律与电容元件特性方程（VCR）：

$$i_C(t) = C\frac{dv_C}{dt}, \qquad i_R(t) = \frac{v_C(t) - V_s}{R}$$

由 KCL 得 $i_C(t) + i_R(t) = 0$，整理为标准一阶线性常系数**非齐次微分方程**：

$$RC\frac{dv_C}{dt} + v_C = V_s, \quad t > 0$$

定义时间常数 $\tau = RC$，方程可写成：

$$\frac{dv_C}{dt} + \frac{1}{\tau}v_C = \frac{V_s}{\tau}$$

#### ② 纯符号通式
将方程分离变量：

$$\frac{dv_C}{v_C - V_s} = -\frac{1}{\tau}\,dt$$

两端从 $t = 0^+$（对应 $v_C = V_0$）积分到任意时刻 $t$（对应 $v_C(t)$）：

$$\int_{V_0}^{v_C(t)} \frac{dv_C}{v_C - V_s} = -\int_{0}^{t} \frac{1}{\tau}\,dt \implies \ln\left(\frac{v_C(t) - V_s}{V_0 - V_s}\right) = -\frac{t}{\tau}$$

两边取指数并整理，得到一阶 RC 阶跃响应的**完全响应通式**：

$$v_C(t) = \underbrace{V_s}_{\text{强迫响应 / 稳态响应 } v_f} + \underbrace{(V_0 - V_s)\,e^{-t/\tau}}_{\text{自然响应 / 暂态响应 } v_n}, \quad t \ge 0$$

如果重新按激励来源分组，同一条公式还可以改写为**零输入响应（ZIR）+ 零状态响应（ZSR）**：

$$v_C(t) = \underbrace{V_0\,e^{-t/\tau}}_{\text{零输入响应 (仅由初始储能驱动)}} + \underbrace{V_s\left(1 - e^{-t/\tau}\right)}_{\text{零状态响应 (仅由外部阶跃源驱动)}}$$

当电容初始未充电（$V_0 = 0$）时，得到 *Boylestad Ch. 10* 最经典的**零状态充电公式**与充电电流公式：

$$v_C(t) = V_s\left(1 - e^{-t/\tau}\right), \qquad i_C(t) = C\frac{dv_C}{dt} = \frac{V_s}{R}\,e^{-t/\tau}, \quad t \ge 0$$

#### ③ 代入数值逐步化简（面包板实测标准参数）
取实验室面包板安全实测套件参数：$V_s = 5\ \text{V}$，$R = 10\ \text{k}\Omega = 10^4\ \Omega$，$C = 100\ \mu\text{F} = 10^{-4}\ \text{F}$，初始完全放电 $V_0 = 0\ \text{V}$：

1. 计算时间常数：
   $$\tau = RC = (10 \times 10^3\ \Omega) \times (100 \times 10^{-6}\ \text{F}) = 1.0\ \text{s}$$
2. 代入电容电压与充电电流通式（$t \ge 0$）：
   $$v_C(t) = 5\left(1 - e^{-t/1.0}\right) = 5 - 5e^{-t}\ \text{V}$$
   $$i_C(t) = \frac{5\ \text{V}}{10\ \text{k}\Omega}e^{-t} = 0.5\,e^{-t}\ \text{mA}$$
3. 计算 **Boylestad 充电曲线五大关键里程碑**（经 Python SymPy 精确验算）：

| 时刻 $t$ | 充电百分比 $1 - e^{-t/\tau}$ | 实测目标电压 $v_C(t)$（$V_s=5\ \text{V}$） | 充电电流 $i_C(t)$ | 工程判读 |

## 第三幕：电路学最强捷径——三要素通解与非状态变量 $0^+$ 突变铁律

如果我们每遇到一个含多个电阻和电源的一阶电路，都要从头列写 KCL/KVL 微分方程、分离变量再求积分，不仅费时，而且极易在代数整理中出错。

请同学们把目光锁定在上一幕推导出的完全响应通式上，并把它推广到**任意一阶线性常系数直流激励电路**。只要电路中只含一个独立储能元件（或可化简为单个等效电容 $C_{\text{eq}}$ / 单个等效电感 $L_{\text{eq}}$），电路中**任意一条支路的电压或电流 $x(t)$**，在 $t \ge 0$ 时都严格服从同一条黄金公式——**三要素通解（Three-Element Formula）**：

$$x(t) = x(\infty) + \left[x(0^+) - x(\infty)\right] e^{-t/\tau}, \quad t \ge 0$$

> **教授敲黑板（本课最核心的避坑铁律）**：
> 三要素公式确实对电路中**任何**电压或电流都成立——但有一个生死攸关的前提必须刻在脑子里：
> 1. **只有状态变量（电容电压 $v_C$ 与电感电流 $i_L$）受能量连续性保护**，满足 $v_C(0^+) = v_C(0^-)$、$i_L(0^+) = i_L(0^-)$；
> 2. **所有非状态变量（如电阻电流 $i_R$、电容电流 $i_C$、电感电压 $v_L$）在 $t = 0^+$ 换路瞬间都允许发生阶跃突变**！求非状态变量 $x(t)$ 时，**绝不能拿 $x(0^-)$ 当作 $x(0^+)$**，必须在 $t = 0^+$ 等效电路里（把电容换成数值为 $v_C(0^+)$ 的恒压源，把电感换成数值为 $i_L(0^+)$ 的恒流源）现算 $x(0^+)$！

### 3.1 教授板书：Sadiku 7.5 经典 RC 三要素综合例题（含非状态变量突变）

**题目设定**：如下图所示，单刀双掷开关 $S$ 在位置 $A$ 停留了足够长时间，于 $t = 0$ 瞬间切换至位置 $B$。已知 $V_1 = 18\ \text{V}$，$R_1 = 3\ \Omega$，$R_2 = 6\ \Omega$，$C = 0.25\ \text{F}$，$V_2 = 36\ \text{V}$，$R_3 = 6\ \Omega$，$R_4 = 12\ \Omega$。
**求解目标**：求 $t \ge 0$ 时的电容电压 $v_C(t)$、电阻 $R_3$ 电流 $i_3(t)$（方向从 $V_2$ 正极向右流出）以及电容电流 $i_C(t)$，并检验 $i_3$ 在 $t = 0$ 处的跳变。

#### ① 公理溯源
1. **直流稳态性质**：直流稳态下电容电流 $i_C = C\frac{dv_C}{dt} = 0$，电容等效为**开路**；
2. **换路定则（能量连续性）**：$v_C(0^+) = v_C(0^-)$；
3. **戴维南等效（`W2-L7`）**：对 $t > 0$ 的线性含源二端网络从电容两端看进去，可等效为 $V_{\text{th}}$ 与 $R_{\text{th}}$ 串联，时间常数 $\tau = R_{\text{th}} C$；
4. **三要素通解**：对状态变量 $v_C(t)$ 与非状态变量 $i_3(t)$ 均适用 $x(t) = x(\infty) + [x(0^+) - x(\infty)]e^{-t/\tau}$。

#### ② 纯符号通式
1. **$t = 0^-$（开关在 $A$，直流稳态，$C$ 开路）**：
   $$v_C(0^-) = V_1\frac{R_2}{R_1 + R_2}, \qquad i_3(0^-) = \frac{V_2}{R_3 + R_4}$$
2. **$t > 0$ 戴维南等效与时间常数（开关在 $B$）**：
   $$R_{\text{th}} = R_3 \parallel R_4 = \frac{R_3 R_4}{R_3 + R_4}, \qquad V_{\text{th}} = V_2\frac{R_4}{R_3 + R_4}, \qquad \tau = R_{\text{th}} C$$
3. **状态变量 $v_C(t)$ 的三要素通式**：
   $$v_C(0^+) = v_C(0^-), \qquad v_C(\infty) = V_{\text{th}}$$
   $$v_C(t) = V_{\text{th}} + \left[v_C(0^+) - V_{\text{th}}\right]e^{-t/\tau}$$
4. **非状态变量 $i_3(t)$ 的 $0^+$ 现算与三要素通式**：
   在 $t = 0^+$ 瞬间，$C$ 等效为电压源 $v_C(0^+)$，由欧姆定律现算 $i_3(0^+)$；在 $t = \infty$ 时 $C$ 再次开路，节点电压为 $v_C(\infty) = V_{\text{th}}$：
   $$i_3(0^+) = \frac{V_2 - v_C(0^+)}{R_3}, \qquad i_3(\infty) = \frac{V_2 - V_{\text{th}}}{R_3} = \frac{V_2}{R_3 + R_4}$$
   $$i_3(t) = i_3(\infty) + \left[i_3(0^+) - i_3(\infty)\right]e^{-t/\tau}$$
5. **电容电流 $i_C(t)$ 交叉校验**：
   $$i_C(t) = C\frac{dv_C}{dt} = -\frac{v_C(0^+) - V_{\text{th}}}{R_{\text{th}}}e^{-t/\tau} = i_3(t) - \frac{v_C(t)}{R_4}$$

#### ③ 代入数值逐步化简（Python SymPy 全程验算）
1. **求 $t = 0^-$ 初值**：
   $$v_C(0^-) = 18 \times \frac{6}{3 + 6} = 12\ \text{V}$$
   此时 $B$ 侧独立构成回路：$i_3(0^-) = \frac{36}{6 + 12} = 2\ \text{A}$，$i_C(0^-) = 0\ \text{A}$。
2. **求 $t > 0$ 戴维南参数与 $\tau$**：
   $$R_{\text{th}} = \frac{6 \times 12}{6 + 12} = 4\ \Omega, \qquad V_{\text{th}} = 36 \times \frac{12}{6 + 12} = 24\ \text{V}$$
   $$\tau = R_{\text{th}} C = 4 \times 0.25 = 1\ \text{s}$$
3. **写出状态变量 $v_C(t)$**：
   由连续性得 $v_C(0^+) = v_C(0^-) = 12\ \text{V}$，稳态值 $v_C(\infty) = V_{\text{th}} = 24\ \text{V}$：
   $$v_C(t) = 24 + (12 - 24)e^{-t/1} = 24 - 12e^{-t}\ \text{V}, \quad t \ge 0$$
4. **现算非状态变量 $i_3(0^+)$ 并写出 $i_3(t)$（关键陷阱拆解！）**：
   - 在 $t = 0^+$ 瞬间，$C$ 钳位在 $12\ \text{V}$：
     $$i_3(0^+) = \frac{36 - 12}{6} = 4\ \text{A} \neq i_3(0^-) = 2\ \text{A}$$
   - 在 $t = \infty$ 稳态，$v_C(\infty) = 24\ \text{V}$：
     $$i_3(\infty) = \frac{36 - 24}{6} = 2\ \text{A}$$
   - 代入三要素通解：
     $$i_3(t) = 2 + (4 - 2)e^{-t} = 2 + 2e^{-t}\ \text{A}, \quad t \ge 0$$
   - **陷阱警示**：如果某位同学错误地把 $i_3(0^-) = 2\ \text{A}$ 当成 $i_3(0^+)$，代入后会算出 $i_3(t) = 2 + (2 - 2)e^{-t} = 2\ \text{A}$ 的荒谬常数，完全丢失了换路瞬间高达 $+2\ \text{A}$ 的浪涌电流！
5. **用 KCL 与微积分双路径校验 $i_C(t)$**：
   - 微分法：$i_C(t) = C\frac{dv_C}{dt} = 0.25 \times 12e^{-t} = 3e^{-t}\ \text{A}$（从 $0\ \text{A}$ 突变到 $3\ \text{A}$）；
   - KCL 法：$i_4(t) = \frac{v_C(t)}{12} = 2 - e^{-t}\ \text{A} \implies i_3(t) - i_4(t) = (2 + 2e^{-t}) - (2 - e^{-t}) = 3e^{-t}\ \text{A}$。两法完全一致，SymPy `dsolve` 残差为 `0`！

## 第四幕：一阶 RL 阶跃响应与电感反向电动势突变

理解了 RC 电路之后，RL 电路就是一面完美的物理对偶镜。在 RL 电路中，受磁场储能 $W_L = \frac{1}{2}L i_L^2$ 保护的连续状态变量是**电感电流 $i_L(t)$**，而允许在换路瞬间猛烈跳变的非状态变量则是**电感电压 $v_L(t)$**。在工程上，切断感性负载时产生的剧烈负电压跳变就是大名鼎鼎的**感性反向电动势（Inductive Kickback）**——这也是为什么继电器线圈旁必须并联续流二极管的原因。

### 4.1 教授板书：Sadiku 7.6 经典 RL 阶跃响应例题

**题目设定**：直流电压源 $V_s = 24\ \text{V}$ 依次串联电阻 $R_1 = 4\ \Omega$、$R_2 = 4\ \Omega$，接入由 $R_3 = 8\ \Omega$ 与电感 $L = 2\ \text{H}$ 并联组成的负载网络。开关 $S$ 跨接在 $R_2$ 两端，在 $t < 0$ 时长期闭合（将 $R_2$ 短路），于 $t = 0$ 瞬间断开。
**求解目标**：求 $t \ge 0$ 时的电感电流 $i_L(t)$、电感两端电压 $v_L(t)$（上正下负）以及 $R_3$ 支路电流 $i_{R3}(t)$（向下为正）。

#### ① 公理溯源
1. **直流稳态性质**：直流稳态下 $v_L = L\frac{di_L}{dt} = 0$，电感等效为**短路**；
2. **换路定则（磁链守恒）**：$i_L(0^+) = i_L(0^-)$；
3. **戴维南等效与 RL 时间常数**：从电感端口看入 $t > 0$ 的线性含源网络得 $V_{\text{th}}, R_{\text{th}}$，时间常数为 $\tau = \frac{L}{R_{\text{th}}}$；
4. **三要素通解**：$x(t) = x(\infty) + [x(0^+) - x(\infty)]e^{-t/\tau}$。

#### ② 纯符号通式
1. **$t = 0^-$（开关 $S$ 闭合短接 $R_2$，电感 $L$ 直流短路并短接 $R_3$）**：
   $$i_L(0^-) = \frac{V_s}{R_1}, \qquad v_L(0^-) = 0, \qquad i_{R3}(0^-) = 0$$
2. **$t > 0$ 戴维南等效与时间常数（开关 $S$ 断开，$R_1 + R_2$ 串入）**：
   $$R_{\text{th}} = (R_1 + R_2) \parallel R_3 = \frac{(R_1 + R_2)R_3}{R_1 + R_2 + R_3}, \qquad V_{\text{th}} = V_s\frac{R_3}{R_1 + R_2 + R_3}, \qquad \tau = \frac{L}{R_{\text{th}}}$$
3. **状态变量 $i_L(t)$ 的三要素通式**：
   $$i_L(0^+) = i_L(0^-), \qquad i_L(\infty) = \frac{V_{\text{th}}}{R_{\text{th}}} = \frac{V_s}{R_1 + R_2}$$
   $$i_L(t) = i_L(\infty) + \left[i_L(0^+) - i_L(\infty)\right]e^{-t/\tau}$$
4. **非状态变量 $v_L(t)$ 与 $i_{R3}(t)$ 的 $0^+$ 现算与三要素通式**：
   在 $t = 0^+$ 瞬间，$L$ 替换为恒流源 $i_L(0^+)$，对电感上节点列 KCL：
   $$\frac{v_L(0^+) - V_s}{R_1 + R_2} + \frac{v_L(0^+)}{R_3} + i_L(0^+) = 0 \implies v_L(0^+) = R_{\text{th}}\left(\frac{V_s}{R_1 + R_2} - i_L(0^+)\right)$$
   又因 $v_L(\infty) = 0$，故：
   $$v_L(t) = v_L(0^+)\,e^{-t/\tau}, \qquad i_{R3}(t) = \frac{v_L(t)}{R_3} = \frac{v_L(0^+)}{R_3}\,e^{-t/\tau}$$

#### ③ 代入数值逐步化简（Python SymPy 全程验算）
1. **求 $t = 0^-$ 初值**：
   $$i_L(0^-) = \frac{24}{4} = 6\ \text{A}, \qquad v_L(0^-) = 0\ \text{V}, \qquad i_{R3}(0^-) = 0\ \text{A}$$
2. **求 $t > 0$ 戴维南参数与 $\tau$**：
   $$R_1 + R_2 = 4 + 4 = 8\ \Omega$$
   $$R_{\text{th}} = 8 \parallel 8 = 4\ \Omega, \qquad V_{\text{th}} = 24 \times \frac{8}{8 + 8} = 12\ \text{V}$$
   $$\tau = \frac{L}{R_{\text{th}}} = \frac{2\ \text{H}}{4\ \Omega} = 0.5\ \text{s} \implies \frac{1}{\tau} = 2\ \text{s}^{-1}$$
3. **写出状态变量 $i_L(t)$**：
   $i_L(0^+) = 6\ \text{A}$，$i_L(\infty) = \frac{24}{8} = 3\ \text{A}$：
   $$i_L(t) = 3 + (6 - 3)e^{-t/0.5} = 3 + 3e^{-2t}\ \text{A}, \quad t \ge 0$$
4. **现算非状态变量 $v_L(t)$ 与 $i_{R3}(t)$**：
   - 在 $t = 0^+$ 瞬间：
     $$v_L(0^+) = 4 \times (3 - 6) = -12\ \text{V}$$
   - 代入三要素通解（并可用 $L\frac{di_L}{dt} = 2 \times (-6e^{-2t}) = -12e^{-2t}\ \text{V}$ 交叉核对）：
     $$v_L(t) = -12e^{-2t}\ \text{V}, \qquad i_{R3}(t) = \frac{-12e^{-2t}}{8} = -1.5e^{-2t}\ \text{A}, \quad t > 0$$
   - 物理直觉：开关一断开，电感为了拼命维持 $6\ \text{A}$ 的旧电流，瞬间把上端电位拉低到 $-12\ \text{V}$，迫使 $1.5\ \text{A}$ 的电流从地经 $R_3$ 倒灌上来补充（同时电源支路提供 $\frac{24 - (-12)}{8} = 4.5\ \text{A}$，$4.5 + 1.5 = 6\ \text{A}$，KCL 严丝合缝！）。

### 4.2 RC 与 RL 三要素对偶速查表

| 核心属性 | 一阶 RC 阶跃电路 | 一阶 RL 阶跃电路 |
| :--- | :--- | :--- |
| 连续状态变量（不可突变） | 电容电压 $v_C(t)$：$v_C(0^+) = v_C(0^-)$ | 电感电流 $i_L(t)$：$i_L(0^+) = i_L(0^-)$ |
| 允许突变的非状态变量 | 电容电流 $i_C(t)$、各电阻电流 $i_R(t)$ | 电感电压 $v_L(t)$、各电阻电压/电流 |
| 直流稳态等效（$0^-$ 与 $\infty$） | **开路（Open Circuit）** | **短路（Short Circuit）** |
| $t = 0^+$ 现算等效替换 | 替换为恒压源 $v_C(0^+)$ | 替换为恒流源 $i_L(0^+)$ |
| 时间常数公式 | $\tau = R_{\text{th}} C$ | $\tau = \dfrac{L}{R_{\text{th}}}$ |

## 第五幕：仪器安全红线与 3D 面包板示波器实操

理论公式全部打通后，现在我们把视线转向实验台。本课是同学们**第一次在真实面包板上连接台式示波器**实测一阶充放电波形。在通电按下电源开关之前，请先停下来，把下面这条足以救下你整套实验板和示波器探头的安全铁律读三遍！

> ### ⚠️ 示波器探头地线夹共地防短路警示（仪器安全硬性红线）
> - **物理真相**：真实台式示波器所有通道 BNC 端口的外壳、以及探头上的**黑色鳄鱼夹（地线夹）**，在仪器内部直接连通到市电三脚插头的**保护大地（PE, Protective Earth）**。与此同时，实验室里的直流稳压电源负极或函数发生器参考地通常也连接到同一大地（或通过仪器机壳共地）。
> - **致命错误**：很多初学者想直接看串联电阻 $R$ 两端的电压 $v_R(t)$，于是顺手把示波器探头红钩夹在 $V_s$ 正极，把**黑色鳄鱼夹夹在电阻 $R$ 与电容 $C$ 之间的悬浮节点**。这一夹下去，黑色鳄鱼夹立刻通过市电 PE 大地把 $R$ 与 $C$ 的节点直接**零欧姆短路到电源负极（GND）**！结果：电容被瞬间短接旁路，测量波形彻底失真，更危险的是电阻 $R$ 直接跨接电源两端导致过流发烫甚至烧毁电源或探头地线！
> - **唯一正确操作**：
>   1. **共地铁律**：无论连接多少个通道，所有示波器探头的**黑色鳄鱼夹必须全部统一夹在面包板蓝色的公共负极轨（GND）**；
>   2. **测接地电容电压 $v_C(t)$**：CH1 红色探针钩住电容正极节点，黑色鳄鱼夹夹蓝色 GND 轨；
>   3. **测悬浮电阻电压 $v_R(t)$（双通道数学差分法）**：CH1 测电阻左端（电源端 $v_A(t)$），CH2 测电阻右端（电容端 $v_C(t)$），两个黑色鳄鱼夹**全部夹在蓝色 GND 轨**，然后按下示波器面板上的 **`MATH` 键，选择 `CH1 − CH2`**，即可安全、无损地读出悬浮电阻电压 $v_R(t)$！

### 5.1 面包板元器件安全缩放与实操配置

1. **理论低阻电路的 $1000\times$ 安全缩放**：在第三幕的理论例题中，$R_1 = 3\ \Omega, R_2 = 6\ \Omega, R_3 = 6\ \Omega, R_4 = 12\ \Omega$，若直接按此阻值接上 $36\ \text{V}$ 电源，支路电流高达 $4\ \text{A}$，瞬间功率近百瓦，普通 $1/4\ \text{W}$ 面包板电阻会在 $0.1\ \text{s}$ 内冒烟烧断。因此在 3D 面包板实操层中，我们将全部电阻按 **$1000\times$** 缩放至 $3\ \text{k}\Omega, 6\ \text{k}\Omega, 12\ \text{k}\Omega$，并将电容按 **$1/1000$** 缩放至 $250\ \mu\text{F}$——时间常数 $\tau = R_{\text{th}}C = 4\ \text{k}\Omega \times 250\ \mu\text{F} = 1.0\ \text{s}$ 完全不变，而最大电流骤降至安全的 $4\ \text{mA}$！
2. **基础 RC 充电实测套件**：
