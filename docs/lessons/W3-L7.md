# W3-L7：级联运放电路（零加载效应与多级增益分解）

> **教授开场白**：同学们，前面几节课我们已经把反相放大器、同相放大器和加法器这些“单兵作战”的运放积木打磨得非常熟练了。但在真实工程世界里——从心电图前置放大链到音频调音台，再到精密传感器调理电路——你几乎不可能只用一颗运放干完所有活。我们要把多级运放**首尾相连**，也就是**级联（Cascade）**起来。
>
> 今天这节课（对应 Sadiku《电路基础》2026 版第 5.8 节，p. 189–191）我们要彻底搞懂三个决定了你能否在考场和实验台上一击制胜的核心问题：**第一，为什么无源电阻级联一接就“塌陷”，而理想运放级联却能直接把各级增益相乘？第二，遇到多级混合运放电路，怎样做到算得又快又准、且绝不漏掉“中间级先行饱和”这颗暗雷？第三，什么时候绝对不能直接套用乘法法则，必须立刻切回全局节点分析？**

---

## 第 1 幕：无源级联的“加载塌陷” vs 运放级联的“零加载奇迹”

### 1.1 物理直觉：为什么 $0.5 \times 0.5$ 在电阻电路里不等于 $0.25$？

很多同学刚学电路时，脑子里都有一个非常自然的直觉：如果第一级电路把电压衰减一半（$A_1 = 0.5$），第二级电路也把电压衰减一半（$A_2 = 0.5$），那把两级串在一起，总增益不就应该是 $0.5 \times 0.5 = 0.25$ 吗？

**在无源电阻网络中，这个直觉是错的！**

假设我们拿两级完全相同的电阻分压器（每级由两个 $R = 10\text{ k}\Omega$ 电阻构成），输入 $v_i = 10\text{ V}$：
- **单级空载时**：第一级输出 $v_{o1} = 5.0\text{ V}$，空载增益 $A_1 = 0.5$。
- **直接级联后**：当你把第二级分压器接到第一级输出端 $v_1$ 时，第二级相当于一个总阻值为 $R_{\text{in2}} = R + R = 20\text{ k}\Omega$ 的负载，直接**并联**在了第一级的下臂电阻 $R = 10\text{ k}\Omega$ 两端！第二级从第一级抽走了电流，强行把第一级的输出节点电位从 $5.0\text{ V}$ 拽低到了 $4.0\text{ V}$——这就是电路学中臭名昭著的**加载效应（Loading Effect）**。最终第二级输出只有 $2.0\text{ V}$，总增益跌至 $0.20$，平白蒸发了 $20\%$ 的信号幅度！

而**理想运算放大器（Ideal Op Amp）**之所以在多级系统中堪称奇迹，核心就藏在它输出端的戴维南等效模型里：
> **核心机理（Zero Loading Effect）**：在理想运放模型中，输出端是一个**输出电阻 $R_o = 0$ 的理想受控电压源**。无论后级电路的输入电阻 $R_{\text{in2}}$ 是 $100\text{ k}\Omega$ 还是 $1\text{ k}\Omega$，只要后级抽走的电流不超过运放的物理输出电流极限，级间分压系数恒为：
> $$\frac{R_{\text{in2}}}{R_{\text{in2}} + R_o} = \frac{R_{\text{in2}}}{R_{\text{in2}} + 0} \equiv 1$$
> 换句话说，**后级需要多少电流，前级运放的输出级（通过供电电源轨 $\pm V_{CC}$）就按需补多少电流，而输出电压 $v_{o1}$ 纹丝不动！** 这就是“级间隔离（Inter-stage Isolation）”的本质。

### 1.3 教授三段式板书推导：无源直连加载效应定量证明

**① 公理溯源**
- 欧姆定律与电阻串并联等效定理：后级分压器输入端等效阻值 $R_{\text{in2}} = R + R = 2R$ 并联在第一级下臂电阻 $R$ 两端。
- 分压公式（Voltage Division Rule）：串联电阻网络中某段电阻两端电压与该段阻值成正比。

**② 纯符号通式**
设两级相同分压器的所有电阻均为 $R$。单级空载增益为：
$$A_{1,\text{unloaded}} = A_{2,\text{unloaded}} = \frac{R}{R + R} = \frac{1}{2}$$
当两级直接级联时，节点 $v_1$ 对地的总等效电阻为：
$$R_{\text{eq}} = R \parallel (R + R) = \frac{R \cdot 2R}{R + 2R} = \frac{2}{3}R$$
于是第一级实际输出节点电压 $v_1$ 与第二级输出电压 $v_o$ 分别为：
$$v_1 = \frac{R_{\text{eq}}}{R + R_{\text{eq}}} v_i = \frac{\frac{2}{3}R}{R + \frac{2}{3}R} v_i = \frac{2}{5} v_i$$
$$v_o = \frac{R}{R + R} v_1 = \frac{1}{2} \left(\frac{2}{5} v_i\right) = \frac{1}{5} v_i$$
因此无源直连的实际总电压增益为：
$$A_{\text{passive}} = \frac{v_o}{v_i} = \frac{1}{5} < A_{1,\text{unloaded}} A_{2,\text{unloaded}} = \frac{1}{4}$$

**③ 代入数值逐步化简**
代入 $v_i = 10\text{ V}$、$R = 10\text{ k}\Omega$：
$$R_{\text{eq}} = \frac{2}{3} \times 10\text{ k}\Omega = 6.667\text{ k}\Omega$$
$$v_1 = \frac{2}{5} \times 10\text{ V} = 4.0\text{ V} \quad (\text{较空载 } 5.0\text{ V 塌陷 } 1.0\text{ V})$$
$$v_o = \frac{1}{5} \times 10\text{ V} = 2.0\text{ V} \quad (\text{较理想乘积 } 2.5\text{ V 损失 } 20\%)$$

## 第 2 幕：级联增益乘法法则（Eq. 5.21）与“自左向右逐级解耦”黄金流程

### 2.1 Sadiku Fig. 5.23 与 Eq. 5.21：把复杂大电路切成独立积木

在 Sadiku 第 5.8 节中，**级联运放电路（Cascaded Op Amp Circuit）**被严格定义为：将两个或多个运放基本放大级首尾顺次相连，使得**前一级的输出端直接作为后一级的输入端，且不存在将后级信号反馈回前级输入端的跨级支路**。

由于每一级理想运放的输出端都是一个零内阻受控电压源（$R_o = 0$），前级输出电压 $v_k$ 仅由前级自身电路拓扑和输入决定，完全不受后级接入与否的影响。由此直接导出 **Sadiku Eq. 5.21**：

$$A = \frac{v_o}{v_i} = A_1 A_2 A_3 \cdots A_n$$

其中 $A_k = \frac{v_{ok}}{v_{o(k-1)}}$ 为第 $k$ 级单独工作时的闭环电压增益。

> **教授特别提醒（高频易错点）**：级联运放的**电压是逐级独立、零加载的**，但**级间电流并不是零**！如果第 $k+1$ 级是反相放大器（输入电阻 $R_{\text{in}(k+1)} = R_{k+1}$ 有限），它会从第 $k$ 级输出端抽取电流 $i_{\text{in}(k+1)} = \frac{v_{ok}}{R_{k+1}}$。只不过因为第 $k$ 级运放输出内阻 $R_o = 0$，这股电流**不会拉低 $v_{ok}$**，但它会与第 $k$ 级自身的反馈电流 $i_{fk}$ 一起，构成第 $k$ 级运放输出端的总输出电流 $i_{ok}$！

### 2.3 教授三段式板书推导：Eq. 5.21 与“自左向右逐级解耦”五步法

**① 公理溯源**
- 理想运放三公理：① 虚短 $v_+ = v_-$（负反馈线性区）；② 虚断 $i_+ = i_- = 0$；③ 零输出内阻 $R_o = 0$。
- 基尔霍夫电流定律（KCL）：任一运放输出节点的流出电流等于该节点相连所有外部支路电流之和。

**② 纯符号通式**
设电路由 $n$ 级局部负反馈运放顺序级联而成，且无跨级反馈支路。因为第 $k$ 级输出内阻 $R_{ok} = 0$，接入第 $k+1$ 级后，第 $k$ 级闭环传递关系不变：
$$v_{o1} = A_1 v_i, \quad v_{o2} = A_2 v_{o1}, \quad \dots, \quad v_{on} = A_n v_{o(n-1)}$$
由链式恒等式直接得到总电压增益（Eq. 5.21）：
$$A = \frac{v_{on}}{v_i} = \frac{v_{o1}}{v_i} \cdot \frac{v_{o2}}{v_{o1}} \cdots \frac{v_{on}}{v_{o(n-1)}} = \prod_{k=1}^{n} A_k$$
同时，对第 $k$ 级运放输出端写 KCL，得该级运放实际须提供的输出电流：
$$i_{ok} = i_{fk} + i_{\text{in}(k+1)}$$
其中 $i_{fk}$ 为第 $k$ 级自身反馈电阻支路电流，$i_{\text{in}(k+1)}$ 为第 $k+1$ 级从该节点抽取的输入电流（若后级为同相端接入，则 $i_{\text{in}(k+1)} = 0$；若后级为反相端接入，则 $i_{\text{in}(k+1)} = \frac{v_{ok}}{R_{k+1}}$）。

**③ “自左向右逐级解耦”五步黄金解题流程**
1. **拓扑体检**：检查是否存在从后级输出拉回前级输入端的**跨级全局反馈电阻**。若有，立刻停用乘法法则，改用第 5 幕的全局节点法；若无，进入第 2 步。
2. **逐级识图写通式**：自左向右给每一级贴标签（反相、同相、跟随器、加法器、减法器），分别写出各级的纯符号增益 $A_1, A_2, \dots, A_n$。
3. **自左向右算电位**：从最左侧已知输入出发，依次算出 $v_{o1} \to v_{o2} \to \dots \to v_o$。
4. **逐级饱和安检**：每算出一级电位 $v_{ok}$，立刻与该级电源轨 $[-V_{EE}, +V_{CC}]$ 核对！一旦某一级越轨，后续所有级必须以**钳位后的饱和电压**作为输入继续计算。
5. **KCL 核算输出电流**：若题目要求求某一级输出电流 $i_{ok}$，回到该级输出节点，把**自身反馈支路电流**与**后级/负载抽走电流**叠加即可（切忌遗漏自身反馈电流！）。

### 3.3 教授三段式板书推导

**① 公理溯源**
- 拓扑检查：无跨级全局反馈支路，满足纯级联条件，适用 Sadiku Eq. 5.21（$A = A_1 A_2$）。
- 前置模块公式：反相放大器 $A_{\text{inv}} = -\frac{R_f}{R_{\text{in}}}$；同相放大器 $A_{\text{non}} = 1 + \frac{R_f}{R_{\text{gnd}}}$。
- 输出节点 KCL：定义 $i_{ok}$ 为**流出**第 $k$ 颗运放输出端的电流（若算得负值，表示运放输出端实际在**吸收/灌入**电流）。

**② 纯符号通式**
各级电压增益与总增益：
$$A_1 = -\frac{R_{f1}}{R_1}, \qquad A_2 = 1 + \frac{R_{f2}}{R_2}, \qquad A = A_1 A_2 = -\frac{R_{f1}}{R_1}\left(1 + \frac{R_{f2}}{R_2}\right)$$
各级输出电压：
$$v_{o1} = A_1 v_i = -\frac{R_{f1}}{R_1} v_i, \qquad v_o = A_2 v_{o1} = A v_i$$
两颗运放输出电流（注意 Stage 1 虚地 $v_{-1} = 0$，Stage 2 虚短 $v_{-2} = v_{+2} = v_{o1}$ 且虚断 $i_{+2} = 0$）：
$$i_{o1} = \frac{v_{o1} - v_{-1}}{R_{f1}} + i_{+2} = \frac{v_{o1}}{R_{f1}}$$
$$i_{o2} = i_{f2} + i_L = \frac{v_o - v_{-2}}{R_{f2}} + \frac{v_o}{R_L} = \frac{v_o - v_{o1}}{R_{f2}} + \frac{v_o}{R_L}$$

**③ 代入数值逐步化简**
- **第一步：计算增益与逐级电位**
  $$A_1 = -\frac{10\text{ k}\Omega}{2\text{ k}\Omega} = -5, \qquad A_2 = 1 + \frac{12\text{ k}\Omega}{4\text{ k}\Omega} = +4, \qquad A = (-5)(+4) = -20$$
  $$v_{o1} = (-5) \times 0.4\text{ V} = -2.0\text{ V} \quad (|-2.0\text{ V}| < 15\text{ V，线性区 ✓})$$
  $$v_o = (+4) \times (-2.0\text{ V}) = -8.0\text{ V} \quad (|-8.0\text{ V}| < 15\text{ V，线性区 ✓})$$
- **第二步：核算两级运放输出电流**
  $$i_{o1} = \frac{-2.0\text{ V}}{10\text{ k}\Omega} = -0.20\text{ mA} \quad (\text{即 } U_1 \text{ 输出端吸收 } 0.20\text{ mA 反馈电流})$$
  $$i_{f2} = \frac{-8.0\text{ V} - (-2.0\text{ V})}{12\text{ k}\Omega} = \frac{-6.0\text{ V}}{12\text{ k}\Omega} = -0.50\text{ mA}$$
  $$i_L = \frac{-8.0\text{ V}}{2\text{ k}\Omega} = -4.00\text{ mA}$$
  $$i_{o2} = i_{f2} + i_L = -0.50\text{ mA} + (-4.00\text{ mA}) = -4.50\text{ mA} \quad (\text{即 } U_2 \text{ 吸收 } 4.50\text{ mA})$$

> **教授点评**：请盯紧 $i_{o1} = -0.20\text{ mA}$ 这个结果！考试中至少有三分之一的学生因为看到后级是同相输入（$i_{+2} = 0$），就脱口而出“$i_{o1} = 0$”。错了！**零加载不等于零电流**，第一级运放的反馈电阻 $R_{f1}$ 依然接在它的输出端上，必须把自身反馈电流算进去。

### 4.3 教授三段式板书推导

**① 公理溯源**
- 逐级解耦公理（无跨级反馈）+ 运放物理饱和约束（Saturation Clipping）：任一级实际输出必须满足
  $$v_{ok,\text{actual}} = \text{clip}\left(v_{ok,\text{linear}}, -V_{EE}, +V_{CC}\right)$$
- 反相加法器通式（W3-L5）：$v_{o2} = -\left(\frac{R_{f2}}{R_a} v_{o1} + \frac{R_{f2}}{R_b} v_2\right)$。

**② 纯符号通式**
三级依次传递关系：
$$v_{o1,\text{linear}} = -\frac{R_{f1}}{R_1} v_1, \qquad v_{o1} = \text{clip}\left(v_{o1,\text{linear}}, -V_{EE}, +V_{CC}\right)$$
$$v_{o2,\text{linear}} = -\left(\frac{R_{f2}}{R_a} v_{o1} + \frac{R_{f2}}{R_b} v_2\right), \qquad v_{o2} = \text{clip}\left(v_{o2,\text{linear}}, -V_{EE}, +V_{CC}\right)$$
$$v_{o3,\text{linear}} = -\frac{R_{f3}}{R_3} v_{o2}, \qquad v_o = \text{clip}\left(v_{o3,\text{linear}}, -V_{EE}, +V_{CC}\right)$$

**③ 代入数值逐步化简**
代入 $V_{CC} = 12\text{ V}, V_{EE} = 12\text{ V}$，$v_1 = 1.5\text{ V}, v_2 = 2.0\text{ V}$：
- **Stage 1（反相前级）**：
  $$v_{o1,\text{linear}} = -\frac{20\text{ k}\Omega}{2\text{ k}\Omega} \times 1.5\text{ V} = -15.0\text{ V}$$
  由于 $-15.0\text{ V} < -12.0\text{ V}$，**Stage 1 发生负向饱和削波**：
  $$v_{o1,\text{actual}} = -12.0\text{ V}$$
- **Stage 2（反相加法器）**：必须把**钳位后**的 $v_{o1,\text{actual}} = -12.0\text{ V}$ 代入：
  $$v_{o2,\text{actual}} = -\left(\frac{10\text{ k}\Omega}{10\text{ k}\Omega}(-12.0\text{ V}) + \frac{10\text{ k}\Omega}{5\text{ k}\Omega}(2.0\text{ V})\right) = -(-12.0\text{ V} + 4.0\text{ V}) = +8.0\text{ V}$$
  （注：$|+8.0\text{ V}| < 12\text{ V}$，Stage 2 自身未饱和，但输入信号已被污染；若盲用 $-15.0\text{ V}$ 会误算为 $+11.0\text{ V}$。）
- **Stage 3（反相衰减级）**：
  $$v_{o,\text{actual}} = -\frac{10\text{ k}\Omega}{20\text{ k}\Omega} \times (+8.0\text{ V}) = -4.0\text{ V}$$
  与盲算线性结果 $-5.5\text{ V}$ 相比，绝对误差达 $1.5\text{ V}$，相对失真高达 $-27.3\%$。
- **增益分配修复（Gain Staging）**：将 $R_{f1}$ 由 $20\text{ k}\Omega$ 减半至 $10\text{ k}\Omega$（$A_1 = -5$），同时将 $R_a$ 由 $10\text{ k}\Omega$ 减半至 $5\text{ k}\Omega$（$v_{o1}$ 通道权重翻倍为 $-2$），则：
  $$v_{o1,\text{fix}} = (-5)(1.5\text{ V}) = -7.5\text{ V} \quad (\text{安全 ✓})$$
  $$v_{o2,\text{fix}} = -\left(2(-7.5\text{ V}) + 2(2.0\text{ V})\right) = +11.0\text{ V} \quad (\text{安全 ✓})$$
  $$v_{o,\text{fix}} = (-0.5)(+11.0\text{ V}) = -5.5\text{ V} \quad (\text{完全恢复无失真线性输出 ✓})$$

## 第 5 幕：隐蔽陷阱辨析 —— 局部级联 vs 跨级全局反馈

### 5.1 什么时候乘法法则 $A = A_1 A_2$ 彻底失效？

并不是“图上画了两颗首尾相连的运放”就一定能用乘法法则！请牢记教授的**跨级反馈红线**：

> **红线判定标准**：用手指从第二级输出端 $v_o$ 出发，沿着电路图往回看——只要发现哪怕**一根电阻（或电容）跨过第一级运放，把后级输出 $v_o$ 连回第一级的输入节点（$v_{-1}$ 或 $v_{+1}$）**，这就不再是纯级联电路，而是**全局反馈耦合网络（Global Feedback Network）**！
>
> 此时前级反相端 $v_{-1}$ 的 KCL 方程中同时出现了 $v_{o1}$ 和 $v_o$，两级状态深度耦合，**$A \neq A_1 A_2$**，必须毫不犹豫地回归**全局节点分析法（Nodal Analysis）**！

### 5.3 教授三段式板书推导：全局节点分析法破解跨级反馈

**① 公理溯源**
- 反馈极性核验：$v_{-1} \uparrow \implies v_{o1} \downarrow$（反相）$\implies v_o \downarrow$（同相）$\implies$ 经 $R_G$ 拉低 $v_{-1}$，构成**稳定的全局负反馈**，故两颗运放均满足虚短与虚断公理。
- 对节点 $v_{-1} = 0$ 列 KCL（三条支路汇聚：$R_1, R_{f1}, R_G$）。
- Stage 2 自身输入端 $v_{+2}$ 无跨级回流，仍满足标准同相放大器关系 $v_o = A_2 v_{o1}$。

**② 纯符号通式**
由节点 $v_{-1} = 0$ 的 KCL 方程与 Stage 2 局部方程联立：
$$\begin{cases}
\dfrac{v_i - 0}{R_1} + \dfrac{v_{o1} - 0}{R_{f1}} + \dfrac{v_o - 0}{R_G} = 0 \\[10pt]
v_o = \left(1 + \dfrac{R_{f2}}{R_2}\right) v_{o1} \triangleq A_2 v_{o1}
\end{cases}$$
将 $v_{o1} = \dfrac{v_o}{A_2}$ 代入第一式消去中间变量 $v_{o1}$：
$$\frac{v_i}{R_1} + v_o \left(\frac{1}{A_2 R_{f1}} + \frac{1}{R_G}\right) = 0$$
整理得含跨级全局反馈时的精确闭环增益通式：
$$A_{\text{global}} = \frac{v_o}{v_i} = -\frac{1}{R_1 \left(\dfrac{1}{A_2 R_{f1}} + \dfrac{1}{R_G}\right)} = -\frac{A_2 R_{f1} R_G}{R_1 \left(R_G + A_2 R_{f1}\right)}$$
> **极限自检**：令 $R_G \to \infty$（断开跨级电阻），分子分母同除以 $R_G$，上式立即退化为 $-\dfrac{R_{f1}}{R_1} A_2 = A_1 A_2$，完美回到纯级联乘法法则！

**③ 代入数值逐步化简**
代入 $R_1 = 10\text{ k}\Omega, R_{f1} = 20\text{ k}\Omega, R_2 = 10\text{ k}\Omega, R_{f2} = 20\text{ k}\Omega, R_G = 30\text{ k}\Omega$，$v_i = 1.0\text{ V}$：
$$A_2 = 1 + \frac{20\text{ k}\Omega}{10\text{ k}\Omega} = +3$$
$$A_{\text{global}} = -\frac{3 \times 20 \times 30}{10 \times (30 + 3 \times 20)} = -\frac{1800}{10 \times 90} = -2$$
于是实际节点电压为：
$$v_o = (-2) \times 1.0\text{ V} = -2.0\text{ V}, \qquad v_{o1} = \frac{v_o}{A_2} = -\frac{2}{3}\text{ V} \approx -0.667\text{ V}$$
（对比：若误用纯级联乘法法则，会算出 $A = (-2)(+3) = -6$、$v_o = -6.0\text{ V}$，整整错出三倍！）
