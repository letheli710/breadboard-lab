# W2-L6：电源变换（Source Transformation）

> **教授导语（Breadboard Lab 课堂开场）**
> 欢迎回到 Breadboard Lab。上一阶段我们用节点电压法与网孔电流法硬刚复杂电路，但工程现场的电路分析讲究“降维打击”——与其一上来就列三阶、四阶线性方程组，不如先用结构等效把网络一层层压缩。今天这节 **W2-L6：电源变换**（对应 Sadiku 第 4.4 节与 Boylestad 第 8 章），就是电路化简工具箱里最锋利的一把“变形手术刀”：它能把串联结构瞬间翻成并联结构，再把并联结构翻回串联结构，让原本卡死的电阻与电源像拉链一样逐级合并。但请牢记一条铁律：**端口等效只对外部成立，内部元件不可等同，更绝不能把待求支路或受控源的控制变量支路给吞并掉。**

## 第 1 幕：端口等效黑盒直觉 — 外部负载的“盲测”与内外有别

> **左侧舞台联动**：`layer_01_blackbox_probe`（01 端口等效黑盒验证：$v_{oc}$ 与 $i_{sc}$）

### 1.1 站在端口 $a\text{–}b$ 外面看：负载根本分不出黑盒里是谁

想象实验台上有两个密封金属黑盒，每个盒子只伸出两个接线柱 **$a$** 和 **$b$**（Boylestad 第 8 章的经典直觉）：

- **黑盒 A（实际电压源模型）**：内部是一个独立电压源 $v_s$ 与电阻 $R$ **串联**。
- **黑盒 B（实际电流源模型）**：内部是一个独立电流源 $i_s$ 与电阻 $R$ **并联**。

无论你在外部端口 $a\text{–}b$ 之间接上什么负载 $R_L$（电阻、LED、甚至另一整块复杂网络），外部负载唯一能“感知”的物理量，只有端口电压 $v$ 与流出端口的电流 $i$。如果满足：
1. **开路盲测一致**：端口悬空（$i = 0$）时，两盒测得的开路电压 $v_{oc}$ 完全相等；
2. **短路盲测一致**：端口短接（$v = 0$）时，两盒测得的短路电流 $i_{sc}$ 完全相等；

那么由于内部都是线性元件，两者的外部端口伏安特性直线完全重合——**外部世界彻底无法区分黑盒 A 和黑盒 B**。

### 1.3 两条不可逾越的物理边界

1. **理想源的不可变换性**：
   - 理想独立电压源没有串联电阻（$R = 0$），若强行计算等效电流源，会得到 $i_s = v_s / 0 \to \infty$，物理上不存在。
   - 理想独立电流源没有并联电阻（$R = \infty$），若强行计算等效电压源，会得到 $v_s = i_s \cdot \infty \to \infty$，同样不存在。
   - **结论**：只有**非零有限电阻 $0 < R < \infty$** 与源相配（电压源串联 $R$、电流源并联 $R$），才能实施电源变换。
2. **内外有别原则**：电源变换保证的是**端口 $a\text{–}b$ 以外的所有电压、电流和功率完全不变**；但黑盒内部那个电阻 $R$ 上的电流、电压以及发热功率，在变换前后**完全不同**！下一幕我们用板书严格证明这一点。

### 2.2 三段式教授板书推导：端口等效性证明与内部功耗差异

#### ① 公理溯源（Origin）

设两黑盒端口 $a\text{–}b$ 的参考方向完全一致：端口电压 $v = v_{ab}$（$a$ 正 $b$ 负），端口流出电流为 $i$。

1. **对黑盒 A（串联模型）列 KVL**：
   $$-v_s + i R + v = 0 \implies v = v_s - i R$$
   - 令端口开路（$i = 0$），得开路电压：$v_{oc,\text{A}} = v_s$。
   - 令端口短路（$v = 0$），得短路电流：$i_{sc,\text{A}} = \frac{v_s}{R}$。

2. **对黑盒 B（并联模型）在节点 $a$ 列 KCL**：
   $$i_s = \frac{v}{R} + i \implies v = i_s R - i R$$
   - 令端口开路（$i = 0$），得开路电压：$v_{oc,\text{B}} = i_s R$。
   - 令端口短路（$v = 0$），得短路电流：$i_{sc,\text{B}} = i_s$。

3. **端口等效判定**：当且仅当 $v_s = i_s R$ 且两电阻同为 $R$ 时，两黑盒的端口伏安方程 $v(i)$ 具有完全相同的纵截距（$v_{oc}$）、横截距（$i_{sc}$）与斜率（$-R$），因此在端口 $a\text{–}b$ 外接任何负载时，端口电压 $v$ 与电流 $i$ 严格相等。

4. **内部功耗不等效的符号证明**：
   考虑端口开路（$i = 0$）的极端工况：
   - 黑盒 A 内部串联电阻无电流通过，内部功耗 $P_{R,\text{A}} = i^2 R = 0$；
   - 黑盒 B 内部电流源的全部电流 $i_s$ 都灌入并联电阻 $R$，内部功耗 $P_{R,\text{B}} = i_s^2 R \neq 0$！
   可见：**外部端口完全等效，但内部能量耗散截然不同**。

#### ② 纯符号通式（General Formula）

$$v_s = i_s R, \qquad i_s = \frac{v_s}{R}, \qquad R_{\text{series}} = R_{\text{parallel}} = R$$

$$v = v_s - i R \;\Longleftrightarrow\; i = i_s - \frac{v}{R}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）

**数值验证例题**：已知实际电压源 $v_s = 12\text{ V}$ 串联 $R_s = 4\ \Omega$，求其等效实际电流源；并对比外接负载 $R_L = 2\ \Omega$ 以及空载开路时，两者的外部负载功率与内部电阻功耗。

1. **计算等效电流源参数**：
   $$i_s = \frac{v_s}{R_s} = \frac{12}{4} = 3\text{ A}, \qquad R_p = R_s = 4\ \Omega$$
   电流源箭头指向电压源正极端口 $a$。

2. **外接负载 $R_L = 2\ \Omega$ 时的外部与内部对比**：
   - **电压源模型（黑盒 A）**：
     $$i_L = \frac{v_s}{R_s + R_L} = \frac{12}{4 + 2} = 2\text{ A}, \qquad v_L = i_L R_L = 2 \times 2 = 4\text{ V}$$
     $$P_L = v_L i_L = 4 \times 2 = 8\text{ W}, \qquad P_{R_s} = i_L^2 R_s = 2^2 \times 4 = 16\text{ W}$$
   - **电流源模型（黑盒 B）**：
     $$R_{\text{eq}} = R_p \parallel R_L = \frac{4 \times 2}{4 + 2} = \frac{4}{3}\ \Omega, \qquad v_L = i_s R_{\text{eq}} = 3 \times \frac{4}{3} = 4\text{ V}$$
     $$i_L = \frac{v_L}{R_L} = \frac{4}{2} = 2\text{ A}, \qquad P_L = v_L i_L = 4 \times 2 = 8\text{ W}$$
     $$P_{R_p} = \frac{v_L^2}{R_p} = \frac{4^2}{4} = 4\text{ W}$$

3. **空载开路（$R_L = \infty$）对比**：
   - 两盒端口开路电压均为 $v_{oc} = 12\text{ V}$；
   - 黑盒 A 内部功耗 $P_{R_s,\text{oc}} = 0\text{ W}$，而黑盒 B 内部功耗高达：
     $$P_{R_p,\text{oc}} = i_s^2 R_p = 3^2 \times 4 = 36\text{ W}$$

> **教授点睛**：负载端 $v_L = 4\text{ V}, i_L = 2\text{ A}, P_L = 8\text{ W}$ 分毫不差；内部电阻功耗却是 $16\text{ W}$ vs. $4\text{ W}$（空载更是 $0\text{ W}$ vs. $36\text{ W}$）。以后任何考题问你“原电路中与源串联的电阻功率”，**绝不能用变换后的并联电阻来算**！

### 3.3 三段式教授板书推导：多电源网络逐级压缩

#### ① 公理溯源（Origin）

多级电源变换的底层公理是 **KVL 的串联叠加性**、**KCL 的并联叠加性** 以及 **端口局部替换定理**：
- 当多组电阻和电源交替出现串联与并联时，单靠串并联电阻公式无法化简；
- 通过将某支路的并联电流源翻成串联电压源，就能把被隔开的电阻拉进同一条串联链中相加；再翻回并联电流源，就能与邻近并联支路按 KCL 直接代数合并。
- 只要待求支路 $R_o$ 始终位于被替换子网络的外部，其端电压 $v_o$ 在每一步变换中都严格保持不变。

#### ② 纯符号通式（General Formula）

- **串联源与串联电阻合并**：
  $$v_{\text{eq}} = \sum_{k} (\pm v_{sk}), \qquad R_{\text{ser}} = R_1 + R_2$$
- **并联源与并联电阻合并**：
  $$i_{\text{eq}} = \sum_{k} (\pm i_{sk}), \qquad R_{\text{par}} = R_1 \parallel R_2 = \frac{R_1 R_2}{R_1 + R_2}$$
- **最终并联节点端电压**（设净电流源 $i_{\text{net}}$ 向下流出顶部节点）：
  $$v_o = -i_{\text{net}} \cdot \left(R_{\text{par}} \parallel R_o\right)$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）

**题目（Sadiku Section 4.4 经典改编）**：如阶段 0 所示，左侧为 $12\text{ V}$ 电压源（上负下正）串联 $3\ \Omega$；中间红框支路为 $8\ \Omega$ 电阻（$v_o$ 上正下负）；桥接串联电阻 $2\ \Omega$；右侧为 $3\text{ A}$ 电流源（箭头向上）并联 $4\ \Omega$。用电源变换求 $v_o$。

1. **第 1 步（右侧电流源 → 电压源）**：
   将右侧 $3\text{ A}\uparrow$ 与 $4\ \Omega$ 并联支路变换为电压源串联 $4\ \Omega$：
   $$v_{sR} = i_{sR} R_{R1} = 3 \times 4 = 12\text{ V} \quad (\text{正极朝上})$$

2. **第 2 步（右侧串联电阻合并）**：
   变换后的 $4\ \Omega$ 与桥接电阻 $2\ \Omega$ 形成纯串联：
   $$R_R = 4 + 2 = 6\ \Omega$$

3. **第 3 步（左右两侧同步转为电流源，红框 $8\ \Omega$ 纹丝不动）**：
   - **左侧**（注意 $12\text{ V}$ 源上负下正，正极在底端！）：
     $$i_{sL} = \frac{12}{3} = 4\text{ A} \quad (\text{箭头向下 } \downarrow), \qquad R_L = 3\ \Omega$$
   - **右侧**（$12\text{ V}$ 源正极在顶端）：
     $$i_{sR}' = \frac{12}{6} = 2\text{ A} \quad (\text{箭头向上 } \uparrow), \qquad R_R = 6\ \Omega$$

4. **第 4 步（并联电流源与并联电阻合并）**：
   - 合并并联电流源（向下为 $4\text{ A}$，向上为 $2\text{ A}$）：
     $$i_{\text{net}} = 4 - 2 = 2\text{ A} \quad (\text{箭头向下 } \downarrow)$$
   - 合并红框以外的并联电阻 $3\ \Omega$ 与 $6\ \Omega$：
     $$R_{\text{eq}} = 3 \parallel 6 = \frac{3 \times 6}{3 + 6} = \frac{18}{9} = 2\ \Omega$$

5. **第 5 步（单节点直接求解 $v_o$）**：
   此时仅剩 $2\text{ A}\downarrow$、$2\ \Omega$ 与红框内的 $8\ \Omega$ 三者并联。因 $v_o$ 与 $2\ \Omega$ 两端电压相同，先求并联总阻：
   $$R_{\text{tot}} = 2 \parallel 8 = \frac{2 \times 8}{2 + 8} = \frac{16}{10} = 1.6\ \Omega$$
   由于 $2\text{ A}$ 电流源箭头向下（从顶部节点抽走电流），顶部节点电位低于底部参考节点：
   $$v_o = -2 \times 1.6 = -3.2\text{ V}$$

### 4.1 受控源也能变，但控制变量支路是“高压红线”

很多学生以为电源变换只适用于圆形的独立源。其实 **菱形受控源（VCVS、CCVS、VCCS、CCCS）同样完全满足电源变换公式**！
但受控源多了一条生死红线（Sadiku Section 4.4 核心强调）：

### 4.3 三段式教授板书推导：含受控源的电源变换

#### ① 公理溯源（Origin）

对于线性压控电流源 $i_d = g_m v_x$ 与电阻 $R_p$ 并联的二端网络，只要控制变量 $v_x$ 位于该二端网络的**外部**，对端口 $a\text{–}b$ 列 KCL 依然得到 $v = (g_m v_x) R_p - i R_p$。这与受控电压源 $v_d = (g_m R_p) v_x$ 串联电阻 $R_p$ 的端口方程完全一致。
反之，若把包含 $v_x$ 的 $2\ \Omega$ 支路拿去变换，$v_x$ 所依附的物理电阻就会被拓扑改写，控制关系随即失效。

#### ② 纯符号通式（General Formula）

$$v_d = i_d R_p = (g_m v_x) R_p, \qquad i_d = \frac{v_d}{R_s} = \frac{\mu v_x}{R_s}$$

$$\text{约束条件：} R_{\text{ctrl}} \notin \text{被变换子网络（必须位于红框隔离区内）}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）

**题目**：如上左图所示，左侧为 $16\text{ V}$ 独立电压源串联 $2\ \Omega$ 电阻（$v_x$ 定义在 $2\ \Omega$ 两端，左正右负）；右侧为压控电流源 $0.25 v_x$（箭头向上）并联 $4\ \Omega$ 电阻。用电源变换求 $v_x$。

1. **红框锁定**：$v_x$ 定义在 $2\ \Omega$ 电阻上，因此**绝不能**将左侧 $16\text{ V}$ 串联 $2\ \Omega$ 变换为 $8\text{ A} \parallel 2\ \Omega$。
2. **仅变换右侧受控电流源支路**：
   将 $i_d = 0.25 v_x$（箭头向上）并联 $4\ \Omega$ 变换为受控电压源串联 $4\ \Omega$：
   $$v_d = i_d \cdot R_p = (0.25 v_x) \times 4 = v_x \quad (\text{正极朝上})$$
3. **对变换后的单回路列 KVL**（设顺时针回路电流为 $i$）：
   $$-16 + 2i + 4i + v_x = 0$$
4. **代入控制变量约束方程**：
   由欧姆定律，$2\ \Omega$ 电阻上的电压为 $v_x = 2i$，代入 KVL：
   $$-16 + 2i + 4i + 2i = 0 \implies 8i = 16 \implies i = 2\text{ A}$$
5. **求得目标量 $v_x$**：
   $$v_x = 2i = 2 \times 2 = 4\text{ V}$$
