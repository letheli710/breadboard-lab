## 第一幕：多频率激励的“分频宇宙”法则——交流叠加定理（Sadiku §10.4）

### 1.1 为什么交流叠加的真正杀手锏是“多频率”？

在 `W2-L5` 学直流叠加定理时，很多同学会问：“节点电压法已经够快了，干嘛还要把电路拆成好几个子电路算叠加？”
在直流电路里，叠加定理确实大多只是“锦上添花”。但在交流电路里，当电路中同时存在**不同频率的独立源**（例如一个直流偏置电源 $\omega_0 = 0$、一个低频信号源 $\omega_1 = 2\text{ rad/s}$、再加一个高频干扰源 $\omega_2 = 5\text{ rad/s}$）时，**节点电压法和网孔电流法在单一相量域里彻底失效，叠加定理成为你唯一的救命稻草！**

为什么？从物理机制上看：
- 电阻 $R$ 对所有频率一视同仁，但电感阻抗 $\mathbf{Z}_L = j\omega L$ 和电容阻抗 $\mathbf{Z}_C = \frac{1}{j\omega C}$ 是**频率 $\omega$ 的函数**。
- 当电路里同时存在 $\omega_0 = 0$、$\omega_1 = 2$、$\omega_2 = 5$ 时，同一个电容 $C$ 在三个频率下呈现出**三个完全不同的阻抗值**！根本不存在一个“统一的相量电路”能同时容纳它们。
- 更致命的是：**绝不能把不同频率的相量直接相加！** 相量 $\mathbf{V}_1$ 代表以角速度 $\omega_1$ 旋转的向量 $\mathbf{V}_1 e^{j\omega_1 t}$，而 $\mathbf{V}_2$ 代表以角速度 $\omega_2$ 旋转的向量 $\mathbf{V}_2 e^{j\omega_2 t}$。两个转速不同的指针在复平面上相对夹角时刻在变，强行写 $\mathbf{V}_1 + \mathbf{V}_2$ 在数学和物理上都是彻头彻尾的错误！

因此，交流多频率叠加定理必须严格遵循**“分频拆解 → 各自频域求解 → 全部还原时域 → 时域求和”**的四步铁律：

$$v(t) = v_0 + v_1(t) + v_2(t) + \cdots = V_0 + \operatorname{Re}\!\left\{\mathbf{V}_1 e^{j\omega_1 t}\right\} + \operatorname{Re}\!\left\{\mathbf{V}_2 e^{j\omega_2 t}\right\} + \cdots$$

> **教授口诀**：**同频可并相量算，异频必须分宇宙；直流电感短、电容断，最后统统回时域再相加！**（注：仅对电压、电流等线性响应成立；**功率是非线性二次量，绝不能直接用叠加定理求和**！）

### 1.3 三段式教授板书推导：例题 1（DC + $\omega_1=2$ + $\omega_2=5$ 多频率叠加）

**题目**：如上图所示，电路节点 $v_o(t)$ 连接四条支路：① 直流源 $V_0 = 12\text{ V}$ 串联 $R_1 = 4\ \Omega$ 与 $L = 2\text{ H}$；② 交流源 $v_1(t) = 20\cos(2t)\text{ V}$ 串联 $C = 0.25\text{ F}$；③ 负载电阻 $R_L = 4\ \Omega$ 接地；④ 交流电流源 $i_2(t) = 3\sin(5t)\text{ A}$ 注入节点 $v_o$。求稳态输出电压 $v_o(t)$。

#### ① 公理溯源
线性时不变（LTI）电路满足齐次性与可加性，但储能元件阻抗 $\mathbf{Z}_L(\omega) = j\omega L$、$\mathbf{Z}_C(\omega) = \frac{1}{j\omega C}$ 显式依赖激励角频率 $\omega$。当激励包含三个互异频率 $\omega_0 = 0$、$\omega_1$、$\omega_2$ 时，必须将原电路拆分为三个单频子电路分别在对应频域求解，再经由逆相量变换 $v_k(t) = \operatorname{Re}\{\mathbf{V}_{ok} e^{j\omega_k t}\}$ 全部还原回时域后求和：
$$v_o(t) = v_{o0} + v_{o1}(t) + v_{o2}(t)$$

#### ② 纯符号通式
- **子电路 0（直流 $\omega_0 = 0$）**：$v_1$ 短路、$i_2$ 开路；稳态下电感 $L$ 视作短路（$\mathbf{Z}_L(0)=0$），电容 $C$ 视作开路（$\mathbf{Z}_C(0)=\infty$）。由电阻分压公式：
  $$v_{o0} = V_0 \frac{R_L}{R_1 + R_L}$$
- **子电路 1（交流 $\omega_1$）**：$V_0$ 短路、$i_2$ 开路。定义 $\mathbf{Z}_{L1} = j\omega_1 L$、$\mathbf{Z}_{C1} = \frac{1}{j\omega_1 C}$，右侧并联等效阻抗为：
  $$\mathbf{Z}_{\parallel 1} = (R_1 + \mathbf{Z}_{L1}) \parallel R_L = \frac{(R_1 + \mathbf{Z}_{L1})R_L}{R_1 + \mathbf{Z}_{L1} + R_L}$$
  由复阻抗分压公式得相量 $\mathbf{V}_{o1}$：
  $$\mathbf{V}_{o1} = \mathbf{V}_1 \frac{\mathbf{Z}_{\parallel 1}}{\mathbf{Z}_{C1} + \mathbf{Z}_{\parallel 1}}$$
- **子电路 2（交流 $\omega_2$）**：$V_0$ 短路、$v_1$ 短路。定义 $\mathbf{Z}_{L2} = j\omega_2 L$、$\mathbf{Z}_{C2} = \frac{1}{j\omega_2 C}$，节点总导纳与相量 $\mathbf{V}_{o2}$ 分别为：
  $$\mathbf{Y}_{\text{tot},2} = \frac{1}{R_1 + \mathbf{Z}_{L2}} + \frac{1}{\mathbf{Z}_{C2}} + \frac{1}{R_L}, \qquad \mathbf{V}_{o2} = \frac{\mathbf{I}_2}{\mathbf{Y}_{\text{tot},2}}$$

#### ③ 代入数值逐步化简
1. **求直流分量 $v_{o0}$**（$V_0 = 12\text{ V}, R_1 = 4\ \Omega, R_L = 4\ \Omega$）：
   $$v_{o0} = 12 \times \frac{4}{4 + 4} = 6.00\text{ V}$$
2. **求 $\omega_1 = 2\text{ rad/s}$ 分量 $v_{o1}(t)$**（$\mathbf{V}_1 = 20\angle 0^\circ\text{ V}$）：
   $$\mathbf{Z}_{L1} = j(2)(2) = j4\ \Omega, \qquad \mathbf{Z}_{C1} = \frac{1}{j(2)(0.25)} = -j2\ \Omega$$
   $$\mathbf{Z}_{\parallel 1} = \frac{(4 + j4)(4)}{4 + j4 + 4} = \frac{16 + j16}{8 + j4} = \frac{(4 + j4)(2 - j1)}{2^2 + 1^2} = \frac{12 + j4}{5} = 2.4 + j0.8\ \Omega$$
   $$\mathbf{V}_{o1} = 20 \cdot \frac{2.4 + j0.8}{-j2 + 2.4 + j0.8} = 20 \cdot \frac{2.4 + j0.8}{2.4 - j1.2} = 20 \cdot \frac{3 + j1}{3 - j1.5} = \frac{40}{3} + j\frac{40}{3} \approx 18.86\angle 45.00^\circ\text{ V}$$
   还原回时域：
   $$v_{o1}(t) = 18.86\cos(2t + 45^\circ)\text{ V}$$
3. **求 $\omega_2 = 5\text{ rad/s}$ 分量 $v_{o2}(t)$**：
   先统一余弦基准：$i_2(t) = 3\sin(5t) = 3\cos(5t - 90^\circ)\text{ A} \implies \mathbf{I}_2 = 3\angle -90^\circ = -j3\text{ A}$。
   $$\mathbf{Z}_{L2} = j(5)(2) = j10\ \Omega, \qquad \mathbf{Z}_{C2} = \frac{1}{j(5)(0.25)} = -j0.8\ \Omega$$
   $$\mathbf{Y}_{\text{tot},2} = \frac{1}{4 + j10} + \frac{1}{-j0.8} + \frac{1}{4} = \frac{4 - j10}{116} + j1.25 + 0.25 \approx 0.2845 + j1.1638\text{ S} \approx 1.1981\angle 76.26^\circ\text{ S}$$
   $$\mathbf{V}_{o2} = \frac{3\angle -90^\circ}{1.1981\angle 76.26^\circ} \approx 2.504\angle -166.26^\circ\text{ V}$$
   还原回时域：
   $$v_{o2}(t) = 2.50\cos(5t - 166.26^\circ)\text{ V}$$
4. **时域最终合成**：
   $$v_o(t) = 6 + 18.86\cos(2t + 45^\circ) + 2.50\cos(5t - 166.26^\circ)\text{ V}$$

## 第二幕：交流电源变换——用 $\mathbf{V}_s = \mathbf{Z}_s \mathbf{I}_s$ 折叠复杂梯形网络（Sadiku §10.5）

### 2.1 从直流到交流：端口等效的复数升级

在 `W2-L6` 里，我们知道一个电压源串联电阻可以等效为一个电流源并联同一电阻。在**单一角频率 $\omega$** 的相量域中，这一关系原封不动地推广为复阻抗形式：

$$\mathbf{V}_s = \mathbf{Z}_s \mathbf{I}_s \qquad \Longleftrightarrow \qquad \mathbf{I}_s = \frac{\mathbf{V}_s}{\mathbf{Z}_s}$$

其中 $\mathbf{Z}_s$ 保持**完全不变**（既可以是纯电阻，也可以是 $R + jX$ 复阻抗）。但请牢记三条使用红线：
1. **同频前提**：只有同一频率下的源才能在同一相量图里变换并合并。
2. **保护目标变量与控制变量**：如果题目要你求某支路的电流或电压，或者受控源的控制量就在某条支路上，**切勿把该支路吞并进电源变换里**，否则会把目标变量或控制变量“变没”。
3. **仅对外端口等效**：端口 $a$-$b$ 外部的电压电流完全不变，但电源内部的电流与功耗并不等效。

### 2.3 三段式教授板书推导：例题 2（连环交流电源变换求 $\mathbf{V}_x$）

**题目**：某同频交流梯形网络：最左侧为电压源 $\mathbf{V}_s = 24\angle 0^\circ\text{ V}$ 串联 $R_1 = 6\ \Omega$；中间节点接电容支路 $\mathbf{Z}_C = -j6\ \Omega$ 到地；向右侧串联阻抗 $\mathbf{Z}_{\text{ser}} = 5 + j3\ \Omega$ 后到达输出节点 $x$；节点 $x$ 处接入向上电流源 $\mathbf{I}_2 = 2\angle 90^\circ\text{ A}$ 并联负载电阻 $R_3 = 8\ \Omega$。请用交流电源变换法求节点电压相量 $\mathbf{V}_x$（注意保护 $R_3$ 支路不被吞并）。

#### ① 公理溯源
对端口外部而言，电压源 $\mathbf{V}_s$ 串联复阻抗 $\mathbf{Z}_s$ 与电流源 $\mathbf{I}_s = \mathbf{V}_s / \mathbf{Z}_s$ 并联复阻抗 $\mathbf{Z}_s$ 完全等效；并联电流源直接做复数叠加，并联阻抗取倒数和之倒数。

#### ② 纯符号通式
1. 将左侧电压源 $(\mathbf{V}_s, R_1)$ 变换为电流源并与 $\mathbf{Z}_C$ 合并：
   $$\mathbf{I}_{s1} = \frac{\mathbf{V}_s}{R_1}, \qquad \mathbf{Z}_{\text{eq}1} = R_1 \parallel \mathbf{Z}_C = \frac{R_1 \mathbf{Z}_C}{R_1 + \mathbf{Z}_C}$$
2. 将 $(\mathbf{I}_{s1}, \mathbf{Z}_{\text{eq}1})$ 变回电压源，再与 $\mathbf{Z}_{\text{ser}}$ 串联：
   $$\mathbf{V}_{\text{eq}1} = \mathbf{I}_{s1}\mathbf{Z}_{\text{eq}1}, \qquad \mathbf{Z}_{\text{left}} = \mathbf{Z}_{\text{eq}1} + \mathbf{Z}_{\text{ser}}$$
3. 将 $(\mathbf{V}_{\text{eq}1}, \mathbf{Z}_{\text{left}})$ 再次变为电流源，与右侧 $(\mathbf{I}_2, R_3)$ 并联求解 $\mathbf{V}_x$：
   $$\mathbf{I}_{\text{left}} = \frac{\mathbf{V}_{\text{eq}1}}{\mathbf{Z}_{\text{left}}}, \qquad \mathbf{I}_{\text{tot}} = \mathbf{I}_{\text{left}} + \mathbf{I}_2, \qquad \mathbf{Z}_{\text{tot}} = \mathbf{Z}_{\text{left}} \parallel R_3, \qquad \mathbf{V}_x = \mathbf{I}_{\text{tot}}\mathbf{Z}_{\text{tot}}$$

#### ③ 代入数值逐步化简
1. 第一次变换（电压源 → 电流源）并合并 $\mathbf{Z}_C$：
   $$\mathbf{I}_{s1} = \frac{24\angle 0^\circ}{6} = 4\angle 0^\circ\text{ A}$$
   $$\mathbf{Z}_{\text{eq}1} = \frac{6 \times (-j6)}{6 - j6} = \frac{-j36}{6(1 - j1)} = \frac{-j6(1 + j1)}{2} = 3 - j3\ \Omega$$
2. 第二次变换（电流源 → 电压源）并串联 $\mathbf{Z}_{\text{ser}} = 5 + j3\ \Omega$：
   $$\mathbf{V}_{\text{eq}1} = 4 \times (3 - j3) = 12 - j12\text{ V}$$
   $$\mathbf{Z}_{\text{left}} = (3 - j3) + (5 + j3) = 8\ \Omega$$
   （瞧！虚部 $-j3$ 与 $+j3$ 恰好抵消，左侧等效内阻竟然成了纯实数 $8\ \Omega$！）
3. 第三次变换并与右侧合并：
   $$\mathbf{I}_{\text{left}} = \frac{12 - j12}{8} = 1.5 - j1.5\text{ A}$$
   $$\mathbf{I}_{\text{tot}} = (1.5 - j1.5) + j2 = 1.5 + j0.5\text{ A}, \qquad \mathbf{Z}_{\text{tot}} = 8 \parallel 8 = 4\ \Omega$$
   $$\mathbf{V}_x = (1.5 + j0.5) \times 4 = 6 + j2\text{ V} \approx 6.32\angle 18.43^\circ\text{ V}$$

## 第三幕：交流戴维南与诺顿等效（独立源情形）——复阻抗黑盒降维（Sadiku §10.6）

### 3.1 复阻抗戴维南等效的物理深意

在 `W2-L7` 中，我们把任意含独立源的线性直流二端网络等效为 $V_{Th}$ 串联 $R_{Th}$。到了单一角频率 $\omega$ 的相量域，任意线性二端网络从端口 $a$-$b$ 看进去，都可以无损地坍缩为一个**戴维南等效电路**（$\mathbf{V}_{Th}$ 串联 $\mathbf{Z}_{Th}$）或**诺顿等效电路**（$\mathbf{I}_N$ 并联 $\mathbf{Z}_N$）：

$$\mathbf{V}_{Th} = \mathbf{V}_{oc}, \qquad \mathbf{I}_N = \mathbf{I}_{sc} = \frac{\mathbf{V}_{Th}}{\mathbf{Z}_{Th}}, \qquad \mathbf{Z}_{Th} = \mathbf{Z}_N = R_{Th} + jX_{Th}$$

请特别品味 $\mathbf{Z}_{Th} = R_{Th} + jX_{Th}$ 的物理含义：
- 实部 $R_{Th}$ 代表端口内部的等效耗能电阻；
- 虚部 $X_{Th}$ 揭示了端口在当前频率 $\omega$ 下的电抗属性——$X_{Th} > 0$ 呈感性，$X_{Th} < 0$ 呈容性。
- **重磅剧透（`W5-L7/L8`）**：一旦你把前级庞杂的放大器或输电网络坍缩成了 $(\mathbf{V}_{Th}, \mathbf{Z}_{Th})$，接下来给负载 $\mathbf{Z}_L$ 做**共轭匹配（$\mathbf{Z}_L = \mathbf{Z}_{Th}^*$）以榨干最大平均功率**，瞬间就变成了一行公式的事！

当网络**仅含独立源**时，求 $\mathbf{Z}_{Th}$ 最快的方法与直流完全一致：**将所有独立电压源短路、所有独立电流源开路**，直接从端口 $a$-$b$ 向内串并联化简计算输入复阻抗。

### 3.3 三段式教授板书推导：例题 3（独立源网络的 $\mathbf{Z}_{Th}$、$\mathbf{V}_{Th}$ 与 $\mathbf{I}_N$）

**题目**：求上图左侧交流网络在端口 $a$-$b$ 处的戴维南等效电路（$\mathbf{V}_{Th}, \mathbf{Z}_{Th}$）与诺顿等效电路（$\mathbf{I}_N, \mathbf{Z}_N$）。已知 $\mathbf{V}_s = 50\angle 0^\circ\text{ V}$、$\mathbf{Z}_1 = 6 - j8\ \Omega$、$\mathbf{Z}_2 = j10\ \Omega$、$R_2 = 4\ \Omega$、$\mathbf{I}_s = 2\angle 90^\circ\text{ A}$。

#### ① 公理溯源
不含受控源的线性交流网络：
1. 独立源置零（电压源短路、电流源开路）后，端口 $a$-$b$ 测得的输入阻抗即为 $\mathbf{Z}_{Th} = \mathbf{Z}_N$；
2. 端口 $a$-$b$ 开路时，端口电压即为 $\mathbf{V}_{Th} = \mathbf{V}_{oc}$；
3. 诺顿短路电流满足 $\mathbf{I}_N = \mathbf{I}_{sc} = \mathbf{V}_{Th} / \mathbf{Z}_{Th}$。

#### ② 纯符号通式
- **求 $\mathbf{Z}_{Th}$**：$\mathbf{V}_s$ 短路、$\mathbf{I}_s$ 开路后，$\mathbf{Z}_1$ 与 $\mathbf{Z}_2$ 并联再与 $R_2$ 串联：
  $$\mathbf{Z}_{Th} = (\mathbf{Z}_1 \parallel \mathbf{Z}_2) + R_2 = \frac{\mathbf{Z}_1 \mathbf{Z}_2}{\mathbf{Z}_1 + \mathbf{Z}_2} + R_2$$
- **求 $\mathbf{V}_{Th}$**：端口 $a$-$b$ 开路时，电流源 $\mathbf{I}_s$ 全部自右向左流过 $R_2$ 进入中间节点 1。对节点 1 列 KCL：
  $$\frac{\mathbf{V}_1 - \mathbf{V}_s}{\mathbf{Z}_1} + \frac{\mathbf{V}_1}{\mathbf{Z}_2} = \mathbf{I}_s \implies \mathbf{V}_1 = \frac{\mathbf{V}_s/\mathbf{Z}_1 + \mathbf{I}_s}{1/\mathbf{Z}_1 + 1/\mathbf{Z}_2}$$
  再由 KVL 得开路端口电压 $\mathbf{V}_{Th}$ 及诺顿电流 $\mathbf{I}_N$：
  $$\mathbf{V}_{Th} = \mathbf{V}_1 + \mathbf{I}_s R_2, \qquad \mathbf{I}_N = \frac{\mathbf{V}_{Th}}{\mathbf{Z}_{Th}}$$

#### ③ 代入数值逐步化简
1. **计算 $\mathbf{Z}_{Th}$**：
   $$\mathbf{Z}_1 \parallel \mathbf{Z}_2 = \frac{(6 - j8)(j10)}{6 - j8 + j10} = \frac{80 + j60}{6 + j2} = \frac{(40 + j30)(3 - j1)}{3^2 + 1^2} = \frac{150 + j50}{10} = 15 + j5\ \Omega$$
   $$\mathbf{Z}_{Th} = (15 + j5) + 4 = 19 + j5\ \Omega \approx 19.65\angle 14.74^\circ\ \Omega$$
2. **计算 $\mathbf{V}_{Th}$**：
   $$\frac{\mathbf{V}_s}{\mathbf{Z}_1} = \frac{50}{6 - j8} = \frac{50(6 + j8)}{100} = 3 + j4\text{ A}, \qquad \mathbf{I}_s = j2\text{ A}$$
   $$\mathbf{V}_1 = \left(\frac{\mathbf{V}_s}{\mathbf{Z}_1} + \mathbf{I}_s\right)(\mathbf{Z}_1 \parallel \mathbf{Z}_2) = (3 + j6)(15 + j5) = (45 - 30) + j(15 + 90) = 15 + j105\text{ V}$$
   $$\mathbf{V}_{Th} = \mathbf{V}_1 + \mathbf{I}_s R_2 = (15 + j105) + (j2)(4) = 15 + j113\text{ V} \approx 113.99\angle 82.44^\circ\text{ V}$$
3. **计算 $\mathbf{I}_N$（并核验端口短路电流）**：
   $$\mathbf{I}_N = \frac{\mathbf{V}_{Th}}{\mathbf{Z}_{Th}} = \frac{113.99\angle 82.44^\circ}{19.65\angle 14.74^\circ} \approx 5.80\angle 67.70^\circ\text{ A} \approx 2.20 + j5.37\text{ A}$$

## 第四幕：含受控源的交流戴维南等效——$1\angle 0^\circ\text{ V}$ 测试源法（Sadiku §10.6 进阶）

### 4.1 为什么有受控源时不能直接“串并联”求 $\mathbf{Z}_{Th}$？

如果网络里藏着一个受控源（比如晶体管或运放的小信号模型 $g_m \mathbf{V}_x$ 或 $\beta \mathbf{I}_x$），**受控源绝对不能置零**！因为受控源代表了电路内部的能量耦合机制，关掉它就等于拆毁了器件本身。

此时求 $\mathbf{Z}_{Th}$ 有两种万无一失的方法：
1. **外加测试源法（首选，永远适用）**：将所有**独立源置零**（保留受控源不动），在端口 $a$-$b$ 外加一个单位测试电压源 $\mathbf{V}_t = 1\angle 0^\circ\text{ V}$（或单位测试电流源 $\mathbf{I}_t = 1\angle 0^\circ\text{ A}$），求出端口流入电流 $\mathbf{I}_t$（或端口电压 $\mathbf{V}_t$），则：
   $$\mathbf{Z}_{Th} = \frac{\mathbf{V}_t}{\mathbf{I}_t}$$
2. **开路电压/短路电流法**：保留独立源，分别求端口开路电压 $\mathbf{V}_{oc}$ 与端口短路电流 $\mathbf{I}_{sc}$，则 $\mathbf{Z}_{Th} = \mathbf{V}_{oc} / \mathbf{I}_{sc}$。（注意：若电路不含独立源，则 $\mathbf{V}_{oc} = 0, \mathbf{I}_{sc} = 0$，此法出现 $0/0$ 失效，必须用方法 1！）

### 4.3 三段式教授板书推导：例题 4（含受控源的交流戴维南等效）

**题目**：如上图所示，含压控电流源 $g_m \mathbf{V}_x$（$g_m = 0.5\text{ S}$）的交流电路中，$\mathbf{V}_s = 12\angle 0^\circ\text{ V}$、$R_1 = 4\ \Omega$、$\mathbf{Z}_C = -j4\ \Omega$、$\mathbf{Z}_L = j4\ \Omega$，控制电压 $\mathbf{V}_x$ 为节点 1 对地电压。求端口 $a$-$b$ 处的 $\mathbf{V}_{Th}$ 与 $\mathbf{Z}_{Th}$。

#### ① 公理溯源
对含受控源的线性交流网络：
1. 求 $\mathbf{V}_{Th}$ 时保持端口 $a$-$b$ 开路，同时保留独立源与受控源，列写节点 KCL 方程求解端口电压 $\mathbf{V}_{oc}$；
2. 求 $\mathbf{Z}_{Th}$ 时仅将独立源置零（$\mathbf{V}_s = 0$ 短路），**完整保留受控源**，在端口外加测试电压源 $\mathbf{V}_t = 1\angle 0^\circ\text{ V}$，求流入端口的测试电流 $\mathbf{I}_t$，由定义得 $\mathbf{Z}_{Th} = \mathbf{V}_t / \mathbf{I}_t$。

#### ② 纯符号通式
- **Step A（开路求 $\mathbf{V}_{Th}$）**：端口开路时，流出节点 $a$ 进入 $\mathbf{Z}_L$ 的电流等于受控源注入电流 $g_m \mathbf{V}_x$：
  $$\frac{\mathbf{V}_{Th} - \mathbf{V}_x}{\mathbf{Z}_L} = g_m \mathbf{V}_x \implies \mathbf{V}_{Th} = \mathbf{V}_x (1 + g_m \mathbf{Z}_L)$$
  对节点 1（电压即 $\mathbf{V}_x$）列 KCL（注意由 $\mathbf{Z}_L$ 流入节点 1 的电流就是 $g_m \mathbf{V}_x$）：
  $$\frac{\mathbf{V}_x - \mathbf{V}_s}{R_1} + \frac{\mathbf{V}_x}{\mathbf{Z}_C} - g_m \mathbf{V}_x = 0 \implies \mathbf{V}_x = \frac{\mathbf{V}_s / R_1}{1/R_1 + 1/\mathbf{Z}_C - g_m}$$
- **Step B（外加测试源 $\mathbf{V}_t$ 求 $\mathbf{Z}_{Th}$）**：令 $\mathbf{V}_s = 0$，端口接 $\mathbf{V}_t$。对节点 1 列 KCL：
  $$\mathbf{V}_x \left(\frac{1}{R_1} + \frac{1}{\mathbf{Z}_C} + \frac{1}{\mathbf{Z}_L}\right) = \frac{\mathbf{V}_t}{\mathbf{Z}_L}$$
  再对端口节点 $a$ 列 KCL 求流入网络的测试电流 $\mathbf{I}_t$：
  $$\mathbf{I}_t = \frac{\mathbf{V}_t - \mathbf{V}_x}{\mathbf{Z}_L} - g_m \mathbf{V}_x, \qquad \mathbf{Z}_{Th} = \frac{\mathbf{V}_t}{\mathbf{I}_t}$$

#### ③ 代入数值逐步化简
1. **代入求 $\mathbf{V}_{Th}$**（$\mathbf{V}_s = 12\text{ V}, R_1 = 4\ \Omega, \mathbf{Z}_C = -j4\ \Omega, \mathbf{Z}_L = j4\ \Omega, g_m = 0.5\text{ S}$）：
   $$\mathbf{V}_x = \frac{12 / 4}{0.25 + j0.25 - 0.5} = \frac{3}{-0.25 + j0.25} = \frac{3(-0.25 - j0.25)}{0.125} = -6 - j6\text{ V}$$
   $$\mathbf{V}_{Th} = (-6 - j6)\bigl(1 + 0.5(j4)\bigr) = (-6 - j6)(1 + j2) = (-6 + 12) + j(-12 - 6) = 6 - j18\text{ V} \approx 18.97\angle -71.57^\circ\text{ V}$$
2. **代入求 $\mathbf{Z}_{Th}$**（取 $\mathbf{V}_t = 1\angle 0^\circ\text{ V}$）：
   $$\mathbf{V}_x \left(\frac{1}{4} + \frac{1}{-j4} + \frac{1}{j4}\right) = \frac{1}{j4} \implies \mathbf{V}_x (0.25 + j0.25 - j0.25) = -j0.25 \implies \mathbf{V}_x = -j1\text{ V}$$
   （电感与电容在节点 1 的导纳恰好谐振抵消，算术瞬间变清爽！）
   $$\mathbf{I}_t = \frac{1 - (-j1)}{j4} - 0.5(-j1) = (0.25 - j0.25) + j0.5 = 0.25 + j0.25\text{ A}$$
   $$\mathbf{Z}_{Th} = \frac{1}{0.25 + j0.25} = \frac{4}{1 + j1} = 2 - j2\ \Omega \approx 2.83\angle -45.00^\circ\ \Omega$$
   **物理洞察**：虽然电路中接入了感性元件 $\mathbf{Z}_L = j4\ \Omega$，但在受控源反馈作用下，端口等效阻抗虚部为 $-j2\ \Omega$，整体呈现**容性**！

### 5.3 三段式教授板书推导：例题 5（含反馈电容的交流反相运放）

**题目**：如上图所示，理想运放构成交流反相电路，输入电压 $v_i(t) = 2\cos(1000t)\text{ V}$（$\omega = 1000\text{ rad/s}$），$R_1 = 10\text{ k}\Omega$，$R_f = 50\text{ k}\Omega$，$C_f = 20\text{ nF}$。求闭环复增益 $\mathbf{A}_v(j\omega)$ 与稳态输出电压 $v_o(t)$。

#### ① 公理溯源
工作在线性负反馈区的理想运放满足相量域虚断（$\mathbf{I}_- = \mathbf{I}_+ = 0$）与虚短（$\mathbf{V}_- = \mathbf{V}_+$）。因为同相端接地（$\mathbf{V}_+ = 0$），故反相端构成虚地 $\mathbf{V}_- = 0$。对反相输入节点列 KCL 即得输入电流等于反馈电流。

#### ② 纯符号通式
输入阻抗 $\mathbf{Z}_1 = R_1$，反馈复阻抗为电阻 $R_f$ 与电容 $\mathbf{Z}_{C_f} = \frac{1}{j\omega C_f}$ 并联：
$$\mathbf{Z}_f = R_f \parallel \frac{1}{j\omega C_f} = \frac{R_f \cdot \frac{1}{j\omega C_f}}{R_f + \frac{1}{j\omega C_f}} = \frac{R_f}{1 + j\omega R_f C_f}$$
对虚地节点 $\mathbf{V}_- = 0$ 列 KCL：
$$\frac{\mathbf{V}_i - 0}{\mathbf{Z}_1} + \frac{\mathbf{V}_o - 0}{\mathbf{Z}_f} = 0 \implies \mathbf{A}_v(j\omega) = \frac{\mathbf{V}_o}{\mathbf{V}_i} = -\frac{\mathbf{Z}_f}{\mathbf{Z}_1} = -\frac{R_f / R_1}{1 + j\omega R_f C_f}$$
$$\mathbf{V}_o = \mathbf{A}_v(j\omega)\,\mathbf{V}_i$$

#### ③ 代入数值逐步化简
1. **计算无量纲频率因子 $\omega R_f C_f$ 与反馈复阻抗 $\mathbf{Z}_f$**：
   $$\omega R_f C_f = (1000\text{ rad/s}) \times (50 \times 10^3\ \Omega) \times (20 \times 10^{-9}\text{ F}) = 1.00$$
   $$\mathbf{Z}_{C_f} = \frac{1}{j(1000)(20 \times 10^{-9})} = -j50\text{ k}\Omega$$
   $$\mathbf{Z}_f = \frac{50\text{ k}\Omega}{1 + j1} = 25 - j25\text{ k}\Omega \approx 35.36\angle -45^\circ\text{ k}\Omega$$
2. **计算复增益 $\mathbf{A}_v(j1000)$**：
   $$\mathbf{A}_v = -\frac{50\text{ k}\Omega / 10\text{ k}\Omega}{1 + j1} = -\frac{5}{1 + j1} = -2.5 + j2.5 = \frac{5}{\sqrt{2}}\angle 135^\circ \approx 3.536\angle 135.00^\circ$$
   （注意：直流增益幅值为 $5$（$13.98\text{ dB}$），而在 $\omega = 1000\text{ rad/s}$ 时幅值恰好跌到 $5/\sqrt{2} \approx 3.536$（$10.97\text{ dB}$），正好下降了 **$-3.01\text{ dB}$**！这就是 `W5-L9` 里大名鼎鼎的**$-3\text{ dB}$ 截止角频率 $\omega_c = \frac{1}{R_f C_f}$**！）
3. **计算稳态输出相量 $\mathbf{V}_o$ 并还原回时域**：
   $$\mathbf{V}_o = \mathbf{A}_v \mathbf{V}_i = (3.536\angle 135^\circ)(2\angle 0^\circ) \approx 7.07\angle 135^\circ\text{ V}$$
   $$v_o(t) = 7.07\cos(1000t + 135^\circ)\text{ V}$$
