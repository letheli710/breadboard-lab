# W4-L6：二阶电路初值与终值确定（$t=0^-, 0^+, \infty$ 三时刻等效替换法）

> **教授开场白**：欢迎回到 Breadboard Lab。上一阶段我们用“三要素法”轻松拿下了含单个储能元件的一阶 RC/RL 电路；今天起，我们正式踏入 **Alexander, Sadiku & Fredette《电路基础》（2026 版）第 8 章——二阶电路（Second-Order Circuits）**。很多同学一见到 RLC 串联或并联电路就急着列二阶微分方程，结果解到最后卡在“待定常数 $A_1, A_2$ 算不出来”或者“符号全反”。请记住我一句话：**二阶电路的胜负，80% 在列微分方程之前就已经决定了——它取决于你能不能把 $t=0^-$、$t=0^+$、$t=\infty$ 这三张快照拍得滴水不漏。** 这节课是纯方法论课，左侧舞台为你准备了三层 2D 交互原理图，我们一幕一幕把这套“三时刻等效替换法”刻进肌肉记忆。

---

## 第 1 幕：为什么二阶电路必须求“导数初值”？——从两个待定常数与能量守恒出发

### 1.1 教授讲授：一阶与二阶的根本鸿沟

在一阶电路（只有一个独立电容或电感）中，电路方程是一阶常微分方程，通解只有一个待定常数 $A$，因此只要知道一个初值 $x(0^+)$ 和一个终值 $x(\infty)$，整个时间波形就被唯一锁死。

然而，当电路中同时存在**两个独立储能元件**（例如一个电感 $L$ 和一个电容 $C$）时，电路的控制方程升阶为二阶线性常微分方程：

$$\frac{d^2 x(t)}{dt^2} + 2\alpha \frac{dx(t)}{dt} + \omega_0^2 x(t) = f_{\text{dc}}$$

高等数学告诉我们：一个二阶微分方程的通解必然包含**两个独立的待定常数 $A_1$ 和 $A_2$**（例如过阻尼时的 $x(t) = x(\infty) + A_1 e^{s_1 t} + A_2 e^{s_2 t}$）。要解出两个未知数，必须提供**两个在 $t=0^+$ 时刻的独立初始条件**：

1. **状态变量本身的初值**：$v_C(0^+)$ 与 $i_L(0^+)$；
2. **状态变量一阶导数的初值**：$\left.\dfrac{dv_C}{dt}\right|_{t=0^+}$ 与 $\left.\dfrac{di_L}{dt}\right|_{t=0^+}$。

可是，导数 $\frac{dv_C(0^+)}{dt}$ 和 $\frac{di_L(0^+)}{dt}$ 并不能直接拿万用表去测，我们怎么从电路图里把它算出来？答案就藏在 `W4-L1` 与 `W4-L2` 学过的元件本构关系（Element Constitutive Equations）里：

$$\frac{dv_C(0^+)}{dt} = \frac{i_C(0^+)}{C}, \qquad \frac{di_L(0^+)}{dt} = \frac{v_L(0^+)}{L}$$

请盯紧这两个等式！它们把“看不见的微积分导数”，精准翻译成了“$t=0^+$ 这一瞬间的普通电流 $i_C(0^+)$ 和普通电压 $v_L(0^+)$”。

### 1.2 核心物理边界：谁绝对不能突变？谁可以瞬间跃变？

这是初学者踩坑最多的地方。在有限功率（不含冲激电源）的实际电路中：

| 变量类别 | 物理量 | 跨 $t=0$ 开关瞬间是否连续？ | 物理根源 |
| :--- | :--- | :--- | :--- |
| **状态守恒变量（不可跃变）** | 电容电压 $v_C(t)$ | **严格连续**：$v_C(0^+) = v_C(0^-)$ | 电场储能 $w_C = \frac{1}{2} C v_C^2$ 不能在零时间内突变，否则功率 $p_C = \frac{dw_C}{dt} \to \infty$ |
| **状态守恒变量（不可跃变）** | 电感电流 $i_L(t)$ | **严格连续**：$i_L(0^+) = i_L(0^-)$ | 磁场储能 $w_L = \frac{1}{2} L i_L^2$ 不能在零时间内突变，否则功率 $p_L = \frac{dw_L}{dt} \to \infty$ |
| **非状态变量（允许跃变！）** | 电容电流 $i_C(t)$ | **允许突变**：通常 $i_C(0^+) \neq i_C(0^-)$ | 仅改变电容电压的变化率 $\frac{dv_C}{dt}$，不违背能量连续性 |
| **非状态变量（允许跃变！）** | 电感电压 $v_L(t)$ | **允许突变**：通常 $v_L(0^+) \neq v_L(0^-)$ | 仅改变电感电流的变化率 $\frac{di_L}{dt}$，不违背能量连续性 |

> **教授红牌警告**：在 $t=0^-$ 直流稳态下，确实有 $i_C(0^-) = 0$ 且 $v_L(0^-) = 0$；在 $t=\infty$ 新稳态下，也确实有 $\frac{dv_C(\infty)}{dt} = 0$ 且 $\frac{di_L(\infty)}{dt} = 0$。**但绝不能把这两个“零”搬到 $t=0^+$！** 开关动作的瞬间，电容电流 $i_C(0^+)$ 和电感电压 $v_L(0^+)$ 往往会从 $0$ 瞬间跳变到一个巨大的非零值，从而推动整个二阶电路开启充放电振荡！

## 第 2 幕：三时刻拍照法总览——$t=0^-$、$t=0^+$、$t=\infty$ 三联等效电路对比

### 2.1 教授讲授：把动态电路拆成三张纯电阻直流快照

请把目光投向左侧舞台的三个切换标签：`01 t=0⁻ 稳态拍照`、`02 t=0⁺ 冻结替换台`、`03 t=∞ 新稳态拍照`。无论二阶 RLC 电路画得多复杂，只要严格执行以下三步等效替换，任何微积分难题都会瞬间退化成你在 `W2-L1` 就已经滚瓜烂熟的**纯电阻直流电路分析**：

1. **第一张快照：$t = 0^-$ 稳态电路（开关尚未动作）**
   - **等效规则**：直流稳态下，电容电压不再变化 $\Rightarrow i_C(0^-) = 0$，**电容替换成开路（Open Circuit）**；电感电流不再变化 $\Rightarrow v_L(0^-) = 0$，**电感替换成短路（Short Circuit）**。
   - **唯一任务**：只求两个守恒量——电容两端开路电压 $v_C(0^-)$、电感支路短路电流 $i_L(0^-)$。求出后立刻根据能量守恒写下：
     $$v_C(0^+) = v_C(0^-), \qquad i_L(0^+) = i_L(0^-)$$
   - **顺带提醒**：标清参考方向！电容电流 $i_C$ 与电容电压 $v_C$、电感电压 $v_L$ 与电感电流 $i_L$ **必须满足无源符号约定（Passive Sign Convention）**——即电流从元件的“$+$”端流入、“$-$”端流出。

2. **第二张快照：$t = 0^+$ 冻结瞬间电路（开关已动作！核心替换台）**
   - **物理原理**：在 $t=0^+$ 这一冻结瞬间，电容两端电压被强行钉死在 $v_C(0^+)$，不管流过它的电流是多少，它的端电压此刻就是 $v_C(0^+)$——这在电路定义上就是一个**数值等于 $v_C(0^+)$ 的独立直流电压源**！同理，电感支路电流被强行钉死在 $i_L(0^+)$，不管它两端电压是多少，流过它的电流此刻就是 $i_L(0^+)$——这在电路定义上就是一个**数值等于 $i_L(0^+)$ 的独立直流电流源**！
   - **等效规则**：
     - 画出**开关动作后**的拓扑；
     - **电容 $\longrightarrow$ 独立电压源 $v_C(0^+)$**（极性与 $v_C$ 参考极性完全一致）；
     - **电感 $\longrightarrow$ 独立电流源 $i_L(0^+)$**（箭头方向与 $i_L$ 参考方向完全一致）。
   - **核心任务**：用普通直流电路方法（KCL、KVL、节点分析法）算出流过该替换电压源的电流 $i_C(0^+)$（从“$+$”端流入）以及该替换电流源两端的电压 $v_L(0^+)$（电流流入端为“$+$”），随后立刻除以 $C$ 和 $L$：
     $$\left.\frac{dv_C}{dt}\right|_{t=0^+} = \frac{i_C(0^+)}{C}, \qquad \left.\frac{di_L}{dt}\right|_{t=0^+} = \frac{v_L(0^+)}{L}$$

3. **第三张快照：$t = \infty$ 新稳态电路（开关保持在新位置）**
   - **等效规则**：过渡过程全部衰减完毕，电路进入新的直流稳态。再次将**电容替换成开路、电感替换成短路**（注意：开关保持在 $t>0$ 的新位置！）。
   - **核心任务**：算出终值 $v_C(\infty)$ 和 $i_L(\infty)$。

### 3.3 三段式教授板书推导（严禁符号与数字混写）

#### ① 公理溯源
1. **直流稳态条件**（$t=0^-$ 与 $t=\infty$）：$\dfrac{dv_C}{dt} = 0 \implies i_C = 0$（电容开路）；$\dfrac{di_L}{dt} = 0 \implies v_L = 0$（电感短路）。
2. **能量连续性公理**（跨 $t=0$）：$i_L(0^+) = i_L(0^-)$，$v_C(0^+) = v_C(0^-)$。
3. **无源符号约定与本构方程**（$t=0^+$）：$v_L(0^+) = L\dfrac{di_L(0^+)}{dt}$，$i_C(0^+) = C\dfrac{dv_C(0^+)}{dt}$，并配合 KVL、KCL 求解纯电阻等效替换电路。

#### ② 纯符号通式（全程不代入任何具体数值）
- **快照 1（$t = 0^-$，接 $V_1$）**：$R_1$ 与 $R_2$ 串联，$C$ 开路并联在 $R_2$ 两端：
  $$i_L(0^+) = i_L(0^-) = \frac{V_1}{R_1 + R_2}, \qquad v_C(0^+) = v_C(0^-) = \frac{R_2}{R_1 + R_2} V_1$$
- **快照 2（$t = 0^+$，切至 $V_2$，用 $i_L(0^+)$ 电流源与 $v_C(0^+)$ 电压源替换）**：
  - 对左侧主回路列 KVL：
    $$V_2 - R_1 i_L(0^+) - v_L(0^+) - v_C(0^+) = 0 \implies v_L(0^+) = V_2 - R_1 i_L(0^+) - v_C(0^+)$$
    将 $R_1 i_L(0^+) + v_C(0^+) = V_1$ 代入得简洁纯符号式：
    $$v_L(0^+) = V_2 - V_1 \implies \left.\frac{di_L}{dt}\right|_{t=0^+} = \frac{v_L(0^+)}{L} = \frac{V_2 - V_1}{L}$$
  - 对右侧并联节点列 KCL：
    $$i_L(0^+) = \frac{v_C(0^+)}{R_2} + i_C(0^+) \implies i_C(0^+) = i_L(0^+) - \frac{v_C(0^+)}{R_2} = 0 \implies \left.\frac{dv_C}{dt}\right|_{t=0^+} = \frac{i_C(0^+)}{C} = 0$$
- **快照 3（$t = \infty$，保持接 $V_2$）**：
  $$i_L(\infty) = \frac{V_2}{R_1 + R_2}, \qquad v_C(\infty) = \frac{R_2}{R_1 + R_2} V_2$$

#### ③ 代入数值逐步化简
将 $V_1 = 12\text{ V}$、$V_2 = 30\text{ V}$、$R_1 = 6\ \Omega$、$R_2 = 6\ \Omega$、$L = 0.5\text{ H}$、$C = 0.25\text{ F}$ 依次代入：

1. **状态初值**：
   $$i_L(0^+) = \frac{12}{6 + 6} = 1\text{ A}, \qquad v_C(0^+) = \frac{6}{6 + 6} \times 12 = 6\text{ V}$$
2. **导数初值**：
   $$v_L(0^+) = 30 - 6 \times 1 - 6 = 18\text{ V} \implies \left.\frac{di_L}{dt}\right|_{t=0^+} = \frac{18}{0.5} = 36\text{ A/s}$$
   $$i_C(0^+) = 1 - \frac{6}{6} = 0\text{ A} \implies \left.\frac{dv_C}{dt}\right|_{t=0^+} = \frac{0}{0.25} = 0\text{ V/s}$$
3. **新稳态终值**：
   $$i_L(\infty) = \frac{30}{6 + 6} = 2.5\text{ A}, \qquad v_C(\infty) = \frac{6}{6 + 6} \times 30 = 15\text{ V}$$

> **教授点评**：请留意这道题里的一个绝佳物理洞察！开关切到 $30\text{ V}$ 的瞬间，电感电压 $v_L$ 从 $0\text{ V}$ 猛然跃升到 $18\text{ V}$，因此电感电流立刻以 $36\text{ A/s}$ 的陡峭斜率往上冲；而电容电流 $i_C(0^+)$ **恰好算出来是 $0\text{ A}$**——原因不是“偷懒照抄 $i_C(0^-)=0$”，而是因为电感锁死了流入节点的电流 $1\text{ A}$，电容锁死了节点电压 $6\text{ V}$ 使 $R_2$ 分流仍是 $1\text{ A}$，两者相减才碰巧为零。下一幕的混合型双电源电路里，你会亲眼看到 $i_C(0^+)$ 和 $v_L(0^+)$ **双双剧烈跃变**！

### 4.3 三段式教授板书推导（严禁符号与数字混写）

#### ① 公理溯源
1. **直流稳态替换**（$t=0^-$ 与 $t=\infty$）：$C \to$ 开路，$L \to$ 短路。
2. **能量守恒**（$t=0^- \to 0^+$）：$i_L(0^+) = i_L(0^-)$，$v_C(0^+) = v_C(0^-)$。
3. **冻结替换与节点分析法**（`W2-L1`）：在 $t=0^+$，将 $C$ 换为电压源 $v_C(0^+)$（从而节点 $B$ 电位直接钳位为 $v_B(0^+) = v_C(0^+)$），将 $L$ 换为电流源 $i_L(0^+)$；对节点 $A$、$B$ 分别列 KCL 方程，再利用本构关系求导数初值。

#### ② 纯符号通式（全程不代入任何具体数值）
- **快照 1（$t = 0^-$，$S$ 断开，左右解耦）**：
  $$i_L(0^+) = i_L(0^-) = \frac{V_s}{R_1 + R_2}, \qquad v_C(0^+) = v_C(0^-) = I_s R_4$$
- **快照 2（$t = 0^+$，$S$ 闭合，$v_B(0^+) = v_C(0^+)$）**：
  - 对节点 $A$ 列 KCL（流出为正）：
    $$\frac{v_A(0^+) - V_s}{R_1} + i_L(0^+) + \frac{v_A(0^+) - v_C(0^+)}{R_3} = 0$$
    解出节点 $A$ 的瞬时电位：
    $$v_A(0^+) = \frac{\dfrac{V_s}{R_1} + \dfrac{v_C(0^+)}{R_3} - i_L(0^+)}{\dfrac{1}{R_1} + \dfrac{1}{R_3}}$$
  - 由 $R_2$ 与电感串联支路的 KVL 求电感端电压 $v_L(0^+)$ 及电流变化率：
    $$v_L(0^+) = v_A(0^+) - R_2 i_L(0^+), \qquad \left.\frac{di_L}{dt}\right|_{t=0^+} = \frac{v_L(0^+)}{L}$$
  - 对节点 $B$ 列 KCL（流入等于流出）求电容电流 $i_C(0^+)$ 及电压变化率：
    $$i_C(0^+) = I_s - \frac{v_C(0^+)}{R_4} + \frac{v_A(0^+) - v_C(0^+)}{R_3}, \qquad \left.\frac{dv_C}{dt}\right|_{t=0^+} = \frac{i_C(0^+)}{C}$$
- **快照 3（$t = \infty$，$S$ 闭合，$L$ 短路，$C$ 开路）**：
  对节点 $A$ 与节点 $B$ 联立两阶节点电压方程：
  $$\begin{cases} \left(\dfrac{1}{R_1} + \dfrac{1}{R_2} + \dfrac{1}{R_3}\right) v_A(\infty) - \dfrac{1}{R_3} v_B(\infty) = \dfrac{V_s}{R_1} \\[10pt] -\dfrac{1}{R_3} v_A(\infty) + \left(\dfrac{1}{R_3} + \dfrac{1}{R_4}\right) v_B(\infty) = I_s \end{cases}$$
  解出 $v_A(\infty)$ 与 $v_B(\infty)$ 后即得：
  $$i_L(\infty) = \frac{v_A(\infty)}{R_2}, \qquad v_C(\infty) = v_B(\infty)$$

#### ③ 代入数值逐步化简
代入 $V_s = 24\text{ V}$、$I_s = 6\text{ A}$、$R_1 = 4\ \Omega$、$R_2 = 4\ \Omega$、$R_3 = 4\ \Omega$、$R_4 = 6\ \Omega$、$L = 0.5\text{ H}$、$C = 0.25\text{ F}$：

1. **状态初值（$t=0^- \to 0^+$）**：
   $$i_L(0^+) = \frac{24}{4 + 4} = 3\text{ A}, \qquad v_C(0^+) = 6 \times 6 = 36\text{ V}$$
2. **导数初值（$t=0^+$ 冻结替换台）**：
   - 求节点 $A$ 电位：
     $$v_A(0^+) = \frac{\dfrac{24}{4} + \dfrac{36}{4} - 3}{\dfrac{1}{4} + \dfrac{1}{4}} = \frac{6 + 9 - 3}{0.5} = \frac{12}{0.5} = 24\text{ V}$$
   - 求电感电压与电感电流导数：
     $$v_L(0^+) = 24 - 4 \times 3 = 12\text{ V} \implies \left.\frac{di_L}{dt}\right|_{t=0^+} = \frac{12}{0.5} = +24\text{ A/s}$$
   - 求电容电流与电容电压导数：
     $$i_C(0^+) = 6 - \frac{36}{6} + \frac{24 - 36}{4} = 6 - 6 - 3 = -3\text{ A} \implies \left.\frac{dv_C}{dt}\right|_{t=0^+} = \frac{-3}{0.25} = -12\text{ V/s}$$
3. **新稳态终值（$t=\infty$）**：
   - 联立节点方程（两边同乘 $12$ 消去分母）：
     $$\begin{cases} 9 v_A(\infty) - 3 v_B(\infty) = 72 \\ -3 v_A(\infty) + 5 v_B(\infty) = 72 \end{cases} \implies \begin{cases} 3 v_A(\infty) - v_B(\infty) = 24 \\ -3 v_A(\infty) + 5 v_B(\infty) = 72 \end{cases}$$
   - 两式相加得 $4 v_B(\infty) = 96 \implies v_B(\infty) = 24\text{ V}$，代回得 $v_A(\infty) = \dfrac{24 + 24}{3} = 16\text{ V}$。
   - 因此终值为：
     $$i_L(\infty) = \frac{16}{4} = 4\text{ A}, \qquad v_C(\infty) = 24\text{ V}$$
