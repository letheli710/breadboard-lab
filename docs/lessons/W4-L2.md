# W4-L2：电感的物理结构、电磁感应伏安关系与磁场储能

> **教授开场白**：欢迎回到 Breadboard Lab。上一讲（W4-L1）我们认识了**电容**——它是用“电场”存能量的器件，最讨厌**电压**发生突变。今天，我们将迎来无源电路三大基本元件的最后一位主角，也是电容在电磁世界里的完美镜像——**电感（Inductor）**。如果说电容像一只蓄水池或一根弹簧，那么电感就像一块沉重的高速旋转飞轮：一旦电流转起来，你休想在一瞬间把它按停。准备好了吗？让我们从剥开一颗电感的外壳开始。

## 第 1 幕：从“飞轮惯性”到绕线螺线管 — 电感的物理结构与磁通剥壳

> **左侧舞台联动**：切换至 `01 3D 色环/绕线电感封装与面包板插法` 与 `02 3D 线圈磁通透视与右手定则`，旋转观察轴向色环电感（淡绿底色、略微鼓腹）与工字绕线电感的内部漆包线匝数 $N$ 及铁氧体磁芯。

### 1.1 物理直觉：为什么电流也有“惯性”？（Boylestad 飞轮类比）

在力学里，质量越大的飞轮，启动它旋转越费劲；可一旦它高速转起来，想让它立刻刹停同样需要极大的制动力矩。电感在电路中扮演的正是**电气飞轮（Electrical Flywheel）**的角色：

- **电流 $i$ 对应飞轮转速 $\omega$**：只要电流流过螺线管线圈，根据奥斯特电磁效应与**右手螺旋定则**（四指顺着线圈电流方向弯曲，大拇指指向线圈内部磁场 $\vec{B}$ 方向），线圈内部就会建立起磁场。
- **电感量 $L$ 对应转动惯量 $J$**：电感量越大，建立相同电流所需的磁场能量越多，它反抗电流变化的“脾气”就越大。
- **工程防呆提醒（面包板实操）**：在实验室里，新手最容易把 **0410 轴向色环电感** 误当成 1/4 W 碳膜电阻！两者都有四道色环，但色环电感的底色通常是**淡绿色或湖蓝色**，两端呈轻微哑铃状鼓起，且读数单位是 **微亨（$\mu\text{H}$）** 而非欧姆。此外，绕线电感有两大隐形参数不可忽视：一是漆包线本身的**直流寄生电阻 $R_{\text{DCR}}$**，二是磁芯的**饱和电流 $I_{\text{sat}}$**——当电流超过 $I_{\text{sat}}$ 时，铁氧体磁畴全部对齐饱和，磁导率 $\mu_r$ 暴跌，电感瞬间退化成一根发热的普通导线。

### 1.3 教授三段式板书推导：螺线管电感量公式与空心/磁芯对比

**例题 1.1**：绕制一个均匀长直螺线管，匝数 $N = 200$ 匝，线圈半径 $r = 5\text{ mm}$，线圈长度 $\ell = 40\text{ mm}$。分别计算：（a）空心状态（$\mu_r = 1$）下的电感量 $L_{\text{air}}$；（b）插入相对磁导率 $\mu_r = 200$ 的铁氧体磁芯后的电感量 $L_{\text{ferrite}}$。

#### ① 公理溯源
由安培环路定律（Ampère's Law），长直螺线管内部均匀磁感应强度 $B$ 与电流 $i$ 满足：
$$B = \mu \frac{N i}{\ell}, \qquad \mu = \mu_0 \mu_r$$
穿过单匝线圈横截面积 $A$ 的磁通量为 $\Phi = B A$，则 $N$ 匝线圈的总磁链（Flux Linkage）为 $\lambda = N \Phi$。根据电感的定义 $\lambda = L i$，即可消去电流 $i$ 得到仅由几何尺寸与磁芯材料决定的电感量。

#### ② 纯符号通式
$$\lambda = N \Phi = N (B A) = N \left( \mu_0 \mu_r \frac{N i}{\ell} \right) A = \frac{N^2 \mu_0 \mu_r A}{\ell} \cdot i$$
因此，螺线管电感量的纯符号通式为：
$$L = \frac{N^2 \mu_0 \mu_r A}{\ell} = \frac{N^2 \mu_0 \mu_r (\pi r^2)}{\ell}$$

#### ③ 代入数值逐步化简
已知真空磁导率 $\mu_0 = 4\pi \times 10^{-7}\text{ H/m}$，$N = 200$，$r = 5 \times 10^{-3}\text{ m}$，$\ell = 4 \times 10^{-2}\text{ m}$：

- **步骤 1（计算横截面积 $A$）**：
  $$A = \pi r^2 = \pi \times (5 \times 10^{-3})^2 = 25\pi \times 10^{-6}\text{ m}^2 \approx 7.854 \times 10^{-5}\text{ m}^2$$

- **步骤 2（空心电感量 $\mu_r = 1$）**：
  $$L_{\text{air}} = \frac{200^2 \times (4\pi \times 10^{-7}) \times 1 \times (25\pi \times 10^{-6})}{4 \times 10^{-2}} = \frac{4 \times 10^4 \times 100\pi^2 \times 10^{-13}}{4 \times 10^{-2}} = 10^{-5}\pi^2\text{ H} \approx 98.70\text{ }\mu\text{H}$$

- **步骤 3（插入铁氧体磁芯 $\mu_r = 200$）**：
  $$L_{\text{ferrite}} = \mu_r \cdot L_{\text{air}} = 200 \times 98.70\text{ }\mu\text{H} = 19\,739.2\text{ }\mu\text{H} \approx 19.74\text{ mH}$$

> **教授点评**：看到了吗？同一副线圈，插进一根铁氧体磁芯，电感量直接放大 200 倍，从微亨级跃升到接近 $20\text{ mH}$！同时请牢记 $L \propto N^2$：匝数翻倍，电感量不是翻倍，而是变为 **4 倍**——因为匝数翻倍既让磁场 $B$ 翻倍，又让切割磁通的线圈数翻倍。

## 第 2 幕：电磁感应的微积分伏安关系 — 从电流斜率到电压波形

> **左侧舞台联动**：切换至 `03 2D 原理图与 i(t)↔v(t) 波形及反电动势续流演示`，拖动时间轴观察电流上升段、恒流平台段与急速下降段对应的感应电压极性。

### 2.1 法拉第电磁感应定律与被动参考方向

在电路分析中，我们采用**被动参考方向（Passive Sign Convention）**：电流 $i(t)$ 从电感电压 $v(t)$ 的正极（$+$）流入、负极（$-$）流出。根据法拉第电磁感应定律 $v = \frac{d\lambda}{dt}$，结合线性电感 $\lambda = L i$，立得电感最核心的**微分伏安关系**：

$$v(t) = L \frac{di(t)}{dt}$$

将两端从初始时刻 $t_0$ 积分到当前时刻 $t$，得到电感的**积分记忆形式**：

$$i(t) = \frac{1}{L} \int_{t_0}^{t} v(\tau)\,d\tau + i(t_0)$$

这两条公式背后藏着两条决定整个电路分析命运的铁律：
1. **直流稳态等效为短路**：若流过电感的电流是恒定直流（$i(t) = I_{\text{DC}}$），则 $\frac{di}{dt} = 0 \implies v(t) = 0\text{ V}$。两端压降为零却能通过任意恒定电流——这正是**理想导线（短路）**的定义！
2. **电感电流不能发生瞬时突变**：若电流在 $\Delta t \to 0$ 内跳变，则 $\frac{di}{dt} \to \infty$，需要无穷大的端电压，这在物理上不可能。因此，在任何有限电压激励下，电感电流必须连续：$i_L(t_0^+) = i_L(t_0^-)$。

### 2.3 教授三段式板书推导：微分求电压与积分求电流

#### 例题 2.1（微分求分段电压）：
已知电感 $L = 10\text{ mH}$，流过它的分段线性电流 $i(t)$ 如上图所示：在 $0 \le t < 2\text{ ms}$ 内由 $0$ 线性升至 $40\text{ mA}$；在 $2\text{ ms} \le t < 5\text{ ms}$ 保持 $40\text{ mA}$ 不变；在 $5\text{ ms} \le t < 6\text{ ms}$ 内由 $40\text{ mA}$ 线性降至 $0$。求各时间段的感应电压 $v(t)$。

- **① 公理溯源**：在被动参考方向下，理想电感端电压与电流变化率成正比，满足 $v(t) = L \frac{di(t)}{dt}$。
- **② 纯符号通式**：对于任意线性段 $[t_a, t_b]$，若电流由 $I_a$ 线性变至 $I_b$，则：
  $$v(t) = L \frac{I_b - I_a}{t_b - t_a}$$
- **③ 代入数值逐步化简**（$L = 10 \times 10^{-3}\text{ H}$）：
  - **区间 1（$0 < t < 2\text{ ms}$）**：
    $$v_1 = (10 \times 10^{-3}) \times \frac{40 \times 10^{-3} - 0}{2 \times 10^{-3} - 0} = 10^{-2} \times 20 = +0.2\text{ V} = +200\text{ mV}$$
  - **区间 2（$2\text{ ms} < t < 5\text{ ms}$）**：
    $$v_2 = (10 \times 10^{-3}) \times \frac{40 \times 10^{-3} - 40 \times 10^{-3}}{3 \times 10^{-3}} = 0\text{ V}$$
  - **区间 3（$5\text{ ms} < t < 6\text{ ms}$）**：
    $$v_3 = (10 \times 10^{-3}) \times \frac{0 - 40 \times 10^{-3}}{1 \times 10^{-3}} = 10^{-2} \times (-40) = -0.4\text{ V} = -400\text{ mV}$$

> **关键洞察**：注意看下盘图形！电流 $i(t)$ 是连续的，但电压 $v(t)$ 却可以在 $t = 0, 2, 5, 6\text{ ms}$ 处发生**垂直阶跃跳变**。并且，电感电压的正负面积恰好抵消：$(+200\text{ mV})(2\text{ ms}) + (-400\text{ mV})(1\text{ ms}) = 0$，这保证了 $t = 6\text{ ms}$ 时电流精准回到 $0$！

#### 例题 2.2（积分求衰减电压下的电流）：
若一个 $L = 20\text{ mH}$ 的电感初始电流 $i(0) = 100\text{ mA}$，在 $t \ge 0$ 时两端施加衰减电压 $v(t) = 6e^{-500t}\text{ V}$。求 $i(t)$ 的解析式、$t = 2\text{ ms}$ 时的电流值以及 $t \to \infty$ 时的稳态电流与最终磁场储能。

- **① 公理溯源**：由 $v(t) = L\frac{di}{dt}$ 两端积分，得电感的积分记忆伏安关系。
- **② 纯符号通式**：对于指数电压 $v(t) = V_0 e^{-\alpha t}$：
  $$i(t) = i(0) + \frac{1}{L}\int_{0}^{t} V_0 e^{-\alpha \tau}\,d\tau = i(0) + \frac{V_0}{\alpha L}\left(1 - e^{-\alpha t}\right)$$
- **③ 代入数值逐步化简**（$L = 0.02\text{ H}, V_0 = 6\text{ V}, \alpha = 500\text{ s}^{-1}, i(0) = 0.1\text{ A}$）：
  $$\frac{V_0}{\alpha L} = \frac{6}{500 \times 0.02} = \frac{6}{10} = 0.6\text{ A}$$
  $$i(t) = 0.1 + 0.6\left(1 - e^{-500t}\right) = 0.7 - 0.6e^{-500t}\text{ A} \quad (t \ge 0)$$
  - 当 $t = 2\text{ ms} = 0.002\text{ s}$ 时：$500t = 1$，$i(2\text{ ms}) = 0.7 - 0.6 e^{-1} \approx 0.7 - 0.2207 = 0.4793\text{ A}$。
  - 当 $t \to \infty$ 时：$e^{-500t} \to 0$，故 $i(\infty) = 0.7\text{ A}$，最终磁场储能 $w(\infty) = \frac{1}{2} L i^2(\infty) = \frac{1}{2}(0.02)(0.7)^2 = 4.90\text{ mJ}$。

## 第 3 幕：磁场储能、水锤效应与续流二极管保护

> **左侧舞台联动**：保持在 `03 2D 原理图与 i(t)↔v(t) 波形及反电动势续流演示`，点击右侧“断开开关”按钮，对比未加保护时的 $-2000\text{ V}$ 电弧击穿与并联 1N4148 续流二极管后的安全续流。

### 3.1 磁场储能公式推导（三段式板书）

#### ① 公理溯源
在被动参考方向下，电感吸收的瞬时电功率为 $p(t) = v(t)i(t)$。理想电感不消耗热能，所有吸收的能量全部转化为线圈周围空间及磁芯中的**磁场能** $w_L(t) = \int_{-\infty}^{t} p(\tau)\,d\tau$。

#### ② 纯符号通式
将 $v = L\frac{di}{dt}$ 代入功率积分（设初始电流 $i(-\infty) = 0$）：
$$w_L(t) = \int_{-\infty}^{t} \left(L\frac{di}{d\tau}\right) i\,d\tau = L \int_{0}^{i(t)} i'\,di' = \frac{1}{2} L i^2(t)$$

#### ③ 代入数值逐步化简
以例题 2.1 中 $L = 10\text{ mH}$ 电感在恒流平台段（$i = 40\text{ mA}$）为例，其峰值磁场储能为：
$$w_{\max} = \frac{1}{2} (10 \times 10^{-3}) (40 \times 10^{-3})^2 = 5 \times 10^{-3} \times 1.6 \times 10^{-3} = 8.00 \times 10^{-6}\text{ J} = 8.00\text{ }\mu\text{J}$$

### 3.2 水锤效应与断电反电动势（Inductive Kickback）

Boylestad 在第 11 章用了一个极佳的工程比喻：**水锤效应（Water Hammer）**。当消防水龙带里高速奔涌的水流被瞬间砸死阀门时，水流巨大的动量无处释放，会在阀门处撞出极高的瞬间水压，甚至震裂钢管。

在电路里，如果你用一个开关强行切断正在流过 $I_0 = 200\text{ mA}$ 电流的 $L = 10\text{ mH}$ 继电器线圈，假设触点在 $\Delta t = 1\text{ }\mu\text{s}$ 内强行断开：
$$v_L = L \frac{\Delta i}{\Delta t} = (10 \times 10^{-3}) \times \frac{0 - 0.2}{1 \times 10^{-6}} = -2000\text{ V}$$
**负两千伏！** 电感为了维持电流继续向下流动，会瞬间翻转自身极性（下正上负），在开关两端叠加出超过 $2000\text{ V}$ 的高压尖峰，直接击穿驱动它的 MOSFET 或在面包板机械开关触点间拉出蓝白色电弧。

**工程救星——续流二极管（Flyback Diode / Freewheeling Diode）**：
解决方法极其优雅：在电感两端**反向并联**一只二极管（阴极接正电源，阳极接开关端）。
- **开关闭合正常供电时**：二极管承受反向电压，处于截止状态，完全不干涉电路。
- **开关突然断开瞬间**：电感企图向下维持电流并产生负向反电动势，此时二极管立刻**正向导通**！它为电感里的 $200\text{ mA}$ 电流提供了一条闭合的“环形跑道”，把反向电压死死钳位在 $-V_D \approx -0.7\text{ V}$，让磁场储能 $\frac{1}{2}LI_0^2$ 平缓地消耗在二极管压降与线圈内阻 $R_{\text{DCR}}$ 上。

## 第 4 幕：电感的串并联等效与电容—电感完整对偶律

> **左侧舞台联动**：切换回 `01 3D 色环/绕线电感封装与面包板插法`，注意观察面包板上两颗相邻电感保持正交或适当间距以尽量避免磁通互感耦合（$M \approx 0$）。

### 4.1 串并联等效公式（与电阻完全同构）

当多个电感之间没有磁耦合（无互感）时，用 KVL 和 KCL 即可立证：
- **电感串联**（共用同一电流 $i$，电压相加）：
  $$v = v_1 + v_2 + \dots + v_n = (L_1 + L_2 + \dots + L_n)\frac{di}{dt} \implies L_{\text{eq,s}} = \sum_{k=1}^{n} L_k$$
- **电感并联**（共用同一电压 $v$，电流相加）：
  $$i = \sum_{k=1}^{n} \frac{1}{L_k}\int v\,dt \implies \frac{1}{L_{\text{eq,p}}} = \sum_{k=1}^{n} \frac{1}{L_k}$$
  对于两只电感并联：$L_{\text{eq,p}} = \frac{L_1 L_2}{L_1 + L_2}$。

> **防混淆记忆法**：**电感串并联像电阻（串加并倒），电容串并联反着来（并加串倒）**！

### 4.3 教授三段式板书推导：混联电感等效计算

- **① 公理溯源**：无互感电感串联满足 $L_{\text{eq,s}} = \sum L_k$，并联满足 $\frac{1}{L_{\text{eq,p}}} = \sum \frac{1}{L_k}$。
- **② 纯符号通式**：由拓扑结构，先串 $L_3, L_4$，再与 $L_2$ 并联，最后与 $L_1$ 串联：
  $$L_{\text{eq}} = L_1 + \frac{L_2 (L_3 + L_4)}{L_2 + (L_3 + L_4)}$$
- **③ 代入数值逐步化简**（$L_1 = 4\text{ mH}, L_2 = 6\text{ mH}, L_3 = 8\text{ mH}, L_4 = 4\text{ mH}$）：
  1. $L_{34} = L_3 + L_4 = 8 + 4 = 12\text{ mH}$
  2. $L_{234} = L_2 \parallel L_{34} = \frac{6 \times 12}{6 + 12} = \frac{72}{18} = 4\text{ mH}$
  3. $L_{\text{eq}} = L_1 + L_{234} = 4 + 4 = 8\text{ mH}$

### 5.1 直流稳态混合电路四步法

当一个包含电阻 $R$、电感 $L$ 与电容 $C$ 的电路在恒定直流电源下运行足够长时间达到**直流稳态（DC Steady State）**时，所有电压电流不再随时间变化（$\frac{dv}{dt} = 0, \frac{di}{dt} = 0$）：
1. **电容换开路**：把每个电容替换为断路，但务必保留两端标号以标注待求电压 $v_C$。
2. **电感换短路**：把每个电感替换为理想导线，并标出待求支路电流 $i_L$ 的方向。
3. **求解纯电阻直流网络**：利用欧姆定律、分压/分流或节点分析求 $v_C$ 与 $i_L$。**特别留意与开路电容串联的电阻**：该支路电流为零，电阻上压降也为零！
4. **代回计算磁电总储能**：$w_L = \frac{1}{2}Li_L^2$，$w_C = \frac{1}{2}Cv_C^2$，$w_{\text{total}} = w_L + w_C$。

### 5.3 教授三段式板书推导：含 $R, L, C$ 直流稳态例题完整求解

**例题 5.1**：在如上所示的面包板安全级电路中，$V_s = 9\text{ V}$，$R_1 = 100\text{ }\Omega$，$R_2 = 300\text{ }\Omega$，$R_3 = 150\text{ }\Omega$，$R_4 = 200\text{ }\Omega$，$L = 20\text{ mH}$，$C = 10\text{ }\mu\text{F}$。求直流稳态下的电感电流 $i_L$、电容电压 $v_C$、以及电路总储能 $w_{\text{total}}$。

#### ① 公理溯源
在直流稳态下，$\frac{di_L}{dt} = 0 \implies v_L = 0$（电感等效为短路）；$\frac{dv_C}{dt} = 0 \implies i_C = 0$（电容等效为开路）。由 KCL，$R_4$ 与电容 $C$ 串联，故 $i_{R4} = i_C = 0$，由欧姆定律 $v_{R4} = i_{R4} R_4 = 0$，因此电容电压直接等于节点 $A$ 对地电压 $v_C = v_A$。

#### ② 纯符号通式
$$R_{23} = \frac{R_2 R_3}{R_2 + R_3}, \qquad v_A = V_s \cdot \frac{R_{23}}{R_1 + R_{23}}$$
$$v_C = v_A, \qquad i_L = \frac{v_A}{R_3}$$
$$w_L = \frac{1}{2} L i_L^2, \qquad w_C = \frac{1}{2} C v_C^2, \qquad w_{\text{total}} = w_L + w_C$$

#### ③ 代入数值逐步化简
1. **并联支路等效电阻**：

   $$v_C = v_A = 9 \times \frac{100}{100 + 100} = 4.5\text{ V}$$
3. **总电流与电感电流 $i_L$**：
   $$I_s = \frac{9}{100 + 100} = 45\text{ mA}, \qquad i_L = \frac{4.5}{150} = 0.030\text{ A} = 30\text{ mA}$$
   （安全核验：$P_{R1} = (0.045)^2(100) = 0.2025\text{ W} < 0.25\text{ W}$，$P_{R2} = 0.0675\text{ W}$，$P_{R3} = 0.135\text{ W}$，$i_L = 30\text{ mA} \ll I_{\text{sat}}$，完全满足面包板安全规范！）

   $$w_L = \frac{1}{2} (20 \times 10^{-3}) (30 \times 10^{-3})^2 = 9.00 \times 10^{-6}\text{ J} = 9.00\text{ }\mu\text{J}$$
   $$w_C = \frac{1}{2} (10 \times 10^{-6}) (4.5)^2 = 101.25 \times 10^{-6}\text{ J} = 101.25\text{ }\mu\text{J}$$
   $$w_{\text{total}} = w_L + w_C = 9.00 + 101.25 = 110.25\text{ }\mu\text{J}$$
