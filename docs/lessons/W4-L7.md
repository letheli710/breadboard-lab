# W4-L7：无源串联/并联 RLC 自然响应（特征方程与三种阻尼状态）

> **教授开场白**：同学们好！欢迎回到 Breadboard Lab。在 **W4-L4** 里，我们见识了一阶 RC 和 RL 电路的“单调宿命”——无论你怎么改电阻和电容，一阶电路的能量只会像漏水的水桶一样乖乖地单调指数衰减，永远翻不起浪花。而在 **W4-L6** 中，我们已经练就了给二阶电路求“出发点” $x(0^+)$ 和“出发斜率” $\frac{dx}{dt}(0^+)$ 的硬功夫。
>
> 今天这一讲（对应 Sadiku《电路基础》2026 版 **Section 8.3 & 8.4**），我们要把电感 $L$ 和电容 $C$ 关进同一个无源笼子里，看看当磁场能量 $\frac{1}{2}Li^2$ 和电场能量 $\frac{1}{2}Cv^2$ 开始“互相倒腾”时，电阻 $R$ 这只“刹车手”如何通过一个小小的二次特征方程，把电路命运彻底划分为**过阻尼、临界阻尼、欠阻尼**三种截然不同的戏剧性结局。

### 1.2 三段式教授板书推导：标准二阶齐次方程与特征方程

#### ① 公理溯源（物理定律与元件 VCR）
- **无源串联 RLC（单回路共享电流 $i(t)$）**：沿回路顺时针列写 KVL，并代入电阻、电感、电容的伏安关系（采用关联参考方向）：
  $$v_R(t) + v_L(t) + v_C(t) = 0 \implies R i(t) + L\frac{di(t)}{dt} + \frac{1}{C}\int_{-\infty}^{t} i(\tau)\,d\tau = 0$$
- **无源并联 RLC（单节点共享电压 $v(t)$）**：对上节点列写 KCL，流出电流之和为零：
  $$i_R(t) + i_L(t) + i_C(t) = 0 \implies \frac{v(t)}{R} + \frac{1}{L}\int_{-\infty}^{t} v(\tau)\,d\tau + C\frac{dv(t)}{dt} = 0$$

#### ② 纯符号通式（消去积分并标准化）
对上述两式分别关于时间 $t$ 求一次导数以消去积分号，再分别除以最高阶导数的系数 $L$ 和 $C$：
- **串联 RLC**：
  $$\frac{d^2 i}{dt^2} + \frac{R}{L}\frac{di}{dt} + \frac{1}{LC} i = 0$$
- **并联 RLC**：
  $$\frac{d^2 v}{dt^2} + \frac{1}{RC}\frac{dv}{dt} + \frac{1}{LC} v = 0$$

> **教授点睛**：请注意！不论你是求串联里的 $i(t)$、$v_C(t)$ 还是并联里的 $v(t)$、$i_L(t)$，同一个线性电路里所有支路变量都共享**完全相同的齐次微分方程左端算子**！我们统一引入两个具有清晰物理意义的常数——**尼珀频率（阻尼系数）$\alpha$** 与 **无阻尼谐振角频率 $\omega_0$**：
$$\frac{d^2 x}{dt^2} + 2\alpha \frac{dx}{dt} + \omega_0^2 x = 0$$

将指数试探解 $x(t) = A e^{st}$（其中 $A \neq 0$）代入，消去公因子 $A e^{st}$，立即得到电路的“基因密码”——**特征方程（Characteristic Equation）**：
$$s^2 + 2\alpha s + \omega_0^2 = 0$$
用一元二次方程求根公式解出两个**自然频率（特征根 / 极点）**：
$$s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}$$

#### ③ 串联 vs. 并联核心参数醒目对照表

| 对比维度 | 无源串联 RLC（Section 8.3） | 无源并联 RLC（Section 8.4） | 物理直觉与防踩坑口诀 |
| :--- | :---: | :---: | :--- |
| **控制方程定律** | KVL（电压环路和为零） | KCL（电流节点和为零） | 串联看 $i(t)$，并联看 $v(t)$，完全对偶 |
| **谐振角频率 $\omega_0$** | $\omega_0 = \dfrac{1}{\sqrt{LC}}$ | $\omega_0 = \dfrac{1}{\sqrt{LC}}$ | **完全同式**！只由 $L$ 和 $C$ 的能量交换节拍决定 |
| **尼珀频率 $\alpha$** | $\alpha = \dfrac{R}{2L}$ | $\alpha = \dfrac{1}{2RC}$ | **串联正比于 $R$，并联反比于 $R$！** |
| **临界电阻 $R_{\text{crit}}$** | $R_{\text{crit}} = 2\sqrt{\dfrac{L}{C}}$ | $R_{\text{crit}} = \dfrac{1}{2}\sqrt{\dfrac{L}{C}}$ | 令 $\alpha = \omega_0$ 解出，注意系数是 $2$ 还是 $\frac{1}{2}$ |
| **电阻 $R$ 增大时的趋势** | $\alpha \uparrow \Rightarrow$ **阻尼增强**（趋向过阻尼） | $\alpha \downarrow \Rightarrow$ **阻尼减弱**（趋向欠阻尼） | 并联电阻越大，分流消耗功率 $P_R = v^2/R$ 越小！ |
| **无损极限（纯 LC 振荡）** | $R = 0$（电阻短路） | $R \to \infty$（电阻开路） | 把耗能元件彻底“请出局”的方式截然相反 |

## 第 2 幕：特征根判别式——三种阻尼形态的数学基因与同屏波形对比

### 2.1 教授导学：根号里的 $\alpha^2 - \omega_0^2$ 决定了电路的三种“性格”

盯着特征根公式 $s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}$ 看：根号内部 $\Delta = \alpha^2 - \omega_0^2$ 的正负号，直接把所有无源 RLC 电路分成了三大阵营。这里我们也可以顺带认识工程里常用的无量纲**阻尼比** $\zeta = \frac{\alpha}{\omega_0}$：

1. **过阻尼（Overdamped, $\alpha > \omega_0$ 或 $\zeta > 1$）**：
   - 根号为正，特征根为两个**不相等的负实数** $s_1, s_2$（记 $s_1$ 更靠近原点，$s_2$ 更远离原点）。
   - 通解形式：
     $$x(t) = A_1 e^{s_1 t} + A_2 e^{s_2 t}$$
   - **物理画像**：刹车踩太死！能量来不及在 $L$ 与 $C$ 之间反弹，就被 $R$ 消耗殆尽。虽然完全不振荡，但由于慢模态 $e^{s_1 t}$ 拖后腿，它回到零反而**很慢（有长拖尾）**。

2. **临界阻尼（Critically Damped, $\alpha = \omega_0$ 或 $\zeta = 1$）**：
   - 根号恰好为零，特征根为**二重负实根** $s_1 = s_2 = -\alpha$。
   - 通解形式（因为重根需要补一个线性独立项 $t e^{-\alpha t}$）：
     $$x(t) = (A_1 + A_2 t) e^{-\alpha t}$$
   - **物理画像**：黄金平衡点！在**绝对不产生振荡过冲**的前提下，以**最快速度**回归平衡态。汽车减震器、高档指针仪表、门闭门器的理想调校目标就是临界阻尼。

3. **欠阻尼（Underdamped, $\alpha < \omega_0$ 或 $\zeta < 1$）**：
   - 根号为负，引入**阻尼振荡角频率** $\omega_d = \sqrt{\omega_0^2 - \alpha^2}$，特征根为一对**共轭复根** $s_{1,2} = -\alpha \pm j\omega_d$。
   - 由欧拉公式 $e^{\pm j\omega_d t} = \cos\omega_d t \pm j\sin\omega_d t$ 化为实函数通解：
     $$x(t) = e^{-\alpha t}\left(B_1 \cos\omega_d t + B_2 \sin\omega_d t\right) = M e^{-\alpha t}\cos(\omega_d t - \phi)$$
     其中包络初始幅值 $M = \sqrt{B_1^2 + B_2^2}$，相位 $\phi = \operatorname{atan2}(B_2, B_1)$。
   - **物理画像**：刹车太轻！电容放电完毕时，电感里还蓄满磁场能量 $\frac{1}{2}Li^2$，于是电感强行把电容**反向充电**；反向充满后电容再反推电感……电场与磁场来回倒腾能量，每一轮被电阻 $R$ 抽走一部分“过路费”，形成被指数包络线 $\pm M e^{-\alpha t}$ 夹紧的**衰减正弦振荡（Ringing）**。

## 第 3 幕：复平面 $s$ 极点轨迹——一眼看穿“欠阻尼震荡、临界最快、过阻尼拖尾”的几何本质

### 3.1 教授导学：把特征根画在复平面上，规律会自己开口说话

请记住一条贯穿整个信号与系统、自动控制和模拟电路的黄金法则：**极点在复平面 $s = \sigma + j\omega$ 上的位置，就是时域波形的“基因地图”**：
- **纵坐标 $|\omega_d|$** 控制**振荡有多快**（只要离开实轴，波形就会振荡）；
- **横坐标 $-\sigma$（距虚轴的水平距离）** 控制**衰减有多快**（越往左，衰减越快；最靠近虚轴的那个极点称为**主导极点**，它决定了波形的拖尾有多长！）。

现在固定 $\omega_0 = 10\text{ rad/s}$，让阻尼系数 $\alpha$ 从 $0$ 一路增大到 $+\infty$，观察特征根 $s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}$ 的运动轨迹：
1. **无阻尼起点（$\alpha = 0$）**：两极点稳稳落在虚轴上的 $(0, \pm 10)$，距离虚轴为 $0$，不衰减、纯振荡。
2. **欠阻尼半圆（$0 < \alpha < \omega_0$）**：算一下极点到原点的距离：
   $$|s_{1,2}| = \sqrt{(-\alpha)^2 + (\pm\omega_d)^2} = \sqrt{\alpha^2 + (\omega_0^2 - \alpha^2)} = \omega_0 = 10$$
   太神奇了！所有欠阻尼极点都严格沿着**左半平面以原点为圆心、半径为 $\omega_0$ 的半圆**向左滑动！
3. **临界阻尼碰撞（$\alpha = \omega_0$）**：上下两个共轭极点终于在负实轴 $(-10, 0)$ 迎头相撞，形成二重实根！此时它离虚轴的水平距离达到所有“最慢极点”里的最大值 $\omega_0$——**这就是为什么临界阻尼能做到“无超调且衰减最快”的几何证明！**
4. **过阻尼分裂（$\alpha > \omega_0$）**：相撞后两极点分道扬镳：一个飞速冲向 $-\infty$（快模态 $s_2$，瞬间消失），**另一个却反向往原点 $0^-$ 退缩**（慢模态 $s_1 \approx -\frac{\omega_0^2}{2\alpha} \to 0^-$）。它离虚轴越来越近，拖垮了整个电路的回零速度！

### 4.2 三段式教授板书推导

#### ① 公理溯源
串联无源 RLC 回路满足 KVL 且电流 $i = C\frac{dv_C}{dt}$，将 $i$ 消去后，$v_C(t)$ 同样满足标准二阶齐次微分方程：
$$LC\frac{d^2 v_C}{dt^2} + RC\frac{dv_C}{dt} + v_C = 0 \implies \frac{d^2 v_C}{dt^2} + \frac{R}{L}\frac{dv_C}{dt} + \frac{1}{LC} v_C = 0$$
由 W4-L6 初值定理，电容电压与电感电流不可突变，故：
$$v_C(0^+) = v_C(0^-),\qquad \frac{dv_C}{dt}(0^+) = \frac{i(0^+)}{C}$$

#### ② 纯符号通式
先计算与电阻 $R$ 无关的固有谐振角频率和临界电阻，以及随 $R$ 变化的尼珀频率：
$$\omega_0 = \frac{1}{\sqrt{LC}},\qquad \alpha = \frac{R}{2L},\qquad R_{\text{crit}} = 2\sqrt{\frac{L}{C}}$$
待定系数由两个初值方程联立解出：
- **过阻尼（$\alpha > \omega_0$）**：$v_C(t) = A_1 e^{s_1 t} + A_2 e^{s_2 t}$，联立 $A_1 + A_2 = v_C(0^+)$ 与 $s_1 A_1 + s_2 A_2 = v_C'(0^+)$；
- **临界阻尼（$\alpha = \omega_0$）**：$v_C(t) = (A_1 + A_2 t)e^{-\alpha t}$，联立 $A_1 = v_C(0^+)$ 与 $A_2 - \alpha A_1 = v_C'(0^+)$；
- **欠阻尼（$\alpha < \omega_0$）**：$v_C(t) = e^{-\alpha t}(B_1 \cos\omega_d t + B_2 \sin\omega_d t)$，联立 $B_1 = v_C(0^+)$ 与 $-\alpha B_1 + \omega_d B_2 = v_C'(0^+)$。

#### ③ 代入数值逐步化简
先算公共不变量与初值导数：
$$\omega_0 = \frac{1}{\sqrt{0.5 \times 0.02}} = \frac{1}{\sqrt{0.01}} = 10\text{ rad/s},\qquad R_{\text{crit}} = 2\sqrt{\frac{0.5}{0.02}} = 2\sqrt{25} = 10\ \Omega$$
$$v_C(0^+) = 12\text{ V},\qquad \frac{dv_C}{dt}(0^+) = \frac{i(0^+)}{C} = \frac{0}{0.02} = 0\text{ V/s}$$

- **档位 ①：$R = 12.5\ \Omega$（过阻尼）**
  $$\alpha = \frac{12.5}{2 \times 0.5} = 12.5\text{ Np/s} > \omega_0 = 10\text{ rad/s}$$
  $$s_{1,2} = -12.5 \pm \sqrt{12.5^2 - 10^2} = -12.5 \pm \sqrt{56.25} = -12.5 \pm 7.5 \implies s_1 = -5\text{ s}^{-1},\ s_2 = -20\text{ s}^{-1}$$
  代入初值条件：
  $$\begin{cases} A_1 + A_2 = 12 \\ -5 A_1 - 20 A_2 = 0 \end{cases} \implies A_1 = 16\text{ V},\quad A_2 = -4\text{ V}$$
  故完整解为（已通过 SymPy 回代校验）：
  $$v_C(t) = 16 e^{-5t} - 4 e^{-20t}\text{ V},\qquad i(t) = C\frac{dv_C}{dt} = 1.6\left(e^{-20t} - e^{-5t}\right)\text{ A}\quad (t \ge 0)$$

- **档位 ②：$R = 10\ \Omega$（临界阻尼）**
  $$\alpha = \frac{10}{2 \times 0.5} = 10\text{ Np/s} = \omega_0 \implies s_1 = s_2 = -10\text{ s}^{-1}$$
  代入初值条件：
  $$\begin{cases} A_1 = 12 \\ A_2 - 10 A_1 = 0 \end{cases} \implies A_1 = 12\text{ V},\quad A_2 = 120\text{ V/s}$$
  故完整解为：
  $$v_C(t) = (12 + 120t) e^{-10t}\text{ V},\qquad i(t) = C\frac{dv_C}{dt} = -24 t e^{-10t}\text{ A}\quad (t \ge 0)$$

- **档位 ③：$R = 6\ \Omega$（欠阻尼）**
  $$\alpha = \frac{6}{2 \times 0.5} = 6\text{ Np/s} < \omega_0 = 10\text{ rad/s},\qquad \omega_d = \sqrt{10^2 - 6^2} = 8\text{ rad/s}$$
  $$s_{1,2} = -6 \pm j8\text{ s}^{-1}$$
  代入初值条件：
  $$\begin{cases} B_1 = 12 \\ -6 B_1 + 8 B_2 = 0 \end{cases} \implies B_1 = 12\text{ V},\quad B_2 = 9\text{ V}$$
  故完整解为：
  $$v_C(t) = e^{-6t}(12\cos 8t + 9\sin 8t)\text{ V} = 15 e^{-6t}\cos(8t - 36.87^\circ)\text{ V},\qquad i(t) = -3 e^{-6t}\sin 8t\text{ A}\quad (t \ge 0)$$

> **教授快速体检**：看看 $i(t)$ 的符号为什么一开始是负的？因为我们按关联参考方向定义了 $i$ 流入电容正极板，而 $t=0$ 时电容正极板带 $+12\text{ V}$ 正在向外**放电**，所以电流自然为负！在档位 ③ 中，$i(t) = -3e^{-6t}\sin 8t$ 在 $t = \pi/8 \approx 0.393\text{ s}$ 时过零变正，说明电感惯性已经把电容反向充到了负电压，开始第二轮反推！

### 5.2 三段式教授板书推导

#### ① 公理溯源
在无源并联 RLC 公共节点处应用 KCL（三个支路均采用关联参考方向向下流出）：
$$i_R(t) + i_L(t) + i_C(t) = 0 \implies \frac{v(t)}{R} + i_L(t) + C\frac{dv(t)}{dt} = 0$$
由 W4-L6 换路定则，$v(0^+) = v(0^-)$ 且 $i_L(0^+) = i_L(0^-)$，在 $t = 0^+$ 时刻立即解出节点电压的一阶导数初值：
$$\frac{dv}{dt}(0^+) = -\frac{1}{C}\left[\frac{v(0^+)}{R} + i_L(0^+)\right]$$

#### ② 纯符号通式
并联 RLC 的特征参数为：
$$\alpha = \frac{1}{2RC},\qquad \omega_0 = \frac{1}{\sqrt{LC}}$$
当 $\alpha < \omega_0$ 时进入欠阻尼状态，阻尼振荡角频率 $\omega_d = \sqrt{\omega_0^2 - \alpha^2}$，通解及导数为：
$$v(t) = e^{-\alpha t}\left(B_1 \cos\omega_d t + B_2 \sin\omega_d t\right)$$
$$\frac{dv}{dt} = e^{-\alpha t}\left[(-\alpha B_1 + \omega_d B_2)\cos\omega_d t + (-\alpha B_2 - \omega_d B_1)\sin\omega_d t\right]$$
令 $t = 0^+$，得到确定 $B_1, B_2$ 的万能公式：
$$B_1 = v(0^+),\qquad B_2 = \frac{1}{\omega_d}\left[\frac{dv}{dt}(0^+) + \alpha B_1\right]$$

#### ③ 代入数值逐步化简
1. **判别阻尼状态**：
   $$\alpha = \frac{1}{2RC} = \frac{1}{2 \times 50 \times 25 \times 10^{-6}} = 400\text{ Np/s}$$
   $$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{0.16 \times 25 \times 10^{-6}}} = \frac{1}{\sqrt{4 \times 10^{-6}}} = 500\text{ rad/s}$$
   因为 $\alpha = 400 < \omega_0 = 500$（注意：$R = 50\ \Omega > R_{\text{crit, parallel}} = 40\ \Omega$，再次印证并联电路电阻越大越容易欠阻尼！），电路处于**欠阻尼**状态：
   $$\omega_d = \sqrt{500^2 - 400^2} = 300\text{ rad/s},\qquad s_{1,2} = -400 \pm j300\text{ s}^{-1}$$
2. **求 $t = 0^+$ 导数初值**：
   $$i_R(0^+) = \frac{v(0^+)}{R} = \frac{12}{50} = 0.24\text{ A}$$
   $$\frac{dv}{dt}(0^+) = -\frac{0.24 + 0.15}{25 \times 10^{-6}} = -\frac{0.39}{25 \times 10^{-6}} = -15600\text{ V/s}$$
3. **求解 $B_1, B_2$ 并回代检验**：
   $$B_1 = v(0^+) = 12\text{ V}$$
   $$B_2 = \frac{-15600 + 400 \times 12}{300} = \frac{-15600 + 4800}{300} = \frac{-10800}{300} = -36\text{ V}$$
   因此完整响应为（SymPy 验证微分方程残差 $= 0$，初值与初导数完全吻合）：
   $$v(t) = e^{-400t}\left(12\cos 300t - 36\sin 300t\right)\text{ V}\quad (t \ge 0)$$

## 第 6 幕：3D 面包板实操实验台——拧动 $1\text{ k}\Omega$ 电位器亲眼见证欠阻尼振铃归零

### 6.1 教授导学：把黑板公式搬到真实面包板，必须跨过的三个工程门槛

教材例题里的 $0.5\text{ H}$ 和 $0.02\text{ F}$ 在真实实验桌上并不好用（$0.02\text{ F}$ 往往是有极性大电解电容，一反向振荡就会鼓包损坏）。在 **Breadboard Lab 3D 实操台**上，我们选用工程最舒适的音频段观测参数：
- **电感**：$L = 10\text{ mH}$（工字功率电感）
- **电容**：$C = 1\ \mu\text{F}$（无极性 CBB 薄膜电容）
- **固有谐振频率**：$\omega_0 = \frac{1}{\sqrt{10^{-2} \times 10^{-6}}} = 10^4\text{ rad/s} \implies f_0 = \frac{\omega_0}{2\pi} \approx 1.59\text{ kHz}$（周期 $T_0 \approx 628\ \mu\text{s}$，普通示波器调到 $200\ \mu\text{s/div}$ 即可清晰定格！）
- **串联临界电阻**：$R_{\text{crit}} = 2\sqrt{\frac{L}{C}} = 2\sqrt{\frac{10^{-2}}{10^{-6}}} = 200\ \Omega$。
- **电位器选型**：配一只 **$0\text{–}1\text{ k}\Omega$ 线性电位器**。当你把旋钮从 $0\ \Omega$ 慢慢顺时针拧大：
  1. **$R_{\text{total}} \approx 40\ \Omega$**（欠阻尼）：示波器屏幕上出现剧烈的 $1.56\text{ kHz}$ 衰减正弦振铃，电压向下冲破 $0\text{ V}$ 线；
  2. **$R_{\text{total}} = 200\ \Omega$**（临界阻尼）：振铃恰好被彻底“掐死”，波形以最利落的弧线一头扎回 $0\text{ V}$ 且纹丝不动；
  3. **$R_{\text{total}} \ge 500\ \Omega$**（过阻尼）：继续拧大电阻，波形反而不干脆了，拖出一条长长的迟钝尾巴！

> **实验室真实踩坑预警（寄生电阻 $R_L$）**：真实 $10\text{ mH}$ 电感并不是理想零电阻，它的铜线绕组自带 **$R_L \approx 8\text{–}15\ \Omega$** 的直流电阻！因此就算你把电位器拧到 $0\ \Omega$，回路总电阻 $R_{\text{total}} = R_{\text{pot}} + R_L$ 依然不为零，波形总会慢慢衰减；同时临界阻尼对应的电位器读数也不是 $200\ \Omega$，而是 $R_{\text{pot}} = 200\ \Omega - R_L$！

## Claude 工程落地清单（Type D 三层舞台实现规格）

### 1. 全局状态与数学内核（`rlcSolver.ts`）
- **状态接口**：`{ topology: 'series' | 'parallel', R: number, L: number, C: number, v0: number, i0: number, rParasitic: number, lockGhostCurves: boolean }`。
- **解析求解器**：
  - 统一计算 $\omega_0 = 1/\sqrt{LC}$；串联取 $\alpha = (R + R_L)/(2L)$，并联取 $\alpha = 1/(2RC)$。
  - 引入临界容差带 $|\alpha - \omega_0| / \omega_0 < 10^{-3}$ 自动切换至临界阻尼解析式 $(A_1 + A_2 t)e^{-\alpha t}$，防止浮点除法 `s1 - s2 ≈ 0` 产生数值爆炸。
  - 同步输出：`dampingRegime`、`poles: [{re, im}, {re, im}]`、时域采样数组 `samples[400]`（含 $v_C(t)$、$i_L(t)$ 及欠阻尼上下包络 $\pm M e^{-\alpha t}$）。

### 2. 左侧三层舞台组件规范
- **Layer 01（`01_schematic` · 2D 串联/并联切换原理图）**：
  - 点击拓扑切换按钮平滑过渡串联 KVL 回路与并联 KCL 节点图，实时在元件旁渲染 $\alpha$ 公式高亮（串联红色高亮分子 $R$，并联橙色高亮分母 $R$）。
- **Layer 02（`02_waveform_splane` · 实时示波器 + $s$ 平面联动）**：
  - 上半区：交互式 SVG 示波器，支持勾选“三态同屏对比”锁定过阻尼/临界/欠阻尼残影，并用虚线渲染 $\pm M e^{-\alpha t}$ 指数包络与首峰过冲游标。
  - 下半区：复平面 $s$ 极点图，拖动电阻滑块 $R$ 时实时播放极点沿半径 $\omega_0$ 半圆滑动 → 负实轴 $(-\omega_0, 0)$ 碰撞 → 沿负实轴分裂的动画，并在 $R_{\text{crit}}$ 处设置磁吸触感。
- **Layer 03（`03_breadboard_3d` · Three.js 3D 面包板实操台）**：
  - 3D 场景元件：半尺寸面包板、`10 mH` 工字电感（标明寄生电阻 $R_L = 10\ \Omega$）、`1 μF` 绿色无极性 CBB 薄膜电容、`0–1 kΩ` 可拖拽旋转电位器旋钮、SPDT 充/放电拨动开关、`5 V` 电源模块与虚拟台式示波器。
  - 交互闭环：用户鼠标拖拽拧动 3D 电位器旋钮 → 实时更新 `R` 与总阻尼态 → 拨动 SPDT 开关触发放电 → 示波器屏幕 `CanvasTexture` 以 $200\ \mu\text{s/div}$ 动态扫描呈现“振铃 → 临界归零 → 过阻尼拖尾”。

### 3. 验收测试标准
- **数学一致性**：例题 1（$L=0.5\text{ H}, C=0.02\text{ F}$）三档位与例题 2（$R=50\ \Omega, L=160\text{ mH}, C=25\ \mu\text{F}$）在解析内核中的输出与本文 SymPy 校验值误差 $< 10^{-6}$。
- **临界点防除零**：滑块停留在 $R = R_{\text{crit}}$ 时波形连续无 `NaN` / `Infinity` 闪烁。
- **响应式与零报错**：三层舞台切换流畅，控制台零 Runtime Error，所有 JSON 与内联 SVG 通过严格格式校验。
