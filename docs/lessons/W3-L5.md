## 第 1 幕：工程痛点——为什么不能用普通电阻把多路音源直接拧在一起？

### 教授开场白

各位同学，今天我们把实验室变成一间录音棚。假设你手里有两路音源：一路是主唱麦克风信号 $v_1$，另一路是木吉他信号 $v_2$，你想把它们混合成一路输出送给功放或耳机。

一个刚学完分压器的初学者可能会立刻拍大腿：“这还不简单？给 $v_1$ 串一个 $10\text{ k}\Omega$ 电阻，给 $v_2$ 也串一个 $10\text{ k}\Omega$ 电阻，再把两根线的尾巴直接拧在一起接到负载 $R_L = 10\text{ k}\Omega$ 上不就行了吗？”

**千万别这么干！** 一旦你把无源电阻的尾巴直接拧在一起，就会遭遇模拟电路里最令人头疼的**通道串扰与加载效应（Crosstalk & Loading Effect）**。

### 定量对比：为什么无源混音一定会“打架”？

我们用一组最直观的数字（已由 Python 精确验算）来验证这两者的天壤之别：设 $R_1 = R_2 = R_L = R_f = 10\text{ k}\Omega$，固定主唱通道 $v_1 = 2.0\text{ V}$，现在让吉他通道 $v_2$ 从 $0\text{ V}$（静音）推到 $4.0\text{ V}$（扫弦高潮）：

| 测试架构 | 工况 A：$v_1=2.0\text{ V},\ v_2=0.0\text{ V}$ | 工况 B：$v_1=2.0\text{ V},\ v_2=4.0\text{ V}$ | 通道 1 电流 $i_1$ 变化 | 工程诊断 |
| :--- | :--- | :--- | :--- | :--- |
| **无源电阻直连** | $v_{\text{mix}} = 0.667\text{ V}$，$i_1 = 0.133\text{ mA}$，$i_2 = -0.067\text{ mA}$ | $v_{\text{mix}} = 2.000\text{ V}$，$i_1 = 0.000\text{ mA}$，$i_2 = 0.200\text{ mA}$ | **骤降 100%（彻底被顶死）** | 严重串扰：$v_2$ 静音时主唱电流倒灌进吉他口；$v_2$ 变大时主唱被压制 |
| **运放虚地加法器** | $v_- = 0.000\text{ V}$，$i_1 = 0.200\text{ mA}$，$i_2 = 0.000\text{ mA}$，$v_o = -2.00\text{ V}$ | $v_- = 0.000\text{ V}$，$i_1 = 0.200\text{ mA}$，$i_2 = 0.400\text{ mA}$，$v_o = -6.00\text{ V}$ | **0.0% 变化（纹丝不动）** | 完美隔离：虚地节点把各通道彻底解耦为独立电流源 |

> **教授点睛**：把多路电阻直接拧在一起，公共节点 $v_{\text{mix}}$ 的电位是**浮动**的——谁嗓门大，谁就把节点电压抬高，直接把其他通道的电流顶回去。而反相加法器通过负反馈把反相输入端死死钉在**虚地（Virtual Ground，$v_- = 0\text{ V}$）**。对第 $k$ 路输入源而言，它看到的永远是一端接地的纯电阻 $R_k$，根本“看不见”隔壁还有没有其他通道，因此支路电流永远严格满足 $i_k = v_k / R_k$，在虚地节点无损汇流！

### 三段式教授板书推导（严禁符号与数字混写）

#### ① 公理溯源
本电路建立在三条铁打不动的电路公理之上：
1. **理想运放虚短公理（Virtual Short）**：由于存在负反馈且运放工作在线性区，两输入端电位相等。又因同相端直接接地，故节点 $a$ 为虚地节点：
   $$v_a = v_- = v_+ = 0\text{ V}$$
2. **理想运放虚断公理（Virtual Open）**：理想运放输入阻抗无穷大，没有电流流入运放输入端：
   $$i_- = i_+ = 0\text{ A}$$
3. **节点 $a$ 处基尔霍夫电流定律（KCL，`W1-L5`）与欧姆定律**：流入节点 $a$ 的各支路电流之和，必须全部经由反馈电阻 $R_f$ 流出：
   $$i_1 + i_2 + i_3 = i_- + i_f = i_f$$

#### ② 纯符号通式
将每一条输入支路及反馈支路的欧姆定律表达式代入节点 $a$ 的 KCL 方程：
$$i_1 = \frac{v_1 - v_a}{R_1},\quad i_2 = \frac{v_2 - v_a}{R_2},\quad i_3 = \frac{v_3 - v_a}{R_3},\quad i_f = \frac{v_a - v_o}{R_f}$$

代入虚地条件 $v_a = 0$，得：
$$\frac{v_1}{R_1} + \frac{v_2}{R_2} + \frac{v_3}{R_3} = \frac{0 - v_o}{R_f} = -\frac{v_o}{R_f}$$

两边同乘 $-R_f$，即得 **Sadiku Eq. (5.14)**：
$$v_o = -\left(\frac{R_f}{R_1}v_1 + \frac{R_f}{R_2}v_2 + \frac{R_f}{R_3}v_3\right)$$

若将输入扩展至 $n$ 路，令第 $k$ 路通道权重系数 $w_k = \frac{R_f}{R_k}$，则一般多路通式为：
$$v_o = -\sum_{k=1}^{n} \frac{R_f}{R_k} v_k = -\sum_{k=1}^{n} w_k v_k$$

> **叠加定理交叉印证（链接 `W2-L5` & `W3-L3`）**：由于理想运放在线性区是严格线性元件，令 $v_2 = v_3 = 0$ 时，虚地节点 $v_- = 0\text{ V}$ 使 $R_2, R_3$ 两端电位均为 $0\text{ V}$（零电流、如同开路），电路退化为标准反相放大器，$v_{o1} = -\frac{R_f}{R_1}v_1$。同理得 $v_{o2} = -\frac{R_f}{R_2}v_2$、$v_{o3} = -\frac{R_f}{R_3}v_3$，三者相加完全吻合 Eq. (5.14)！

#### ③ 代入数值逐步化简
以一组三路测试信号演示严格代入规范：已知 $R_f = 20\text{ k}\Omega$，$R_1 = 10\text{ k}\Omega$（$v_1 = 1.0\text{ V}$），$R_2 = 5\text{ k}\Omega$（$v_2 = 0.5\text{ V}$），$R_3 = 20\text{ k}\Omega$（$v_3 = -2.0\text{ V}$）。

1. **写出纯符号通式**：
   $$v_o = -\left(\frac{R_f}{R_1}v_1 + \frac{R_f}{R_2}v_2 + \frac{R_f}{R_3}v_3\right)$$
2. **整行代入带单位数值**：
   $$v_o = -\left(\frac{20\text{ k}\Omega}{10\text{ k}\Omega}\times 1.0\text{ V} + \frac{20\text{ k}\Omega}{5\text{ k}\Omega}\times 0.5\text{ V} + \frac{20\text{ k}\Omega}{20\text{ k}\Omega}\times (-2.0\text{ V})\right)$$
3. **逐项化简权重与加权电压**：
   $$v_o = -\left(2 \times 1.0\text{ V} + 4 \times 0.5\text{ V} + 1 \times (-2.0\text{ V})\right) = -(2.0\text{ V} + 2.0\text{ V} - 2.0\text{ V}) = -2.0\text{ V}$$
4. **支路电流验算（独立 KCL 校核）**：
   - $i_1 = \frac{1.0\text{ V}}{10\text{ k}\Omega} = 0.100\text{ mA}$
   - $i_2 = \frac{0.5\text{ V}}{5\text{ k}\Omega} = 0.100\text{ mA}$
   - $i_3 = \frac{-2.0\text{ V}}{20\text{ k}\Omega} = -0.100\text{ mA}$
   - $i_f = i_1 + i_2 + i_3 = 0.100 + 0.100 - 0.100 = 0.100\text{ mA}$
   - $v_o = -i_f R_f = -(0.100\text{ mA})(20\text{ k}\Omega) = -2.0\text{ V}$（验算一致）。

### 三大高频工程拓扑速查

1. **等权加法器（Unity-Gain Summer）**
   - **选型条件**：令 $R_1 = R_2 = R_3 = R_f = R$。
   - **输出公式**：
     $$v_o = -(v_1 + v_2 + v_3)$$
   - **直觉**：每一路输入权重均为 $1$，直接对多路电压做纯净求和再反相。

2. **反相平均器（Inverting Averager）**
   - **选型条件**：若有 $n$ 路输入，令所有输入电阻相等 $R_1 = R_2 = \dots = R_n = R$，且取反馈电阻为输入电阻的 $\frac{1}{n}$，即：
     $$R_f = \frac{R}{n}$$
   - **输出公式**：
     $$v_o = -\frac{1}{n}\left(v_1 + v_2 + \dots + v_n\right)$$
   - **工程应用**：例如工业测温阵列中将 4 个温度传感器取 $R = 20\text{ k}\Omega$、$R_f = 5\text{ k}\Omega$，硬件级实时求平均，既防溢出又将随机白噪声标准差压低一半（$\frac{1}{\sqrt{4}} = 0.5$）。

3. **音频混音器与电平偏置移位（Audio Mixer & DC Level Shifter）**
   - **音频混音器**：在每一路输入端串联可调电位器（作为可变 $R_k$），即可独立调节单轨音量权重 $w_k = R_f/R_k$；而在反馈回路放置总电位器 $R_f$，即可一键控制所有通道的总音量（Master Gain），且各通道推子互不影响。
   - **电平偏置移位（双极性 → 单极性 ADC）**：
     - 实际音频或交流传感器信号常为双极性 $v_{\text{sig}} \in [-1.0\text{ V}, +1.0\text{ V}]$，而常见单片机（STM32/ESP32）的 ADC 只能采集 $[0\text{ V}, 3.3\text{ V}]$，负半周会被直接削掉甚至损坏引脚。
     - **解法**：使用两路反相加法器，通道 1 接 $v_{\text{sig}}$（取 $R_1 = R_f = 10\text{ k}\Omega$，$w_1 = 1$）；通道 2 接负参考直流源 $V_{\text{ref}} = -3.3\text{ V}$（取 $R_2 = 20\text{ k}\Omega$，$w_2 = \frac{10\text{ k}\Omega}{20\text{ k}\Omega} = 0.5$）。
     - **代入验证**：
       $$v_o = -\left(1 \cdot v_{\text{sig}} + 0.5 \cdot (-3.3\text{ V})\right) = -v_{\text{sig}} + 1.65\text{ V}$$
       当 $v_{\text{sig}} = -1.0\text{ V}$ 时 $v_o = +2.65\text{ V}$；当 $v_{\text{sig}} = 0\text{ V}$ 时 $v_o = +1.65\text{ V}$；当 $v_{\text{sig}} = +1.0\text{ V}$ 时 $v_o = +0.65\text{ V}$。整段波形稳稳悬浮在 $[0.65\text{ V}, 2.65\text{ V}] \subset [0\text{ V}, 3.3\text{ V}]$ 安全区内！（若系统要求不反相，只需在后级再级联一级单位增益反相器，或在 MCU 软件里对采样值做 `3.3V - v_adc` 即可。）

## 第 4 幕：教材经典精讲——Sadiku Example 5.6 完整求解与饱和边界验算

### 题目与电路图（100% 沿 Sadiku Section 5.6 Example 5.6 / Fig. 5.18）

### 严格三段式板书求解

#### ① 公理溯源
1. 假设运放工作在线性区，依据理想运放虚短与虚断公理：$v_- = v_+ = 0\text{ V}$，$i_- = 0\text{ A}$。
2. 节点 $a$ 处 KCL：$i_1 + i_2 = i_f$。
3. **输出节点处 KCL（常见易错点！）**：运放输出端必须同时承担流向负载电阻 $R_L$ 的电流 $i_L$ 与流向反馈电阻 $R_f$ 的电流（注意方向：从输出端流向虚地节点的电流为 $-i_f$）：
   $$i_o = i_L + (-i_f) = \frac{v_o - 0}{R_L} + \frac{v_o - v_-}{R_f}$$
4. **线性区边界条件**：输出电压必须满足 $-V_{CC} \le v_o \le +V_{CC}$；一旦越界，运放立即饱和削波，虚短条件 $v_- = 0\text{ V}$ 随即失效。

#### ② 纯符号通式
$$v_o = -\left(\frac{R_f}{R_1}v_1 + \frac{R_f}{R_2}v_2\right)$$
$$i_1 = \frac{v_1}{R_1},\quad i_2 = \frac{v_2}{R_2},\quad i_f = i_1 + i_2 = -\frac{v_o}{R_f}$$
$$i_L = \frac{v_o}{R_L},\quad i_o = \frac{v_o}{R_L} + \frac{v_o}{R_f} = i_L - i_f$$

#### ③ 代入数值逐步化简
1. **求解输出电压 $v_o$**：
   $$v_o = -\left(\frac{10\text{ k}\Omega}{5\text{ k}\Omega} \times 2\text{ V} + \frac{10\text{ k}\Omega}{2.5\text{ k}\Omega} \times 1\text{ V}\right) = -(2 \times 2\text{ V} + 4 \times 1\text{ V}) = -(4\text{ V} + 4\text{ V}) = -8\text{ V}$$
2. **求解各输入支路电流与反馈电流 $i_f$**：
   $$i_1 = \frac{2\text{ V}}{5\text{ k}\Omega} = 0.4\text{ mA},\qquad i_2 = \frac{1\text{ V}}{2.5\text{ k}\Omega} = 0.4\text{ mA}$$
   $$i_f = i_1 + i_2 = 0.4\text{ mA} + 0.4\text{ mA} = 0.8\text{ mA}$$
   （交叉校核：$i_f = \frac{0 - (-8\text{ V})}{10\text{ k}\Omega} = 0.8\text{ mA}$，完全吻合。）
3. **求解负载电流 $i_L$ 与运放输出总电流 $i_o$**：
   $$i_L = \frac{-8\text{ V}}{2\text{ k}\Omega} = -4.0\text{ mA}$$
   $$i_o = i_L - i_f = -4.0\text{ mA} - 0.8\text{ mA} = -4.8\text{ mA}$$
   > **物理含义**：$i_o = -4.8\text{ mA}$ 中的负号表示电流实际**灌入（Sink）**运放输出端——左侧反馈支路涌来 $0.8\text{ mA}$，右侧负载电阻从地向 $-8\text{ V}$ 节点倒流来 $4.0\text{ mA}$，两股电流汇合成 $4.8\text{ mA}$ 被运放内部下拉晶体管吸走。

### 电源轨饱和边界检验（Saturation Boundary Check）

| 供电方案 | 理论线性解 $v_{o,\text{ideal}}$ | 边界判定 | 实际输出 $v_{o,\text{actual}}$ | 实际反相端电位 $v_-$ | 反馈电流 $i_f$ 与隔离状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **方案 A：$\pm 12\text{ V}$** | $-8.00\text{ V}$ | $\|-8.00\text{ V}\| \le 12\text{ V}$（线性区） | **$-8.00\text{ V}$** | **$0.000\text{ V}$（虚地成立）** | $i_f = 0.800\text{ mA}$，两通道完美隔离 |
| **方案 B：$\pm 5\text{ V}$** | $-8.00\text{ V}$ | $-8.00\text{ V} < -5\text{ V}$（**负向饱和削波**） | **$-5.00\text{ V}$（钳位）** | **$+\frac{3}{7}\text{ V} \approx +0.429\text{ V}$（虚地瓦解！）** | $i_f = \frac{19}{35}\text{ mA} \approx 0.543\text{ mA}$，通道重新串扰 |

> **深度验算（饱和后如何求真实 $v_-$？）**：当供电仅为 $\pm 5\text{ V}$ 时，$v_o$ 被钉死在 $-5\text{ V}$，负反馈环路失去调节余量，虚短 $v_- = 0\text{ V}$ **不再成立**；但运放输入阻抗依然极高，虚断 $i_- \approx 0\text{ A}$ 仍可近似成立。对节点 $a$ 列 KCL：
> $$\frac{v_- - 2\text{ V}}{5\text{ k}\Omega} + \frac{v_- - 1\text{ V}}{2.5\text{ k}\Omega} + \frac{v_- - (-5\text{ V})}{10\text{ k}\Omega} = 0$$
> 两边同乘 $10\text{ k}\Omega$：$2(v_- - 2) + 4(v_- - 1) + (v_- + 5) = 0 \implies 7v_- = 3 \implies v_- = \frac{3}{7}\text{ V} \approx 0.429\text{ V}$。此时 $i_1 = \frac{2 - 3/7}{5\text{ k}\Omega} \approx 0.314\text{ mA}$，$i_2 = \frac{1 - 3/7}{2.5\text{ k}\Omega} \approx 0.229\text{ mA}$，两路支路电流都因饱和被压扁，音频输出产生刺耳削波失真！
