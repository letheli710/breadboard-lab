### 第三章：右侧讲课正文（共 7 幕）

#### 第 1 幕：困局破冰——为什么惠斯通电桥里的 5 颗电阻既不串联也不并联？
**联动左侧舞台**：Layer 02（Step 0：原始 5 电阻电桥）

前七节课，我们靠串联相加、并联倒数相加，一路披荆斩棘，几乎拆解了所有常规直流电阻网络。但是今天，我要给你看一张在电工史上鼎鼎大名的电路——**惠斯通电桥（Wheatstone Bridge）**。

请你盯着这张图看 5 秒钟，试着找出哪怕**一对**串联或并联的电阻：

- $R_{ac}$ 和 $R_{cb}$ 是串联吗？**不是！**因为它们之间的节点 c 还挂着一根横跨中央的“桥臂电阻” $R_{cd}$。只要电流流过 $R_{cd}$，流入 $R_{ac}$ 的电流就不再等于流入 $R_{cb}$ 的电流——**串联的充要条件是两元件共享一个“度数为 2”（没有第三条支路分流）的节点**，这里节点 c 的度数是 3，串联宣告破产。
- 那 $R_{ac}$ 和 $R_{ad}$ 是并联吗？**也不是！**它们虽然在顶部共同连着节点 a，但底部一个连着 c，一个连着 d——中间被 $R_{cd}$ 隔开了。**并联的充要条件是两元件两端连接在完全相同的两个节点上**，这里 $V_c \neq V_d$（不平衡电桥），并联也宣告破产。

以此类推，你把这 5 颗电阻两两配对检查完全部 $\binom{5}{2} = 10$ 种组合，会发现一个令人头皮发麻的事实：**任意两颗电阻之间，既不串联，也不并联！**

这不是你的眼力问题，而是**拓扑结构**决定的：电桥里的四个节点 a, b, c, d 全部都是 3 条及以上支路交汇的节点，形成了一个“死结”。要解开这个死结，我们不能再靠“两两合并”，而必须把视角从“二端元件”升级到**“三端网络等效变换”**——也就是本课的主角：**Y–Δ（星形–三角形）等效变换**。

#### 第 2 幕：几何变形与公理溯源——从端口等效推导出 $\Delta \to Y$ 变换
**联动左侧舞台**：Layer 01（打开端口虚拟欧姆表，方向切至 Δ → Y）

仔细观察第 1 幕电桥的上半部分：节点 a, c, d 之间由三颗电阻围成了一个闭合三角形——我们叫它 **$\Delta$（Delta，三角形）网络**。如果我们能把这个“三端黑盒”内部的三颗电阻，换成另一种连法——从中心引出一个中性点 n，分别连向三个端口形成一个 **Y（Wye，星形）网络**——只要对外暴露的三个端口 a, b, c 之间任意两端的等效电阻完全一致，外部电路根本察觉不到黑盒里被掉包了！

按照 Alexander & Sadiku（Ch. 2.7）的标准记法，我们给三端网络的三个端口命名为 a（左上）、b（右上）、c（正下）：

- **$\Delta$ 网络的三条边**：$R_a$ 位于 b–c 之间（正对端口 a），$R_b$ 位于 a–c 之间（正对端口 b），$R_c$ 位于 a–b 之间（正对端口 c）。
- **Y 网络的三条臂**：$R_1$ 连向端口 a，$R_2$ 连向端口 b，$R_3$ 连向端口 c，三者在内部汇合于中心节点 n。

下面我们严格按三段式推导 $\Delta \to Y$ 的精确公式：
##### ① 公理溯源（端口两两开路等效电阻相等）
要使 $\Delta$ 网络与 Y 网络对外部完全等效，将第三个端口悬空（开路）时，其余任意两端口之间测得的等效电阻必须严格相等：

- **端口 ****a–b**** 间（****c**** 端开路）**：Y 侧为 $R_1, R_2$ 串联；$\Delta$ 侧为 $R_c$ 与 $(R_a + R_b)$ 并联： $$R_{ab}(Y) = R_{ab}(\Delta) \implies R_1 + R_2 = \frac{R_c(R_a + R_b)}{R_a + R_b + R_c} \tag{1}$$

- **端口 ****b–c**** 间（****a**** 端开路）**： $$R_{bc}(Y) = R_{bc}(\Delta) \implies R_2 + R_3 = \frac{R_a(R_b + R_c)}{R_a + R_b + R_c} \tag{2}$$

- **端口 ****c–a**** 间（****b**** 端开路）**： $$R_{ca}(Y) = R_{ca}(\Delta) \implies R_3 + R_1 = \frac{R_b(R_c + R_a)}{R_a + R_b + R_c} \tag{3}$$
##### ② 纯符号通式
用 $(1) + (3) - (2)$ 消去 $R_2$ 与 $R_3$：

$$2R_1 = \frac{(R_c R_a + R_c R_b) + (R_b R_c + R_b R_a) - (R_a R_b + R_a R_c)}{R_a + R_b + R_c} = \frac{2 R_b R_c}{R_a + R_b + R_c}$$

两边同除以 $2$，再由三端口轮换对称性直接写出全部三条 **$\Delta \to Y$ 通式**：

$$R_1 = \frac{R_b R_c}{R_a + R_b + R_c}, \qquad R_2 = \frac{R_c R_a}{R_a + R_b + R_c}, \qquad R_3 = \frac{R_a R_b}{R_a + R_b + R_c}$$
##### ③ 代入数值逐步化简
设已知一个 $\Delta$ 网络的三条边为 $R_a = 15,\Omega$、$R_b = 10,\Omega$、$R_c = 25,\Omega$，求其等效 Y 网络的 $R_1, R_2, R_3$：

- 先算公共分母（三臂之和）： $$R_\Sigma = R_a + R_b + R_c = 15 + 10 + 25 = 50,\Omega$$

- 分别代入三条通式： $$R_1 = \frac{R_b R_c}{R_\Sigma} = \frac{10 \times 25}{50} = \frac{250}{50} = 5,\Omega$$ $$R_2 = \frac{R_c R_a}{R_\Sigma} = \frac{25 \times 15}{50} = \frac{375}{50} = 7.5,\Omega$$ $$R_3 = \frac{R_a R_b}{R_\Sigma} = \frac{15 \times 10}{50} = \frac{150}{50} = 3,\Omega$$

**端口复核**：测 a–b 端口，Y 侧 $R_1 + R_2 = 5 + 7.5 = 12.5,\Omega$；$\Delta$ 侧 $25 \parallel (15 + 10) = 25 \parallel 25 = 12.5,\Omega$，分毫不差！

#### 第 3 幕：逆向推导与“叠画记忆法”——永不背错 6 条公式的视觉秘诀
**联动左侧舞台**：Layer 01（滑块拖至 t = 0.50“叠画记忆态”，悬停查看相邻与对面关系）

既然能从 $\Delta$ 变到 Y，反过来，如果手里是 Y 网络，怎么还原出 $\Delta$ 网络？我们先严格推导出 $Y \to \Delta$ 通式，再教你一个**一辈子不会背错 6 条公式的图形记忆法**。
##### ① 公理溯源（端口等效方程组的逆解）
承接第 2 幕由端口两两开路等效导出的 $\Delta \to Y$ 三式：

$$R_1 = \frac{R_b R_c}{R_\Sigma}, \qquad R_2 = \frac{R_c R_a}{R_\Sigma}, \qquad R_3 = \frac{R_a R_b}{R_\Sigma} \quad (R_\Sigma = R_a + R_b + R_c)$$

为了把分母里的 $R_\Sigma$ 与乘积项凑成整齐的对称结构，我们计算 Y 网络三个电阻的**两两乘积之和**：

$$R_1 R_2 + R_2 R_3 + R_3 R_1 = \frac{R_a R_b R_c^2 + R_a^2 R_b R_c + R_a R_b^2 R_c}{R_\Sigma^2} = \frac{R_a R_b R_c (R_c + R_a + R_b)}{R_\Sigma^2} = \frac{R_a R_b R_c}{R_\Sigma}$$
##### ② 纯符号通式
把上式分别除以 $R_1$、$R_2$、$R_3$，公共因子 $\frac{1}{R_\Sigma}$ 与对应的两项乘积瞬间约分干净，得到全部三条 **$Y \to \Delta$ 通式**：

$$R_a = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1}, \qquad R_b = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_2}, \qquad R_c = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}$$
##### ③ 代入数值逐步化简
把第 2 幕算出的 Y 网络（$R_1 = 5,\Omega$、$R_2 = 7.5,\Omega$、$R_3 = 3,\Omega$）代回逆变换公式，验证是否能精确还原：

- 先算公共分子（两两乘积之和）： $$P_\Sigma = R_1 R_2 + R_2 R_3 + R_3 R_1 = (5)(7.5) + (7.5)(3) + (3)(5) = 37.5 + 22.5 + 15 = 75,\Omega^2$$

- 分别除以各自**对面**的 Y 电阻： $$R_a = \frac{P_\Sigma}{R_1} = \frac{75}{5} = 15,\Omega, \qquad R_b = \frac{P_\Sigma}{R_2} = \frac{75}{7.5} = 10,\Omega, \qquad R_c = \frac{P_\Sigma}{R_3} = \frac{75}{3} = 25,\Omega$$

完美还原！


##### 教授的独家图形记忆法：“把 $\Delta$ 叠画在 Y 外面”
考试时题目绝不会乖乖按 $R_1, R_2, R_3$ 和 $R_a, R_b, R_c$ 给你编号，可能全是 $R_x, R_y, R_z$ 甚至 $R_{10}, R_{20}, R_{30}$。**死记字母下标是踩坑之源！** 你只需要在草稿纸上把 $\Delta$ 直接叠画在 Y 的外框上（见下方示意图），记住两句口诀，哪怕字母全打乱也绝不会错：

- **$\Delta \to Y$（已知外框，求内部星形臂）**：

**“相邻两臂之积，除以三臂之和。”** 站在你想求的 Y 臂（如 $R_1$）所连的端口（端口 a）上，伸出双手摸到的两条 $\Delta$ 边（$R_b$ 和 $R_c$）就是它的**相邻两臂**。 $$R_{\text{内}} = \frac{\text{相邻两外边之积}}{\text{三外边之和}}$$

- **$Y \to \Delta$（已知内部，求外框三角边）**：

**“两两乘积之和，除以对面电阻。”** 站在你想求的 $\Delta$ 边（如 $R_a$）上往三角形内部看，笔直指向你正对面的那条 Y 臂（$R_1$）就是你的**对面电阻**。 $$R_{\text{外}} = \frac{\text{三内臂两两乘积之和}}{\text{正对面的那条内臂}}$$

**量纲自检技巧**：$\Delta \to Y$ 分子是 $\Omega^2$、分母是 $\Omega$，商为 $\Omega$；$Y \to \Delta$ 分子是 $\Omega^2$、分母是 $\Omega$，商也是 $\Omega$。凡是写反了分子分母，量纲一秒钟就会露馅！

#### 第 4 幕：对称网络秒杀技巧——$R_\Delta = 3 R_Y$ 与工程直觉
**联动左侧舞台**：Layer 01（开启“对称网络锁定”开关）

在三相电力系统、传感器电桥和芯片匹配网络中，三颗电阻阻值完全相等的**平衡（对称）网络**出现频率极高。此时你完全不需要列分数，一眼就能心算秒杀！
##### ① 公理溯源（对称约束代入通式）
当 $\Delta$ 网络满足 $R_a = R_b = R_c = R_\Delta$，或 Y 网络满足 $R_1 = R_2 = R_3 = R_Y$ 时，三端口完全对称，必有变换后的三颗电阻也全部相等。
##### ② 纯符号通式
代入 $\Delta \to Y$ 通式：

$$R_Y = \frac{R_\Delta \cdot R_\Delta}{R_\Delta + R_\Delta + R_\Delta} = \frac{R_\Delta^2}{3 R_\Delta} = \frac{R_\Delta}{3}$$

反之，代入 $Y \to \Delta$ 通式：

$$R_\Delta = \frac{R_Y^2 + R_Y^2 + R_Y^2}{R_Y} = \frac{3 R_Y^2}{R_Y} = 3 R_Y$$

于是得到电路学中最常用的心算黄金法则：

$$R_\Delta = 3 R_Y \iff R_Y = \frac{R_\Delta}{3}$$
##### ③ 代入数值逐步化简
**秒杀案例**：一个 5 电阻惠斯通电桥，5 颗电阻全部为 $30,\Omega$，求 $R_{ab}$。

- **顶部 $\Delta \to Y$ 秒杀**：顶部三颗 $30,\Omega$ 构成对称 $\Delta$，除以 $3$ 直接变为三颗 $R_Y = \frac{30}{3} = 10,\Omega$ 的 Y 网络。
- **退化为串并联**：
  - 左侧支路：$R_{\text{left}} = 10 + 30 = 40,\Omega$
  - 右侧支路：$R_{\text{right}} = 10 + 30 = 40,\Omega$
  - 并联后与顶部 $10,\Omega$ 串联： $$R_{ab} = 10 + (40 \parallel 40) = 10 + 20 = 30,\Omega$$

**物理直觉防反记**：很多同学考场上会犹豫“到底是 $R_\Delta = 3 R_Y$ 还是 $R_Y = 3 R_\Delta$？”记住一个物理事实就永远不会反：**在 $\Delta$ 里，电流从 ****a**** 走到 ****b**** 有两条并联路（直接走 $R_c$，或者绕道 $R_b + R_a$），并联会让总电阻变小；而在 Y 里，电流只能串联走过 $R_1 + R_2$。为了对外呈现相同的阻值，并联的 $\Delta$ 每一条边必须比串联的 Y 更大——正好大 3 倍（$\Delta$ 大 Y 小）！**

##### 本题完整三段式规范解答复盘
- **① 公理溯源**：将顶部 $\Delta$（节点 a, c, d 间的 $R_{ac}, R_{ad}, R_{cd}$）替换为端口等效的星形网络（$R_1, R_2, R_3$），消除跨接桥臂。
- **② 纯符号通式**： $$R_1 = \frac{R_{ac} R_{ad}}{R_\Sigma}, \quad R_2 = \frac{R_{ac} R_{cd}}{R_\Sigma}, \quad R_3 = \frac{R_{ad} R_{cd}}{R_\Sigma} \quad (R_\Sigma = R_{ac} + R_{ad} + R_{cd})$$ $$R_{ab} = R_1 + \big[(R_2 + R_{cb}) \parallel (R_3 + R_{db})\big]$$
- **③ 代入数值逐步化简**： $$R_\Sigma = 12 + 18 + 6 = 36,\Omega$$ $$R_1 = \frac{12 \times 18}{36} = 6,\Omega, \qquad R_2 = \frac{12 \times 6}{36} = 2,\Omega, \qquad R_3 = \frac{18 \times 6}{36} = 3,\Omega$$ $$R_{\text{left}} = R_2 + R_{cb} = 2 + 10 = 12,\Omega, \qquad R_{\text{right}} = R_3 + R_{db} = 3 + 21 = 24,\Omega$$ $$R_{ab} = 6 + (12 \parallel 24) = 6 + \frac{12 \times 24}{12 + 24} = 6 + 8 = 14,\Omega$$

#### 第 6 幕：工程避坑指南——T–Π 变形识别与转换方向选择
**联动左侧舞台**：Layer 01（切换视角观察直角画法与斜线画法的拓扑同一性）

很多学生在教材例题里能一眼认出电桥，一到真实原理图或 Boylestad Ch. 7 的复杂梯形网络就傻眼了——原因只有一个：**工程师画 PCB 原理图习惯用横平竖直的直角走线，而不是斜着画三角形或 Y 字！**

请记住这两个**拓扑等价变装**：

- **T 型网络 $\equiv$ Y 型网络**：把 Y 的两条上臂拉平变成水平，下臂垂直，就是一个标准的 **T 字**。
- **$\Pi$（Pi）型网络 $\equiv$ $\Delta$ 型网络**：把 $\Delta$ 底部的单个节点 c 拉长成一整条水平公共底线（地线），三角形立刻变成一座门框形的 **$\Pi$ 字**。

**转换方向怎么选？记住两条实战军规**：

- **优先做 $\Delta \to Y$**：因为绝大多数复杂网络（电桥、双桥、梯形衰减器）只要把一个 $\Delta$ 缩成 Y，节点间的交叉连接立刻断开，极易退化为串并联。
- **什么时候做 $Y \to \Delta$？** 当一个 Y 网络的外部已经并联着其他电阻时，把内部的 Y 撑开成 $\Delta$，新生成的三条边会恰好与外部电阻**直接并联**，一步合并三组电阻！
- **千万别把要测电压/电流的目标支路吞掉！** 如果题目要求的是桥臂电阻 $R_{cd}$ 上的电流 $I_{cd}$，把顶部 $\Delta$ 转成 Y 后 $R_{cd}$ 就消失了——此时先求总电流 $I_{ab}$，或者留到下节课用 **World 2 节点分析法** 一招通吃。
