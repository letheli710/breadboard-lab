# W2-L5：线性性质与叠加定理（Linearity & Superposition）

> **教授开场白**：同学们，上一周我们学了节点分析法和网孔分析法，它们就像“重型推土机”，不管电路里有几个电源，列出一堆联立方程总能硬推出来。但今天我要教给你们一把电路分析界的“外科手术刀”——**叠加定理（Superposition Theorem）**。当你面对一个同时挂着电压源和电流源的线性电路时，你根本不必同时被它们两个折磨：**一次只开一个独立源，把其余独立源统统“关机”，分别算出简单分电路的响应，最后直接相加！** 但这把手术刀有两条带电的红线：第一，**受控源绝不能关机**；第二，**功率绝对不能直接叠加**。今天我们用六幕把它彻底讲透。

---

## 第 1 幕：为什么多电源电路可以“分而治之”？——线性性质与水泵直觉

### 1.1 教学直觉（Boylestad 水泵类比）
想象一片由平滑直管道组成的水网（对应纯电阻线性网络），同时接了两台水泵：
- **水泵 A**（独立电源 1）单独开启时，把出水口水压推高了 $2\text{ m}$，水流速度为 $0.5\text{ L/s}$；
- **水泵 B**（独立电源 2）单独开启时，把同一个出水口水压推高了 $8\text{ m}$，水流速度为 $2.0\text{ L/s}$。

如果管道是**理想线性管道**（水压与水流严格成正比，没有单向阀、没有湍流阻力突变），那么两台水泵同时开启时，出水口的总水压就精准等于 $2 + 8 = 10\text{ m}$，总水流就精准等于 $0.5 + 2.0 = 2.5\text{ L/s}$。这就是电路中**线性（Linearity）**赋予我们的超能力。

### 1.3 三段式教授板书推导

#### ① 公理溯源（Origin）
一个电路被称为**线性电路（Linear Circuit）**，当且仅当它仅由线性元件（如定值电阻 $v = iR$）、线性受控源和独立源组成。当我们对这样的电路列写 KCL 与 KVL 时，得到的是一组**线性代数方程组**：

$$\mathbf{G}\mathbf{v} = \mathbf{i}_s$$

其中电导矩阵 $\mathbf{G}$ 仅取决于电阻值与线性受控源的增益系数，与独立源向量 $\mathbf{i}_s$ 无关。由线性代数的基本性质，矩阵逆映射 $\mathbf{v} = \mathbf{G}^{-1}\mathbf{i}_s$ 天然满足**齐次性**与**可加性**——这就是叠加定理成立的数学根基！如果电路中混入了二极管、饱和电感或计算对象是二次量（如功率 $p = i^2 R$），映射不再是线性矩阵乘法，叠加定理立刻失效。

#### ② 纯符号通式（General Formula）
设电路响应（某支路电压或电流）是激励（独立源）的映射 $y = \mathcal{L}(x)$，则线性性质严格等价于同时满足以下两条公理：

$$
\text{齐次性（Homogeneity）：}\quad \mathcal{L}(k x) = k\,\mathcal{L}(x)
$$

$$
\text{可加性（Additivity）：}\quad \mathcal{L}(x_1 + x_2) = \mathcal{L}(x_1) + \mathcal{L}(x_2)
$$

合并为线性叠加通式（对任意 $N$ 个独立源）：

$$
\mathcal{L}\!\left(\sum_{j=1}^{N} k_j x_j\right) = \sum_{j=1}^{N} k_j\,\mathcal{L}(x_j)
$$

对纯电阻分压器，输出电压与输入电压的符号关系为：

$$
v_o = \frac{R_2}{R_1 + R_2}\,v_s
$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
在图 1 左侧分压电路中，取 $R_1 = 4\ \Omega$、$R_2 = 6\ \Omega$，验证齐次性：
1. 当输入 $v_s = 10\text{ V}$ 时：
   $$v_{o1} = \frac{6}{4 + 6} \times 10 = \frac{6}{10} \times 10 = 6\text{ V}, \qquad i_1 = \frac{10}{4 + 6} = 1\text{ A}$$
2. 将输入放大 $k = 3$ 倍，令 $v_s' = 3 \times 10 = 30\text{ V}$：
   $$v_{o2} = \frac{6}{4 + 6} \times 30 = 18\text{ V} = 3\,v_{o1}, \qquad i_2 = \frac{30}{10} = 3\text{ A} = 3\,i_1$$
3. **警钟预埋**：顺手看一眼电阻 $R_2$ 的功率变化——输入放大 $3$ 倍时，$p_1 = i_1^2 R_2 = 1^2 \times 6 = 6\text{ W}$，而 $p_2 = i_2^2 R_2 = 3^2 \times 6 = 54\text{ W} = 9\,p_1 \neq 3\,p_1$！功率按 $k^2$ 缩放，**从第一幕起它就不满足齐次性**。

## 第 2 幕：叠加定理的核心手术——独立源如何“置零”？（短路 vs. 开路）

### 2.1 教授点拨：别死记硬背！看“谁等于零”
很多同学初学叠加定理时，最容易把“电压源短路、电流源开路”记反。我教你们一个**永远不会记混的物理判据**：
- **把独立电压源“置零”** $\implies$ 强制其两端电压 $v_s = 0\text{ V}$，但允许任意电流通过 $\implies$ 两端电位相等 $\implies$ **理想导线（短路，Short Circuit）**！
- **把独立电流源“置零”** $\implies$ 强制其支路电流 $i_s = 0\text{ A}$，但允许两端存在任意电压 $\implies$ 支路完全断流 $\implies$ **断开导线（开路，Open Circuit）**！

> **反证记忆法**：如果你把电压源“开路”了，断口两端会有电压，并没有让 $v=0$；如果你把电流源“短路”了，短路线里会流过电流，并没有让 $i=0$！

### 2.3 三段式教授板书推导

#### ① 公理溯源（Origin）
在线性电路的节点方程 $\mathbf{G}\mathbf{v} = \mathbf{i}_s$ 中，右侧的激励向量可以拆分为各个独立源的贡献之和：$\mathbf{i}_s = \mathbf{i}_{s1} + \mathbf{i}_{s2} + \cdots + \mathbf{i}_{sN}$。为了单独求解第 $k$ 个独立源对应的分量 $\mathbf{v}^{(k)} = \mathbf{G}^{-1}\mathbf{i}_{sk}$，我们必须保持左侧电导矩阵 $\mathbf{G}$ 的拓扑结构不变，仅令其余所有独立源的输出值为 $0$：
- 独立电压源输出 $v_s = 0$，其伏安特性退化为 $v = 0$（对任意 $i$），物理实现就是一根**零电阻短路线**。
- 独立电流源输出 $i_s = 0$，其伏安特性退化为 $i = 0$（对任意 $v$），物理实现就是一个**无穷大电阻断口（开路）**。
- **为什么受控源不能动？** 因为受控源的激励与电路内部未知变量成正比（如 $2i_x$），它在方程中属于**左侧矩阵 $\mathbf{G}$ 的一部分**，而非右侧独立激励 $\mathbf{i}_s$。一旦把受控源置零，你就篡改了矩阵 $\mathbf{G}$ 本身，拆出来的根本不是原来的电路！

#### ② 纯符号通式（General Formula）
对图 2 所示的双独立源网络（$V_s$ 与 $R_1$ 串联，$R_2$ 与 $I_s$ 并联），叠加定理三步法给出任意支路电压 $v$ 与电流 $i$ 的纯符号分解式：

$$
v = v' + v'', \qquad i = i' + i''
$$

- **子电路 1（仅保留 $V_s$，$I_s$ 开路）**：$R_1$ 与 $R_2$ 串联分压
  $$v' = V_s\,\frac{R_2}{R_1 + R_2}, \qquad i' = \frac{V_s}{R_1 + R_2}$$
- **子电路 2（仅保留 $I_s$，$V_s$ 短路）**：$R_1$ 与 $R_2$ 并联分流
  $$i'' = I_s\,\frac{R_1}{R_1 + R_2}, \qquad v'' = i'' R_2 = I_s\,\frac{R_1 R_2}{R_1 + R_2}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
叠加定理标准**三步法口诀**（请刻进肌肉记忆）：
1. **Step 1（关机留一）**：每次只保留 **1 个独立源**工作，将所有其余**独立电压源短路**、**独立电流源开路**，**所有受控源原位保留**。
2. **Step 2（分别求解）**：利用串并联、分压分流或节点法，算出该子电路下目标电压/电流的分量（务必标注与原电路完全一致的参考极性/方向！）。
3. **Step 3（代数累加）**：对所有独立源重复上述两步，将各分量**带符号代数相加**，得到最终电压或电流。

### 3.3 三段式教授板书推导

#### ① 公理溯源（Origin）
本电路仅含定值电阻 $R_1, R_2$ 与两个独立源 $V_s, I_s$，严格满足线性条件。将节点 $v$ 处电压拆分为 $V_s$ 单独作用时的 $v'$ 与 $I_s$ 单独作用时的 $v''$，两者参考极性均取“上正下负”，电流 $i', i''$ 参考方向均取“向下流过 $R_2$”。

#### ② 纯符号通式（General Formula）

$$
v = v' + v'' = V_s\,\frac{R_2}{R_1 + R_2} + I_s\,\frac{R_1 R_2}{R_1 + R_2}
$$

$$
i = i' + i'' = \frac{V_s}{R_1 + R_2} + I_s\,\frac{R_1}{R_1 + R_2}
$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
已知 $V_s = 6\text{ V}$，$I_s = 3\text{ A}$，$R_1 = 8\ \Omega$，$R_2 = 4\ \Omega$：

1. **子电路 1（仅保留 $6\text{ V}$ 电压源，$3\text{ A}$ 电流源开路）**：
   $$v' = 6 \times \frac{4}{8 + 4} = 6 \times \frac{4}{12} = 2\text{ V}$$
   $$i' = \frac{v'}{4} = \frac{2}{4} = 0.5\text{ A} \quad (\text{向下})$$

2. **子电路 2（仅保留 $3\text{ A}$ 电流源，$6\text{ V}$ 电压源短路）**：
   此时 $8\ \Omega$ 与 $4\ \Omega$ 并联，用并联分流公式求流过 $4\ \Omega$ 的电流 $i''$：
   $$i'' = 3 \times \frac{8}{8 + 4} = 3 \times \frac{8}{12} = 2\text{ A} \quad (\text{向下})$$
   $$v'' = i'' \times 4 = 2 \times 4 = 8\text{ V}$$

3. **代数叠加总解**：
   $$v = v' + v'' = 2 + 8 = 10\text{ V}$$
   $$i = i' + i'' = 0.5 + 2 = 2.5\text{ A}$$

4. **用节点分析法（W2-L1）交叉验算**：
   对原电路顶节点列写 KCL：
   $$\frac{v - 6}{8} + \frac{v}{4} = 3 \implies (v - 6) + 2v = 24 \implies 3v = 30 \implies v = 10\text{ V}, \quad i = \frac{10}{4} = 2.5\text{ A}$$
   结果分毫不差！

## 第 4 幕：禁区警告（一）——受控源绝不置零！含受控源的叠加实战

### 4.1 教授敲黑板：为什么受控源是“不可触碰的菱形”？
> **头号高频错题警告**：考场上超过 40% 的丢分，源于学生看见菱形受控源（例如 $2i_x$）也顺手把它“开路”或“短路”了！

请记住：**叠加定理只对独立源（圆形符号）动手术，对受控源（菱形符号）绝对禁止置零！** 因为受控源不是外部独立能源，而是电路内部的线性放大/耦合元件（比如晶体管或运放模型）。在每个子电路里，受控源都要**原封不动地留在原地**，只是它的控制量会随之变成该子电路对应的分量（例如从 $2i_x$ 变为 $2i_x'$ 和 $2i_x''$）。

### 4.3 三段式教授板书推导

#### ① 公理溯源（Origin）
设顶节点电压为 $v$，中间支路 $R_2$ 向下流过的控制电流为 $i_x = v/R_2$，流控电流源（CCCS）$\beta i_x$ 向下流出顶节点。对原电路列写 KCL：

$$\frac{v - V_s}{R_1} + \frac{v}{R_2} + \beta\frac{v}{R_2} = I_s \implies \left(\frac{1}{R_1} + \frac{1 + \beta}{R_2}\right)v = \frac{V_s}{R_1} + I_s$$

看清左侧括号了吗？受控源系数 $\beta$ 直接融进了等效电导 $G_{\text{eq}} = \frac{1}{R_1} + \frac{1+\beta}{R_2}$ 中！因此拆分独立源 $V_s$ 和 $I_s$ 时，左侧的 $G_{\text{eq}}$ 必须保持不变，受控源 $\beta i_x$ 绝不可置零。

#### ② 纯符号通式（General Formula）
保留受控源 $\beta i_x$，分别求两个独立源的分量：

$$
v' = \frac{V_s / R_1}{\dfrac{1}{R_1} + \dfrac{1 + \beta}{R_2}}, \qquad v'' = \frac{I_s}{\dfrac{1}{R_1} + \dfrac{1 + \beta}{R_2}}
$$

$$
v = v' + v'', \qquad i_x = i_x' + i_x'' = \frac{v'}{R_2} + \frac{v''}{R_2}
$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
已知 $V_s = 16\text{ V}$，$I_s = 6\text{ A}$（向上），$R_1 = 4\ \Omega$，$R_2 = 4\ \Omega$，受控电流源 $2i_x$（向下，即 $\beta = 2$）：

1. **子电路 1（仅保留 $16\text{ V}$，$6\text{ A}$ 开路，保留 $2i_x'$）**：
   因为 $i_x' = \dfrac{v'}{4}$，对顶节点列写 KCL：
   $$\frac{v' - 16}{4} + \frac{v'}{4} + 2\left(\frac{v'}{4}\right) = 0 \implies \frac{4v' - 16}{4} = 0 \implies v' = 4\text{ V}$$
   $$i_x' = \frac{v'}{4} = \frac{4}{4} = 1\text{ A}$$

2. **子电路 2（仅保留 $6\text{ A}$，$16\text{ V}$ 短路，保留 $2i_x''$）**：
   因为 $i_x'' = \dfrac{v''}{4}$，对顶节点列写 KCL：
   $$\frac{v''}{4} + \frac{v''}{4} + 2\left(\frac{v''}{4}\right) = 6 \implies \frac{4v''}{4} = 6 \implies v'' = 6\text{ V}$$
   $$i_x'' = \frac{v''}{4} = \frac{6}{4} = 1.5\text{ A}$$

3. **代数叠加总解**：
   $$v = v' + v'' = 4 + 6 = 10\text{ V}, \qquad i_x = i_x' + i_x'' = 1 + 1.5 = 2.5\text{ A}$$

4. **反面教材警示（若误把 $2i_x$ 开路置零）**：
   错误子电路 1 会算出 $v_{\text{err}}' = 8\text{ V}$，错误子电路 2 会算出 $v_{\text{err}}'' = 12\text{ V}$，得到荒谬的 $v_{\text{err}} = 20\text{ V}$（整整大了一倍！）。记住：**菱形受控源，永远锁死在原地！**

### 5.3 三段式教授板书推导

#### ① 公理溯源（Origin）
电阻吸收的瞬时功率 $p = i^2 R = \dfrac{v^2}{R}$ 是电流或电压的**二次函数（Quadratic Function）**。二次函数 $f(x) = Rx^2$ 既不满足齐次性（$f(kx) = k^2 f(x) \neq kf(x)$），也不满足可加性（$f(x_1+x_2) \neq f(x_1)+f(x_2)$）。因此，**求功率时必须先用叠加定理求出总电流 $i$（或总电压 $v$），最后再平方求功率**。

#### ② 纯符号通式（General Formula）

$$
p = i^2 R = (i_1 + i_2)^2 R = i_1^2 R + i_2^2 R + 2 i_1 i_2 R = p_1 + p_2 + 2 i_1 i_2 R \neq p_1 + p_2
$$

等价的电压展开式：

$$
p = \frac{(v_1 + v_2)^2}{R} = \frac{v_1^2}{R} + \frac{v_2^2}{R} + \frac{2 v_1 v_2}{R} = p_1 + p_2 + \frac{2 v_1 v_2}{R} \neq p_1 + p_2
$$

> **唯一例外（思考题）**：只有当 $i_1 = 0$ 或 $i_2 = 0$（某独立源对该电阻毫无贡献）时，交叉项 $2i_1 i_2 R = 0$，功率才会碰巧等于 $p_1 + p_2$（在交流稳态里，若两电源频率不同，平均功率也可叠加，那是后续周次的精彩故事）。

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
1. **反例 A（第 3 幕 Sadiku 4.3 电路，$R_2 = 4\ \Omega$）**：
   - 分量功率：$p_1 = i_1^2 R_2 = (0.5)^2 \times 4 = 1\text{ W}$，$p_2 = i_2^2 R_2 = 2^2 \times 4 = 16\text{ W}$。
   - 错误直接相加：$p_{\text{wrong}} = p_1 + p_2 = 1 + 16 = 17\text{ W}$。
   - **正确真实功率**：先得总电流 $i = 0.5 + 2 = 2.5\text{ A}$，再计算：
     $$p_{\text{true}} = i^2 R_2 = (2.5)^2 \times 4 = 6.25 \times 4 = 25\text{ W}$$
   - 交叉项核验：$2 i_1 i_2 R_2 = 2 \times 0.5 \times 2 \times 4 = +8\text{ W}$，正好满足 $17 + 8 = 25\text{ W}$！

2. **反例 B（反向抵消电路，$R_2 = 2\ \Omega$，$i_1 = +3\text{ A}$，$i_2 = -2\text{ A}$）**：
   - 分量功率：$p_1 = 3^2 \times 2 = 18\text{ W}$，$p_2 = (-2)^2 \times 2 = 8\text{ W}$；错误直接相加高达 $26\text{ W}$！
   - **正确真实功率**：总电流 $i = 3 + (-2) = 1\text{ A}$，真实功率仅：
     $$p_{\text{true}} = 1^2 \times 2 = 2\text{ W}$$
   - 交叉项核验：$2 i_1 i_2 R_2 = 2 \times 3 \times (-2) \times 2 = -24\text{ W}$，$26 - 24 = 2\text{ W}$！两股反向水流互相抵消，耗散功率反而比单独开任何一个电源都小！
