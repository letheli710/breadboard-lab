# W5-L5：瞬时功率、平均功率、有效值（RMS）与交流最大功率传输

> **教授开场白**
> 欢迎回到 Breadboard Lab！前两周我们已经把交流电路的“语法”打通了——相量、阻抗、以及上一讲（`W5-L4`）的交流戴维南等效。但工程师造电路绝不是为了把电压电流算出来摆在纸面上欣赏的，我们的终极目标永远是**能量的搬运与做功**。
>
> 在直流电路里，功率简单得像小学生乘法：$P = VI$。可一旦换上正弦交流电，电压和电流每秒钟翻转一百次，还常常“步调不一致”（存在相位差）。此时你可能会立刻冒出三个灵魂拷问：
> 1. 电压和电流时正时负，交流功率是不是忽正忽负？**“负功率”到底意味着什么？**
> 2. 墙上插座写着 **120 V**（北美）或 **220 V**（中国），电压明明在剧烈波动，这个定值到底是怎么定义出来的？
> 3. 回想 `W2-L8` 直流电路里“$R_L = R_{Th}$ 时负载获得最大功率”，到了交流电路，负载变成了复阻抗 $\mathbf{Z}_L = R_L + jX_L$，难道是 $\mathbf{Z}_L = \mathbf{Z}_{Th}$ 吗？**大错特错！** 今天我们要揭晓工程界最优雅的匹配法则——**共轭匹配**。
>
> 打开你左侧的 **2D 示波器工作台**，我们一幕一幕把交流功率的底细看透！

## 第 1 幕：瞬时功率的二倍频脉动与能量回流

### 1.1 物理图景：为什么功率会以 $2\omega$ 脉动，还会掉进“负区”？

打开左侧示波器 **Layer 01（三曲线同屏示波器）**。假设一个线性交流单口网络两端电压为 $v(t) = V_m \cos(\omega t + \theta_v)$，流入端口的电流为 $i(t) = I_m \cos(\omega t + \theta_i)$（遵循关联参考方向）。

在任意瞬时 $t$，网络吸收的**瞬时功率** $p(t) = v(t)i(t)$ 并不是恒定值，而是由两股力量叠加而成：
1. **一个恒定不变的直流偏置项**：$\frac{1}{2} V_m I_m \cos(\theta_v - \theta_i)$，它决定了整个周期净吸收的平均功率；
2. **一个以二倍角频率 $2\omega$ 剧烈振荡的正弦项**：$\frac{1}{2} V_m I_m \cos(2\omega t + \theta_v + \theta_i)$。为什么频率翻倍？因为在一个电源周期 $T$ 内，电压和电流同为正时乘积为正，同为负时“负负得正”乘积依然为正——功率在一个周期里完成了**两次完整的起伏**！

最精彩的是图中的**红色阴影区（$p(t) < 0$）**：当电压和电流存在相位差（$\theta_v \neq \theta_i$）时，每个半周里都会有短暂的瞬间出现 **$v(t)$ 与 $i(t)$ 异号**，导致 $p(t) < 0$。
- **$p(t) > 0$**：电源把能量输送给负载（电阻发热，或者电感/电容正在“充电蓄能”）；
- **$p(t) < 0$**：**能量倒流！** 负载里的电感磁场或电容电场把先前储存的能量**原路送回电源**。记住 Boylestad 教材里的经典比喻：电阻是“只进不出的单向黑洞”，而电感和电容是“借了还要还的弹簧”。

### 1.2 三段式教授板书推导：瞬时功率分解

#### ① 公理溯源
根据关联参考方向下的瞬时电功率定义及三角积化和差恒等式：
$$p(t) = v(t)\,i(t)$$
$$\cos A \cos B = \frac{1}{2}\big[\cos(A - B) + \cos(A + B)\big]$$

#### ② 纯符号通式
设端口正弦稳态电压与电流分别为：
$$v(t) = V_m \cos(\omega t + \theta_v), \qquad i(t) = I_m \cos(\omega t + \theta_i)$$
令 $A = \omega t + \theta_v$、$B = \omega t + \theta_i$，则 $A - B = \theta_v - \theta_i$，$A + B = 2\omega t + \theta_v + \theta_i$。代入积化和差恒等式，立即得到**瞬时功率基本公式**（Alexander & Sadiku Eq. 11.4）：
$$p(t) = \underbrace{\frac{1}{2} V_m I_m \cos(\theta_v - \theta_i)}_{\text{恒定分量（平均功率 } P \text{）}} + \underbrace{\frac{1}{2} V_m I_m \cos(2\omega t + \theta_v + \theta_i)}_{\text{二倍频脉动分量（频率 } 2\omega \text{）}}$$
由通式可直接读出瞬时功率的上下极值边界：
$$p_{\max} = \frac{1}{2} V_m I_m \big[\cos(\theta_v - \theta_i) + 1\big], \qquad p_{\min} = \frac{1}{2} V_m I_m \big[\cos(\theta_v - \theta_i) - 1\big]$$

#### ③ 代入数值逐步化简
设某感性负载两端电压与电流为：
$$v(t) = 120\cos(377t + 45^\circ)\text{ V}, \qquad i(t) = 10\cos(377t - 15^\circ)\text{ A}$$
提取纯数值参数：$V_m = 120\text{ V}$，$I_m = 10\text{ A}$，$\theta_v = 45^\circ$，$\theta_i = -15^\circ$，$\omega = 377\text{ rad/s}$。
1. 计算相位差与相位和：
   $$\theta_v - \theta_i = 45^\circ - (-15^\circ) = 60^\circ, \qquad \theta_v + \theta_i = 45^\circ + (-15^\circ) = 30^\circ$$
2. 计算系数 $\frac{1}{2} V_m I_m$：
   $$\frac{1}{2} V_m I_m = \frac{1}{2} \times 120 \times 10 = 600\text{ VA}$$
3. 代入瞬时功率通式：
   $$p(t) = 600\cos(60^\circ) + 600\cos(2 \times 377t + 30^\circ) = 300 + 600\cos(754t + 30^\circ)\text{ W}$$
4. 检验极值与回流区间：
   $$p_{\max} = 300 + 600 = +900\text{ W}, \qquad p_{\min} = 300 - 600 = -300\text{ W}$$
   可见瞬时功率在 $+900\text{ W}$ 与 $-300\text{ W}$ 之间以 $2\omega = 754\text{ rad/s}$ 剧烈脉动，确实存在明显的 $p(t) < 0$ 负功率回流区间！

## 第 2 幕：平均功率（有功功率）与 R / L / C 元件的功率画像

### 2.1 物理图景：电表到底在计量什么？

电费账单不会按瞬时功率每毫秒跳动来收钱，机械瓦特表和数字电表测量的都是瞬时功率在一个周期 $T$ 内的**时间平均值**——这就是**平均功率（Average Power / Active Power）$P$**，单位瓦特（$\text{W}$）。

因为二倍频脉动项 $\frac{1}{2}V_m I_m \cos(2\omega t + \theta_v + \theta_i)$ 在一个周期 $T$ 内正好完成了两次完整的正负对称起伏，它的周期积分**严格为零**！真正留下来做净功的，只有第一项恒定偏置。

把左侧示波器 **Layer 01** 的相位差滑块依次拖到 $0^\circ$、$+90^\circ$ 和 $-90^\circ$，你会看到三类基本理想元件截然不同的“功率人格”：
- **纯电阻 $R$（$\theta_v - \theta_i = 0^\circ$）**：电压与电流完全同相，$p(t)$ 永远不小于零，没有任何回流阴影，能量 100% 不可逆地转化为焦耳热；
- **纯电感 $L$（$\theta_v - \theta_i = +90^\circ$）**：电压超前电流 $90^\circ$，$p(t)$ 围绕零轴上下对称摆动，前半个四分之一周期建立磁场吸能，后半个四分之一周期磁场塌缩全额退还，**平均功率恒为 $0\text{ W}$**；
- **纯电容 $C$（$\theta_v - \theta_i = -90^\circ$）**：电流超前电压 $90^\circ$，同样在电场中周期性吞吐能量，**平均功率也恒为 $0\text{ W}$**。

### 2.2 三段式教授板书推导：平均功率与相量表达

#### ① 公理溯源
周期信号的平均功率定义为一周期内的时间平均积分：
$$P = \frac{1}{T}\int_0^T p(t)\,dt$$

#### ② 纯符号通式
将第 1 幕导出的 $p(t)$ 代入积分：
$$P = \frac{1}{T}\int_0^T \frac{1}{2} V_m I_m \cos(\theta_v - \theta_i)\,dt + \frac{1}{T}\int_0^T \frac{1}{2} V_m I_m \cos(2\omega t + \theta_v + \theta_i)\,dt$$
因为 $\omega T = 2\pi$，第二项在 $[0, T]$ 上积分跨越两个完整余弦周期，其值为 $0$，于是得到**交流平均功率核心公式**（Alexander & Sadiku Eq. 11.8）：
$$P = \frac{1}{2} V_m I_m \cos(\theta_v - \theta_i) = \frac{1}{2}\,\text{Re}\big[\mathbf{V}\mathbf{I}^*\big]$$
对三类理想无源元件分别代入阻抗角 $\theta_Z = \theta_v - \theta_i$：
- 纯电阻（$\theta_v - \theta_i = 0^\circ$）：$P_R = \frac{1}{2} V_m I_m = \frac{1}{2} I_m^2 R = \frac{V_m^2}{2R}$；
- 纯电感（$\theta_v - \theta_i = +90^\circ$）：$P_L = \frac{1}{2} V_m I_m \cos(+90^\circ) = 0\text{ W}$；
- 纯电容（$\theta_v - \theta_i = -90^\circ$）：$P_C = \frac{1}{2} V_m I_m \cos(-90^\circ) = 0\text{ W}$。

#### ③ 代入数值逐步化简
已知某两端口元件两端相量电压 $\mathbf{V} = 100\angle 30^\circ\text{ V}$（峰值相量），串联阻抗 $\mathbf{Z} = 6 + j8\ \Omega$，求该网络吸收的平均功率 $P$。
1. 先求阻抗极坐标形式与电流峰值相量 $\mathbf{I}$：
   $$|\mathbf{Z}| = \sqrt{6^2 + 8^2} = 10\ \Omega, \qquad \theta_Z = \arctan\!\left(\frac{8}{6}\right) \approx 53.13^\circ$$
   $$\mathbf{I} = \frac{\mathbf{V}}{\mathbf{Z}} = \frac{100\angle 30^\circ}{10\angle 53.13^\circ} = 10\angle -23.13^\circ\text{ A}$$
2. 代入平均功率公式（方法一：角度法）：
   $$P = \frac{1}{2} V_m I_m \cos(\theta_v - \theta_i) = \frac{1}{2} \times 100 \times 10 \times \cos(53.13^\circ) = 500 \times 0.6 = 300\text{ W}$$
3. 交叉校验（方法二：仅电阻耗功法）：
   因为纯电感 $j8\ \Omega$ 平均功率恒为 $0\text{ W}$，全部平均功率必由 $R = 6\ \Omega$ 消耗：
   $$P = \frac{1}{2} I_m^2 R = \frac{1}{2} \times 10^2 \times 6 = 300\text{ W}$$
   两种方法严丝合缝！

## 第 3 幕：有效值（RMS）的热效应定义与家用市电解密

### 3.1 物理图景：为什么需要一个“等效直流值”？

现在切换到左侧舞台 **Layer 02（交流热效应等效 RMS 面积演示台）**。
假如你买了一台电热水壶，铭牌上写着“220 V”。但交流电一秒钟有 100 次过零点，平均值明明是 $0\text{ V}$！工程师要怎么用一个**单一实数**来衡量交流电的“烧水本领”？

答案就是**焦耳热等效思想**（Boylestad Ch. 19 核心直觉）：
> 把同一只电阻 $R$ 分别接到周期交流电流 $i(t)$ 和恒定直流电流 $I_{\text{eff}}$ 上。如果在一个完整周期 $T$ 内，两者在电阻 $R$ 上**发出的热量完全相等**，那么这个等效直流值 $I_{\text{eff}}$ 就称为交流电的**有效值（Effective Value）**，从数学运算顺序（先平方、再求平均、最后开根号）又称为 **均方根值（RMS, Root-Mean-Square）**。

看看右侧的面积演示图：正弦平方波 $i^2(t) = I_m^2 \cos^2(\omega t)$ 在 $0$ 和 $I_m^2$ 之间上下起伏，而如果把高于中线 $\frac{1}{2}I_m^2$ 的“波峰”一刀切下来，**严丝合缝地填进下面的“波谷”**，正好拼出一个高为 $\frac{1}{2}I_m^2$ 的水平矩形！因此正弦波的有效值满足 $I_{\text{rms}}^2 = \frac{1}{2}I_m^2$，开根号即得 $I_{\text{rms}} = \frac{I_m}{\sqrt{2}} \approx 0.707\,I_m$。

> **生活安全警示**：
> 北美家用插座标称 **120 V**、中国家用插座标称 **220 V**，**全部都是 RMS 有效值**！它们在每个周期内冲到的真实峰值电压分别高达 **$120\sqrt{2} \approx 169.7\text{ V} \approx 170\text{ V}$** 和 **$220\sqrt{2} \approx 311.1\text{ V} \approx 311\text{ V}$**！选型整流桥或滤波电容耐压时，如果你按 220 V 选了一颗 250 V 耐压的电容，通电瞬间就会被 311 V 的波峰直接击穿炸裂！

### 3.2 三段式教授板书推导：RMS 定义与功率公式改写

#### ① 公理溯源
周期交流电流 $i(t)$ 与等效直流电流 $I_{\text{eff}}$ 在电阻 $R$ 上一个周期 $T$ 内消耗的平均功率（焦耳热）相等：
$$P_{\text{ac}} = \frac{1}{T}\int_0^T i^2(t)\,R\,dt = I_{\text{eff}}^2\,R = P_{\text{dc}}$$

#### ② 纯符号通式
两边消去非零电阻 $R$ 并开算术平方根，得到**任意周期信号的有效值通用定义**（Alexander & Sadiku Eq. 11.24）：
$$I_{\text{rms}} = I_{\text{eff}} = \sqrt{\frac{1}{T}\int_0^T i^2(t)\,dt}, \qquad V_{\text{rms}} = \sqrt{\frac{1}{T}\int_0^T v^2(t)\,dt}$$
对正弦波 $i(t) = I_m \cos(\omega t + \theta_i)$（其中 $\omega = \frac{2\pi}{T}$），利用降幂公式 $\cos^2\alpha = \frac{1}{2}(1 + \cos 2\alpha)$：
$$I_{\text{rms}} = \sqrt{\frac{I_m^2}{T}\int_0^T \frac{1 + \cos(2\omega t + 2\theta_i)}{2}\,dt} = \sqrt{\frac{I_m^2}{2}} = \frac{I_m}{\sqrt{2}} \approx 0.7071\,I_m$$
同理 $V_{\text{rms}} = \frac{V_m}{\sqrt{2}}$。将其代回平均功率公式 $P = \frac{1}{2}V_m I_m \cos(\theta_v - \theta_i)$，恼人的系数 $\frac{1}{2}$ 瞬间消失：
$$P = \frac{V_m}{\sqrt{2}}\cdot\frac{I_m}{\sqrt{2}}\cos(\theta_v - \theta_i) = V_{\text{rms}}\,I_{\text{rms}}\cos(\theta_v - \theta_i)$$

#### ③ 代入数值逐步化简
1. **家用市电峰值换算**：
   - 北美市电：$V_{\text{rms}} = 120\text{ V} \implies V_m = 120\sqrt{2} \approx 169.71\text{ V} \approx 170\text{ V}$；
   - 中国市电：$V_{\text{rms}} = 220\text{ V} \implies V_m = 220\sqrt{2} \approx 311.13\text{ V} \approx 311\text{ V}$。
2. **用 RMS 值直接复算第 1 幕功率**：
   已知 $V_m = 120\text{ V}$，$I_m = 10\text{ A}$，$\theta_v - \theta_i = 60^\circ$：
   $$V_{\text{rms}} = \frac{120}{\sqrt{2}} = 60\sqrt{2}\text{ V} \approx 84.85\text{ V}, \qquad I_{\text{rms}} = \frac{10}{\sqrt{2}} = 5\sqrt{2}\text{ A} \approx 7.07\text{ A}$$
   $$P = V_{\text{rms}}\,I_{\text{rms}}\cos(60^\circ) = (60\sqrt{2})(5\sqrt{2})(0.5) = 600 \times 0.5 = 300\text{ W}$$

## 第 4 幕：非正弦周期波与 DC + AC 混合信号的 RMS 实战

### 4.1 物理图景：别把 $/\sqrt{2}$ 当成万金油！

很多初学者最容易犯的错误，就是看见任何周期波形都条件反射地除以 $\sqrt{2}$。**大错特错！**
- 系数 $1/\sqrt{2} \approx 0.707$ **只属于纯正弦波**；
- 如果是**对称方波**（在 $+V_p$ 和 $-V_p$ 之间跳变），平方后恒等于 $V_p^2$，所以 $V_{\text{rms}} = V_p$；
- 如果是**对称三角波**或**锯齿波**，波峰尖瘦，能量占比低，积分得出 $V_{\text{rms}} = \frac{V_p}{\sqrt{3}} \approx 0.577\,V_p$；
- 更常见于开关电源纹波与放大器偏置的，是 **DC + AC 混合信号** $v(t) = V_{dc} + V_{1m}\cos(\omega t)$。因为直流分量与交流正弦分量在一个周期内**互相正交**（交叉乘积项积分严格为 $0$），它们的总有效值服从**能量勾股定理**：
  $$V_{\text{rms}} = \sqrt{V_{dc}^2 + V_{1,\text{rms}}^2}$$
  **绝不是**简单相加 $V_{dc} + V_{1,\text{rms}}$！

### 4.2 三段式教授板书推导：DC+AC 正交叠加与三角波积分

#### ① 公理溯源
均方根值的普遍积分定义对一切周期 $T$ 的可积波形均成立：
$$V_{\text{rms}} = \sqrt{\frac{1}{T}\int_0^T v^2(t)\,dt}$$

#### ② 纯符号通式
1. **DC + AC 混合波** $v(t) = V_{dc} + V_{1m}\cos(\omega t)$（其中 $\omega = \frac{2\pi}{T}$）：
   $$V_{\text{rms}}^2 = \frac{1}{T}\int_0^T \Big[V_{dc}^2 + 2 V_{dc} V_{1m}\cos(\omega t) + V_{1m}^2\cos^2(\omega t)\Big]\,dt$$
   中间交叉项 $\frac{1}{T}\int_0^T 2 V_{dc} V_{1m}\cos(\omega t)\,dt = 0$，第三项平均值为 $\frac{1}{2}V_{1m}^2 = V_{1,\text{rms}}^2$，故：
   $$V_{\text{rms}} = \sqrt{V_{dc}^2 + \frac{1}{2}V_{1m}^2} = \sqrt{V_{dc}^2 + V_{1,\text{rms}}^2}$$
2. **对称三角波**（峰值为 $V_p$，在 $[0, T/4]$ 上线性上升 $v(t) = \frac{4V_p}{T}t$，四个四分之一周期平方对称）：
   $$V_{\text{rms}} = \sqrt{\frac{4}{T}\int_0^{T/4} \left(\frac{4V_p}{T}t\right)^2 dt} = \sqrt{\frac{64 V_p^2}{T^3}\left[\frac{t^3}{3}\right]_0^{T/4}} = \sqrt{\frac{V_p^2}{3}} = \frac{V_p}{\sqrt{3}} \approx 0.5774\,V_p$$

#### ③ 代入数值逐步化简
设某直流电源输出端带有交流纹波：$v(t) = 12 + 5\sqrt{2}\cos(377t)\text{ V}$，求其真有效值 $V_{\text{rms}}$。
1. 拆解直流与交流有效值分量：
   $$V_{dc} = 12\text{ V}, \qquad V_{1m} = 5\sqrt{2}\text{ V} \implies V_{1,\text{rms}} = \frac{5\sqrt{2}}{\sqrt{2}} = 5\text{ V}$$
2. 代入正交叠加通式（经典 5-12-13 勾股数组）：
   $$V_{\text{rms}} = \sqrt{12^2 + 5^2} = \sqrt{144 + 25} = \sqrt{169} = 13\text{ V}$$
   （对比常见误算：$12 + 5 = 17\text{ V}$ 是完全错误的；若该信号加在 $13\ \Omega$ 电阻上，平均功率为 $P = \frac{V_{\text{rms}}^2}{R} = \frac{13^2}{13} = 13\text{ W}$。）

## 第 5 幕：交流最大平均功率传输定理——共轭匹配 $\mathbf{Z}_L = \mathbf{Z}_{Th}^*$

### 5.1 物理图景：回链 `W2-L8` 与 `W5-L4`，为什么必须“共轭”？

切换到左侧舞台 **Layer 03（交流共轭匹配功率峰值台）**。
回想我们在 `W2-L8` 学过的直流最大功率传输定理：把负载左侧的复杂网络化简为戴维南等效（$V_{Th}, R_{Th}$），当 $R_L = R_{Th}$ 时负载获得最大功率 $P_{\max} = \frac{V_{Th}^2}{4 R_{Th}}$。

现在到了交流稳态电路，借助上一讲 `W5-L4` 的**交流戴维南等效**，任意线性含源网络在端口 $a\text{--}b$ 处都可化简为一个相量电压源 $\mathbf{V}_{Th}$ 串联一个复阻抗 $\mathbf{Z}_{Th} = R_{Th} + jX_{Th}$，右接可调复负载 $\mathbf{Z}_L = R_L + jX_L$。

想让负载电阻 $R_L$ 吃到的平均功率 $P$ 达到最大，分两步直觉思考就豁然开朗：
1. **第一步（消除路障）**：电抗部分 $j(X_{Th} + X_L)$ 既不做功（纯储能元件平均功率为 $0$），又白白增大回路总阻抗、拖小电流！怎样让它彻底消失？只需让负载电抗与内电抗**大小相等、符号相反**：$X_L = -X_{Th}$。此时感抗与容抗互相抵消，回路进入**串联谐振**！
2. **第二步（回到 `W2-L8`）**：一旦电抗清零，整个交流回路就退化成了一个纯电阻分压回路，此时只需让电阻相等 $R_L = R_{Th}$，负载就能榨取出理论最大平均功率！

合二为一，这就是射频、通信与天线匹配的核心法则——**复共轭匹配（Conjugate Matching）**：
$$\mathbf{Z}_L = \mathbf{Z}_{Th}^* = R_{Th} - jX_{Th}$$

> **铁血防坑警报：分母 8 还是分母 4？**
> - 若 $\mathbf{V}_{Th}$ 是**峰值（幅值）相量**（如 $v_{Th}(t) = V_m \cos(\omega t + \phi) \leftrightarrow \mathbf{V}_{Th} = V_m\angle\phi$），则：
>   $$P_{\max} = \frac{|\mathbf{V}_{Th}|^2}{8 R_{Th}}$$
> - 若 $\mathbf{V}_{Th}$ 已经标明是 **RMS 有效值相量**（$V_{Th,\text{rms}} = |\mathbf{V}_{Th}|/\sqrt{2}$），则：
>   $$P_{\max} = \frac{V_{Th,\text{rms}}^2}{4 R_{Th}}$$
> 考试中一半以上的丢分，都源于把峰值相量错代进了分母 $4$，或者把 RMS 相量错代进了分母 $8$！

### 5.2 三段式教授板书推导：二元偏导极值与双分母关系

#### ① 公理溯源
在交流戴维南等效回路中，负载电流峰值相量为 $\mathbf{I} = \frac{\mathbf{V}_{Th}}{\mathbf{Z}_{Th} + \mathbf{Z}_L}$，只有负载实部电阻 $R_L$ 消耗平均功率：
$$P = \frac{1}{2}|\mathbf{I}|^2 R_L$$

#### ② 纯符号通式
将 $\mathbf{Z}_{Th} = R_{Th} + jX_{Th}$ 与 $\mathbf{Z}_L = R_L + jX_L$ 代入平均功率表达式（以峰值相量 $|\mathbf{V}_{Th}|$ 记）：
$$P(R_L, X_L) = \frac{|\mathbf{V}_{Th}|^2 R_L}{2\big[(R_{Th} + R_L)^2 + (X_{Th} + X_L)^2\big]}$$
分别对独立变量 $X_L$ 和 $R_L$ 求一阶偏导并令其为零（Alexander & Sadiku Section 11.3）：
1. 对 $X_L$ 求偏导：
   $$\frac{\partial P}{\partial X_L} = \frac{-|\mathbf{V}_{Th}|^2 R_L (X_{Th} + X_L)}{\big[(R_{Th} + R_L)^2 + (X_{Th} + X_L)^2\big]^2} = 0 \implies X_L = -X_{Th}$$
2. 将 $X_L = -X_{Th}$ 代入 $P$ 后，再对 $R_L$ 求导：
   $$P(R_L, -X_{Th}) = \frac{|\mathbf{V}_{Th}|^2 R_L}{2(R_{Th} + R_L)^2}$$
   $$\frac{\partial P}{\partial R_L} = \frac{|\mathbf{V}_{Th}|^2 (R_{Th} - R_L)}{2(R_{Th} + R_L)^3} = 0 \implies R_L = R_{Th}$$
综合两式得**共轭匹配条件**：
$$\mathbf{Z}_L = R_L + jX_L = R_{Th} - jX_{Th} = \mathbf{Z}_{Th}^*$$
将 $R_L = R_{Th}, X_L = -X_{Th}$ 代回 $P$，结合 $V_{Th,\text{rms}} = \frac{|\mathbf{V}_{Th}|}{\sqrt{2}}$，得到**峰值相量 / RMS 相量双形式最大功率通式**：
$$P_{\max} = \frac{|\mathbf{V}_{Th}|^2}{8 R_{Th}} = \frac{V_{Th,\text{rms}}^2}{4 R_{Th}}$$

#### ③ 代入数值逐步化简
假设某射频功放输出端的戴维南等效为 $\mathbf{V}_{Th} = 16\angle 0^\circ\text{ V}$（峰值相量），$\mathbf{Z}_{Th} = 4 + j3\ \Omega$：
1. 求共轭匹配负载：
   $$\mathbf{Z}_L = \mathbf{Z}_{Th}^* = 4 - j3\ \Omega$$
   （即串联 $4\ \Omega$ 电阻与容抗 $-j3\ \Omega$，刚好抵消源端 $+j3\ \Omega$ 感抗。）
2. 用峰值相量公式（分母 $8$）计算：
   $$P_{\max} = \frac{16^2}{8 \times 4} = \frac{256}{32} = 8\text{ W}$$
3. 用 RMS 相量公式（分母 $4$）交叉验算：
   $$V_{Th,\text{rms}} = \frac{16}{\sqrt{2}} = 8\sqrt{2}\text{ V} \implies P_{\max} = \frac{(8\sqrt{2})^2}{4 \times 4} = \frac{128}{16} = 8\text{ W}$$

## 第 6 幕：综合实战——先求交流戴维南，再双轨验算共轭匹配

### 6.1 经典工程母题

在真实电路（或期末考试大题）里，题目绝不会直接把 $\mathbf{V}_{Th}$ 和 $\mathbf{Z}_{Th}$ 喂到你嘴边。你必须先执行 `W5-L4` 的**交流戴维南等效**，再无缝衔接本讲的**共轭匹配**。

> **实战例题**：如图所示频域电路中，独立正弦电源 $\mathbf{V}_s = 20\angle 0^\circ\text{ V}$（**峰值相量**），串联支路阻抗 $\mathbf{Z}_1 = 4 + j2\ \Omega$，并联支路为电容抗 $\mathbf{Z}_2 = -j4\ \Omega$，端口 $a\text{--}b$ 接入可调复负载 $\mathbf{Z}_L$。求：
> (1) 负载 $\mathbf{Z}_L$ 取何值时可获得最大平均功率？
> (2) 分别用**峰值相量公式（$/8$）**与**RMS 相量公式（$/4$）**双重校验最大平均功率 $P_{\max}$。

### 6.2 三段式教授板书推导：完整求解与双轨核验

#### ① 公理溯源
1. 交流戴维南定理：移去 $\mathbf{Z}_L$，独立源置零求端口输入阻抗 $\mathbf{Z}_{Th}$，恢复电源求端口开路电压 $\mathbf{V}_{Th}$；
2. 交流最大平均功率传输定理：$\mathbf{Z}_L = \mathbf{Z}_{Th}^* = R_{Th} - jX_{Th}$，且 $P_{\max} = \frac{|\mathbf{V}_{Th}|^2}{8 R_{Th}} = \frac{V_{Th,\text{rms}}^2}{4 R_{Th}}$。

#### ② 纯符号通式
$$\mathbf{Z}_{Th} = \mathbf{Z}_1 \parallel \mathbf{Z}_2 = \frac{\mathbf{Z}_1 \mathbf{Z}_2}{\mathbf{Z}_1 + \mathbf{Z}_2}, \qquad \mathbf{V}_{Th} = \mathbf{V}_s \cdot \frac{\mathbf{Z}_2}{\mathbf{Z}_1 + \mathbf{Z}_2}$$
$$\mathbf{Z}_L = \mathbf{Z}_{Th}^*, \qquad P_{\max} = \frac{|\mathbf{V}_{Th}|^2}{8\,\text{Re}(\mathbf{Z}_{Th})} = \frac{(|\mathbf{V}_{Th}|/\sqrt{2})^2}{4\,\text{Re}(\mathbf{Z}_{Th})}$$

#### ③ 代入数值逐步化简
1. **求戴维南阻抗 $\mathbf{Z}_{Th}$**（电源 $\mathbf{V}_s$ 短路置零，$\mathbf{Z}_1$ 与 $\mathbf{Z}_2$ 并联）：
   $$\mathbf{Z}_{Th} = \frac{(4 + j2)(-j4)}{(4 + j2) + (-j4)} = \frac{8 - j16}{4 - j2} = \frac{(8 - j16)(4 + j2)}{4^2 + 2^2} = \frac{32 + j16 - j64 + 32}{20} = \frac{64 - j48}{20} = 3.2 - j2.4\ \Omega$$
   由此提取实部电阻 $R_{Th} = 3.2\ \Omega$，虚部电抗 $X_{Th} = -2.4\ \Omega$（容性）。
2. **求共轭匹配负载 $\mathbf{Z}_L$**：
   $$\mathbf{Z}_L = \mathbf{Z}_{Th}^* = 3.2 + j2.4\ \Omega$$
   （负载必须呈**感性** $+j2.4\ \Omega$，恰好与戴维南等效容抗 $-j2.4\ \Omega$ 抵消！）
3. **求戴维南开路电压 $\mathbf{V}_{Th}$**（分压公式）：
   $$\mathbf{V}_{Th} = 20 \times \frac{-j4}{4 - j2} = \frac{-j80(4 + j2)}{20} = -j4(4 + j2) = 8 - j16\text{ V}$$
   计算模值与幅角：
   $$|\mathbf{V}_{Th}| = \sqrt{8^2 + (-16)^2} = \sqrt{64 + 256} = \sqrt{320} = 8\sqrt{5} \approx 17.89\text{ V}, \qquad \theta_{Th} = \arctan(-2) \approx -63.43^\circ$$
4. **双轨验算最大平均功率 $P_{\max}$**：
   - **路径 A（峰值相量，分母 $8 R_{Th}$）**：
     $$P_{\max} = \frac{|\mathbf{V}_{Th}|^2}{8 R_{Th}} = \frac{(8\sqrt{5})^2}{8 \times 3.2} = \frac{320}{25.6} = 12.5\text{ W}$$
   - **路径 B（RMS 相量，分母 $4 R_{Th}$）**：
     $$V_{Th,\text{rms}} = \frac{8\sqrt{5}}{\sqrt{2}} = 4\sqrt{10}\text{ V} \implies V_{Th,\text{rms}}^2 = 160\text{ V}^2$$
     $$P_{\max} = \frac{V_{Th,\text{rms}}^2}{4 R_{Th}} = \frac{160}{4 \times 3.2} = \frac{160}{12.8} = 12.5\text{ W}$$
   两条路径均精确给出 **$12.5\text{ W}$**，验证完毕！
