# W4-L1：电容的物理结构、微分伏安关系与电场储能

> **教授开场白**：欢迎进入第四周！前三周我们打交道的电阻是电路里的“耗能苦力”——电流一过，电能立刻变成热量散失，永远不会还给你。今天我们要认识第一位**储能元件（Energy-Storage Element）**：**电容（Capacitor）**。它不烧能量，它把电能存进两块金属板之间的**电场**里，需要时再还给电路。更迷人的是，它的电压和电流不再是简单的欧姆定律乘法关系，而是第一次把**微积分**请进了我们的电路方程。准备好了吗？我们从把一颗电容剥开来看开始。

## 第 1 幕：剥开电容——物理结构、弹性隔膜直觉与面包板极性铁律

**联动舞台**：`01 3D 瓷片/电解电容封装与面包板插法` & `02 3D 平行板剥壳与电场储能透视`

### 1.1 电容长什么样？物理公式从何而来

不管外观是土黄色扁片状的**瓷片电容（Ceramic Capacitor）**，还是黑蓝圆柱状的**铝电解电容（Aluminum Electrolytic Capacitor）**，拆到最里层，所有电容的本质都只有三样东西：**两块相互平行的导电金属极板**，加上中间夹着的一层**绝缘电介质（Dielectric）**。

当你在两块极板间加上电压 $v$ 时，电源就像一台“电荷搬运泵”：把一块极板上的电子抽走，搬到另一块极板上。于是上极板带正电 $+q$，下极板带负电 $-q$，两板之间建立起电场。实验证明，极板上储存的电荷量 $q$ 与两端电压 $v$ 成正比：

$$q = C v$$

比例系数 $C$ 就是**电容量（Capacitance）**，单位是**法拉（Farad, $\text{F}$）**，定义为 $1\ \text{F} = 1\ \text{C/V}$。由于 $1\ \text{F}$ 在普通电子电路中极其庞大，面包板上最常见的是微法（$1\ \mu\text{F} = 10^{-6}\ \text{F}$）、纳法（$1\ \text{nF} = 10^{-9}\ \text{F}$）和皮法（$1\ \text{pF} = 10^{-12}\ \text{F}$）。

对经典的平行板电容器而言，电容量完全由**几何尺寸**和**介质材料**决定（Sadiku Sec. 6.1）：

$$C = \frac{\varepsilon A}{d} = \frac{\varepsilon_r \varepsilon_0 A}{d}$$

其中：
- $A$ 是两极板的正对有效面积（$\text{m}^2$）——**面积越大，能停放电荷的“停车场”越大，$C$ 越大**；
- $d$ 是两极板之间的距离（$\text{m}$）——**距离越近，异种电荷相互吸引得越紧，同样电压能锁住更多电荷，$C$ 越大**；
- $\varepsilon = \varepsilon_r \varepsilon_0$ 是电介质的介电常数（$\text{F/m}$），其中真空介电常数 $\varepsilon_0 = 8.854 \times 10^{-12}\ \text{F/m}$，$\varepsilon_r$ 为相对介电常数（空气 $\approx 1$，云母 $\approx 5$，高介电陶瓷可达数千）。插入电介质后，介质内部分子偶极子发生极化，部分削弱内部电场，从而在同等电压下容纳更多电荷。

### 1.2 Boylestad 物理直觉：把电容想象成“弹性隔膜水箱”

很多同学刚学电容会疑惑：“中间明明是绝缘体，直流电根本穿不过去，怎么会有电流流进流出呢？”

请借用 Boylestad 第 10 章的经典直觉模型：把电容想象成一根装满水的水管中间，横着绷紧了一张**极具弹性的橡胶隔膜**。
- 水滴（电子）绝对**无法穿透**橡胶隔膜；
- 但是，当水泵（电源）从左边把水压进来时，橡胶隔膜向右鼓起，同时把隔膜右边等量的水挤出水管！你在外面看，左边流进多少水流，右边就流出多少水流——这就是电容的**充电电流**；
- 随着隔膜越绷越紧，反推力（两端电压 $v$）越来越大，直到反推力等于水泵水压，水流停止（直流稳态开路），但能量已经完完整整储存在紧绷的橡胶隔膜（**电场**）里了！

### 1.3 面包板实战安全铁律：认准极性与 2 倍耐压裕量

在 Breadboard Lab 桌面插电路前，先区分两种最常用的电容：
1. **瓷片电容（如标有 `104` 即 $10 \times 10^4\ \text{pF} = 0.1\ \mu\text{F}$）**：**无极性**，两脚随便插，正反都行。
2. **铝电解电容（如 `100 μF 25 V`）**：**严格有极性！**
   - **外观辨识双保险**：外壳侧面印有一条醒目的**白色/银色条带，上面带有一排负号（`-`）**，对应的引脚是**负极（且出厂引脚较短）**；另一侧**较长的引脚是正极（`+`）**。
   - **为什么绝不能反接？** 铝电解电容之所以体积小、容量大，靠的是阳极铝箔表面那层纳米级厚度的氧化铝绝缘膜。如果在 5 V 或 9 V 直流供电下反接，这层氧化膜会在反向电场下迅速发生电化学击穿，电容瞬间变成低阻发热体，内部电解液沸腾汽化，顶部刻有“十字/K字防爆纹”的铝壳会鼓包甚至**爆浆喷溅**！
   - **耐压选型铁律（2 倍裕量）**：电路供电 5 V，电容额定耐压选 **16 V 或 25 V**；供电 9 V，首选 **25 V**（最低不低于 16 V），切忌贴边选 6.3 V 或 10 V。

### 1.5 教授板书例题 1：平行板电容与电介质替换效应（Sadiku Sec. 6.1 典型例题）

**题目**：一个平行板电容器的两极板正对面积 $A = 20\ \text{cm}^2$，极板间距 $d = 1\ \text{mm}$。
1. 当极板间充满空气（$\varepsilon_{r1} = 1$）时，求电容量 $C_{\text{air}}$；
2. 若在极板间填满相对介电常数 $\varepsilon_{r2} = 5$ 的云母（Mica）介质，求新的电容量 $C_{\text{mica}}$。

**① 公理溯源**
依据静电学高斯定理与平行板匀强电场关系 $E = \frac{q}{\varepsilon A}$ 及 $v = E d$，由电容定义 $C = \frac{q}{v}$ 可导出平行板电容的物理决定式：
$$C = \frac{\varepsilon A}{d}, \qquad \varepsilon = \varepsilon_r \varepsilon_0$$

**② 纯符号通式**
设空气与云母两种工况下的相对介电常数分别为 $\varepsilon_{r1}$ 与 $\varepsilon_{r2}$，则：
$$C_{\text{air}} = \frac{\varepsilon_{r1} \varepsilon_0 A}{d}, \qquad C_{\text{mica}} = \frac{\varepsilon_{r2} \varepsilon_0 A}{d} = \frac{\varepsilon_{r2}}{\varepsilon_{r1}} C_{\text{air}}$$

**③ 代入数值逐步化简**
先统一换算为国际单位制（SI）：
$$A = 20\ \text{cm}^2 = 20 \times 10^{-4}\ \text{m}^2 = 2.0 \times 10^{-3}\ \text{m}^2, \qquad d = 1\ \text{mm} = 1.0 \times 10^{-3}\ \text{m}$$
$$\varepsilon_0 = 8.854 \times 10^{-12}\ \text{F/m}$$

代入空气工况（$\varepsilon_{r1} = 1$）：
$$C_{\text{air}} = \frac{1 \times 8.854 \times 10^{-12} \times 2.0 \times 10^{-3}}{1.0 \times 10^{-3}} = 1.7708 \times 10^{-11}\ \text{F} \approx 17.71\ \text{pF}$$

代入云母工况（$\varepsilon_{r2} = 5$）：
$$C_{\text{mica}} = \frac{5}{1} \times 17.708\ \text{pF} = 88.54\ \text{pF}$$

> **教授点评**：看出来了吗？几何尺寸一毫米没动，仅仅把空气换成云母，容量直接翻了 5 倍。这也是为什么你在面包板上买到的陶瓷电容小小一颗就能做到 $0.1\ \mu\text{F}$——工程师把 $\varepsilon_r$ 做到了几千，同时把多层极板叠在一起拼命增大 $A$、压薄 $d$。

## 第 2 幕：微积分入场——电容的微分/积分伏安关系与电压连续性铁律

**联动舞台**：`03 2D 原理图与分段线性 v(t)↔i(t) 微积分波形联动`

### 2.1 从 $q = Cv$ 到 $i = C\frac{dv}{dt}$

在 W1-L1 中我们学过，电流是电荷随时间的变化率：$i = \frac{dq}{dt}$。在**无源符号约定（Passive Sign Convention）**下（电流 $i$ 从电容电压 $v$ 的正极性端流入），对 $q = Cv$ 两边同时对时间 $t$ 求导（假设 $C$ 为常数），便得到电容最核心的**微分伏安关系（VCR）**：

$$i(t) = C \frac{dv(t)}{dt}$$

请停下来默念三遍这个公式背后的物理含义：
1. **电容电流不取决于电压有多高，而取决于电压变化有多快！** 哪怕电容两端顶着 $100\ \text{V}$ 高压，只要电压纹丝不动（$\frac{dv}{dt} = 0$），流过电容的电流就严格等于 $0$。
2. **电容两端电压 $v(t)$ 不能发生瞬时突变（阶跃跳变）！** 如果你想让电容电压在 $\Delta t \to 0$ 的瞬间从 $0\ \text{V}$ 跳到 $5\ \text{V}$，那么 $\frac{dv}{dt} \to \infty$，需要的电流 $i = C\frac{dv}{dt} \to \infty$——物理世界里没有任何电源能提供无穷大电流。因此，**电容电压永远是一条连续曲线**（可以有折角，但绝不能有垂直断崖）；相反，**电容电流可以发生瞬时跳变**（例如方波）。

### 2.2 积分形式与“记忆元件”

将微分关系两边从初值时刻 $t_0$ 到当前时刻 $t$ 积分，便得到已知电流求电压的**积分伏安关系**：

$$v(t) = \frac{1}{C} \int_{t_0}^{t} i(\tau)\,d\tau + v(t_0)$$

请注意末尾那一项 **$v(t_0)$**！电阻只关心“此时此刻”的电流，没有记忆；而电容此刻的电压 $v(t)$ 等于**历史上所有流进去的电流累积效果**，再加上初始时刻已经存着的电压 $v(t_0)$。因此我们称电容为**具有记忆能力的动态元件（Memory Element）**。

### 2.4 教授板书例题 2：由分段线性电压 $v(t)$ 求电流 $i(t)$ 与最大储能（Sadiku Sec. 6.2 典型例题）

**题目**：如图 2-1 所示，一个 $C = 2\ \mu\text{F}$ 的电容两端施加分段线性电压 $v(t)$：
- $0 \le t < 2\ \text{ms}$：$v(t)$ 从 $0\ \text{V}$ 线性升至 $10\ \text{V}$；
- $2 \le t < 4\ \text{ms}$：$v(t)$ 保持恒定 $10\ \text{V}$；
- $4 \le t < 6\ \text{ms}$：$v(t)$ 从 $10\ \text{V}$ 线性降至 $-10\ \text{V}$；
- $6 \le t \le 8\ \text{ms}$：$v(t)$ 从 $-10\ \text{V}$ 线性升至 $0\ \text{V}$。

求各时间段的电容电流 $i(t)$ 以及该周期内电容储存的最大电场能量 $w_{\max}$。

**① 公理溯源**
依据电容微分伏安关系与电场储能公式：
$$i(t) = C \frac{dv(t)}{dt}, \qquad w(t) = \frac{1}{2} C v^2(t)$$

**② 纯符号通式**
对于任意线性区间 $[t_a, t_b]$，设端点电压分别为 $v_a$ 与 $v_b$，则斜率为常数，区间电流为：
$$i_{ab} = C \frac{v_b - v_a}{t_b - t_a}$$
最大储能出现在电压绝对值 $|v(t)|_{\max}$ 处：
$$w_{\max} = \frac{1}{2} C \left(|v(t)|_{\max}\right)^2$$

**③ 代入数值逐步化简**
已知 $C = 2 \times 10^{-6}\ \text{F}$，逐段计算斜率并乘以 $C$：
- **区间 1（$0 \le t < 2\ \text{ms}$）**：
  $$i_1 = (2 \times 10^{-6}) \times \frac{10 - 0}{(2 - 0)\times 10^{-3}} = (2 \times 10^{-6}) \times 5000 = +10\ \text{mA}$$
- **区间 2（$2 \le t < 4\ \text{ms}$）**：
  $$i_2 = (2 \times 10^{-6}) \times \frac{10 - 10}{(4 - 2)\times 10^{-3}} = 0\ \text{mA}$$
- **区间 3（$4 \le t < 6\ \text{ms}$）**：
  $$i_3 = (2 \times 10^{-6}) \times \frac{-10 - 10}{(6 - 4)\times 10^{-3}} = (2 \times 10^{-6}) \times (-10000) = -20\ \text{mA}$$
- **区间 4（$6 \le t \le 8\ \text{ms}$）**：
  $$i_4 = (2 \times 10^{-6}) \times \frac{0 - (-10)}{(8 - 6)\times 10^{-3}} = (2 \times 10^{-6}) \times 5000 = +10\ \text{mA}$$
- **最大电场储能**（$|v|_{\max} = 10\ \text{V}$）：
  $$w_{\max} = \frac{1}{2} \times (2 \times 10^{-6}) \times 10^2 = 1.0 \times 10^{-4}\ \text{J} = 100\ \mu\text{J}$$

### 2.5 教授板书例题 3：由分段恒定电流 $i(t)$ 与初值 $v(0)$ 积分求电压与储能

**题目**：一个 $C = 50\ \mu\text{F}$ 的电容在 $t = 0$ 时已存有初始电压 $v(0) = 2\ \text{V}$。若流入它的电流为：
- $0 \le t < 4\ \text{ms}$：$i(t) = +15\ \text{mA}$；
- $4 \le t \le 10\ \text{ms}$：$i(t) = -10\ \text{mA}$。

求 $v(4\ \text{ms})$、$v(10\ \text{ms})$ 及这两个时刻电容储存的能量 $w(4\ \text{ms})$ 与 $w(10\ \text{ms})$。

**① 公理溯源**
依据电容积分伏安关系：
$$v(t) = \frac{1}{C} \int_{t_0}^{t} i(\tau)\,d\tau + v(t_0)$$

**② 纯符号通式**
设第一段 $[0, t_1]$ 恒流为 $I_1$，第二段 $[t_1, t_2]$ 恒流为 $I_2$，则由电压连续性（$v(t_1^+) = v(t_1^-)$）逐段递推：
$$v(t_1) = v(0) + \frac{I_1 t_1}{C}, \qquad v(t_2) = v(t_1) + \frac{I_2 (t_2 - t_1)}{C}$$
对应储能为：
$$w(t_1) = \frac{1}{2} C v^2(t_1), \qquad w(t_2) = \frac{1}{2} C v^2(t_2)$$

**③ 代入数值逐步化简**
已知 $C = 50 \times 10^{-6}\ \text{F}$，$v(0) = 2\ \text{V}$：
- **$t_1 = 4\ \text{ms}$ 时**：
  $$v(4\ \text{ms}) = 2 + \frac{(15 \times 10^{-3}) \times (4 \times 10^{-3})}{50 \times 10^{-6}} = 2 + \frac{60 \times 10^{-6}}{50 \times 10^{-6}} = 2 + 1.2 = 3.2\ \text{V}$$
  $$w(4\ \text{ms}) = \frac{1}{2} \times (50 \times 10^{-6}) \times 3.2^2 = 25 \times 10^{-6} \times 10.24 = 256\ \mu\text{J}$$
- **$t_2 = 10\ \text{ms}$ 时**（时间跨度 $t_2 - t_1 = 6\ \text{ms}$）：
  $$v(10\ \text{ms}) = 3.2 + \frac{(-10 \times 10^{-3}) \times (6 \times 10^{-3})}{50 \times 10^{-6}} = 3.2 - \frac{60 \times 10^{-6}}{50 \times 10^{-6}} = 3.2 - 1.2 = 2.0\ \text{V}$$
  $$w(10\ \text{ms}) = \frac{1}{2} \times (50 \times 10^{-6}) \times 2.0^2 = 25 \times 10^{-6} \times 4 = 100\ \mu\text{J}$$

> **教授点评**：注意看电荷收支！前 $4\ \text{ms}$ 充入电荷 $+15\ \text{mA} \times 4\ \text{ms} = +60\ \mu\text{C}$，后 $6\ \text{ms}$ 放出电荷 $-10\ \text{mA} \times 6\ \text{ms} = -60\ \mu\text{C}$，净电荷变化为零，所以 $10\ \text{ms}$ 末电压丝毫不差地回到了初值 $2.0\ \text{V}$！千万别漏加 $v(0)$。

## 第 3 幕：电场储能与直流稳态“开路等效”

**联动舞台**：`04 串并联等效与直流稳态开路分析台`

### 3.1 瞬时功率与电场储能的严谨推导

在 W1-L2 中我们知道任意二端元件的瞬时吸收功率为 $p(t) = v(t) i(t)$。把电容的 $i(t) = C\frac{dv}{dt}$ 代入，并对时间从 $-\infty$（此时电容完全未充电，$v(-\infty) = 0$）积分到当前时刻 $t$：

$$w(t) = \int_{-\infty}^{t} p(\tau)\,d\tau = \int_{-\infty}^{t} C v \frac{dv}{d\tau}\,d\tau = C \int_{0}^{v(t)} v\,dv = \frac{1}{2} C v^2(t) = \frac{q^2(t)}{2C}$$

请注意这个公式的两个重要推论：
1. 理想电容是**无损储能元件**：充电时 $p > 0$（从电路吸能存入电场），放电时 $p < 0$（把电场能量原封不动还回电路），自身不产生焦耳热。
2. 能量 $w = \frac{1}{2}Cv^2$ 与电压的**平方**成正比——电压翻倍，储能变为原来的 **4 倍**！

### 3.2 直流稳态铁律：为什么电容“相当于开路”？

当一个由**直流电源、电阻和电容**组成的电路通电足够长时间、所有暂态充放电彻底结束后，电路进入**直流稳态（DC Steady State）**。此时电路中所有节点的电压都稳定为恒定直流值，不再随时间变化：

$$\frac{dv}{dt} = 0 \implies i_C = C \frac{dv}{dt} = 0$$

**电流恒为零、但两端可以维持非零电压**——这在电路模型里就是**开路（Open Circuit）**的定义！

> **直流稳态解题黄金三步法**：
> 1. **开路替换**：把电路中所有电容都画成断开的虚线空口（标记好原来的正负极性与节点位置）；
> 2. **纯阻求压**：在剩下的纯电阻网络中，用欧姆定律、串联分压或节点分析求出电容两端对应的节点电压差 $V_C$（切记：**与电容串联的孤立支路电阻电流也为 $0$，压降为 $0\ \text{V}$**）；
> 3. **代入储能**：用 $w_C = \frac{1}{2} C V_C^2$ 算出每个电容的储能并求和。

### 3.4 教授板书例题 4：直流稳态双电容网络求电压与总储能（Sadiku Ex. 6.6 同型题）

**题目**：如图 3-1 所示直流电路，电源 $V_s = 12\ \text{V}$，电阻 $R_1 = 3\ \text{k}\Omega$、$R_2 = 6\ \text{k}\Omega$、$R_3 = 2\ \text{k}\Omega$、$R_4 = 4\ \text{k}\Omega$，电容 $C_1 = 10\ \mu\text{F}$ 并联在 $R_2$ 两端（节点 A 对地），$C_2 = 20\ \mu\text{F}$ 并联在 $R_4$ 两端（节点 B 对地）。电路处于直流稳态，求 $V_{C1}$、$V_{C2}$ 以及两电容储存的总能量 $w_{\text{total}}$。

**① 公理溯源**
直流稳态下电压不随时间变化（$\frac{dv}{dt} = 0$），电容电流 $i_C = C\frac{dv}{dt} = 0$，等效为**开路**。剩余纯电阻网络遵循欧姆定律与串并联分压定律，电容储能满足 $w = \frac{1}{2} C v^2$。

**② 纯符号通式**
将 $C_1$、$C_2$ 开路后，右侧支路 $R_3$ 与 $R_4$ 串联后再与 $R_2$ 并联，记并联等效电阻为 $R_p$：
$$R_p = R_2 \parallel (R_3 + R_4) = \frac{R_2 (R_3 + R_4)}{R_2 + R_3 + R_4}$$
回路总电阻与总电流为：
$$R_{\text{tot}} = R_1 + R_p, \qquad I_s = \frac{V_s}{R_{\text{tot}}}$$
电容 $C_1$ 跨接于节点 A 与地之间，电容 $C_2$ 跨接于节点 B 与地之间（由 $R_3, R_4$ 串联分压得 $V_B$）：
$$V_{C1} = V_A = I_s R_p = V_s \frac{R_p}{R_1 + R_p}, \qquad V_{C2} = V_B = V_A \frac{R_4}{R_3 + R_4}$$
各电容储能与总储能为：
$$w_{C1} = \frac{1}{2} C_1 V_{C1}^2, \qquad w_{C2} = \frac{1}{2} C_2 V_{C2}^2, \qquad w_{\text{total}} = w_{C1} + w_{C2}$$

**③ 代入数值逐步化简**
- 计算并联与总电阻：
  $$R_3 + R_4 = 2\ \text{k}\Omega + 4\ \text{k}\Omega = 6\ \text{k}\Omega$$
  $$R_p = \frac{6\ \text{k}\Omega \times 6\ \text{k}\Omega}{6\ \text{k}\Omega + 6\ \text{k}\Omega} = 3\ \text{k}\Omega, \qquad R_{\text{tot}} = 3\ \text{k}\Omega + 3\ \text{k}\Omega = 6\ \text{k}\Omega$$
- 计算总电流与电容稳态电压：
  $$I_s = \frac{12\ \text{V}}{6\ \text{k}\Omega} = 2\ \text{mA}$$
  $$V_{C1} = V_A = (2\ \text{mA}) \times (3\ \text{k}\Omega) = 6\ \text{V}$$
  $$V_{C2} = V_B = 6\ \text{V} \times \frac{4\ \text{k}\Omega}{2\ \text{k}\Omega + 4\ \text{k}\Omega} = 4\ \text{V}$$
- 计算各自储能与总储能：
  $$w_{C1} = \frac{1}{2} \times (10 \times 10^{-6}) \times 6^2 = 180\ \mu\text{J}$$
  $$w_{C2} = \frac{1}{2} \times (20 \times 10^{-6}) \times 4^2 = 160\ \mu\text{J}$$
  $$w_{\text{total}} = 180\ \mu\text{J} + 160\ \mu\text{J} = 340\ \mu\text{J}$$

## 第 4 幕：电容串并联——与电阻“镜像相反”的物理本质

**联动舞台**：`04 串并联等效与直流稳态开路分析台`

### 4.1 为什么电容串并联公式与电阻正好相反？

很多初学者做题一紧张就会把电容串并联和 W1-L7 的电阻公式搞混。别死记硬背，用**物理图像 + KCL/KVL**一次打通，一辈子都不会忘：

1. **电容并联（$C_{\text{eq}} = C_1 + C_2 + \dots + C_N$）——相当于增大极板面积 $A$！**
   - 所有并联电容承受**相同的电压 $v$**，由 KCL 得总电流 $i = i_1 + i_2 + \dots + i_N = (C_1 + C_2 + \dots + C_N)\frac{dv}{dt}$。
   - 物理上，把两块平行板并排连在一起，相当于把极板总面积相加：$A_{\text{eq}} = A_1 + A_2$，所以容量**直接相加**，越并越大！
2. **电容串联（$\frac{1}{C_{\text{eq}}} = \frac{1}{C_1} + \frac{1}{C_2} + \dots + \frac{1}{C_N}$）——相当于拉大极板间距 $d$！**
   - 所有串联电容流过**相同的电流 $i$**（因而积累相同的电荷变化量 $q$），由 KVL 得总电压 $v = v_1 + v_2 + \dots + v_N = \left(\frac{1}{C_1} + \frac{1}{C_2} + \dots + \frac{1}{C_N}\right)\int i\,dt$。
   - 物理上，把两个电容首尾相接，中间串联的两块极板正负电荷相互抵消，等效于把总极板间距拉大为 $d_{\text{eq}} = d_1 + d_2$，所以容量**倒数相加**，越串越小（永远小于最小的那一颗电容）！
   - 两电容串联的常用速算式：$C_{\text{eq}} = \frac{C_1 C_2}{C_1 + C_2}$。

### 4.2 重要推论：串联电容的“反比分压”规律

两个初始未充电的电容 $C_1$、$C_2$ 串联接在总电压 $V_s$ 上，它们储存的电荷量严格相等：$q = C_1 V_1 = C_2 V_2$。由此立刻推出：

$$V_1 = V_s \frac{C_2}{C_1 + C_2}, \qquad V_2 = V_s \frac{C_1}{C_1 + C_2}$$

**规律警句**：串联电容分压，**容量越小的电容，分到的电压反而越大**！在工程上，绝对不能把一颗小电容和一颗大电容随便串联去分高压，因为绝大部分电压都会砸在小电容头上，极易将其击穿。

### 4.4 教授板书例题 5：混联电容网络化简、反比分压与能量守恒验算（Sadiku Sec. 6.3 典型例题）

**题目**：如图 4-1 右侧所示，$C_1 = 60\ \mu\text{F}$，$C_2 = 20\ \mu\text{F}$，$C_3 = 20\ \mu\text{F}$，$C_4 = 20\ \mu\text{F}$，整体接入 $V_s = 9\ \text{V}$ 直流电源（初始均未充电）。
1. 求总等效电容 $C_{\text{eq}}$；
2. 求各电容两端的稳态电压 $V_{C1}, V_{C2}, V_{C3}, V_{C4}$；
3. 分别通过“总等效电容”与“四颗电容储能逐个求和”两种方法计算总储能，验证能量守恒。

**① 公理溯源**
依据电容串联公式 $\frac{1}{C_{\text{ser}}} = \sum \frac{1}{C_k}$、并联公式 $C_{\text{par}} = \sum C_k$、电荷守恒 $Q = C V$ 以及电场储能公式 $w = \frac{1}{2} C V^2$。

**② 纯符号通式**
由右向左逐级归并：
$$C_{34} = \frac{C_3 C_4}{C_3 + C_4}, \qquad C_{234} = C_2 + C_{34}, \qquad C_{\text{eq}} = \frac{C_1 C_{234}}{C_1 + C_{234}}$$
总电荷量 $Q_{\text{tot}} = C_{\text{eq}} V_s$ 全部储存在串联前端电容 $C_1$ 及等效组合 $C_{234}$ 上，由反比分压得：
$$V_{C1} = \frac{Q_{\text{tot}}}{C_1} = V_s \frac{C_{234}}{C_1 + C_{234}}, \qquad V_{C2} = V_{234} = V_s \frac{C_1}{C_1 + C_{234}}$$
右侧串联支路 $C_3$ 与 $C_4$ 共享电压 $V_{234}$：
$$V_{C3} = V_{234} \frac{C_4}{C_3 + C_4}, \qquad V_{C4} = V_{234} \frac{C_3}{C_3 + C_4}$$
总储能两种算法：
$$w_{\text{eq}} = \frac{1}{2} C_{\text{eq}} V_s^2, \qquad w_{\text{sum}} = \frac{1}{2} \left(C_1 V_{C1}^2 + C_2 V_{C2}^2 + C_3 V_{C3}^2 + C_4 V_{C4}^2\right)$$

**③ 代入数值逐步化简**
- **总等效电容**：
  $$C_{34} = \frac{20 \times 20}{20 + 20} = 10\ \mu\text{F}$$
  $$C_{234} = 20 + 10 = 30\ \mu\text{F}$$
  $$C_{\text{eq}} = \frac{60 \times 30}{60 + 30} = 20\ \mu\text{F}$$
- **各电容电压**（$V_s = 9\ \text{V}$，总电荷 $Q_{\text{tot}} = 20\ \mu\text{F} \times 9\ \text{V} = 180\ \mu\text{C}$）：
  $$V_{C1} = \frac{180\ \mu\text{C}}{60\ \mu\text{F}} = 3\ \text{V}, \qquad V_{C2} = V_{234} = \frac{180\ \mu\text{C}}{30\ \mu\text{F}} = 6\ \text{V}$$
  （验证 KVL：$V_{C1} + V_{234} = 3 + 6 = 9\ \text{V}$！）
  $$V_{C3} = 6\ \text{V} \times \frac{20}{20 + 20} = 3\ \text{V}, \qquad V_{C4} = 6\ \text{V} \times \frac{20}{20 + 20} = 3\ \text{V}$$
- **能量守恒双路验算**：
