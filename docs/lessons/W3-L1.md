# W3-L1：认识真实运放（LM358/LM741 封装、VCVS 模型与三区饱和）

> **教授导言**：同学们好，欢迎进入第三周。前两周我们一直在和电阻、独立源、受控源以及戴维南等效打交道。很多同学在学完 `W1-L2 受控源` 时心里一定嘀咕过：“教授，书上画的那个菱形压控电压源（VCVS）现实里到底长什么样？我去电子市场能买到一颗菱形元件吗？”今天我就把一颗真实的黑色塑料小爬虫——**运算放大器（Operational Amplifier, 简称运放）**——拍在面包板上。它内部塞了几十颗晶体管，但在电路分析的视角下，剥开环氧树脂外壳，它本质上就是一颗**高增益、高输入电阻、低输出电阻的真实 VCVS 受控源**。本课严格对齐 *Fundamentals of Electric Circuits, 2026 Release* (Alexander, Sadiku & Fredette) **Section 5.1 & 5.2 (p. 174–176)**，我们先认清它的 8 条腿、搞懂它的能量来源，再把它的内部模型和“微伏级悬崖”彻底看透。

---

## 第 1 幕：黑匣子里的 8 条腿——DIP-8 封装、跨沟插法与 LM358 vs LM741 引脚生死线

> **联动左侧舞台**：`01 3D 芯片封装与面包板跨沟插法`（`3D_THREEJS_DEVICE_AND_BREADBOARD`）  
> **本幕目标**：掌握 DIP-8 封装缺口定位法、面包板跨沟插法，并牢记实验室最常用的两颗芯片 **LM358（双运放）** 与 **LM741（单运放）** 的致命引脚差异。

### 1.1 为什么芯片必须“跨过那条沟”？

拿到一颗直插式双列 8 脚封装（**DIP-8**）芯片，先别急着往面包板上按。你盯着面包板正中央看，会发现一条贯通左右的长槽，我们叫它**中央隔离沟（Center Trench）**。面包板同一行中，沟左边的 `a–b–c–d–e` 五个孔在内部由同一根金属簧片连通，沟右边的 `f–g–h–i–j` 五个孔由另一根金属簧片连通，左右两排互不导通。

如果把 DIP-8 芯片插在沟的同一侧，左边第 1 脚和右边第 8 脚就会被同一根金属簧片直接短接，电源和信号全乱套；**唯有让芯片像跨河架桥一样骑在中央隔离沟上（左侧引脚插在 `e` 列，右侧引脚插在 `f` 列）**，8 条引脚才各自拥有独立的 4 个外部接线孔。

### 1.2 认引脚的黄金法则：缺口朝左，逆时针数 1 到 8

观察芯片顶面：一端有一个半圆形凹槽（**Notch / 缺口**），缺口左下方通常还有一个压印小圆点。把缺口朝左（或朝上）放好：
- **缺口朝上时**：左上角就是 **Pin 1**，沿左侧向下依次是 `1 → 2 → 3 → 4`，跨过底部到右侧再向上依次是 `5 → 6 → 7 → 8`（整体呈 **U 形逆时针** 排列）。

### 1.3 LM358 vs LM741：千万别凭感觉互换！

教材 Section 5.2 重点以经典的 **741 单运放** 为例，而同学们手头的实验套件里最常见的是 **LM358 双运放**（一颗 DIP-8 里装了两套完全独立的运放）。请务必死盯住两者的 **供电脚（$V_{CC}$ / $V_{EE}$）** 与 **输出脚**：

| 引脚编号 | LM358（双运放，Dual） | LM741（单运放，Single） | 实验室踩坑警示 |
| :---: | :--- | :--- | :--- |
| **Pin 1** | **OUT1**（运放 A 输出） | Offset Null（失调调零） | LM358 是输出，LM741 悬空不接 |
| **Pin 2** | **IN1−**（运放 A 反相输入 $v_1$） | **IN−**（反相输入 $v_1$） | 两者一致 |
| **Pin 3** | **IN1+**（运放 A 同相输入 $v_2$） | **IN+**（同相输入 $v_2$） | 两者一致 |
| **Pin 4** | **GND / $V_{EE}$**（负电源或地） | **$V_{EE}$ / $V^-$**（负电源） | **两者 Pin 4 同为负电源轨** |
| **Pin 5** | **IN2+**（运放 B 同相输入） | Offset Null（失调调零） | LM741 悬空不接 |
| **Pin 6** | **IN2−**（运放 B 反相输入） | **OUT**（唯一输出 $v_o$） | LM741 的输出在 Pin 6！ |
| **Pin 7** | **OUT2**（运放 B 输出） | **$V_{CC}$ / $V^+$**（正电源） | **致命差异：LM741 正电源在 Pin 7** |
| **Pin 8** | **$V_{CC}$ / $V^+$**（正电源） | NC（空脚，无内部连接） | **致命差异：LM358 正电源在 Pin 8** |

> **教授敲黑板**：上电前务必核对丝印型号！把 LM358 插进按 LM741 接好线的面包板，等于把 $+9\text{ V}$ 正电源直接捅进 LM358 的 **OUT2（Pin 7）输出级**，轻则芯片滚烫冒烟，重则电源拉垮。

### 2.1 打破“永动机”错觉：有源器件的隐藏能量门

以后我们在画运放电路原理图时，为了画面清爽，常常只画 3 条线：反相输入 $v_1$、同相输入 $v_2$、输出 $v_o$。于是很多初学者一上来就犯晕：

> “老师，你马上要告诉我运放两个输入端的电流 $i_1 \approx 0$、$i_2 \approx 0$，可输出端却能点亮一颗 $5\text{ mA}$ 的 LED！这不违反 `W1-L5` 学的 KCL 吗？”

**绝没有违反 KCL！** 运放不是无源电阻，它是一个**有源器件（Active Element）**。把整个运放芯片连同它的供电脚 $+V_{CC}$ 和 $-V_{EE}$ 用一个封闭曲面（超节点）包起来，你会看到它一共有 **5 条电流通道**：
- 反相输入电流 $i_1$（流入芯片）
- 同相输入电流 $i_2$（流入芯片）
- 正电源轨电流 $i_+$（从 $+V_{CC}$ 流入芯片）
- 负电源轨电流 $i_-$（按 Sadiku 正方向约定，定义为从 $-V_{EE}$ 流入芯片）
- 输出电流 $i_o$（从输出端流出芯片，流向负载 $R_L$）

### 2.3 教授三段式板书推导：Eq. (5.1) 拉电流（Sourcing）与灌电流（Sinking）算例

**场景设定**：某真实运放接双电源 $\pm 9\text{ V}$，输出端接负载电阻 $R_L = 1\text{ k}\Omega$ 到地。已知输入偏置电流极小，取 $i_1 = i_2 = 0.1\ \mu\text{A} = 0.0001\text{ mA}$。分别考察：
- **工况 A（拉电流 Sourcing）**：输出 $v_o = +5.0\text{ V}$，芯片内部静态电流经负电源流出 $1.0\text{ mA}$（即按流入方向 $i_- = -1.0000\text{ mA}$），求正电源供电电流 $i_+$。
- **工况 B（灌电流 Sinking）**：输出 $v_o = -4.0\text{ V}$，芯片内部静态电流从正电源流入 $i_+ = +1.0000\text{ mA}$，求负电源引脚电流 $i_-$。

#### ① 公理溯源
对包含整个运放封装的封闭超节点应用基尔霍夫电流定律（`W1-L5 KCL`：流入封闭面的总电流等于流出封闭面的总电流），并结合负载端欧姆定律：
$$\sum i_{\text{in}} = \sum i_{\text{out}} \implies i_1 + i_2 + i_+ + i_- = i_o \quad \text{[Sadiku Eq. (5.1)]}$$
$$i_o = \frac{v_o}{R_L}$$

#### ② 纯符号通式
由 Eq. (5.1) 移项，分别解出正电源电流 $i_+$ 与负电源电流 $i_-$ 的纯符号表达式：
$$i_+ = \frac{v_o}{R_L} - i_1 - i_2 - i_-$$
$$i_- = \frac{v_o}{R_L} - i_1 - i_2 - i_+$$

#### ③ 代入数值逐步化简
- **工况 A（拉电流，$v_o = +5.0\text{ V}$）**：
  1. 先算负载电流：$i_o = \frac{+5.0\text{ V}}{1\text{ k}\Omega} = +5.0000\text{ mA}$
  2. 代入 $i_+$ 通式（统一换算为 $\text{mA}$）：
     $$i_+ = 5.0000 - 0.0001 - 0.0001 - (-1.0000) = 5.9998\text{ mA} \approx 6.00\text{ mA}$$
  3. **物理读解**：负载拿走的 $5.00\text{ mA}$ 几乎 100% 来自正电源 $+V_{CC}$（另外 $1.00\text{ mA}$ 维持芯片内部电路偏置并经 $-V_{EE}$ 回流），输入端贡献仅 $0.0002\text{ mA}$（不足万分之零点四）。

- **工况 B（灌电流，$v_o = -4.0\text{ V}$）**：
  1. 先算负载电流：$i_o = \frac{-4.0\text{ V}}{1\text{ k}\Omega} = -4.0000\text{ mA}$（负号表示电流从地经 $R_L$ 倒灌进运放输出脚）
  2. 代入 $i_-$ 通式：
     $$i_- = -4.0000 - 0.0001 - 0.0001 - 1.0000 = -5.0002\text{ mA} \approx -5.00\text{ mA}$$
  3. **物理读解**：$i_- = -5.0002\text{ mA}$ 的负号意味着实际有 $5.0002\text{ mA}$ 电流从芯片的 $-V_{EE}$ 引脚**流出**并回到 $-9\text{ V}$ 电源负极（其中 $4.00\text{ mA}$ 来自负载倒灌，$1.00\text{ mA}$ 来自正电源静态偏置）。KCL 严丝合缝！

### 3.1 剥壳后的三大核心元件

把塑料封装剥开，无论内部是 20 颗还是 50 颗晶体管，只要运放工作在线性区，对外端口的电气行为都可以用 `W1-L2` 学过的 **压控电压源（VCVS）** 和 `W2-L7` 学过的 **戴维南等效电路** 精准刻画：

1. **输入端口等效**：反相端 $v_1$ 与同相端 $v_2$ 之间跨接一个极大的**输入电阻 $R_i$**。定义差模输入电压（Differential Input Voltage）为：
   $$v_d = v_2 - v_1$$
   注意减法顺序永远是 **“同相端（+）减反相端（−）”**！
2. **核心放大引擎**：输出侧含有一个压控电压源（VCVS），其空载输出电压为：
   $$v_{oc} = A v_d = A (v_2 - v_1)$$
   这里的 $A$ 称为**开环差模电压增益（Open-loop Voltage Gain）**。
3. **输出端口等效**：受控源 $A v_d$ 并非直接连到输出引脚，而是串联了一个很小的**输出电阻 $R_o$**——这正是我们在 `W2-L7` 学过的标准戴维南等效结构！

### 3.4 教授三段式板书推导：分贝增益换算与戴维南负载分压误差

**算例设定**：已知某真实运放开环增益 $A = 10^5$，输入电阻 $R_i = 2\text{ M}\Omega$，输出电阻 $R_o = 75\ \Omega$，双电源供电 $\pm 9\text{ V}$。现令差模输入电压 $v_d = +50\ \mu\text{V}$，输出端接负载电阻 $R_L = 2\text{ k}\Omega$。求：（a）分贝增益 $A_{\text{dB}}$；（b）输入电流 $i_{\text{in}}$；（c）带载输出电压 $v_o$ 与加载压降百分比。

#### ① 公理溯源
1. 电压增益的分贝（dB）定义（Sadiku Section 5.2）：
   $$A_{\text{dB}} = 20 \log_{10} A$$
2. 输入侧欧姆定律与输出侧戴维南分压原理（`W2-L7`）：
   $$i_{\text{in}} = \frac{v_d}{R_i}, \qquad v_o = \frac{R_L}{R_o + R_L} \cdot v_{oc}, \qquad v_{oc} = A v_d$$

#### ② 纯符号通式
联立消去中间量 $v_{oc}$，得到带载输出电压与相对压降误差 $\varepsilon_{\text{load}}$ 的纯符号通式：
$$v_o = \left(\frac{R_L}{R_o + R_L}\right) A v_d$$
$$\varepsilon_{\text{load}} = \left(1 - \frac{R_L}{R_o + R_L}\right) \times 100\% = \frac{R_o}{R_o + R_L} \times 100\%$$

#### ③ 代入数值逐步化简
1. **分贝增益**：
   $$A_{\text{dB}} = 20 \log_{10}(10^5) = 20 \times 5 = 100\text{ dB}$$
   （若 $A = 10^8$，同理 $A_{\text{dB}} = 20 \times 8 = 160\text{ dB}$；若 $A = 2 \times 10^5$，则 $A_{\text{dB}} = 20 \log_{10}(2\times 10^5) \approx 106.02\text{ dB}$。）
2. **输入电流**：
   $$i_{\text{in}} = \frac{50 \times 10^{-6}\text{ V}}{2 \times 10^{6}\ \Omega} = 25 \times 10^{-12}\text{ A} = 25\text{ pA}$$
   区区 $25\text{ pA}$（皮安），比常见毫安级信号电流小 8 个数量级！
3. **空载 VCVS 电压与带载输出电压**：
   $$v_{oc} = 10^5 \times (50 \times 10^{-6}\text{ V}) = +5.000\text{ V}$$
   $$v_o = \frac{2000\ \Omega}{75\ \Omega + 2000\ \Omega} \times 5.000\text{ V} = \frac{2000}{2075} \times 5.000\text{ V} \approx 4.8193\text{ V}$$
4. **输出电流与负载压降误差**：
   $$i_o = \frac{4.8193\text{ V}}{2000\ \Omega} \approx 2.4096\text{ mA}, \qquad \varepsilon_{\text{load}} = \frac{75}{2075} \times 100\% \approx 3.61\%$$
   可见在 $R_L = 2\text{ k}\Omega$ 时，$75\ \Omega$ 输出电阻仅吃掉了 $3.61\%$ 的电压，这就是为什么我们必须坚持使用 **$\text{k}\Omega$ 级负载**（如果误接 $10\ \Omega$ 负载，绝大部分电压都会白白掉在芯片内部的 $R_o$ 上并导致芯片过热）。

### 4.1 输出电压的物理天花板：三区传输特性

上一幕的公式 $v_o = A v_d$ 有一个铁律前提：**输出电压绝不可能超过供电轨**！运放不是升压器，在 Sadiku 的简化三区模型下，无论你给多大的差模输入 $v_d$，输出电压都被牢牢锁在 $[-V_{EE}, +V_{CC}]$ 之间，划分为三个工作区：

1. **正饱和区（Positive Saturation）**：当 $v_d > +\frac{V_{CC}}{A}$ 时，输出被削平在 $+V_{CC}$；
2. **线性放大区（Linear Region）**：当 $-\frac{V_{EE}}{A} \le v_d \le +\frac{V_{CC}}{A}$ 时，输出严格按 $v_o = A v_d$ 线性变化；
3. **负饱和区（Negative Saturation）**：当 $v_d < -\frac{V_{EE}}{A}$ 时，输出被削平在 $-V_{EE}$。

### 4.2 真实芯片的摆幅折损：双电源 $\pm 9\text{ V}$ vs 单电源 $+9\text{ V} / 0\text{ V}$

在理想教材曲线里，输出可以顶到 $+9\text{ V}$ 和 $-9\text{ V}$；但同学们把 LM358 插到面包板上接示波器时，立刻会发现两个非常真实的硬件细节：
- **双电源 $\pm 9\text{ V}$ 模式（本课默认）**：输出可在正负之间对称摆动，正饱和上限受内部输出级晶体管压降限制，实际约停在 **$+7.5\text{ V}$**（即 $V_{CC} - 1.5\text{ V}$），负饱和下限在 LM358 上可逼近 **$-8.9\text{ V}$**（LM741 则在约 $\pm 7.5\text{ V}$）。
- **单电源 $+9\text{ V} / 0\text{ V}$ 模式**：若手头只有一节 $9\text{ V}$ 电池，将 Pin 4 直接接 GND（$0\text{ V}$）。此时芯片**彻底失去负电压输出能力**；LM358 的输出下限可贴近 **$0\text{ V}$**（典型 $5\text{–}20\text{ mV}$），而输出上限依旧被限制在约 **$+7.5\text{ V}$**。

### 4.4 教授三段式板书推导：$\pm 90\ \mu\text{V}$ 饱和悬崖与 $3\text{ mV}$ 输入失调电压直觉

**算例设定**：在双电源 $\pm 9\text{ V}$、开环增益 $A = 10^5$ 的条件下，求：（a）线性区的差模输入边界 $v_{d,\text{sat}}$ 与总窗口宽度 $\Delta v_{d,\text{lin}}$；（b）若真实芯片存在典型的 $V_{OS} = 3\text{ mV}$ 输入失调电压，即使在面包板上将两个输入脚直接短接到地，该失调电压是饱和边界的多少倍？

#### ① 公理溯源
线性区需同时满足 $v_o = A v_d$ 与电源轨约束 $-V_{EE} \le v_o \le +V_{CC}$。

#### ② 纯符号通式
将线性方程代入电源轨约束，解出线性区边界与总宽度：
$$-\frac{V_{EE}}{A} \le v_d \le +\frac{V_{CC}}{A}$$
$$\Delta v_{d,\text{lin}} = \frac{V_{CC} + V_{EE}}{A}, \qquad k_{OS} = \frac{V_{OS}}{V_{CC} / A}$$

#### ③ 代入数值逐步化简
1. **饱和边界与线性区总宽度**：
   $$v_{d,\text{sat}+} = +\frac{9\text{ V}}{10^5} = +9 \times 10^{-5}\text{ V} = +90\ \mu\text{V}$$
   $$v_{d,\text{sat}-} = -\frac{9\text{ V}}{10^5} = -9 \times 10^{-5}\text{ V} = -90\ \mu\text{V}$$
   $$\Delta v_{d,\text{lin}} = 90\ \mu\text{V} - (-90\ \mu\text{V}) = 180\ \mu\text{V}$$
2. **输入失调电压倍数**：
   将 $V_{OS} = 3\text{ mV}$ 统一换算为微伏：$V_{OS} = 3000\ \mu\text{V}$。
   $$k_{OS} = \frac{3000\ \mu\text{V}}{90\ \mu\text{V}} = \frac{100}{3} \approx 33.33\text{ 倍}$$
3. **工程直觉**：哪怕你用镊子把真实运放的 Pin 2 和 Pin 3 死死短接在一起（理论 $v_d = 0$），芯片内部差分对晶体管制造工艺的微小失配等效出来的 $3\text{ mV}$ 失调电压，就已经超出线性区悬崖 **33.3 倍**！所以**开环运放在现实中根本不可能停在线性区**——一上电就会啪地一声拍死在正电源轨或负电源轨上。

### 5.1 工程视角：把“悬崖”当武器——开环即比较器（Comparator）

既然开环运放几乎没有线性区，只要 $v_2$ 比 $v_1$ 高出哪怕 $0.1\text{ mV}$ 输出就立刻翻转到正饱和，只要 $v_2$ 比 $v_1$ 低出 $0.1\text{ mV}$ 输出就立刻翻转到负饱和——这在工程上并不是“废品”，而恰恰是 **电压比较器（Comparator）** 的核心工作原理！
- **应用场景**：把 $v_1$ 接到一个参考阈值电压（例如温度传感器设定的 $2.5\text{ V}$ 报警线），把 $v_2$ 接到实时温度信号。一旦温度超标（$v_2 > v_1$），输出瞬间跳变到正饱和点亮报警 LED；温度降回阈值以下（$v_2 < v_1$），输出瞬间翻回负饱和（或单电源 $0\text{ V}$）熄灭 LED。
- **引出下一课（W3-L2）**：那如果我们想做**线性放大器**（比如把麦克风的 $10\text{ mV}$ 语音信号不失真地放大 100 倍到 $1\text{ V}$），绝不能让运放开环裸奔！我们必须在输出端与反相输入端之间拉一条**负反馈（Negative Feedback）**通路，利用负反馈自动把 $v_d$ 死死按回 $0\text{ V}$ 附近的微伏级线性区内——这就是下一课“理想运放与虚短虚断”的全部奥秘。
