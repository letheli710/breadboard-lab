## 第 1 幕：从旋转指针到正弦波——三要素与几何投影直觉

### 1.1 教授导学与几何直觉（Boylestad Ch. 13–14 坡度补位）

很多同学第一次背正弦波公式 $v(t) = V_m \cos(\omega t + \phi)$ 时，脑子里只有一条上下扭动的曲线。但我要请你先看左侧舞台 **图层 01**：把正弦波想象成游乐场里一架**匀速逆时针旋转的摩天轮**（或者一根在复平面上以角速度 $\omega$ 逆时针旋转的发光指针）：

1. **指针的长度**就是**幅值（Amplitude）$V_m$**：它决定了波形能达到的最高峰和最低谷。
2. **指针转动的快慢**就是**角频率（Angular Frequency）$\omega$**（单位 $\text{rad/s}$）：指针转满一圈是 $2\pi$ 弧度，所用时间就是一个**周期 $T$**（单位 $\text{s}$），每秒转的圈数就是**频率 $f = 1/T$**（单位 $\text{Hz}$），因此三者死死锁定为：
   $$\omega = 2\pi f = \frac{2\pi}{T}$$
3. **指针在 $t = 0$ 时的起跑角度**就是**初相位（Phase）$\phi$**：如果 $\phi > 0$，说明在发令枪响（$t=0$）之前，指针就已经提前逆时针转过了 $\phi$ 角度；波形在时间轴上反而**向左平移**（提前达到峰值！）。
4. **余弦波的本质**：在任何时刻 $t$，这根旋转指针与水平轴（实轴）的夹角都是 $\omega t + \phi$。此时指针尖端向**水平实轴（或按竖直展开投影轴）**投下的影子长度，不多不少，正好就是 $V_m \cos(\omega t + \phi)$！

> **为什么电路学界（Sadiku 标准）偏爱 $\cos$ 而不是 $\sin$？**
> 因为欧拉公式 $e^{j\theta} = \cos\theta + j\sin\theta$ 中，$\cos\theta$ 是**实部（$\text{Re}$）**，直接对应水平实轴的投影。把所有波形统一成 $\cos$，后续做相量变换时零摩擦、零符号错误！

### 1.3 三段式教授板书推导：正弦波三要素提取（Sadiku Example 9.1 同型题）

**例题 1.1**：已知某交流电压源的输出波形为 $v(t) = 12\cos(50t + 10^\circ)\text{ V}$，求该正弦波的幅值 $V_m$、初相位 $\phi$、角频率 $\omega$、周期 $T$ 与频率 $f$。

#### ① 公理溯源
根据标准余弦波定义（Sadiku Eq. 9.1–9.5），任意正弦时域信号均可表示为：
$$v(t) = V_m \cos(\omega t + \phi)$$
其中角频率 $\omega$、周期 $T$ 与频率 $f$ 满足圆周运动基本关系：
$$\omega T = 2\pi, \qquad f = \frac{1}{T}$$

#### ② 纯符号通式
将实测信号表达式与标准型逐项比对系数，得到各参数的纯符号解：
$$T = \frac{2\pi}{\omega}, \qquad f = \frac{\omega}{2\pi}$$

#### ③ 代入数值逐步化简
将 $V_m = 12\text{ V}$、$\omega = 50\text{ rad/s}$、$\phi = +10^\circ$ 代入纯符号通式：
1. **幅值**：$V_m = 12\text{ V}$
2. **初相位**：$\phi = +10^\circ$（说明波形比基准 $\cos(50t)$ 提前了 $10^\circ$）
3. **角频率**：$\omega = 50\text{ rad/s}$
4. **周期**：
   $$T = \frac{2\pi}{50} = \frac{\pi}{25} \approx 0.1257\text{ s} = 125.66\text{ ms}$$
5. **频率**：
   $$f = \frac{50}{2\pi} \approx 7.958\text{ Hz}$$

> **教授防坑提醒**：注意 $50t + 10^\circ$ 里隐藏着电路学最经典的“混搭写法”——$50t$ 的单位是**弧度（rad）**，而 $10^\circ$ 的单位是**角度（deg）**！如果要在计算器里代具体时间 $t$ 求瞬时电压，**必须先把两边单位统一**（全部转成弧度或全部转成角度），否则算出来的数值会错得离谱！

## 第 2 幕：相位超前与滞后的比较铁律——统一余弦正幅值法则

### 2.1 教授导学：为什么不能凭肉眼直接比相位？

考试里最容易丢分的陷阱长这样：
$$v_1(t) = -10\cos(\omega t + 50^\circ)\text{ V}, \qquad v_2(t) = 12\sin(\omega t - 10^\circ)\text{ V}$$
很多同学扫一眼 $+50^\circ$ 和 $-10^\circ$，脱口而出：“$v_1$ 超前 $v_2$ $60^\circ$！”——**全错！**

> **Breadboard Lab 相位比较铁律（缺一不可）**：
> 在比较两个同频正弦波的超前（Lead）或滞后（Lag）关系前，**必须同时满足三条铁律**：
> 1. **同频率**：角频率 $\omega$ 必须完全相同（不同频的波相位差一直在变，无法谈论固定超前/滞后）；
> 2. **同函数**：全部统一转换为**余弦函数 $\cos$**；
> 3. **正幅值**：余弦函数前面的幅值系数必须为**正数（$V_m > 0$）**。

只要记住下面这组**三角罗盘转换口诀**（在右侧罗盘图上，顺时针走 $90^\circ$ 是减 $90^\circ$，逆时针走 $90^\circ$ 是加 $90^\circ$）：
- $\sin(\omega t + \theta) = \cos(\omega t + \theta - 90^\circ)$（正弦落后余弦 $90^\circ$）
- $-\sin(\omega t + \theta) = \cos(\omega t + \theta + 90^\circ)$（负正弦超前余弦 $90^\circ$）
- $-\cos(\omega t + \theta) = \cos(\omega t + \theta \pm 180^\circ)$（负号等于翻转 $180^\circ$，选加或减让最终角度落在 $(-180^\circ, +180^\circ]$ 内）

统一完成后，设 $v_1(t) = V_{m1}\cos(\omega t + \phi_1)$ 与 $v_2(t) = V_{m2}\cos(\omega t + \phi_2)$：
- 若 $\phi_2 > \phi_1$，则 **$v_2$ 超前 $v_1$**，超前角为 $\Delta\phi = \phi_2 - \phi_1$（等价于 $v_1$ 滞后 $v_2$ $\Delta\phi$）。

### 2.3 三段式教授板书推导：相位超前/滞后判定（Sadiku Example 9.2）

**例题 2.1**：计算以下两个同频正弦电压之间的相位角差，并判断谁超前、谁滞后：
$$v_1(t) = -10\cos(\omega t + 50^\circ)\text{ V}, \qquad v_2(t) = 12\sin(\omega t - 10^\circ)\text{ V}$$

#### ① 公理溯源
依据三角函数诱导公式（相位比较铁律）：
$$-\cos(\theta) = \cos(\theta \pm 180^\circ), \qquad \sin(\theta) = \cos(\theta - 90^\circ)$$
两同频正幅值余弦波 $V_{m1}\cos(\omega t + \phi_1)$ 与 $V_{m2}\cos(\omega t + \phi_2)$ 的相位差定义为 $\Delta\phi = \phi_2 - \phi_1$。

#### ② 纯符号通式
设原始信号为 $v_1(t) = -A\cos(\omega t + \alpha)$ 与 $v_2(t) = B\sin(\omega t + \beta)$（其中 $A, B > 0$），则统一化为正幅值余弦波后的标准初相角为：
$$\phi_1 = \alpha - 180^\circ, \qquad \phi_2 = \beta - 90^\circ$$
相位差为：
$$\Delta\phi = \phi_2 - \phi_1 = (\beta - 90^\circ) - (\alpha - 180^\circ) = \beta - \alpha + 90^\circ$$

#### ③ 代入数值逐步化简
代入 $A = 10\text{ V}$、$\alpha = +50^\circ$、$B = 12\text{ V}$、$\beta = -10^\circ$：
1. 化简 $v_1(t)$：
   $$\phi_1 = 50^\circ - 180^\circ = -130^\circ \implies v_1(t) = 10\cos(\omega t - 130^\circ)\text{ V}$$
2. 化简 $v_2(t)$：
   $$\phi_2 = -10^\circ - 90^\circ = -100^\circ \implies v_2(t) = 12\cos(\omega t - 100^\circ)\text{ V}$$
3. 计算相位差并判定：
   $$\Delta\phi = \phi_2 - \phi_1 = (-100^\circ) - (-130^\circ) = +30^\circ$$
   由于 $\phi_2 > \phi_1$，结论为：**$v_2(t)$ 超前 $v_1(t)$ $30^\circ$**（等价表述：$v_1(t)$ 滞后 $v_2(t)$ $30^\circ$）。

## 第 3 幕：欧拉公式与相量变换——给旋转矢量拍一张 $t=0$ 的复平面快照

### 3.1 教授导学：相量到底是什么？

很多教材把相量讲得很玄乎，其实它只靠一条史上最美的公式——**欧拉公式（Euler's Identity）**：
$$e^{j\theta} = \cos\theta + j\sin\theta \qquad (j = \sqrt{-1})$$
（注：电路学里为了不与电流 $i$ 冲突，虚数单位永远写作 $j$ 而不是 $i$。）

现在把我们的正弦电压 $v(t) = V_m\cos(\omega t + \phi)$ 改写成复指数的**实部**：
$$v(t) = V_m\cos(\omega t + \phi) = \text{Re}\left\{ V_m e^{j(\omega t + \phi)} \right\} = \text{Re}\left\{ \underbrace{V_m e^{j\phi}}_{\text{相量 }\mathbf{V}} \cdot \underbrace{e^{j\omega t}}_{\text{公共旋转因子}} \right\}$$

请立刻盯着上面这个拆解式看三秒钟！
在一个**线性、单一频率 $\omega$** 的交流稳态电路里，**每一个节点电压、每一条支路电流都带着完全一模一样的旋转因子 $e^{j\omega t}$**！就像一整个车队都在以同样的速度 $\omega$ 绕着操场跑圈，如果我们只关心每辆车之间的相对位置和车长，完全可以**在 $t=0$ 时刻按一下快门，拍一张静止的俯视快照**——把公共因子 $e^{j\omega t}$ 暂时剥离出去，剩下的就是不含时间 $t$ 的复数**相量（Phasor）**：
$$\mathbf{V} = V_m e^{j\phi} = V_m \angle \phi$$

- **正变换（时域 $\to$ 频域/相量域）**：$v(t) = V_m\cos(\omega t + \phi) \;\Longrightarrow\; \mathbf{V} = V_m \angle \phi$
- **逆变换（频域/相量域 $\to$ 时域）**：$\mathbf{V} = V_m \angle \phi \;\Longrightarrow\; v(t) = \text{Re}\{\mathbf{V} e^{j\omega t}\} = V_m\cos(\omega t + \phi)$

### 3.2 复数直角坐标 ↔ 极坐标互转与四则运算法则

相量本质上是一个复数，有两种最常用的“穿衣方式”：
- **直角坐标（Rectangular Form）**：$\mathbf{Z} = x + jy$（**做加减法时必须用它！**实部加实部，虚部加虚部）
- **极坐标（Polar Form）**：$\mathbf{Z} = r \angle \phi$（**做乘除法时必须用它！**模相乘/除，角相加/减）

互转公式：
- 极坐标 $\to$ 直角坐标：$x = r\cos\phi,\quad y = r\sin\phi$
- 直角坐标 $\to$ 极坐标：$r = \sqrt{x^2 + y^2}$，而相角 $\phi$ **绝对不能无脑按计算器的 $\arctan(y/x)$**！因为 $\arctan$ 的值域只有 $(-90^\circ, +90^\circ)$，当实部 $x < 0$（复数落在第二或第三象限）时，**必须进行 $\pm 180^\circ$ 象限校正**：
  - 第一、四象限（$x > 0$）：$\phi = \arctan\left(\frac{y}{x}\right)$
  - **第二象限（$x < 0, y > 0$）**：$\phi = 180^\circ + \arctan\left(\frac{y}{x}\right)$
  - **第三象限（$x < 0, y < 0$）**：$\phi = -180^\circ + \arctan\left(\frac{y}{x}\right)$

### 3.4 三段式教授板书推导：跨象限极坐标转换与复数乘除

**例题 3.1**：已知两个复数 $\mathbf{Z}_1 = -3 + j4$ 与 $\mathbf{Z}_2 = -6 - j8$，将其转为极坐标形式，并计算乘积 $\mathbf{Z}_1\mathbf{Z}_2$ 与商 $\mathbf{Z}_1/\mathbf{Z}_2$。

#### ① 公理溯源
直角坐标 $\mathbf{Z} = x + jy$ 与极坐标 $r\angle\phi$ 的映射公理为：
$$r = \sqrt{x^2 + y^2}, \qquad \phi = \begin{cases} \arctan(y/x), & x > 0 \\ \arctan(y/x) + 180^\circ, & x < 0,\; y \ge 0 \\ \arctan(y/x) - 180^\circ, & x < 0,\; y < 0 \end{cases}$$
极坐标乘除公理为：
$$(r_1\angle\phi_1)(r_2\angle\phi_2) = (r_1 r_2)\angle(\phi_1 + \phi_2), \qquad \frac{r_1\angle\phi_1}{r_2\angle\phi_2} = \left(\frac{r_1}{r_2}\right)\angle(\phi_1 - \phi_2)$$

#### ② 纯符号通式
设 $\mathbf{Z}_1 = x_1 + jy_1$（第二象限：$x_1 < 0, y_1 > 0$），$\mathbf{Z}_2 = x_2 + jy_2$（第三象限：$x_2 < 0, y_2 < 0$），则：
$$r_1 = \sqrt{x_1^2 + y_1^2}, \quad \phi_1 = \arctan\left(\frac{y_1}{x_1}\right) + 180^\circ$$
$$r_2 = \sqrt{x_2^2 + y_2^2}, \quad \phi_2 = \arctan\left(\frac{y_2}{x_2}\right) - 180^\circ$$
$$\mathbf{Z}_1\mathbf{Z}_2 = r_1 r_2 \angle (\phi_1 + \phi_2), \qquad \frac{\mathbf{Z}_1}{\mathbf{Z}_2} = \frac{r_1}{r_2} \angle (\phi_1 - \phi_2)$$

#### ③ 代入数值逐步化简
代入 $x_1 = -3, y_1 = 4$ 与 $x_2 = -6, y_2 = -8$：
1. 转换 $\mathbf{Z}_1$（第二象限）：
   $$r_1 = \sqrt{(-3)^2 + 4^2} = 5, \qquad \phi_1 = \arctan\left(\frac{4}{-3}\right) + 180^\circ = -53.13^\circ + 180^\circ = +126.87^\circ$$
   $$\implies \mathbf{Z}_1 = 5\angle 126.87^\circ$$
2. 转换 $\mathbf{Z}_2$（第三象限）：
   $$r_2 = \sqrt{(-6)^2 + (-8)^2} = 10, \qquad \phi_2 = \arctan\left(\frac{-8}{-6}\right) - 180^\circ = 53.13^\circ - 180^\circ = -126.87^\circ$$
   $$\implies \mathbf{Z}_2 = 10\angle -126.87^\circ$$
3. 极坐标乘法：
   $$\mathbf{Z}_1\mathbf{Z}_2 = (5 \times 10)\angle(126.87^\circ + (-126.87^\circ)) = 50\angle 0^\circ = 50$$
4. 极坐标除法：
   $$\frac{\mathbf{Z}_1}{\mathbf{Z}_2} = \left(\frac{5}{10}\right)\angle(126.87^\circ - (-126.87^\circ)) = 0.5\angle 253.74^\circ = 0.5\angle -106.26^\circ$$
   （减 $360^\circ$ 将主值角度规整到 $(-180^\circ, +180^\circ]$ 区间，展开为直角坐标即 $-0.14 - j0.48$。）

## 第 4 幕：同频正弦波的相量叠加——用矢量平行四边形终结三角恒等式地狱

### 4.1 教授导学：KCL / KVL 在交流电路里的救星

设想一个交流节点汇入了两条支路电流：$i_1(t) = 4\cos(\omega t + 30^\circ)\text{ A}$ 和 $i_2(t) = 5\sin(\omega t - 20^\circ)\text{ A}$。按 KCL，总电流 $i(t) = i_1(t) + i_2(t)$。如果直接在时域硬算，你得把 $\cos(\omega t + 30^\circ)$ 和 $\sin(\omega t - 20^\circ)$ 全部用和角公式拆开，再合并 $\cos\omega t$ 与 $\sin\omega t$ 的系数，再辅助角合成——不仅慢，而且极易算错符号。

借助相量变换的**线性性质（Linearity）**：
$$i_1(t) + i_2(t) \;\Longleftrightarrow\; \mathbf{I}_1 + \mathbf{I}_2$$
我们只需四步走完“**时域 $\to$ 极坐标相量 $\to$ 直角坐标相加 $\to$ 极坐标还原时域**”：
1. 把所有正弦波按第 2 幕铁律统一成**正幅值 $\cos$**；
2. 写出各自极坐标相量 $\mathbf{I}_1, \mathbf{I}_2$；
3. 各自转成直角坐标 $(x + jy)$，实部加实部、虚部加虚部（几何上就是复平面上的**矢量平行四边形法则**！）；
4. 把合相量 $\mathbf{I}$ 转回极坐标 $I_m\angle\phi$，贴回 $\cos(\omega t + \phi)$ 完工！

### 4.3 三段式教授板书推导：同频正弦叠加（Sadiku Example 9.6）

**例题 4.1**：利用相量法将以下两个同频交流电流合成单一正弦波：
$$i(t) = i_1(t) + i_2(t) = 4\cos(\omega t + 30^\circ) + 5\sin(\omega t - 20^\circ)\text{ A}$$

#### ① 公理溯源
由相量变换的线性公理与三角诱导公式：
$$A\cos(\omega t + \phi_1) + B\sin(\omega t + \theta_2) \;\Longleftrightarrow\; \mathbf{I}_1 + \mathbf{I}_2 = A\angle\phi_1 + B\angle(\theta_2 - 90^\circ)$$

#### ② 纯符号通式
令 $\phi_2 = \theta_2 - 90^\circ$，将两相量展开至直角坐标求和：
$$I_x = A\cos\phi_1 + B\cos\phi_2, \qquad I_y = A\sin\phi_1 + B\sin\phi_2$$
合成幅值与初相角（若 $I_x > 0$，无需象限校正）：
$$I_m = \sqrt{I_x^2 + I_y^2}, \qquad \phi = \arctan\left(\frac{I_y}{I_x}\right)$$
最终时域表达式为 $i(t) = I_m\cos(\omega t + \phi)$。

#### ③ 代入数值逐步化简
代入 $A = 4\text{ A}, \phi_1 = 30^\circ, B = 5\text{ A}, \theta_2 = -20^\circ$：
1. 统一为正余弦并写相量：
   $$\phi_2 = -20^\circ - 90^\circ = -110^\circ \implies \mathbf{I}_1 = 4\angle 30^\circ\text{ A}, \quad \mathbf{I}_2 = 5\angle -110^\circ\text{ A}$$
2. 转直角坐标并求和：
   $$I_x = 4\cos(30^\circ) + 5\cos(-110^\circ) = 3.4641 + (-1.7101) = 1.7540\text{ A}$$
   $$I_y = 4\sin(30^\circ) + 5\sin(-110^\circ) = 2.0000 + (-4.6985) = -2.6985\text{ A}$$
3. 转极坐标（$I_x > 0, I_y < 0$，位于第四象限）：
   $$I_m = \sqrt{(1.7540)^2 + (-2.6985)^2} = \sqrt{3.0765 + 7.2819} = 3.2184\text{ A}$$
   $$\phi = \arctan\left(\frac{-2.6985}{1.7540}\right) = -56.98^\circ$$
4. 还原为时域波形：
   $$i(t) = 3.218\cos(\omega t - 56.98^\circ)\text{ A}$$

## 第 5 幕：微积分降维打击——$\frac{d}{dt} \leftrightarrow j\omega$ 与相量法秒杀微分方程

### 5.1 教授导学：今天最震撼的魔法时刻

前面 4 幕都是热身，现在迎来本节课的终极高潮！请看对一个正弦电压 $v(t) = \text{Re}\{\mathbf{V} e^{j\omega t}\}$ 求时间导数会发生什么：
$$\frac{dv(t)}{dt} = \frac{d}{dt}\text{Re}\left\{\mathbf{V} e^{j\omega t}\right\} = \text{Re}\left\{ \mathbf{V} \cdot \frac{d}{dt}(e^{j\omega t}) \right\} = \text{Re}\left\{ \underbrace{(j\omega \mathbf{V})}_{\text{导数的相量}} e^{j\omega t} \right\}$$

看到没有？！因为指数函数 $e^{j\omega t}$ 求导只是把系数 $j\omega$ 掉下来，所以：
- **时域求导 $\dfrac{d}{dt}$ $\;\Longleftrightarrow\;$ 频域乘以 $j\omega$**：由于 $j = 1\angle +90^\circ$，求导在几何上就是把原相量**逆时针旋转 $90^\circ$**，长度伸缩 $\omega$ 倍！
- **时域积分 $\displaystyle\int dt$ $\;\Longleftrightarrow\;$ 频域除以 $j\omega$**：由于 $\frac{1}{j} = -j = 1\angle -90^\circ$，积分在几何上就是把原相量**顺时针旋转 $90^\circ$**，长度伸缩 $1/\omega$ 倍！

**这意味着什么？**
上周我们在 W4-L4/W4-L5 费尽九牛二虎之力解的交流稳态微分方程，今天只要一进相量域，所有 $\frac{d}{dt}$ 换成 $j\omega$，所有 $\int dt$ 换成 $\frac{1}{j\omega}$，**微分方程瞬间变成了一元一次代数方程**！一步除法就能直接拿到交流稳态特解！

### 5.3 三段式教授板书推导：相量法秒杀微积分方程（Sadiku Example 9.7）

**例题 5.1**：利用相量法求以下微积分方程的稳态特解 $i(t)$：
$$4i(t) + 8\int i(t)\,dt - 3\frac{di(t)}{dt} = 50\cos(2t + 75^\circ)$$

#### ① 公理溯源
依据相量变换的线性、微分与积分性质（Sadiku Section 9.3）：
$$i(t) \leftrightarrow \mathbf{I}, \qquad \frac{di(t)}{dt} \leftrightarrow j\omega\mathbf{I}, \qquad \int i(t)\,dt \leftrightarrow \frac{\mathbf{I}}{j\omega}$$

#### ② 纯符号通式
设一般线性常系数微积分方程为：
$$a\,i(t) + b\int i(t)\,dt + c\frac{di(t)}{dt} = V_m\cos(\omega t + \phi_s)$$
两边同时作相量变换，提取公因子 $\mathbf{I}$：
$$\left(a + \frac{b}{j\omega} + j\omega c\right)\mathbf{I} = V_m\angle\phi_s$$
利用 $\frac{1}{j} = -j$ 整理系数分母 $\mathbf{D} = a + j\left(\omega c - \frac{b}{\omega}\right)$，直接解得响应相量：
$$\mathbf{I} = \frac{V_m\angle\phi_s}{a + j\left(\omega c - \dfrac{b}{\omega}\right)}$$

#### ③ 代入数值逐步化简
对照题干，提取参数 $a = 4, b = 8, c = -3, \omega = 2\text{ rad/s}, V_m = 50, \phi_s = 75^\circ$：
1. 计算分母复数 $\mathbf{D}$：
   $$\mathbf{D} = 4 + \frac{8}{j2} - 3(j2) = 4 - j4 - j6 = 4 - j10$$
2. 将分母 $\mathbf{D}$ 转为极坐标（$x = 4 > 0, y = -10 < 0$，第四象限）：
   $$|\mathbf{D}| = \sqrt{4^2 + (-10)^2} = \sqrt{116} \approx 10.7703$$
   $$\theta_D = \arctan\left(\frac{-10}{4}\right) = -68.20^\circ \implies \mathbf{D} = 10.7703\angle -68.20^\circ$$
3. 极坐标除法求相量 $\mathbf{I}$：
   $$\mathbf{I} = \frac{50\angle 75^\circ}{10.7703\angle -68.20^\circ} = \left(\frac{50}{10.7703}\right)\angle\left(75^\circ - (-68.20^\circ)\right) = 4.6424\angle 143.20^\circ\text{ A}$$
4. 逆变换还原为时域稳态特解：
   $$i(t) = 4.642\cos(2t + 143.20^\circ)\text{ A}$$

> **教授收官点睛**：还记得上周为了求一个类似方程花了整整一黑板吗？今天四行代数就干干净净出了答案！下节课（W5-L2），我们将把今天这把“$j\omega$ 手术刀”直接切进电阻、电感、电容的元件方程里，正式请出交流电路的三巨头——**阻抗（Impedance）**！
