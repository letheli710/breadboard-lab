## 第 1 幕：物理直觉与指数衰减的诞生 — 为什么“越放越慢”？

### 1.1 教授讲授：从漏水桶到电容放电

同学们先别急着写微分方程，我们先跟着 Boylestad 的思路建立一个极其牢固的物理直觉。

假设你面前有一个蓄满水的大水桶，底部开了一个小孔。刚开始水位最高，水压最大，水流喷得最猛，水位下降得最快；可过了一会儿，水位降了一半，水压也减半，水流变细了，水位下降的速度自然也就慢了一半。越往后，剩下的水越少，推动水流出的压力越小，所以水位**永远越降越慢**。

把水桶换成已经充好电（初始电压 $V_0$）的电容 $C$，把底部小孔换成并联在它两端的电阻 $R$：
1. 在 $t = 0^+$ 刚切入放电回路的瞬间，电容电压最高为 $V_0$，驱动的泄放电流 $i = v/R$ 也最大，电荷流失最快，因此电压曲线的初始下降斜率最陡。
2. 随着电荷通过电阻变成热量散失，电容电压 $v(t)$ 下降；电压一下降，流过电阻的电流 $i(t) = v(t)/R$ 立刻按比例减小，电荷流失随之变慢。
3. 用一句话概括自然界最核心的衰减法则：**衰减的速度，严格正比于当前剩余的量**。在数学里，唯一满足“导数与自身成正比”的函数，就是**自然指数函数 $e^{-t/\tau}$**。

### 2.2 三段式教授板书推导：无源 RC 微分方程与能量守恒

> **板书铁律**：先把公理和纯符号推到底，绝不在半路塞进具体数字；等通式彻底成型，再代入面包板安全实测参数检验！

#### ① 公理溯源
对图 2-1 顶部节点列基尔霍夫电流定律（KCL，均取流出节点为正），并结合电容与电阻的伏安关系（VCR）：
$$i_C(t) + i_R(t) = 0$$
$$i_C(t) = C\frac{dv(t)}{dt}, \qquad i_R(t) = \frac{v(t)}{R}$$
将两个 VCR 代入 KCL，得到一阶齐次线性常微分方程：
$$C\frac{dv(t)}{dt} + \frac{v(t)}{R} = 0, \qquad \text{初值条件：} v(0^+) = v(0^-) = V_0$$

#### ② 纯符号通式
两边同除以 $C$ 并分离变量：
$$\frac{dv}{dt} + \frac{1}{RC}v = 0 \implies \frac{dv}{v} = -\frac{1}{RC}\,dt$$
从 $t = 0$（对应电压 $V_0$）积分到任意时刻 $t$（对应电压 $v(t)$）：
$$\int_{V_0}^{v(t)} \frac{dv'}{v'} = -\int_0^t \frac{1}{RC}\,dt'$$
$$\ln\frac{v(t)}{V_0} = -\frac{t}{RC}$$
两边取自然指数，并定义**RC 电路时间常数** $\tau = RC$：
$$v(t) = V_0 e^{-t/\tau}, \qquad \tau = RC \quad (t \ge 0)$$

接下来我们用纯符号严格验证**能量守恒**！
电阻上的瞬时电流与瞬时耗散功率为：
$$i_R(t) = \frac{v(t)}{R} = \frac{V_0}{R}e^{-t/\tau}, \qquad p_R(t) = \frac{v^2(t)}{R} = \frac{V_0^2}{R}e^{-2t/\tau}$$
电阻在 $[0, t]$ 内累计耗散的热能为：
$$w_R(t) = \int_0^t p_R(\xi)\,d\xi = \frac{V_0^2}{R}\left[-\frac{\tau}{2}e^{-2\xi/\tau}\right]_0^t = \frac{1}{2}CV_0^2\left(1 - e^{-2t/\tau}\right)$$
令 $t \to \infty$，电阻消耗的总热量为：
$$w_R(\infty) = \int_0^\infty p_R(t)\,dt = \frac{1}{2}CV_0^2 = w_C(0)$$
**教授批注**：注意指数上是 $-2t/\tau$！电压按 $e^{-t/\tau}$ 衰减，而能量与电压平方成正比，所以能量按 $e^{-2t/\tau}$ 衰减——速度是电压衰减的两倍！在 $t = 1\tau$ 时，电容已经释放了 $1 - e^{-2} \approx 86.47\%$ 的能量！

#### ③ 代入数值逐步化简（面包板安全实测参数）
取面包板实操层的安全参数：$V_0 = 5\text{ V}$，$R = 10\text{ k}\Omega = 10^4\ \Omega$，$C = 100\ \mu\text{F} = 10^{-4}\text{ F}$。
1. **求时间常数 $\tau$**：
   $$\tau = RC = (10^4\ \Omega) \times (10^{-4}\text{ F}) = 1.0\text{ s}$$
2. **写电压与电流解析式**：
   $$v(t) = 5 e^{-t/1.0} = 5 e^{-t}\text{ V}, \qquad i_R(t) = \frac{5}{10^4}e^{-t} = 0.5 e^{-t}\text{ mA}$$
3. **验证关键时刻电压与总能量**：
   - 初始峰值电流 $I_0 = 0.50\text{ mA}$，电阻初始峰值功率 $P_0 = \frac{5^2}{10^4} = 2.50\text{ mW} \ll 250\text{ mW}$（绝对安全）。
   - 初始储能 $w_C(0) = \frac{1}{2}(10^{-4})(5^2) = 1.25\text{ mJ}$。
   - $t = 1\text{ s}\ (1\tau)$：$v(1) = 5 e^{-1} \approx 1.8394\text{ V} \approx 1.84\text{ V}$。
   - $t = 5\text{ s}\ (5\tau)$：$v(5) = 5 e^{-5} \approx 0.0337\text{ V} \approx 33.7\text{ mV}$。

## 第 3 幕：时间常数 $\tau$ 的几何与工程意义（$1\tau$ 切线法则与 $5\tau$ 稳态判据）

### 3.1 教授讲授：用几何切线“一眼看穿” $\tau$

时间常数 $\tau$ 不是一个抽象的代数符号，它在示波器屏幕上有着极其漂亮的几何身份：
对 $v(t) = V_0 e^{-t/\tau}$ 在 $t = 0$ 处求一阶导数，得到初始下降斜率：
$$\left.\frac{dv}{dt}\right|_{t=0} = -\frac{V_0}{\tau}$$
由此写出 $t = 0$ 处的切线方程：
$$v_{\text{tan}}(t) = V_0 - \frac{V_0}{\tau}t = V_0\left(1 - \frac{t}{\tau}\right)$$
令 $v_{\text{tan}}(t) = 0$，立即解得 $t = \tau$！

这句话的物理翻译无比精彩：**如果电容一直保持 $t = 0$ 瞬间那股最猛的初始泄放速率不减缓，它恰好会在 $t = \tau$ 时刻把电彻底放光。** 正是因为它“越放越慢”，所以在真正到达 $t = \tau$ 时，它并没有归零，而是优雅地剩下了 $e^{-1} \approx 36.79\%$。

## 第 4 幕：对偶之美 — 无源 RL 衰减电路与 $\tau = L/R$ 的物理反直觉

### 4.1 教授讲授：为什么电阻越大，RC 放得越慢，RL 却衰得越快？

这是期末考试和面试里最常让人“脑子打结”的直觉陷阱：
- 在 **无源 RC 电路** 中，$\tau = RC$。电阻 $R$ 越大，泄放通道越窄，电流 $v/R$ 越小，电容里的电荷要排很久才能放完，所以 $\tau$ **变大**（衰减变慢）。
- 在 **无源 RL 电路** 中，$\tau = L/R$。电感维持的是**电流** $i(t)$，抵抗电流消失。此时电阻 $R$ 串联在回路里，消耗功率 $p_R = i^2 R$。$R$ 越大，同样的电流经过它时被“烧掉”的磁能越猛烈，电感里的磁场能量瞬间就被电阻吃光了，所以 $\tau$ **变小**（衰减变快）！如果 $R \to \infty$（强行拉断电感回路），$\tau \to 0$，电流瞬间跌零就会产生极高的反向感应高压 $v_L = L\frac{di}{dt}$——这就是继电器线圈必须并联续流二极管的原因。

### 4.3 三段式教授板书推导：无源 RL 自然响应

#### ① 公理溯源
对图 4-1 单回路按顺时针方向列基尔霍夫电压定律（KVL），并代入电感与电阻的伏安关系：
$$v_L(t) + v_R(t) = 0$$
$$v_L(t) = L\frac{di(t)}{dt}, \qquad v_R(t) = R i(t)$$
得到无源 RL 一阶齐次线性微分方程：
$$L\frac{di(t)}{dt} + R i(t) = 0, \qquad \text{初值条件：} i(0^+) = i(0^-) = I_0$$

#### ② 纯符号通式
两边同除以 $L$ 并分离变量积分：
$$\frac{di}{i} = -\frac{R}{L}\,dt \implies \int_{I_0}^{i(t)} \frac{di'}{i'} = -\int_0^t \frac{R}{L}\,dt'$$
$$\ln\frac{i(t)}{I_0} = -\frac{R}{L}t$$
定义**RL 电路时间常数** $\tau = L/R$，得到自然响应电流通式：
$$i(t) = I_0 e^{-t/\tau}, \qquad \tau = \frac{L}{R} \quad (t \ge 0)$$
验证电阻总耗散能量：
$$w_R(\infty) = \int_0^\infty i^2(t) R\,dt = I_0^2 R \int_0^\infty e^{-2Rt/L}\,dt = I_0^2 R \cdot \frac{L}{2R} = \frac{1}{2}LI_0^2 = w_L(0)$$
能量再次严丝合缝地守恒！

#### ③ 代入数值逐步化简
设某工业继电器线圈电感 $L = 0.5\text{ H}$，续流回路总电阻 $R = 10\ \Omega$，换路前稳态电流 $I_0 = 2\text{ A}$：
1. **时间常数**：
   $$\tau = \frac{L}{R} = \frac{0.5\text{ H}}{10\ \Omega} = 0.05\text{ s} = 50\text{ ms}$$
2. **电流与初始储能**：
   $$i(t) = 2 e^{-t/0.05} = 2 e^{-20t}\text{ A}, \qquad w_L(0) = \frac{1}{2}(0.5)(2^2) = 1.0\text{ J}$$
3. **求 $t = 0.1\text{ s}\ (2\tau)$ 时的电流**：
   $$i(0.1\text{ s}) = 2 e^{-20 \times 0.1} = 2 e^{-2} \approx 0.2707\text{ A}$$
> **面包板安全提醒**：此例题电阻 $R = 10\ \Omega < 100\ \Omega$，初始电流 $2\text{ A}$、瞬时功率高达 $40\text{ W}$，属于理论与电力电子级参数，**不可**直接插在教学面包板上演示。

## 第 5 幕：带开关多电阻网络的戴维南等效与综合实战

### 5.1 教授讲授：复杂开关网络的“四步通关法”

真实电路里极少只有“一个电容配一个电阻”。一旦出现开关和三四个电阻，请严格遵守这四个步骤，绝不会错：
1. **看 $t = 0^-$（换路前稳态）**：直流电源已接通很久，**电容当开路、电感当短路**，求出电容初始电压 $v_C(0^-)$ 或电感初始电流 $i_L(0^-)$。
2. **用换路定则跨过 $t = 0$**：电容电压不突变 $v_C(0^+) = v_C(0^-)$；电感电流不突变 $i_L(0^+) = i_L(0^-)$。（切记：电阻电压和电阻电流**可以**突变！）
3. **看 $t > 0$（换路后无源拓扑）**：把储能元件暂时摘下来，从它的两个端口向剩余纯电阻网络看进去，求出**戴维南等效电阻 $R_{Th}$**，从而确定 $\tau = R_{Th} C$ 或 $\tau = L/R_{Th}$。
4. **写通解与算能量分配**：写出 $v_C(t)$ 或 $i_L(t)$，再利用串并联分压/分流求出任意指定电阻的瞬态波形及**能量耗散占比**。

### 5.3 三段式教授板书推导：带开关多电阻 RC 综合例题

**题目**：如图 5-1 所示，$V_s = 24\text{ V}$，$R_1 = 6\ \Omega$，$R_2 = 12\ \Omega$，$R_3 = 6\ \Omega$，$R_4 = 6\ \Omega$，$C = 0.2\text{ F}$。开关 $S$ 在 $t < 0$ 时已长期闭合，于 $t = 0$ 瞬间断开。求：（1）$t \ge 0$ 时的电容电压 $v_C(t)$ 与 $R_2$ 两端电压 $v_{R_2}(t)$；（2）电容初始储能 $W_0$ 及 $t > 0$ 后三个电阻各自消耗的热能与占比，并验证能量守恒。

#### ① 公理溯源
- 直流稳态公理（$t = 0^-$）：$\frac{dv_C}{dt} = 0 \implies i_C(0^-) = 0$，电容等效为**开路**；由分压与并联化简求 $v_C(0^-)$。
- 换路定则：$v_C(0^+) = v_C(0^-)$。
- 戴维南等效定理（$t > 0$）：无源线性电阻网络从电容端口看入可等效为单一电阻 $R_{Th}$，故 $v_C(t)$ 满足一阶无源 RC 微分方程 $C\frac{dv_C}{dt} + \frac{v_C}{R_{Th}} = 0$。
- 焦耳热积分公理：$W_{R_k} = \int_0^\infty p_{R_k}(t)\,dt$。

#### ② 纯符号通式
1. **$t = 0^-$ 稳态初值**：
   $$R_{\text{right}} = R_2 \parallel (R_3 + R_4), \qquad v_A(0^-) = V_s \frac{R_{\text{right}}}{R_1 + R_{\text{right}}}$$
   $$V_0 = v_C(0^+) = v_C(0^-) = v_A(0^-) \frac{R_4}{R_3 + R_4}$$
2. **$t > 0$ 戴维南等效电阻与时间常数**：
   开关断开后，$R_2$ 与 $R_3$ 串联，再与 $R_4$ 并联于电容两端：
   $$R_{23} = R_2 + R_3, \qquad R_{Th} = R_{23} \parallel R_4 = \frac{(R_2 + R_3)R_4}{R_2 + R_3 + R_4}, \qquad \tau = R_{Th} C$$
3. **响应波形通式**：
   $$v_C(t) = V_0 e^{-t/\tau}, \qquad i_{R_{23}}(t) = \frac{v_C(t)}{R_2 + R_3}, \qquad v_{R_2}(t) = \frac{R_2}{R_2 + R_3}v_C(t)$$
4. **能量分配通式**：
   $$W_0 = \frac{1}{2}CV_0^2$$
   由于 $R_4$ 与 $R_{23}$ 并联在相同电压 $v_C(t)$ 两端，其瞬时功率之比恒等于电导之比：
   $$W_{R_4} = \int_0^\infty \frac{v_C^2(t)}{R_4}\,dt = \frac{V_0^2 \tau}{2 R_4} = W_0 \frac{R_{Th}}{R_4}$$
   $$W_{R_2} = \int_0^\infty i_{R_{23}}^2(t) R_2\,dt = W_0 \frac{R_{Th}}{R_2 + R_3}\cdot\frac{R_2}{R_2 + R_3}, \qquad W_{R_3} = W_0 \frac{R_{Th}}{R_2 + R_3}\cdot\frac{R_3}{R_2 + R_3}$$

#### ③ 代入数值逐步化简
代入 $V_s = 24\text{ V}, R_1 = 6\ \Omega, R_2 = 12\ \Omega, R_3 = 6\ \Omega, R_4 = 6\ \Omega, C = 0.2\text{ F}$：
1. **求 $V_0$**：
   $$R_{\text{right}} = 12 \parallel (6 + 6) = 12 \parallel 12 = 6\ \Omega$$
   $$v_A(0^-) = 24 \times \frac{6}{6 + 6} = 12\text{ V}, \qquad V_0 = v_C(0^+) = 12 \times \frac{6}{6 + 6} = 6\text{ V}$$
2. **求 $R_{Th}$ 与 $\tau$**：
   $$R_{23} = 12 + 6 = 18\ \Omega, \qquad R_{Th} = 18 \parallel 6 = \frac{18 \times 6}{18 + 6} = \frac{108}{24} = 4.5\ \Omega$$
   $$\tau = R_{Th} C = 4.5 \times 0.2 = 0.9\text{ s}$$
3. **求瞬态电压**：
   $$v_C(t) = 6 e^{-t/0.9} = 6 e^{-\frac{10}{9}t}\text{ V} \quad (t \ge 0)$$
   $$v_{R_2}(t) = \frac{12}{12 + 6} \cdot 6 e^{-t/0.9} = 4 e^{-t/0.9}\text{ V} \quad (t > 0)$$
   > **教授提醒**：注意到没有？$t = 0^-$ 时 $v_{R_2}(0^-) = v_A(0^-) = 12\text{ V}$，而 $t = 0^+$ 时 $v_{R_2}(0^+) = 4\text{ V}$！电阻电压在换路瞬间发生了从 $12\text{ V}$ 到 $4\text{ V}$ 的**合法跳变**，只有电容电压稳稳守住了 $6\text{ V}$！
4. **能量守恒精确核算**：
   $$W_0 = \frac{1}{2} \times 0.2 \times 6^2 = 3.6\text{ J}$$
   $$W_{R_4} = 3.6 \times \frac{4.5}{6} = 2.7\text{ J}\ (75.00\%)$$
   $$W_{R_2} = 3.6 \times \frac{4.5}{18} \times \frac{12}{18} = 0.6\text{ J}\ (16.67\%)$$
   $$W_{R_3} = 3.6 \times \frac{4.5}{18} \times \frac{6}{18} = 0.3\text{ J}\ (8.33\%)$$
   $$W_{R_4} + W_{R_2} + W_{R_3} = 2.7 + 0.6 + 0.3 = 3.6\text{ J} = W_0 \quad \checkmark$$

## 第 6 幕：3D 面包板安全实测、工程缩放与综合诊断

### 6.1 教授讲授：为什么实验室要把 $\Omega / \text{F}$ 缩放成 $\text{k}\Omega / \mu\text{F}$？

同学们马上要切到左侧舞台第 3 层（`3D_THREEJS_BREADBOARD`）亲手插接 RC 放电电路了。先别急着动手，看看为什么刚才第 5 幕的例题（$R_{Th} = 4.5\ \Omega, C = 0.2\text{ F}$）不能直接搬上桌：
- 理论题里为了口算方便常写几欧姆配零点几法拉，但真实世界里 $0.2\text{ F}$ 是超级电容级别，$4.5\ \Omega$ 放电瞬时电流超过 $1.3\text{ A}$，普通面包板弹簧片接触电阻和 $1/4\text{ W}$ 碳膜电阻会瞬间发烫冒烟。
- 工程缩放秘诀：**把电阻放大 $2000\text{ 倍}$ 到 $\text{k}\Omega$ 级，把电容缩小 $2000\text{ 倍}$ 到 $\mu\text{F}$ 级，乘积 $\tau = RC$ 保持在完美的秒级！**
- 本课 3D 实操标准件：$V_s = 5\text{ V}$，$R = 10\text{ k}\Omega$，$C = 100\ \mu\text{F} \implies \tau = 1.0\text{ s}$。峰值电流仅 $0.5\text{ mA}$，电阻功耗仅 $2.5\text{ mW}$，安全、安静、波形清晰！
