# W2-L1：节点分析法（Nodal Analysis）

> **教授开场白**：欢迎进入 Week 2！在第一周，我们手里已经握紧了三把钥匙：`W1-L3 欧姆定律`、`W1-L4 节点/支路/回路` 和 `W1-L5 基尔霍夫电流定律（KCL）`。但你有没有发现，当电路里同时冒出五六只电阻、两三个电源时，靠“串联/并联化简”根本拆不动了？今天，我们要把这三把钥匙熔铸成电路分析的第一套**工业级通用算法——节点分析法（Nodal Analysis）**。只要学会这套系统化步骤，无论多复杂的纯电流源电阻网络，你都能像写程序一样稳稳解出全图每一处的电压和电流。

## 第 1 幕：海拔直觉与参考地选择——为什么只需要 $n - 1$ 个数字？

### 教授讲透直觉（Boylestad Ch. 8 坡度补位）
在直接列方程之前，我们先打通一个终生受用的物理直觉（对应 *Introductory Circuit Analysis, 14th Ed.* Ch. 8 的入门坡度）：**把电路中的“节点电位”想象成地理上的“海拔高度”，把“支路电流”想象成“水流”。**

假设山坡上有两座水塔，水塔 1 海拔 $h_1$，水塔 2 海拔 $h_2$，中间连着一根水管。决定水流方向和流速的，不是水塔离地心有多远，而是**两座水塔之间的海拔高度差 $h_1 - h_2$**。为了让每个人报海拔时都有统一标准，地理学规定：**海平面海拔为 $0\,\text{m}$**。

电路世界完全一样：
1. **参考节点（Reference Node / Ground）**就是电路里的“海平面”，我们人为指定它的电位为 **$0\,\text{V}$**。
2. 其余每一个非参考节点 $k$ 的**节点电压（Node Voltage）$v_k$**，指的就是“节点 $k$ 相对于参考地的电位差”（$v_k = V_k - V_{\text{ref}} = V_k - 0$）。
3. **为什么它如此高效？** 一旦你求出了所有非参考节点的“海拔”（$v_1, v_2, \dots, v_{n-1}$），电路中任意一只跨接在节点 $a$ 和节点 $b$ 之间的电阻 $R$，其两端电压立刻就是 $v_{ab} = v_a - v_b$，流过它的电流立刻就是 $i = \dfrac{v_a - v_b}{R}$——**全图信息一网打尽！**

### 参考节点选择与 $n - 1$ 定律
- **选谁当参考地？** 理论上任意节点都可以当参考地，但工程上有一条偷懒黄金法则：**优先选择连接支路最多的节点**（通常是电路底部的公共汇流母线）。接在参考地上的电阻越多，方程里出现的“$- 0$”项就越多，代数化简越轻松。
- **为什么只需要列 $n - 1$ 个方程？** 如果电路共有 $n$ 个节点（例如上图 $n = 3$），选定 $1$ 个参考节点后，只剩 $n - 1$ 个未知节点电位。如果对第 $n$ 个节点（参考地）也强行列 KCL，你会发现它恰好等于前 $n - 1$ 个 KCL 方程之和取反，属于线性相关方程，不提供任何新信息。

> **教授提醒（常见接地符号辨析）**：在 *Sadiku Sec. 3.2* 中，参考地常用三种符号：三条递减短线（大地接地 Earth Ground）、三斜杠耙子（机壳接地 Chassis Ground）或空心倒三角（公共端 Common）。在理想电路分析中，三者含义完全相同：**$0\,\text{V}$ 电位基准点**。

## 第 2 幕：核心心法——“统一流出法”与支路电流翻译引擎

### 为什么新手列节点方程老是正负号出错？
我批改过上千份电路作业，90% 的节点分析法失分都源于同一个坏习惯：**列方程前先在图上随手乱画一堆电阻电流箭头，结果列到节点 1 时是流出，列到节点 2 时又得抬头看刚才箭头画的是进还是出，正负号瞬间乱成一锅粥。**

今天教授教你一套**零失误机械心法——“统一流出法”**：
1. **电阻支路**：每当你站到某个非参考节点 $v_k$ 上列 KCL 时，**无条件假设所有与节点 $v_k$ 相连的电阻支路电流全部从 $v_k$ 流出**！
   - 经电阻 $R$ 流向邻居节点 $v_j$ 的电流，直接写为 $\dfrac{v_k - v_j}{R}$；
   - 经电阻 $R$ 流向参考地 ($0\,\text{V}$) 的电流，直接写为 $\dfrac{v_k - 0}{R} = \dfrac{v_k}{R}$。
2. **独立电流源支路**：电流源的箭头方向是电路给定的铁律，不可更改。采用最直观的平衡式：
   $$\sum i_{\text{流出当前节点的电阻电流}} = \sum I_{\text{流入当前节点的独立电流源}} - \sum I_{\text{流出当前节点的独立电流源}}$$
   （等价写法：所有流出电流代数和 $= 0$，此时流入的电流源取负号、流出的电流源取正号。）

> **直觉释疑**：站到 $v_1$ 时我们假设 $R_2$ 电流向右流出（$\frac{v_1 - v_2}{R_2}$），站到 $v_2$ 时我们又假设 $R_2$ 电流向左流出（$\frac{v_2 - v_1}{R_2}$），这不矛盾吗？**完全不矛盾！** 因为 $\frac{v_2 - v_1}{R_2} = -\frac{v_1 - v_2}{R_2}$，代数符号已经自动保证了同一条支路的真实电流唯一确定。

### 三段式教授板书推导（通式建立与热身演练）

#### ① 公理溯源（Origin）
- 回链 `W1-L5 KCL`：对任意非参考节点 $k$，流出该节点的所有支路电流代数和恒为零（$\sum i_{\text{out}} = 0$）。
- 回链 `W1-L3 欧姆定律`：对连接节点 $k$ 与节点 $j$ 的线性电阻 $R_{kj}$，沿 $k \to j$ 方向的支路电流由两节点电位差驱动：$i_{k \to j} = \dfrac{v_k - v_j}{R_{kj}} = G_{kj}(v_k - v_j)$，其中电导 $G_{kj} = \dfrac{1}{R_{kj}}$。

#### ② 纯符号通式（General Formula）
对上图中含 $n - 1 = 2$ 个非参考节点的通用网络（电阻 $R_1, R_2, R_3$，独立电流源 $I_s$ 流入节点 $1$）：

$$\begin{cases} \dfrac{v_1 - 0}{R_1} + \dfrac{v_1 - v_2}{R_2} = I_s \\[10pt] \dfrac{v_2 - v_1}{R_2} + \dfrac{v_2 - 0}{R_3} = 0 \end{cases}$$

改写为**电导标准形式**（$G_1 = \frac{1}{R_1},\; G_2 = \frac{1}{R_2},\; G_3 = \frac{1}{R_3}$）：

$$\begin{cases} (G_1 + G_2)v_1 - G_2 v_2 = I_s \\[6pt] -G_2 v_1 + (G_2 + G_3)v_2 = 0 \end{cases}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
以上图热身参数 $I_s = 5\,\text{A},\; R_1 = 3\,\Omega,\; R_2 = 6\,\Omega,\; R_3 = 6\,\Omega$ 为例：

- **Step A（代入元件数值）**：
  $$\begin{cases} \dfrac{v_1}{3} + \dfrac{v_1 - v_2}{6} = 5 \\[8pt] \dfrac{v_2 - v_1}{6} + \dfrac{v_2}{6} = 0 \end{cases}$$
- **Step B（通分消分母）**：两式两边同时乘以最小公倍数 $6$：
  $$\begin{cases} 2v_1 + (v_1 - v_2) = 30 \\ (v_2 - v_1) + v_2 = 0 \end{cases}$$
- **Step C（合并同类项并求解）**：
  $$\begin{cases} 3v_1 - v_2 = 30 \\ -v_1 + 2v_2 = 0 \implies v_1 = 2v_2 \end{cases}$$
  将 $v_1 = 2v_2$ 代入第一式：
  $$3(2v_2) - v_2 = 30 \implies 5v_2 = 30 \implies v_2 = 6\,\text{V},\quad v_1 = 12\,\text{V}$$
- **Step D（反求支路电流与 KCL 闭环验算）**：
  $$i_1 = \frac{12}{3} = 4\,\text{A},\quad i_2 = \frac{12 - 6}{6} = 1\,\text{A},\quad i_3 = \frac{6}{6} = 1\,\text{A}$$
  核验节点 $v_1$：流出 $4 + 1 = 5\,\text{A} =$ 流入 $I_s = 5\,\text{A}$ ✓；核验节点 $v_2$：流入 $1\,\text{A} =$ 流出 $1\,\text{A}$ ✓。

### 三段式教授板书推导（经典例题 1 完整求解）

#### ① 公理溯源（Origin）
- 全图共有 $n = 3$ 个节点（$v_1, v_2$ 及底部参考地 $0$），依据 `W1-L5 KCL` 与节点分析法规则，列出 $n - 1 = 2$ 个独立 KCL 方程。
- 所有电阻支路电流按“统一流出法”由 `W1-L3 欧姆定律` 改写为节点电位差除以电阻值；跨接独立电流源 $I_{s2}$ 严格按箭头方向在节点 $1$ 计入流入、在节点 $2$ 计入流出。

#### ② 纯符号通式（General Formula）
以纯字母 $R_1, R_2, R_3$ 及 $I_{s1}, I_{s2}$ 列写两节点 KCL（流出电阻电流之和 $=$ 净流入独立电流源之和）：

$$\begin{cases} \dfrac{v_1}{R_1} + \dfrac{v_1 - v_2}{R_2} = I_{s1} + I_{s2} \\[10pt] \dfrac{v_2 - v_1}{R_2} + \dfrac{v_2}{R_3} = -I_{s2} \end{cases}$$

等价写为电导矩阵形式 $\mathbf{G}\mathbf{v} = \mathbf{i}$：

$$\begin{bmatrix} \dfrac{1}{R_1} + \dfrac{1}{R_2} & -\dfrac{1}{R_2} \\[10pt] -\dfrac{1}{R_2} & \dfrac{1}{R_2} + \dfrac{1}{R_3} \end{bmatrix} \begin{bmatrix} v_1 \\[6pt] v_2 \end{bmatrix} = \begin{bmatrix} I_{s1} + I_{s2} \\[6pt] -I_{s2} \end{bmatrix}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
已知 $I_{s1} = 5\,\text{A},\; I_{s2} = 10\,\text{A},\; R_1 = 2\,\Omega,\; R_2 = 4\,\Omega,\; R_3 = 6\,\Omega$：

- **Step A（代入数值）**：
  $$\begin{cases} \dfrac{v_1}{2} + \dfrac{v_1 - v_2}{4} = 5 + 10 \\[8pt] \dfrac{v_2 - v_1}{4} + \dfrac{v_2}{6} = -10 \end{cases}$$
- **Step B（通分消分母）**：
  - 方程 (1) 两边同乘 $4$：$2v_1 + (v_1 - v_2) = 60$
  - 方程 (2) 两边同乘 $12$（$4$ 与 $6$ 的最小公倍数）：$3(v_2 - v_1) + 2v_2 = -120$
- **Step C（整理标准方程组并消元求解）**：
  $$\begin{cases} 3v_1 - v_2 = 60 & \text{(1)} \\ -3v_1 + 5v_2 = -120 & \text{(2)} \end{cases}$$
  将 (1) $+$ (2) 直接消去 $v_1$：
  $$4v_2 = -60 \implies v_2 = -15\,\text{V}$$
  将 $v_2 = -15\,\text{V}$ 代回 (1)：
  $$3v_1 - (-15) = 60 \implies 3v_1 + 15 = 60 \implies 3v_1 = 45 \implies v_1 = 15\,\text{V}$$
- **Step D（回代反求全部支路电流 + 物理意义解码）**：
  $$i_1 = \frac{v_1 - 0}{R_1} = \frac{15}{2} = 7.5\,\text{A} \;(\text{自 } v_1 \text{ 向下流向地})$$
  $$i_2 = \frac{v_1 - v_2}{R_2} = \frac{15 - (-15)}{4} = \frac{30}{4} = 7.5\,\text{A} \;(\text{自 } v_1 \text{ 向右流向 } v_2)$$
  $$i_3 = \frac{v_2 - 0}{R_3} = \frac{-15}{6} = -2.5\,\text{A} \;(\text{负号表示真实电流为 } 2.5\,\text{A 自参考地向上流入 } v_2!)$$
  - **KCL 终极验算**：
    - 节点 $v_1$：流入 $= 5 + 10 = 15\,\text{A}$，流出 $= i_1 + i_2 = 7.5 + 7.5 = 15\,\text{A}$ ✓
    - 节点 $v_2$：流入 $= i_2 + (-i_3) = 7.5 + 2.5 = 10\,\text{A}$，流出 $= I_{s2} = 10\,\text{A}$ ✓

> **教授物理点评**：算出了 $v_2 = -15\,\text{V}$ 千万别慌！这就像吐鲁番盆地海拔 $-154\,\text{m}$ 一样完全正常——$10\,\text{A}$ 强力水泵拼命从节点 $2$ 往外抽水，把节点 $2$ 的“电气海拔”抽到了海平面（参考地）以下 $15\,\text{V}$，于是参考地反而经由 $R_3 = 6\,\Omega$ 向上倒灌 $2.5\,\text{A}$ 进来补水。

### 三段式教授板书推导（进阶例题 2 完整求解）

#### ① 公理溯源（Origin）
- 全图共有 $n = 4$ 个节点（$v_1, v_2, v_3$ 及参考地 $0$），需列写 $n - 1 = 3$ 个节点 KCL 方程；
- 菱形元件 $2i_x$ 为电流控制电流源（CCCS），位于节点 $v_3$ 与参考地之间且箭头向下（从 $v_3$ 流出），其控制变量 $i_x$ 为流经 $R_{12}$（$v_1 \to v_2$）的支路电流，依据欧姆定律补写约束方程 $i_x = \dfrac{v_1 - v_2}{R_{12}}$。

#### ② 纯符号通式（General Formula）
三节点 KCL 与控制变量约束方程组（纯符号形式）：

$$\begin{cases} \dfrac{v_1 - v_2}{R_{12}} + \dfrac{v_1 - v_3}{R_{13}} = I_s & \text{(节点 } 1\text{)} \\[10pt] \dfrac{v_2 - v_1}{R_{12}} + \dfrac{v_2}{R_{2g}} + \dfrac{v_2 - v_3}{R_{23}} = 0 & \text{(节点 } 2\text{)} \\[10pt] \dfrac{v_3 - v_1}{R_{13}} + \dfrac{v_3 - v_2}{R_{23}} + \beta i_x = 0 & \text{(节点 } 3\text{)} \\[10pt] i_x = \dfrac{v_1 - v_2}{R_{12}} & \text{(控制变量约束)} \end{cases}$$

#### ③ 代入数值 · 逐步化简（Step-by-Step Calculation）
已知 $I_s = 5\,\text{A},\; R_{12} = 2\,\Omega,\; R_{13} = 4\,\Omega,\; R_{2g} = 4\,\Omega,\; R_{23} = 8\,\Omega,\; \beta = 2$：

- **Step A（代入数值并立即消去控制变量 $i_x = \dfrac{v_1 - v_2}{2}$）**：
  - 节点 1：$\dfrac{v_1 - v_2}{2} + \dfrac{v_1 - v_3}{4} = 5$
  - 节点 2：$\dfrac{v_2 - v_1}{2} + \dfrac{v_2}{4} + \dfrac{v_2 - v_3}{8} = 0$
  - 节点 3：$\dfrac{v_3 - v_1}{4} + \dfrac{v_3 - v_2}{8} + 2\left(\dfrac{v_1 - v_2}{2}\right) = 0$
- **Step B（通分消分母，整理为标准三元一次方程组）**：
  - 节点 1 两边乘 $4$：$2(v_1 - v_2) + (v_1 - v_3) = 20 \implies 3v_1 - 2v_2 - v_3 = 20 \quad (1)$
  - 节点 2 两边乘 $8$：$4(v_2 - v_1) + 2v_2 + (v_2 - v_3) = 0 \implies -4v_1 + 7v_2 - v_3 = 0 \quad (2)$
  - 节点 3 两边乘 $8$：$2(v_3 - v_1) + (v_3 - v_2) + 8(v_1 - v_2) = 0 \implies 6v_1 - 9v_2 + 3v_3 = 0$，两边同除以 $3$ 化简得：
    $$2v_1 - 3v_2 + v_3 = 0 \quad (3)$$
- **Step C（消元求解 $v_1, v_2, v_3$）**：
  - 用 $(1) + (3)$ 消去 $v_3$：
    $$(3v_1 - 2v_2 - v_3) + (2v_1 - 3v_2 + v_3) = 20 \implies 5v_1 - 5v_2 = 20 \implies v_1 - v_2 = 4 \implies v_1 = v_2 + 4 \quad (4)$$
  - 用 $(2) + (3)$ 消去 $v_3$：
    $$(-4v_1 + 7v_2 - v_3) + (2v_1 - 3v_2 + v_3) = 0 \implies -2v_1 + 4v_2 = 0 \implies v_1 = 2v_2 \quad (5)$$
  - 联立 $(4)$ 与 $(5)$：
    $$2v_2 = v_2 + 4 \implies v_2 = 4\,\text{V},\quad v_1 = 8\,\text{V}$$
  - 代回 $(3)$ 求 $v_3$：
    $$v_3 = 3v_2 - 2v_1 = 3(4) - 2(8) = 12 - 16 = -4\,\text{V}$$
- **Step D（反算受控源与全图支路电流 + 逐节点 KCL 验算）**：
  - 控制电流 $i_x = \dfrac{v_1 - v_2}{2} = \dfrac{8 - 4}{2} = 2\,\text{A}$，因此受控电流源输出 $2i_x = 4\,\text{A}$；
  - 其余支路电流：$i_{13} = \dfrac{8 - (-4)}{4} = 3\,\text{A}$，$i_{2g} = \dfrac{4}{4} = 1\,\text{A}$，$i_{23} = \dfrac{4 - (-4)}{8} = 1\,\text{A}$；
  - 逐节点验算：
    - 节点 $v_1$：流入 $5\,\text{A} =$ 流出 $i_x + i_{13} = 2 + 3 = 5\,\text{A}$ ✓
    - 节点 $v_2$：流入 $i_x = 2\,\text{A} =$ 流出 $i_{2g} + i_{23} = 1 + 1 = 2\,\text{A}$ ✓
    - 节点 $v_3$：流入 $i_{13} + i_{23} = 3 + 1 = 4\,\text{A} =$ 流出 $2i_x = 4\,\text{A}$ ✓

### 破除最大直觉误区：换一个节点接地，结果会变吗？

### 教授压箱底验算“X 光机”：电导矩阵 $\mathbf{G}\mathbf{v} = \mathbf{i}$ 速查规律
对于**仅含电阻与独立电流源（不含受控源）**的电路，标准节点方程组写成矩阵 $\mathbf{G}\mathbf{v} = \mathbf{i}$ 时，必然同时满足以下三条铁律：
1. **主对角元素 $G_{kk}$（自电导）**：等于直接连在节点 $k$ 上的**所有电阻电导之和**，恒为**正数**。
2. **非对角元素 $G_{kj}$（互电导，$k \ne j$）**：等于直接跨接在节点 $k$ 与 $j$ 之间的电导之和的**负值**，且矩阵严格对称（$G_{kj} = G_{jk}$）。
3. **右端向量 $i_k$**：等于直接**流入**节点 $k$ 的独立电流源代数和（流出取负）。

> **考场自检神技**：
> - 做**无受控源**题目时，如果整理完发现 $G_{12} \ne G_{21}$（比如例题 1 中两式 $v_2$ 与 $v_1$ 的互导项都是 $-1/4$），**100% 说明你某个地方写错了符号或漏了支路！**
> - 做**含受控源**题目时（如例题 2），受控源消元会把控制节点电位带入被控节点方程，**系数矩阵 $\mathbf{G}$ 的对称性会被打破**——千万不要死套对称矩阵去蒙答案！

- **`LessonLayoutTypeB`**（左右 45% / 55% 分栏，移动端上下堆叠）：
  - 左侧固定舞台 **`SchematicStage2D`**：
    - 顶部 3 段式图层切换胶囊：`01 节点标注与参考地选择` (`layer_01_nodes_and_ref`) / `02 支路电流翻译为电位差` (`layer_02_kcl_translation`) / `03 节点方程联立求解台` (`layer_03_equation_solver`)。
    - 主画布直接渲染本课件对应幕的内联 `<svg>`（默认常驻第 3 幕核心电路，切换幕次时平滑过渡对应幕的 SVG）。
    - 底部折叠面板 **`HiddenInfoDrawer`**：自动读取 `left_stage_spec.layers[activeLayer].exposed_hidden_info` 逐条呈现物理提示。
  - 右侧滚动主区：
    - **`ActNarrativeCard`**（第 1–5 幕正文 + 内联教学 SVG + 三段式板书 **`DerivationBoard`**）。
    - **`GuidedDerivationPlayer`**：解析 `guided_derivation` JSON，单步推进，支持错误选项即时触发 `professor_intercept` 警示气泡（不解锁下一步），选对后触发 `professor_praise` 并将 `board_append_latex` 动画追加至底部实时黑板。
    - **`DiagnosticQuizCard`**：解析 `diagnostic_quiz` JSON，提交后展示逐题 `feedback` 并依据 `pass_threshold: 0.75` 输出诊断掌握度报告。

### 2. 状态机与双向联动契约
```typescript
interface W2L1LessonState {
  activeAct: 1 | 2 | 3 | 4 | 5;
  activeLayer: "layer_01_nodes_and_ref" | "layer_02_kcl_translation" | "layer_03_equation_solver";
  haloTargets: string[];           // e.g. ["node_v1", "src_Is2", "branch_R2"]
  currentStepNo: number;           // 1..5 in guided_derivation
  completedSteps: number[];
  boardLinesLatex: string[];       // accumulated from step.board_append_latex
  lastInterceptMsg: string | null; // populated when user clicks wrong option
  quizAnswers: Record<string, string>;
}
```
- **联动铁律**：当 `GuidedDerivationPlayer` 进入 `step_no` 时，自动派发 `setActiveLayer(step.sync_left_halo)` 与 `setHaloTargets(step.highlight_targets)`，左侧 `SchematicStage2D` 立即同步切换图层并点亮对应节点/支路光晕。

### 3. SVG 交互钩子与公式渲染规范
- **SVG DOM 属性钩子**：主原理图 `<svg>` 中已预埋 `data-node-id`（`node_v1`, `node_v2`, `node_v3`, `node_gnd`）、`data-branch-id`（`branch_R1`, `branch_R2`, `branch_R3`）与 `data-source-id`（`src_Is1`, `src_Is2`）。前端只需对匹配 `haloTargets` 的元素追加 `.svg-halo-pulse` CSS 呼吸光晕类（`filter: drop-shadow(0 0 6px currentColor)`）。
- **KaTeX 渲染规范**：正文 Markdown 使用 `$...$`（行内）与 `$$...$$`（独立公式块）；JSON 字段中的 `question_latex`、`hint_latex`、`label_latex`、`stem_latex`、`text_latex` 均已做好双反斜杠转义，`board_append_latex` 为纯 LaTeX 数学体（渲染时外包 `$$...$$`）。
