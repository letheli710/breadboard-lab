# W4-L3：运放积分器与微分器——用虚地把波形送进微积分流水线

> **教授开场白**：欢迎回到 Breadboard Lab！在 World 3 的 `W3-L3` 里，我们用两颗电阻搭出了反相放大器，当时你已经尝到了“虚地（Virtual Ground）”的甜头——它就像一只看不见的手，把反相输入端死死钉在 $0\text{ V}$。今天，我们只做一件极其大胆的小动作：**拔掉反相放大器里的一颗电阻，换上 `W4-L1` 刚学过的电容 $C$**。你会亲眼在示波器上看到，一块平平无奇的 LM358 芯片，瞬间变成了一台能实时执行高等数学“积分”和“微分”的模拟计算机！更关键的是，我们不仅要推导出课本里漂亮的理想公式，还要亲手揭穿它在真实面包板上“一上电就撞墙饱和”与“高频毛刺炸屏”的两大工程坑，并用两颗不起眼的小电阻把它们彻底治好。

## 第一幕（Act 1）：从反相放大器到积分器——用一颗电容“改造”虚地节点

### 1.1 强回链 World 3：为什么虚地是模拟微积分的“发动机”？

在 `W3-L3 反相放大器` 中，输出电压 $v_o = -\frac{R_f}{R} v_i$ 的本质是什么？是**输入电阻 $R$ 把输入电压 $v_i$ 变成了精确的电流 $i_R = \frac{v_i}{R}$**，而虚断（$i_- = 0$）强迫这股电流**一滴不漏地流过反馈元件**。

现在，我们把反馈支路的电阻 $R_f$ 拔掉，插上一颗容量为 $C$ 的无极性电容：
- 输入端依然是电阻 $R$，因为 $v_- = v_+ = 0\text{ V}$，流进虚地节点的电流仍然只由输入电压决定：$i_R = \frac{v_i(t)}{R}$。
- 反馈端换成了电容 $C$，根据 `W4-L1` 的电容伏安定律，流过电容的电流与电容两端电压的**变化率**成正比。既然电流被输入端强行“灌”进电容，电容的电压就必须不断累积电荷——**电荷的累积，在数学上就是积分！**

### 1.2 教授板书：理想运放积分器的三段式推导

#### ① 公理溯源
1. **理想运放虚短规则**（`W3-L3`）：同相端直接接地，故 $v_- = v_+ = 0$。
2. **理想运放虚断规则**（`W3-L3`）：输入端不吸取电流，$i_- = 0$。
3. **虚地节点 KCL**：流入节点的电阻电流全部流向反馈电容，即 $i_R(t) = i_C(t)$。
4. **元件伏安关系**：
   - 输入电阻欧姆定律：$i_R(t) = \frac{v_i(t) - v_-}{R}$
   - 反馈电容微分律（`W4-L1`，按左正右负关联参考方向 $v_C = v_- - v_o$）：$i_C(t) = C\frac{dv_C(t)}{dt} = C\frac{d(v_- - v_o)}{dt}$

#### ② 纯符号通式
将 $v_- = 0$ 代入上述两支路电流并令 $i_R(t) = i_C(t)$：

$$\frac{v_i(t)}{R} = C\frac{d\big(0 - v_o(t)\big)}{dt} = -C\frac{dv_o(t)}{dt}$$

分离出输出电压变化率（**斜率公式**，画波形最顺手的武器）：

$$\frac{dv_o(t)}{dt} = -\frac{1}{RC}\,v_i(t)$$

对时间从 $0$ 到 $t$ 两边定积分，得到**运放积分器时域通式**：

$$v_o(t) = -\frac{1}{RC}\int_{0}^{t} v_i(\tau)\,d\tau + v_o(0)$$

> **教授划重点**：请死死盯住那个**负号**！当输入 $v_i > 0$ 时，$\frac{dv_o}{dt} < 0$，输出电压是**向下斜坡**；当输入 $v_i < 0$ 时，$\frac{dv_o}{dt} > 0$，输出电压是**向上斜坡**。$RC$ 被称为积分时间常数，它决定了斜坡的陡峭程度。

#### ③ 代入数值逐步化简（面包板标准参数）
采用本课面包板安全标定参数：$R = 10\text{ k}\Omega = 10 \times 10^3\text{ }\Omega$，$C = 100\text{ nF} = 100 \times 10^{-9}\text{ F}$。

1. 计算时间常数 $RC$：
   $$RC = (10 \times 10^3\text{ }\Omega) \times (100 \times 10^{-9}\text{ F}) = 1.0 \times 10^{-3}\text{ s} = 1.0\text{ ms}$$
2. 计算积分增益系数 $-\frac{1}{RC}$：
   $$-\frac{1}{RC} = -\frac{1}{1.0 \times 10^{-3}\text{ s}} = -1000\text{ s}^{-1} = -1.0\text{ ms}^{-1}$$
3. 当输入施加恒定电平 $v_i = +2.0\text{ V}$ 时，输出斜率为：
   $$\frac{dv_o}{dt} = -1000\text{ s}^{-1} \times (+2.0\text{ V}) = -2000\text{ V/s} = -2.0\text{ V/ms}$$

## 第二幕（Act 2）：示波器里的魔法——方波变三角波的精确几何与饱和红线

### 2.1 双通道示波器实测形态：500 Hz 方波 → 倒相三角波

如果我们给上面这套 $RC = 1.0\text{ ms}$ 的积分器送入一个 **$f = 500\text{ Hz}$、幅值 $\pm 2.0\text{ V}$（峰峰值 $4.0\text{ V}_{pp}$）的对称方波**：
- 周期 $T = \frac{1}{500\text{ Hz}} = 2.0\text{ ms}$，半周期 $T/2 = 1.0\text{ ms}$。
- **正半周（$0 \le t < 1.0\text{ ms}$）**：$v_i = +2.0\text{ V}$，斜率 $k_1 = -2.0\text{ V/ms}$，经过 $1.0\text{ ms}$，输出变化量 $\Delta v_o = (-2.0\text{ V/ms}) \times 1.0\text{ ms} = -2.0\text{ V}$。在稳态对称工作下，输出从 $+1.0\text{ V}$ 笔直滑落到 $-1.0\text{ V}$。
- **负半周（$1.0\text{ ms} \le t < 2.0\text{ ms}$）**：$v_i = -2.0\text{ V}$，斜率 $k_2 = +2.0\text{ V/ms}$，经过 $1.0\text{ ms}$，输出变化量 $\Delta v_o = +2.0\text{ V}$，从 $-1.0\text{ V}$ 笔直爬回 $+1.0\text{ V}$。
- **最终波形**：一个完美的 $\pm 1.0\text{ V}$（峰峰值 $V_{pp,\text{out}} = 2.0\text{ V}$）对称三角波，远远低于 LM358 在 $\pm 9\text{ V}$ 供电下的 $\pm 7.5\text{ V}$ 线性上限！

### 2.2 Sadiku Section 6.6 典型波形变换例题完整求解（含饱和校验）

**题目（对标 Sadiku 6.6）**：已知某理想运放积分器采用 $R = 10\text{ k}\Omega$、$C = 100\text{ nF}$，采用 $\pm 9\text{ V}$ 双电源供电（LM358 线性输出安全上限取 $\pm 7.5\text{ V}$），初始时刻电容未储能，即 $v_o(0) = 0\text{ V}$。若输入端接入频率 $f = 250\text{ Hz}$（周期 $T = 4.0\text{ ms}$）的方波信号：

$$v_i(t) = \begin{cases} +3.0\text{ V}, & 0 \le t < 2.0\text{ ms} \\ -3.0\text{ V}, & 2.0\text{ ms} \le t < 4.0\text{ ms} \end{cases}$$

求：(a) $0 \le t \le 4.0\text{ ms}$ 内输出电压 $v_o(t)$ 的分段表达式、各段斜率与峰峰值；(b) 校验运放是否发生饱和；(c) 若将输入方波幅值增大到 $\pm 5.0\text{ V}$，会发生什么现象？

#### ① 公理溯源
采用分段定积分法则：对于任意分段区间 $[t_k, t_{k+1}]$，输出电压满足连续性条件（电容电压不可突变）：

$$v_o(t) = v_o(t_k) - \frac{1}{RC}\int_{t_k}^{t} v_i(\tau)\,d\tau$$

#### ② 纯符号通式
当 $v_i(\tau) = V_k$ 为该段常数值时：

$$v_o(t) = v_o(t_k) - \frac{V_k}{RC}(t - t_k), \quad k_k = -\frac{V_k}{RC}$$

#### ③ 代入数值逐步化简
已知 $RC = (10 \times 10^3\text{ }\Omega)(100 \times 10^{-9}\text{ F}) = 1.0\text{ ms}$。

1. **第一段（$0 \le t < 2.0\text{ ms}$，$V_1 = +3.0\text{ V}$）**：
   - 斜率：$k_1 = -\frac{+3.0\text{ V}}{1.0\text{ ms}} = -3.0\text{ V/ms} = -3000\text{ V/s}$
   - 表达式：$v_o(t) = 0 - 3000t\text{ V}$（若 $t$ 以 $\text{ms}$ 计，则 $v_o(t) = -3t\text{ V}$）
   - 终点值：$v_o(2.0\text{ ms}) = 0 + (-3.0\text{ V/ms}) \times 2.0\text{ ms} = -6.0\text{ V}$
2. **第二段（$2.0\text{ ms} \le t \le 4.0\text{ ms}$，$V_2 = -3.0\text{ V}$）**：
   - 斜率：$k_2 = -\frac{-3.0\text{ V}}{1.0\text{ ms}} = +3.0\text{ V/ms} = +3000\text{ V/s}$
   - 表达式：$v_o(t) = -6.0 + 3000(t - 0.002)\text{ V}$（若 $t$ 以 $\text{ms}$ 计，则 $v_o(t) = -6.0 + 3(t - 2)\text{ V}$）
   - 终点值：$v_o(4.0\text{ ms}) = -6.0\text{ V} + (+3.0\text{ V/ms}) \times 2.0\text{ ms} = 0\text{ V}$
3. **峰峰值与饱和校验**：
   - 输出在 $0\text{ V}$ 与 $-6.0\text{ V}$ 之间往复摆动，峰峰值 $V_{pp,\text{out}} = 0 - (-6.0) = 6.0\text{ V}$。
   - 最大绝对值 $|v_o|_{\max} = 6.0\text{ V} < 7.5\text{ V}$，**未发生饱和**，波形完整无失真。
4. **若输入幅值增至 $\pm 5.0\text{ V}$ 的饱和分析**：
   - 第一段理论斜率为 $-5.0\text{ V/ms}$，理论终点值 $v_{o,\text{ideal}}(2.0\text{ ms}) = -10.0\text{ V}$。
   - 由于 LM358 负电源轨为 $-9\text{ V}$（保守线性上限 $-7.5\text{ V}$，极限负摆幅约 $-8.8\text{ V}$），输出在 $t \approx 1.5\text{ ms}$（达 $-7.5\text{ V}$）至 $1.76\text{ ms}$（达 $-8.8\text{ V}$）时便会**撞上负电源轨并被硬削平（Clipping）**，失去三角波的尖底！

## 第三幕（Act 3）：工程防翻车（一）——为什么理想积分器一上电就“撞墙”？

### 3.1 强回链 W3-L1：3 mV 失调电压引发的“2.5 秒死亡倒计时”

如果你照着第一幕的理想电路图直接插上面包板，哪怕把输入端直接接地（$v_i = 0$），上电 3 秒后拿万用表量输出端——你会惊恐地发现输出不是 $0\text{ V}$，而是死死卡在 $+7.5\text{ V}$ 或 $-8.8\text{ V}$ 一动不动！

**凶手就是你在 `W3-L1` 见过的老熟人：运放输入失调电压 $V_{OS}$**（LM358 典型值约 $3\text{ mV}$）。对直流信号来说，电容 $C$ 相当于**开路**（阻抗 $X_C = \frac{1}{2\pi f C} \to \infty$），反馈回路彻底断开，运放把这微小的 $3\text{ mV}$ 直流误差不断积分，一路狂奔直到撞上电源轨！

#### ① 公理溯源
1. 直流失调电压 $V_{OS}$ 等效串联在同相端，对反相积分器产生恒定失调漂移率。
2. 在电容 $C$ 两端并联一颗大电阻 $R_f$ 后，构成**有损积分器（Lossy / Practical Integrator）**：
   - 对直流（$f = 0$）：电容开路，电路退化为反馈电阻为 $R_f$ 的反相放大器，对 $V_{OS}$ 的直流噪声增益被死死锁在 $1 + \frac{R_f}{R}$。
   - 对交流信号：当信号频率远高于转折频率 $f_c = \frac{1}{2\pi R_f C}$ 时，电容容抗 $X_C \ll R_f$，大部分电流依然走电容，积分功能几乎不受影响。

#### ② 纯符号通式
- 理想积分器直流漂移率与撞轨时间：
  $$\left|\frac{dv_o}{dt}\right|_{\text{drift}} = \frac{V_{OS}}{RC}, \qquad t_{\text{sat}} = \frac{V_{\text{sat}}}{\left|dv_o/dt\right|_{\text{drift}}} = \frac{V_{\text{sat}}\cdot RC}{V_{OS}}$$
- 有损积分器（并联 $R_f$）的直流输出失调上限与转折频率：
  $$V_{o,\text{DC}} = \left(1 + \frac{R_f}{R}\right) V_{OS}, \qquad f_c = \frac{1}{2\pi R_f C}$$
- 工程黄金法则：确保目标信号频率满足 $f_{\text{signal}} \ge 10 f_c$。

#### ③ 代入数值逐步化简
取 $R = 10\text{ k}\Omega$，$C = 100\text{ nF}$（$RC = 1.0\text{ ms}$），LM358 失调 $V_{OS} = 3\text{ mV}$，正饱和上限 $V_{\text{sat}} = 7.5\text{ V}$：

1. **理想积分器（无 $R_f$）翻车计算**：
   $$\left|\frac{dv_o}{dt}\right|_{\text{drift}} = \frac{3 \times 10^{-3}\text{ V}}{1.0 \times 10^{-3}\text{ s}} = 3.0\text{ V/s}$$
   $$t_{\text{sat}} = \frac{7.5\text{ V}}{3.0\text{ V/s}} = 2.5\text{ s}$$
   （仅需 **2.5 秒**，输出就彻底撞轨锁死！）
2. **并联 $R_f = 100\text{ k}\Omega$ 后的工程挽救**：
   - 直流输出失调被钳制在：
     $$V_{o,\text{DC}} = \left(1 + \frac{100\text{ k}\Omega}{10\text{ k}\Omega}\right) \times 3\text{ mV} = 11 \times 3\text{ mV} = 33\text{ mV} = 0.033\text{ V}$$
     （从撞轨 $7.5\text{ V}$ 骤降到几乎可忽略的 $33\text{ mV}$！）
   - 转折频率：
     $$f_c = \frac{1}{2\pi \times (100 \times 10^3\text{ }\Omega) \times (100 \times 10^{-9}\text{ F})} = \frac{1}{0.06283\text{ s}} \approx 15.92\text{ Hz}$$
   - 校验实验频率 $f = 500\text{ Hz}$：$\frac{f}{f_c} = \frac{500}{15.92} \approx 31.4 \gg 10$，完美兼顾“不漂移”与“真积分”！
   - *(若需对 $50\text{ Hz}$ 左右的极低频信号积分，可选 $R_f = 1\text{ M}\Omega$，此时 $f_c \approx 1.59\text{ Hz}$，直流输出失调为 $101 \times 3\text{ mV} = 303\text{ mV}$，依然完全安全。)*

## 第四幕（Act 4）：把 $R$ 和 $C$ 调换位置——运放微分器与三角波变方波

### 4.1 逆向魔法：当电容挪到输入端

既然把 $C$ 放在反馈端可以实现“积分（方波 → 三角波）”，那如果我们把输入端的 $R$ 和反馈端的 $C$ **彻底对调**呢？
- 输入支路变成电容 $C$：输入电压 $v_i(t)$ 变化得越快，电容充放电电流 $i_C = C\frac{dv_i}{dt}$ 就越大！
- 反馈支路变回电阻 $R$：这股正比于“输入斜率”的电流全部流过电阻 $R$，瞬间在输出端形成压降 $v_o = -R i_C$。

结果就是：**运放微分器（Op-Amp Differentiator）**——专门检测信号变化斜率（边缘）的模拟微分机！

### 4.2 教授板书：理想运放微分器的三段式推导

#### ① 公理溯源
1. **虚短与虚断**：$v_- = v_+ = 0$，$i_- = 0$。
2. **虚地节点 KCL**：$i_C(t) = i_R(t)$。
3. **元件伏安关系**：
   - 输入电容微分律（`W4-L1`）：$i_C(t) = C\frac{d(v_i - v_-)}{dt}$
   - 反馈电阻欧姆定律：$i_R(t) = \frac{v_- - v_o(t)}{R}$

#### ② 纯符号通式
将 $v_- = 0$ 代入并令 $i_C(t) = i_R(t)$：

$$C\frac{dv_i(t)}{dt} = -\frac{v_o(t)}{R}$$

整理得到**运放微分器时域通式**：

$$v_o(t) = -RC\frac{dv_i(t)}{dt}$$

#### ③ 代入数值逐步化简（500 Hz 三角波 → 倒相方波）
沿用相同的标准元件：$C = 100\text{ nF}$，$R = 10\text{ k}\Omega \implies RC = 1.0\text{ ms}$。
输入端接入 $f = 500\text{ Hz}$（$T = 2.0\text{ ms}$，$T/2 = 1.0\text{ ms}$）、峰值为 $\pm 2.0\text{ V}$（$V_{pp,\text{in}} = 4.0\text{ V}$）的对称三角波：

1. **上升沿（$0 \le t < 1.0\text{ ms}$）**：$v_i(t)$ 从 $-2.0\text{ V}$ 线性升至 $+2.0\text{ V}$：
   $$\frac{dv_i}{dt} = \frac{+2.0\text{ V} - (-2.0\text{ V})}{1.0\text{ ms}} = +4.0\text{ V/ms} = +4000\text{ V/s}$$
   $$v_o(t) = -(1.0 \times 10^{-3}\text{ s}) \times (+4000\text{ V/s}) = -4.0\text{ V}$$
2. **下降沿（$1.0\text{ ms} \le t < 2.0\text{ ms}$）**：$v_i(t)$ 从 $+2.0\text{ V}$ 线性降至 $-2.0\text{ V}$：
   $$\frac{dv_i}{dt} = \frac{-2.0\text{ V} - (+2.0\text{ V})}{1.0\text{ ms}} = -4.0\text{ V/ms} = -4000\text{ V/s}$$
   $$v_o(t) = -(1.0 \times 10^{-3}\text{ s}) \times (-4000\text{ V/s}) = +4.0\text{ V}$$
3. **输出特征与饱和校验**：输出为 $\pm 4.0\text{ V}$（峰峰值 $V_{pp,\text{out}} = 8.0\text{ V}$）的**倒相方波**；由于 $|v_o|_{\max} = 4.0\text{ V} < 7.5\text{ V}$，运放工作在线性区，波形边缘利落！

## 第五幕（Act 5）：工程防翻车（二）——高频毛刺放大器与实用抗噪微分器

### 5.1 为什么硬件工程师最怕理想微分器？

在真实实验室里，信号线上总会混入微弱的高频开关噪声或电磁干扰（比如幅值只有 $50\text{ mV}$、频率 $f_n = 50\text{ kHz}$ 的微小毛刺）。普通放大器几乎看不见它，但**理想微分器却像打了鸡血一样把它放大几百倍**！

原因非常简单：高频噪声虽然“个子矮”，但它的**斜率极其陡峭**（$\frac{d}{dt}\sin(2\pi f t) = 2\pi f \cos(2\pi f t)$），频率越高，斜率越大，理想微分器的增益 $|A(f)| = 2\pi f RC$ 会随频率线性飙升到无穷大，不仅把有用信号彻底淹没在毛刺里，还会诱发运放高频自激振荡！

### 5.2 教授板书：高频噪声灾难与串联 $R_s$ 限幅的三段式推导

#### ① 公理溯源
1. 正弦高频干扰 $v_{\text{noise}}(t) = V_n \sin(2\pi f_n t)$ 的最大斜率为 $2\pi f_n V_n$。
2. **工程改造方案**：在输入电容 $C$ 之前**串联一颗小电阻 $R_s$**（构成**实用抗噪微分器**）。当频率很高时，电容容抗 $X_C \to 0$，电路自动退化为普通反相放大器，高频增益被死死封顶在 $\frac{R}{R_s}$！

#### ② 纯符号通式
- 理想微分器在频率 $f$ 处的增益与输出噪声幅值：
  $$|A_{\text{ideal}}(f)| = 2\pi f RC, \qquad V_{o,\text{noise,ideal}} = 2\pi f_n RC \cdot V_n$$
- 串联 $R_s$ 后的实用微分器转折频率、高频增益上限与精确幅频响应：
  $$f_b = \frac{1}{2\pi R_s C}, \qquad |A_{\max}| = \frac{R}{R_s}, \qquad |A_{\text{prac}}(f)| = \frac{2\pi f RC}{\sqrt{1 + (2\pi f R_s C)^2}}$$

#### ③ 代入数值逐步化简
取 $R = 10\text{ k}\Omega$，$C = 100\text{ nF}$（$RC = 1.0\text{ ms}$），假设输入混入 $V_n = 50\text{ mV}$、$f_n = 50\text{ kHz}$ 的高频毛刺：

1. **理想微分器（无 $R_s$）炸屏计算**：
   $$|A_{\text{ideal}}(50\text{ kHz})| = 2\pi \times (50 \times 10^3\text{ Hz}) \times (1.0 \times 10^{-3}\text{ s}) \approx 314.16$$
   $$V_{o,\text{noise,ideal}} = 314.16 \times 0.05\text{ V} \approx 15.71\text{ V}$$
   （区区 $50\text{ mV}$ 毛刺，输出竟然飙到 **$15.71\text{ V}$**，瞬间把 $\pm 9\text{ V}$ 电源轨干穿！）
2. **输入串联 $R_s = 1.0\text{ k}\Omega$ 后的工程封顶**：
   - 高频增益天花板：
     $$|A_{\max}| = \frac{R}{R_s} = \frac{10\text{ k}\Omega}{1.0\text{ k}\Omega} = 10.0$$
   - 限幅转折频率：
     $$f_b = \frac{1}{2\pi \times (1.0 \times 10^3\text{ }\Omega) \times (100 \times 10^{-9}\text{ F})} \approx 1591.55\text{ Hz} \approx 1.59\text{ kHz}$$
   - 在 $50\text{ kHz}$ 处的实际噪声输出：
     $$|A_{\text{prac}}(50\text{ kHz})| = \frac{314.16}{\sqrt{1 + (31.416)^2}} \approx 9.995 \implies V_{o,\text{noise,prac}} \approx 9.995 \times 0.05\text{ V} \approx 0.50\text{ V}$$
   - 而在目标信号 $500\text{ Hz}$ 处：$|A_{\text{ideal}}(500\text{ Hz})| \approx 3.142$，$|A_{\text{prac}}(500\text{ Hz})| \approx 2.997$，仅衰减约 $4.6\%$，完美保留了微分能力，同时将高频毛刺压制了 **31 倍以上**！

### 6.2 面包板常见 3 大翻车现场与排错指南
1. **示波器 CH2 是一条死在 $+7.5\text{ V}$ 或 $-8.8\text{ V}$ 的水平直线**：忘了并联 $100\text{ k}\Omega$ 反馈电阻 $R_f$，或者信号源带有较大的直流偏置（DC Offset），导致积分器饱和。
2. **输出三角波顶部或底部被“削成平头”**：输入频率设得太低（例如误设为 $50\text{ Hz}$）或输入幅值过大，使单半周期积分增量 $|\Delta v_o| = \frac{V_i}{2 f RC}$ 超过了 $\pm 7.5\text{ V}$。调高频率至 $500\text{ Hz}$ 即可恢复尖角。
3. **微分器输出方波上有密集毛刺或高频抖动**：漏接了输入串联电阻 $R_s = 1\text{ k}\Omega$，或长飞线引入了空间电磁干扰。补上 $R_s$ 并剪短电容引脚即可立竿见影。
