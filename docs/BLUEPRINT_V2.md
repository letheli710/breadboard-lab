本规范用于指导 **Breadboard Lab** 的全局课程重构、教学节奏重塑以及工作 AI 的标准化单课生产。所有章节骨架严格对齐主力教材 [*Fundamentals of Electric Circuits, 2026 Release* (Alexander, Sadiku & Fredette)](https://www.mheducation.ca/product/fundamentals-of-electric-circuits-2026-release-ise-9781266358685-can-group)，并结合 [Introductory Circuit Analysis, 14th Edition (Boylestad \& Olivari)](https://www.google.com/search?q=https://github.com/letheli710/EE-TextBook) 补足入门坡度；后期项目与微控制器衔接阶段再引入 *Make: Electronics* 与 *Practical Electronics for Inventors (4th Ed.)*。

## 二、教学节奏与界面呈现硬性标准（工作 AI 必守）

### 1. 拆课铁律
- **1 个核心小节 = 1 课**：半页概念导语（如 Sadiku 1.1、5.1）并入下一节；凡是自带独立定律、独立电路拓扑或独立例题的小节（如 5.2、5.3、5.4、10.2–10.3、11.1–11.4、14.5–14.6 等），一律独立成课，绝不为了压缩总课数而强行合并。
- **单课推导不阉割**：每课控制在 **6–8 幕**，但凡一节课装不下教材核心例题的逐行 LaTeX 推导与局部电路图，就必须拆成两课。

### 2. 课型决定左侧舞台图层（不每课硬凑 3D）

顶部图层切换条是“观察视角透镜（Lenses）”，**默认由右侧滚动自动驱动**，复盘时支持手动点选。工作 AI 必须按课型裁剪图层：

> **核心区分（严禁混淆）**：「**3D 器件剥壳**（掀开芯片外壳看内部结构）」仅用于器件导论课；而「**3D 面包板拼装实操**（插电阻/电容/芯片 + 搭表笔/示波器探头）」是 Breadboard Lab 的核心特色，不仅用于 Type C，**在 Type D 的一阶 RC/RL、二阶 RLC、交流相位与谐振滤波课中同样作为重要实操层保留**。

| 课型代码 | 适用课程举例 | 左侧图层数量与构成 | 3D 器件剥壳 | 3D 面包板实操 |
| :--- | :--- | :--- | :--- | :--- |
| **Type A · 器件导论课** | 电阻、真实运放（5.2）、电容/电感物理结构（6.2/6.4） | **3–4 层**：`01 3D 封装/面包板` → `02 物理机制` → `03 剥壳等效` → `04 特性曲线` | **需要** | **需要**（认识引脚与插法） |
| **Type B · 纯公式/方法论课** | 电荷定义、KCL/KVL、节点/网孔、理想运放（5.3）、交流节点手算 | **2–3 层纯 2D**：交互式标准原理图（按推导步骤高亮节点与支路） | 不需要 | 不需要（聚焦方程推导） |
| **Type C · 经典拓扑 + 实测课** | 分压器、戴维南、反相/同相放大器（5.4/5.5）、有源滤波器 | **3 层**：`01 2D 动态原理图` + `02 特性曲线/波形` + `03 3D 面包板拼装实操` | 不需要 | **必配**（含双向高亮） |
| **Type D · 动态暂态 / 频域实操课** | 一阶 RC/RL（Ch. 7）、二阶 RLC（Ch. 8）、交流相位（9.4）、谐振（14.5） | **3 层**：`01 2D 原理图` + `02 实时示波器/相量/波特图` + `03 3D 面包板实操（接信号源/示波器探头）` | 不需要 | **按需标配**（除纯数学相量课 W5-L1 外，均挂 3D 面包板 + 虚拟示波器实操） |

### 3. Type C 面包板实测安全与防翻车铁律
- **电阻安全缩放（条件触发，不一刀切）**：理论推导严格使用 Sadiku 教材原数值；当且仅当原题阻值 **$< 100\ \Omega$**（常见于 World 1–2 的 $2\ \Omega$、$4\ \Omega$、$6\ \Omega$ 手算题）时，3D 面包板实测层必须等比例放大 $1000\times$ 至标准 E12/E24 $\text{k}\Omega$ 级阻值（如 $2\ \Omega \to 2\text{ k}\Omega$），并在右侧显式说明“等比例放大以保护实验箱，分压比/增益不变”。运放等原本已是 $\text{k}\Omega$ 级的电路无需缩放。
- **电源轨与削波校验**：凡涉及输出负电压的运放拓扑（如反相放大器 W3-L3），3D 实测层必须显式切换为 **$\pm 9\text{ V}$ 双电源供电**（或在进阶提示中说明 $V_{CC}/2$ 虚地偏置），严禁在单 9 V 供电下直接演示正输入反相放大导致 0 V 死锁削波。

### 4. 右侧讲课区 5 条铁律
1. **舒展留白**：卡片内边距宽敞、段落与公式块间距分明，禁止信息挤压逼仄。
2. **每幕必配局部电路图**：每一幕卡片内都必须内嵌一张对应当前讲解焦点的 2D 板书级局部电路图（例如放大节点 $v_1$ 的 3 条支路电流方向），绝不允许出现纯文字墙。
3. **三段式教授板书推导（强制分层）**：每逢公式推导，必须拆成独立视觉模块，禁止符号与数字混写：
   - **① 公理溯源（Origin）**：先唤起前序章节最基础定律（如 Ch. 2 欧姆定律、KCL、KVL），指着电路图逐项翻译，讲清正负号与公式由来；
   - **② 纯符号通式（General Formula）**：用蓝色独立公式卡展示纯粹的字母公式（LaTeX 渲染）；
   - **③ 代入数值 · 逐步化简（Step-by-Step Calculation）**：用绿色独立计算卡按 Step A / B / C / D 逐行代入参数、消分母、移项得出结果。
4. **苏格拉底式引导例题**：每课至少 1 道教材核心例题采用“不直接剧透”的分步引导——每步给出局部电路小图 + 微提问 + 常见错路拦截反馈 + 提示按钮，选对后才把该步 LaTeX 写入动态生长的黑板并同步点亮左侧对应节点。
5. **4 类隐性信息必表露**：电位高低（节点电压气泡）、真实电流路径（含 $i_+/i_-$ 与虚断）、物理边界（饱和/额定极限）、实物↔符号↔公式双向悬停高亮。
